# Arithmetic Operator

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Math is fundamental to programming - adding scores, multiplying prices, dividing portions.

## 📋 Concrete Example

`5 + 3 = 8`, `10 / 3 = 3.333`, `10 // 3 = 3` (floor division), `2 ** 10 = 1024` (power).

## 🔗 Analogy

The buttons on a calculator - each one does a specific math operation on the numbers you give it.
