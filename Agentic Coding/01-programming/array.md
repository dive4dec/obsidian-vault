# Array

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When performance matters (games, science, AI), a fixed-size array stores data more efficiently than a list.

## 📋 Concrete Example

In C: `int scores[5] = {10, 20, 30, 40, 50};`. All elements must be the same type and the size is fixed.

## 🔗 Analogy

A tray of labelled compartments - each slot is exactly the same size, lined up in a row, and you can't add more slots.
