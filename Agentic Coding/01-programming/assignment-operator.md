# Assignment Operator

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

You need a way to put a value into a variable. The assignment operator does exactly that.

## 📋 Concrete Example

`x = 5` puts 5 into x. `x += 3` adds 3 to x (same as `x = x + 3`).

## 🔗 Analogy

An arrow pointing into a box - the value on the right goes into the box labelled on the left.
