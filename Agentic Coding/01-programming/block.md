# Block

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Related statements are grouped into blocks - the body of a function, the code inside an if, etc.

## 📋 Concrete Example

In Python, blocks are defined by indentation: the lines after `if x > 0:` indented by 4 spaces form one block.

## 🔗 Analogy

A paragraph in an essay - sentences that belong together are grouped. In Python, indentation (like paragraph indenting) shows grouping.
