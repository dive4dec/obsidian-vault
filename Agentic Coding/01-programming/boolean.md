# Boolean

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Programs constantly make yes/no decisions - is the game over? Is the user logged in? Booleans capture this.

## 📋 Concrete Example

`is_logged_in = True` or `game_over = False`. Used in `if` conditions: `if is_logged_in: show_dashboard()`.

## 🔗 Analogy

A light switch - it's either ON (True) or OFF (False), nothing in between.
