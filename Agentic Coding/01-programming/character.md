# Character

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Text is made up of individual characters - letters, digits, punctuation, symbols. Each character is a building block of strings.

## 📋 Concrete Example

`'A'` is a character, `'7'` is a character, `'!'` is a character. `len('Hello') = 5` because it has 5 characters.

## 🔗 Analogy

Individual tiles in a Scrabble game - each tile is one letter. You arrange them to spell words.
