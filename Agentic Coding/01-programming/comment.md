# Comment

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Code tells the computer what to do, but comments tell humans (including yourself) why. They're ignored by the computer.

## 📋 Concrete Example

`# This calculates the final price after discount` - the # makes it a comment. Python skips this line.

## 🔗 Analogy

Sticky notes on a recipe - 'this is the spicy version!' or 'grandma trick: add a pinch of salt'. The oven doesn't read them, but you do.
