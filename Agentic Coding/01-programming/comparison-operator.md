# Comparison Operator

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Programs need to compare values - is the score high enough? Are two strings the same?

## 📋 Concrete Example

`5 > 3` is True. `'a' == 'a'` is True. `10 != 20` is True. `age >= 18` checks if old enough to vote.

## 🔗 Analogy

A balance scale comparing two weights - it tells you which side is heavier, or if they're equal.
