# Conditional

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Programs must make decisions - if the score is high enough, show 'You win!'. Conditionals branch the flow.

## 📋 Concrete Example

`if score >= 100: print('You win!') elif score >= 50: print('Try again') else: print('Game over')`

## 🔗 Analogy

A fork in a hiking trail - a sign tells you which path to take based on your destination. The condition is the sign.
