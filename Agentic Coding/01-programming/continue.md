# Continue

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Sometimes you want to skip the rest of the current loop iteration and jump to the next one.

## 📋 Concrete Example

`for n in range(10): if n % 2 == 0: continue; print(n)` - skips even numbers, only prints odd ones.

## 🔗 Analogy

Skipping songs on a playlist - if you don't like a song, you skip to the next one without finishing the current one.
