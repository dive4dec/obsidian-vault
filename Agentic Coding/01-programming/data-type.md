# Data Type

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Computers need to know what kind of data they're working with - text, whole numbers, decimals - because they handle each differently.

## 📋 Concrete Example

`name = 'Alice'` is a string, `age = 14` is an integer, `height = 1.65` is a float.

## 🔗 Analogy

Different shaped containers - you wouldn't put soup in a pencil case. Each data type is a container shaped for its content.
