# Elif

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When there are more than two possibilities, elif (else-if) lets you chain multiple conditions.

## 📋 Concrete Example

`if grade >= 90: print('A') elif grade >= 80: print('B') elif grade >= 70: print('C')`

## 🔗 Analogy

A series of toll booths - at each one, if you meet the condition you exit; otherwise you continue to the next.
