# Else

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When the `if` condition is false, you often want a backup plan. `Else` provides that alternative.

## 📋 Concrete Example

`if age >= 18: print('Adult') else: print('Minor')` - if age is under 18, `Minor` is printed.

## 🔗 Analogy

If it's raining, take an umbrella; otherwise (else), wear sunglasses. The `else` is the otherwise.
