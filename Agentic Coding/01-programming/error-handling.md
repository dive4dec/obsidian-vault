# Error Handling

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Things go wrong - files don't exist, network fails, division by zero. Error handling keeps your program from crashing.

## 📋 Concrete Example

`try: result = 10 / 0 except ZeroDivisionError: print('Cannot divide by zero!')` - the program continues instead of crashing.

## 🔗 Analogy

Wearing a seatbelt - you hope you won't crash, but if you do, the seatbelt (try/except) protects you from disaster.
