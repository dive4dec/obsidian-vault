# Float

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Some values aren't whole - like distances, temperatures, or money. Floats store numbers with decimal points.

## 📋 Concrete Example

`price = 9.99` or `pi = 3.14159`. But `0.1 + 0.2` gives `0.30000000000000004` - floats are slightly imprecise!

## 🔗 Analogy

A ruler with tiny markings - you can measure fractions, but if you look very closely, the marks aren't perfectly even.
