# For Loop

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When you need to repeat something for each item in a collection - process every student, check every file.

## 📋 Concrete Example

`for name in ['Alice', 'Bob']: print(name)` prints each name. `for i in range(5): print(i)` prints 0,1,2,3,4.

## 🔗 Analogy

A teacher calling roll - they go through the class list, one name at a time, doing the same thing (calling the name) for each.
