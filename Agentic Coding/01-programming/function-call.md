# Function Call

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

To use a function, you call it by name with any needed arguments. This executes the function's code.

## 📋 Concrete Example

`greet('Alice')` calls the greet function with `Alice` as the argument. The function runs and may return a value.

## 🔗 Analogy

Pressing the button on a microwave - you've set up the program (function), and pressing the button (calling it) starts it running.
