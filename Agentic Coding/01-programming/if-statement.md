# If Statement

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

The most basic decision in code - do something only if a condition is true.

## 📋 Concrete Example

`if temperature > 30: print('It is hot!')` - the message only prints when it is above 30 degrees.

## 🔗 Analogy

A bouncer at a club door - they check your ID (the condition), and only let you in if it passes.
