# Indentation

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

In Python, indentation isn't just for looks - it defines which statements belong together in a block.

## 📋 Concrete Example

`if True:` then 4 spaces then `print('a')` on the next line - the print is inside the if because of indentation.

## 🔗 Analogy

The way paragraphs work in writing - indenting shows 'this belongs together'. In Python, it's mandatory, not optional.
