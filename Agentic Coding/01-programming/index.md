# Index

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

To access a specific element in a list or string, you need a position number - an index.

## 📋 Concrete Example

`name = 'Alice'` - `name[0]` is `A`, `name[1]` is `l`. Python also counts from the end: `name[-1]` is `e`.

## 🔗 Analogy

House numbers on a street - each house has a number, and you find it by counting from the start (or from the end if using negatives).
