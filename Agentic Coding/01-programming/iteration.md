# Iteration

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Going through items one by one is one of the most common programming patterns - iteration makes this possible.

## 📋 Concrete Example

`for x in [1, 2, 3]: print(x)` iterates over the list. `for ch in 'Hello': print(ch)` iterates over each character.

## 🔗 Analogy

Reading a book page by page - you don't read all pages at once; you go through them one at a time (iterate), processing each before moving to the next.
