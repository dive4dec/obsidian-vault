# JSON

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Different programs and languages need to exchange data. JSON is a universal text format everyone can read and write.

## 📋 Concrete Example

`{'name': 'Alice', 'age': 14, 'hobbies': ['coding', 'chess']}` - this is JSON. Python: `import json; json.loads(data)` converts it to a dict.

## 🔗 Analogy

A universal language like Esperanto - no matter what language you normally speak (Python, JavaScript, Java), everyone can read and write in this format.
