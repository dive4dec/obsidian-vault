# Key-Value Pair

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Dictionaries store data as key-value pairs: you use the key to find the value, like a word and its definition.

## 📋 Concrete Example

`{'apple': 3, 'banana': 5}` - `apple` is the key, 3 is the value. You look up `apple` to get 3.

## 🔗 Analogy

A name tag at a conference - the name (key) identifies the person (value). You find someone by looking for their name tag.
