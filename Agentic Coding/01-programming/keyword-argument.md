# Keyword Argument

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When a function has many parameters, passing them by name (keyword) makes calls clearer and order-independent.

## 📋 Concrete Example

`greet(name='Alice', greeting='Hi')` - order doesn't matter. Compare with positional: `greet('Alice', 'Hi')` where order matters.

## 🔗 Analogy

Ordering food by naming what you want: `I`ll have the burger with extra cheese, no onions' (keyword args) vs. just 'burger, extra, none' (positional).
