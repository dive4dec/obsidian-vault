# List Comprehension

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Creating lists with loops is verbose. List comprehensions do it in one clean line.

## 📋 Concrete Example

`squares = [x**2 for x in range(10)]` creates [0, 1, 4, 9, 16, 25, 36, 49, 64, 81] in one line.

## 🔗 Analogy

A cookie cutter - instead of shaping each cookie by hand (loop), you press the cutter and get them all at once.
