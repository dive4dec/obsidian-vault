# Map

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Applying the same operation to every item in a collection is so common that `map` makes it a one-liner.

## 📋 Concrete Example

`list(map(lambda x: x**2, [1,2,3]))` gives [1, 4, 9]. Each element is squared.

## 🔗 Analogy

A factory assembly line - each item passes through the same machine (function), and comes out transformed.
