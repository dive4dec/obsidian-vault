# Method

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

A method is a function that belongs to a class - it operates on the object's data.

## 📋 Concrete Example

`my_dog.bark()` - bark is a method of the Dog class. It uses `self.name` (the object's data) to produce its output.

## 🔗 Analogy

A skill that a dog knows - `sit`, `fetch`, `bark`. Each dog (object) has the same skills (methods) from the same training (class), but does them in their own way.
