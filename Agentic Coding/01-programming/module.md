# Module

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

A module is a file of Python code you can import - it groups related functions and classes together.

## 📋 Concrete Example

`import math` - the math module has `math.pi`, `math.sqrt()`, `math.cos()`, etc. All math-related functions in one place.

## 🔗 Analogy

A toolbox - the math toolbox has a ruler, compass, and protractor. You open the box (import) and use the tool you need.
