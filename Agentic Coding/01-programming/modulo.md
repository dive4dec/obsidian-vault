# Modulo

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

You often need the remainder after division - checking if a number is even, cycling through positions.

## 📋 Concrete Example

`7 % 3 = 1` (7 divided by 3 is 2 remainder 1). `8 % 2 == 0` means 8 is even.

## 🔗 Analogy

Sharing 7 sweets among 3 friends - each gets 2, and 1 is left over. That leftover is the modulo.
