# Object-Oriented Programming

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Organising code around objects (data + behaviour) makes large programs easier to manage and understand.

## 📋 Concrete Example

A game might have Player, Enemy, and Item classes. Each manages its own data (health, position) and behaviour (move, attack).

## 🔗 Analogy

Organising a school by departments - the Science department handles labs and science teachers, the Music department handles instruments and music teachers. Each manages its own area.
