# Object

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

An object is a specific instance of a class - it has its own data but shares the class's behaviour.

## 📋 Concrete Example

`my_dog = Dog('Rex')` creates an object. `my_dog.bark()` returns 'Rex says woof!'. Another `Dog('Buddy')` is a different object.

## 🔗 Analogy

A specific house built from the blueprint - it has its own paint colour and furniture (data) but the same layout (structure) as the blueprint defined.
