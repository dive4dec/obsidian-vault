# Operator Precedence

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When an expression has multiple operators, which goes first? Precedence rules decide, like math's PEMDAS.

## 📋 Concrete Example

`2 + 3 * 4 = 14` not 20, because * happens before +. Use parentheses to override: `(2 + 3) * 4 = 20`.

## 🔗 Analogy

Priority lanes at immigration - diplomats (higher precedence) go first, then regular passengers. Parentheses are like a VIP pass - they jump the queue.
