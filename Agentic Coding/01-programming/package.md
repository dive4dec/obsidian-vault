# Package

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

When a project has many modules, they're organised into a package - a folder of modules.

## 📋 Concrete Example

`import numpy.random` - numpy is a package, random is a module inside it. `numpy.random.randint(0, 10)` generates a random integer.

## 🔗 Analogy

A tool chest with drawers - each drawer (module) holds related tools. The whole chest (package) organises everything.
