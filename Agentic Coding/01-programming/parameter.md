# Parameter

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Functions need inputs to work with - parameters are the named slots that receive those inputs.

## 📋 Concrete Example

`def add(a, b): return a + b` - `a` and `b` are parameters. When you call `add(3, 5)`, 3 goes into `a`, 5 into `b`.

## 🔗 Analogy

The blanks on a form - 'Name: ____' and 'Age: ____'. When someone fills in the form (calls the function), those blanks get values.
