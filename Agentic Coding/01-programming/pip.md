# Pip

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Pip is Python's package manager - it downloads and installs packages from PyPI (Python Package Index).

## 📋 Concrete Example

`pip install requests` downloads the requests package. `pip list` shows what's installed.

## 🔗 Analogy

An app store for Python - you search for what you need, tap `install` (pip install), and it downloads and sets it up for you.
