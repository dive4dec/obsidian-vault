# Return Value

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Functions often need to give back a result - the return value is what the function hands back to the caller.

## 📋 Concrete Example

`def square(x): return x * x`. `result = square(4)` - `result` now holds 16, the returned value.

## 🔗 Analogy

A vending machine - you put in money (arguments), it processes, and returns a drink (return value). You can then use that drink.
