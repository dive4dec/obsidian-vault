# String Concatenation

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

You often need to join text together - combining a first name and last name, or building a message.

## 📋 Concrete Example

`'Hello, ' + name + '!'` joins the strings. In Python, f-strings are easier: `f'Hello, {name}!'`

## 🔗 Analogy

Gluing paper strips together - each piece of text is a strip, and `+` is the glue that joins them into one long strip.
