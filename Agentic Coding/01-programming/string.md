# String

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Almost every program deals with text - names, messages, passwords. A string is how computers store text.

## 📋 Concrete Example

`greeting = 'Hello, World!'` - the text in quotes is a string. You can join strings: `first + ' ' + last`.

## 🔗 Analogy

A row of letter tiles - each tile is one character, and you string them together to make words and sentences.
