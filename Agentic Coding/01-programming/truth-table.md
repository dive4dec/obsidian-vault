# Truth Table

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

A truth table shows the result of logical operators (and, or, not) for all possible input combinations.

## 📋 Concrete Example

`True and False = False`, `True or False = True`, `not True = False`. A table with all combinations makes it clear.

## 🔗 Analogy

A referee's rulebook for combinations - 'foul AND card = red' (AND), 'rain OR snow = postpone' (OR), 'NOT home = away' (NOT). The table lists every scenario.
