# Type Hint

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Type hints annotate variables and functions with expected types, making code clearer and enabling tool support.

## 📋 Concrete Example

`def greet(name: str) -> str: return 'Hello, ' + name` - hints say name should be a string and the function returns a string.

## 🔗 Analogy

Labels on containers - 'this jar is for sugar, this one for salt'. The label doesn't stop you from putting salt in the sugar jar, but it helps you avoid mistakes.
