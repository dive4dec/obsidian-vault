# Variable

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

You need a way to store information that can change while your program runs, like a player's score in a game.

## 📋 Concrete Example

In Python: `score = 0` stores the number 0. Later, `score = score + 10` updates it.

## 🔗 Analogy

A labelled box on a shelf - you write `score` on the box and put a number inside. You can swap the number anytime.
