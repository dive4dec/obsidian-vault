# Virtual Environment

> **Domain:** [[_programming-fundamentals-moc|Programming Fundamentals]]

## 🎯 Motivation

Different projects need different packages and versions. A venv keeps them isolated so they don't conflict.

## 📋 Concrete Example

`python -m venv myenv` creates an isolated environment. `source myenv/bin/activate` turns it on. Packages installed here don't affect other projects.

## 🔗 Analogy

Separate lockers for each sport - football gear in one locker, swimming gear in another. They don't mix up or interfere.
