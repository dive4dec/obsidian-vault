# 2D Array

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

When data has two dimensions -- a chessboard, a spreadsheet, an image -- a 2D array stores it as rows and columns.

## 📋 Concrete Example

`board = [[0,0,0], [0,1,0], [0,0,0]]`. Access `board[1][2]` gives row 1, column 2. A tic-tac-toe board is a 3x3 2D array.

## 🔗 Analogy

A cinema seating chart. Rows are letters (A, B, C), columns are numbers (1, 2, 3). Seat B5 is at row B, column 5.
