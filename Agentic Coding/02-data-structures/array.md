# Array

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

When you need to store many items of the same type in order and access them quickly by position, arrays are the simplest choice.

## 📋 Concrete Example

In Python: `scores = [85, 92, 78, 90]`. Access `scores[0]` to get 85. You can change `scores[1] = 95` instantly.

## 🔗 Analogy

A row of numbered lockers in a school hallway. Each locker has a number (index) and holds one item. You walk straight to locker 0 or locker 3 without checking the others.
