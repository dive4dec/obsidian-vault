# Binary Tree

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

When data has a natural hierarchy -- file systems, family trees, organisation charts -- trees organise it with parent-child relationships.

## 📋 Concrete Example

A root node with up to two children (left and right). Each child can itself be a root of a smaller tree. A file folder containing subfolders is a tree.

## 🔗 Analogy

A family tree. Each person (node) has up to two parents, and each branch leads to more relatives. The oldest ancestor is the root at the top.
