# Fixed-Size Array

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

Sometimes you know exactly how many items you will store and want the speed and memory efficiency of a fixed buffer.

## 📋 Concrete Example

In C: `int seats[6] = {0,0,0,0,0,0};` reserves exactly 6 integer slots. You cannot add a 7th seat.

## 🔗 Analogy

A six-seater car. You cannot magically add a seventh seat. If you need more passengers, you need a bigger vehicle.
