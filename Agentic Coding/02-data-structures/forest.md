# Forest

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A collection of separate trees. Sometimes data naturally forms multiple disconnected trees rather than one unified tree.

## 📋 Concrete Example

A file system with two separate drives C: and D: -- each is a tree, and together they form a forest. A company with multiple divisions, each with its own org chart, is a forest.

## 🔗 Analogy

A national park with several separate wooded areas. Each grove is a tree, but they are not connected to each other. The whole park is a forest of separate groves.
