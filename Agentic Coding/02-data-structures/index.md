# Index

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

To find a specific element in an array, string, or list, you need its position number -- the index.

## 📋 Concrete Example

`name = 'Alice'` -- `name[0]` is A, `name[1]` is l, `name[-1]` is e (counts from the end).

## 🔗 Analogy

House numbers on a street. To find a house, you walk to its number. Number 0 is the first house at the start of the street.
