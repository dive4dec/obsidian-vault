# Leaf Node

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A leaf node is a tree node with no children. It represents the end of a branch.

## 📋 Concrete Example

In a file system, individual files are leaves -- they contain data but have nothing nested inside them. Folders with only files are also effectively leaves.

## 🔗 Analogy

The tip of a tree branch where a leaf grows. Nothing branches off from there -- it is an endpoint.
