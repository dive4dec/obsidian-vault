# Matrix

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A matrix is a 2D array used for mathematical operations -- transformations, graphics, machine learning. It follows linear algebra rules.

## 📋 Concrete Example

A 3x3 rotation matrix can rotate a 3D object. Matrix multiplication combines transformations. In Python, `numpy` handles matrices efficiently.

## 🔗 Analogy

A spreadsheet used for grading. Rows are students, columns are subjects. Each cell is a score. You can compute averages per row or per column.
