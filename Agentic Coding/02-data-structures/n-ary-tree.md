# N-ary Tree

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

Not all trees limit children to two. An N-ary tree allows each node to have up to N children, modelling real-world hierarchies like file systems and org charts.

## 📋 Concrete Example

A file system folder can contain many subfolders and files -- not just two. An org chart manager can have many direct reports. Each node has a list of children, not just left and right.

## 🔗 Analogy

A family where each parent can have any number of children, not just two. One family might have 1 child, another might have 5. The tree branches vary at each node.
