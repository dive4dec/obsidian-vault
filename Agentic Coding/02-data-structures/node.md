# Node

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A node is the basic building block of linked lists, trees, and graphs -- it holds data and links to other nodes.

## 📋 Concrete Example

A linked list node: `{data: 42, next: pointer_to_next}`. A tree node: `{data: 42, left: ..., right: ...}`.

## 🔗 Analogy

A person in a phone tree. They hold their own information (data) and have the phone numbers of specific other people (pointers) to call next.
