# Pointer

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A pointer is a variable that stores the memory address of another value, letting you link data structures together.

## 📋 Concrete Example

In Python, variables are references (pointers). `a = [1,2]; b = a; b[0] = 99` -- now `a` is also `[99,2]` because both point to the same list.

## 🔗 Analogy

A treasure map that says 'X marks the spot at the oak tree.' The map (pointer) does not contain the treasure (data); it tells you where to find it.
