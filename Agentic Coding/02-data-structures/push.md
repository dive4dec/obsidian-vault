# Push

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

Push is the operation of adding an item to the top of a stack.

## 📋 Concrete Example

`stack = []; stack.push(10)` or in Python `stack.append(10)`. The item 10 is now on top of the stack.

## 🔗 Analogy

Putting a new plate on top of the plate stack in the cafeteria. The new plate is now the top one.
