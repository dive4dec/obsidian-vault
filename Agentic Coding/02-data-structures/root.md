# Root

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

The root is the topmost node of a tree -- the single starting point from which all other nodes descend.

## 📋 Concrete Example

In a file system, `C:\` or `/` is the root. Every file and folder is nested under it. There is exactly one root per tree.

## 🔗 Analogy

The founder of a family dynasty. Every descendant traces their lineage back to this one person at the very top of the family tree.
