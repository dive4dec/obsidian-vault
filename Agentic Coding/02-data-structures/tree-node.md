# Tree Node

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

A tree node stores data plus pointers to its children (and sometimes its parent). It is the building block of all tree structures.

## 📋 Concrete Example

A binary tree node: `{value: 42, left: child1, right: child2, parent: rootnode}`. The left and right pointers link to subtrees.

## 🔗 Analogy

A manager in a company org chart. The manager (node) has their own title (data) and reports to a boss (parent) while managing several team members (children).
