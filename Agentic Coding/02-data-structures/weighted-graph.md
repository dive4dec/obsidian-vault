# Weighted Graph

> **Domain:** [[_data-structures-moc|Data Structures]]

## 🎯 Motivation

When connections have different costs or distances -- road lengths, flight prices, signal strengths -- edges carry weights.

## 📋 Concrete Example

MTR map with travel times: Central to Admiralty = 2 min, Admiralty to Wan Chai = 3 min. The weights help find the fastest route.

## 🔗 Analogy

A hiking trail map where each trail segment shows its length in kilometres. Some paths are short but steep; others are long but flat. The weight is the difficulty.
