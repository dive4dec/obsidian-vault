# Strongly Connected Components

> **Domain:** [[_algorithms-moc|Algorithms]]

## 🎯 Motivation

In a directed graph, an SCC is a group of nodes where every node can reach every other node. Finding SCCs helps understand graph structure.

## 📋 Concrete Example

On a one-way road network, an SCC is a set of intersections where you can drive from any one to any other. Outside the SCC, you might not be able to return.

## 🔗 Analogy

A group of friends who can all message each other directly. Within the group, everyone can reach everyone. But someone outside the group might not be reachable by everyone inside.
