# Bandwidth

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

How much data can be transferred per second. Higher bandwidth = faster downloads and uploads.

## 📋 Concrete Example

Bandwidth: 100 Mbps (megabits per second). A 1GB file takes 80 seconds to download. With 1 Gbps: 8 seconds. Higher bandwidth = faster data transfer.

## 🔗 Analogy

Bandwidth is like a highway's width - a 2-lane road (low bandwidth) handles fewer cars. A 10-lane highway (high bandwidth) handles more cars simultaneously. More bandwidth = more data per second.
