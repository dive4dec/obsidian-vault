# CLI vs GUI

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

CLI (Command Line Interface) vs GUI (Graphical User Interface). CLI is faster for experts; GUI is easier for beginners.

## 📋 Concrete Example

CLI: 'rm *.tmp' deletes all temp files instantly. GUI: select each file, drag to trash. CLI is faster but requires knowing commands. GUI is intuitive but slower for repetitive tasks.

## 🔗 Analogy

CLI is like driving a manual car - more control, faster, but requires skill. GUI is like an automatic - easier to learn, but less control. Each has its place.
