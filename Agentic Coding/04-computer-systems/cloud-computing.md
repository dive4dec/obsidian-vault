# Cloud Computing

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Using remote servers over the internet instead of local machines. AWS, Google Cloud, Azure are cloud providers.

## 📋 Concrete Example

Cloud: you need 100 GPUs for AI training. Buy: $500,000. Rent from cloud: $10/hour x 100 = $1000/hour. Use for 10 hours, pay $10,000. Much cheaper for temporary needs.

## 🔗 Analogy

Cloud computing is like renting a hotel room instead of buying a house - you pay for what you use, when you use it. No maintenance, no upfront cost. But long-term, buying might be cheaper.
