# Command Line

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Using text commands instead of a graphical interface. Faster and more powerful for many tasks.

## 📋 Concrete Example

Command line: 'grep error log.txt | sort | uniq -c' finds, sorts, and counts errors in one line. With a GUI, this would take many clicks and tools.

## 🔗 Analogy

The command line is like giving direct orders to a butler - 'bring tea, close the curtains, call a taxi.' One sentence, multiple actions. The GUI would require finding each button.
