# Concurrency

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Doing multiple things at the same time, but not necessarily simultaneously. Like juggling tasks.

## 📋 Concrete Example

A web server handles 100 requests concurrently: it starts request 1, while waiting for database, starts request 2, etc. Not simultaneous, but no idle time. Efficient.

## 🔗 Analogy

Concurrency is like a teacher monitoring multiple groups - they check Group A, then Group B, then Group C, cycling through. Not simultaneously, but all groups make progress.
