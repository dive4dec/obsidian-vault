# Container

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A lightweight, isolated environment for running applications. Shares the host OS kernel but has its own filesystem and dependencies.

## 📋 Concrete Example

Container: your Python app runs in isolation. It has its own Python version, libraries, and files. It cannot see other containers or the host. Lightweight because it shares the OS kernel.

## 🔗 Analogy

A container is like a private office in a shared building - you have your own desk, files, and supplies (filesystem, libraries). But you share the building infrastructure (OS kernel) with other offices (containers). Lightweight and isolated.
