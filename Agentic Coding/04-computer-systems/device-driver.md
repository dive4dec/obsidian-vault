# Device Driver

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Software that lets the OS communicate with hardware: printers, GPUs, network cards. Each device needs its driver.

## 📋 Concrete Example

GPU driver: translates OS commands (draw this image) into GPU-specific instructions (NVIDIA RTX 6000 specific). Without the driver, the OS cannot use the GPU.

## 🔗 Analogy

A device driver is like a language interpreter - the OS speaks one language, the device speaks another. The driver translates between them so they can communicate.
