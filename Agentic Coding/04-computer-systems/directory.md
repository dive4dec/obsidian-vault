# Directory

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A container for files and subdirectories. Also called a folder.

## 📋 Concrete Example

Directory: /home/user/ contains: documents/, photos/, music/ (subdirectories) and resume.pdf, notes.txt (files). Organizes files hierarchically.

## 🔗 Analogy

A directory is like a drawer in a filing cabinet - it holds folders (subdirectories) and documents (files). Nested directories are like folders within folders.
