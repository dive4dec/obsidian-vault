# DNS

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Domain Name System - translates human-readable names (google.com) to IP addresses (142.250.80.46).

## 📋 Concrete Example

DNS: you type `google.com`. DNS lookup: google.com -> 142.250.80.46. Your browser connects to that IP. Without DNS, you would need to memorize IP addresses.

## 🔗 Analogy

DNS is like a phonebook - you look up `Alice` and find her number 9876-5432. DNS looks up `google.com` and finds its IP address. You use names; DNS translates to numbers.
