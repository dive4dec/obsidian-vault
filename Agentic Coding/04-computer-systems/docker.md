# Docker

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Software that packages applications and their dependencies into containers. Runs identically anywhere.

## 📋 Concrete Example

Docker: package your Python app + all libraries + OS settings into a container. Run on your laptop, on a server, on the cloud - identical behavior. No 'it works on my machine' problems.

## 🔗 Analogy

Docker is like a shipping container - you pack your goods (app + dependencies) into a standard container. It fits on any ship, train, or truck (any machine). The contents are isolated and consistent.
