# Domain Name

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A human-readable web address: google.com, cityu.edu.hk. Easier to remember than IP addresses.

## 📋 Concrete Example

Domain name: cityu.edu.hk. DNS translates it to an IP address. The browser connects to that IP. Domain names are human-friendly aliases for machine IP addresses.

## 🔗 Analogy

A domain name is like a person's name - you say 'call Alice' instead of 'call 9876-5432.' Domain names are human-friendly labels for server IP addresses.
