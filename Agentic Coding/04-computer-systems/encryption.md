# Encryption

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Scrambling data so only authorized parties can read it. Used for security everywhere.

## 📋 Concrete Example

Encryption: `Hello` -> encrypted -> `Xj7#kQ9m`. Only someone with the key can decrypt it back to `Hello`. Without the key, it is gibberish.

## 🔗 Analogy

Encryption is like a secret code - you write 'meet at noon' as 'zrrg ng abbA'. Only your friend with the codebook (key) can read it. Everyone else sees gibberish.
