# Executable

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A file that can be run as a program. On Linux, needs execute permission. On Windows, has .exe extension.

## 📋 Concrete Example

Executable: `python` is at /usr/bin/python. It has execute permission. Type `python` in terminal -> OS finds it via PATH and runs it. The file contains machine code the CPU can execute.

## 🔗 Analogy

An executable is like a ready-to-eat meal - you do not need to cook it, just open and eat. The OS can run it directly. Source code (app.py) needs to be compiled or interpreted first.
