# File Permission

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Who can read, write, or execute a file. Three levels: owner, group, everyone.

## 📋 Concrete Example

Permissions: rwxr-xr--. Owner: read/write/execute. Group: read/execute. Others: read only. 'chmod +x script.sh' adds execute permission for everyone.

## 🔗 Analogy

File permissions are like access levels in a school - the principal (owner) can enter any room, teachers (group) can enter classrooms, students (others) can only enter common areas.
