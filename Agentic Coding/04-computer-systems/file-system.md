# File System

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

How files are organized on storage: directories, files, permissions. The OS manages this.

## 📋 Concrete Example

File system: /home/user/documents/essay.txt. Directories (folders) contain files and subdirectories. Permissions: who can read, write, or execute each file.

## 🔗 Analogy

The file system is like a filing cabinet - drawers (directories) contain folders (subdirectories) which contain documents (files). Each document has permissions: who can read or edit it.
