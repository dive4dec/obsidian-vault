# File

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A named collection of data on storage. Can be text, image, code, or any data.

## 📋 Concrete Example

File: essay.txt contains 500 words of text. photo.jpg contains image data. app.py contains Python code. Each file has a name, type, and size.

## 🔗 Analogy

A file is like a document in a filing cabinet - it has a name (label), content (text or images), and a type (format). The file system stores and organizes files.
