# GPU

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Graphics Processing Unit - designed for parallel computation. Thousands of cores. Used for AI training and gaming.

## 📋 Concrete Example

GPU: 10,000+ cores vs CPU's 4-16. Each GPU core is simpler but there are thousands. Perfect for matrix multiplication (the core of neural networks). AI training uses GPUs because of this.

## 🔗 Analogy

A GPU is like 10,000 assistants doing simple tasks simultaneously - each one is not as smart as the chef (CPU), but together they chop 10,000 carrots at once. AI training needs exactly this: millions of simple calculations done in parallel.
