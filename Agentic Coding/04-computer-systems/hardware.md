# Hardware

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Physical components: CPU, GPU, RAM, SSD, network card, keyboard, monitor. The tangible parts of a computer.

## 📋 Concrete Example

Hardware: you can touch it. CPU (processor), GPU (graphics), RAM (memory), SSD (storage), NIC (network). Software runs on hardware. Without hardware, software is just data.

## 🔗 Analogy

Hardware is like the kitchen equipment - stoves, ovens, refrigerators (CPU, GPU, RAM, SSD). Software is the recipes. You need both to cook: recipes without equipment are useless, equipment without recipes does nothing.
