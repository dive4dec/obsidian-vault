# HTTP

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

HyperText Transfer Protocol - the protocol of the web. Browsers send HTTP requests, servers send HTTP responses.

## 📋 Concrete Example

HTTP request: 'GET /api/users HTTP/1.1'. Response: '200 OK, Content-Type: application/json, Body: [{name: Alice}]'. Every web page load is an HTTP request-response.

## 🔗 Analogy

HTTP is like ordering at a restaurant - you (browser) say 'I want the menu' (GET /menu). The waiter (server) brings it. HTTP defines the format of these requests and responses.
