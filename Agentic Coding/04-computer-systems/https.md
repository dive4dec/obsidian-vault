# HTTPS

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

HTTP Secure - HTTP encrypted with TLS. Prevents eavesdropping. Used for all modern web traffic.

## 📋 Concrete Example

HTTPS: your request is encrypted before sending. Only the server can decrypt it. Someone listening on the network sees gibberish. Your password is safe.

## 🔗 Analogy

HTTPS is like sending a letter in a locked safe - only you and the recipient have the key. Anyone who intercepts it sees a locked box, not the letter. HTTPS encrypts web traffic.
