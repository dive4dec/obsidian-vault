# Kernel

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

The core of the OS. Manages CPU, memory, devices, and system calls. The most privileged software.

## 📋 Concrete Example

Kernel: schedules processes, allocates memory, manages device drivers. When your program needs to read a file, it asks the kernel (system call). The kernel does the actual read.

## 🔗 Analogy

The kernel is like the building manager - they control electricity, water, elevators, and security. Residents (programs) request services through the manager, who handles the actual infrastructure.
