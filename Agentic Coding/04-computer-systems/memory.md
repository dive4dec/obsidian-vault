# Memory

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Memory (RAM) stores data the CPU needs right now. Unlike disk, it is fast but volatile - data disappears when power is off.

## 📋 Concrete Example

Your program loads into RAM: variables, code, data. 8GB RAM means it can hold 8 billion bytes. If your program needs more, the OS uses virtual memory (disk), which is much slower.

## 🔗 Analogy

Memory is like a chef's countertop - ingredients currently being used are on the counter (RAM). The pantry (disk) holds more, but walking to the pantry takes longer. Bigger counter = more ingredients at hand.
