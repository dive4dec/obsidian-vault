# Microservice

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A small, independent service that does one thing well. Multiple microservices work together to form an application.

## 📋 Concrete Example

Microservices: User Service (login), Product Service (catalog), Order Service (checkout), Payment Service (billing). Each runs independently, communicates via APIs. One crashing does not bring down the others.

## 🔗 Analogy

Microservices are like departments in a school - Admissions handles enrollment, Finance handles fees, IT handles technology, Facilities handles buildings. Each department is independent. If IT is down, Admissions still works.
