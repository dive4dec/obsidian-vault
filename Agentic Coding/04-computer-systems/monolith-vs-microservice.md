# Monolith vs Microservice

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Monolith: all code in one application. Microservice: split into small services. Each has trade-offs.

## 📋 Concrete Example

Monolith: one big Python app. Easy to develop, hard to scale. Microservices: 10 small services. Harder to manage, but each scales independently and one crash does not take down everything.

## 🔗 Analogy

A monolith is like a general store - everything in one shop. Easy to manage but hard to expand. Microservices are like a shopping mall - many specialized stores. Harder to manage but each can grow independently.
