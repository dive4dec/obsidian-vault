# Network

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Computers connected to share data. The internet is a global network. Local networks (LAN) connect nearby computers.

## 📋 Concrete Example

Network: your laptop connects to a router (LAN). The router connects to the internet (WAN). You send a request to a server in Tokyo. Data travels through undersea cables in milliseconds.

## 🔗 Analogy

A network is like a postal system - your letter (data) goes from your house (laptop) to the post office (router) to the destination (server). The internet is a global postal system for data.
