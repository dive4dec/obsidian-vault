# Operating System

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

The OS manages all hardware and software: CPU, memory, storage, processes. Windows, macOS, Linux are OSs.

## 📋 Concrete Example

OS jobs: schedule which process uses the CPU, allocate memory, manage files, handle network. When you run Python, the OS gives it CPU time and memory. When it crashes, the OS cleans up.

## 🔗 Analogy

The OS is like a school principal - they assign classrooms (memory), schedule teachers (CPU), manage supplies (storage), and handle emergencies (crashes). Everything runs through them.
