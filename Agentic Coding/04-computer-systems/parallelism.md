# Parallelism

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Doing multiple things simultaneously. Requires multiple CPU cores. True simultaneous execution.

## 📋 Concrete Example

4 CPU cores, 4 threads: each thread runs on a separate core simultaneously. 4 calculations done at the same time. True parallelism. 4x faster than 1 core.

## 🔗 Analogy

Parallelism is like 4 chefs cooking 4 dishes simultaneously in 4 kitchens. True simultaneous work. Concurrency is 1 chef switching between 4 dishes.
