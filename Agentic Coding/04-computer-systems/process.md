# Process

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A running program. The OS creates a process when you run a program, giving it memory and CPU time.

## 📋 Concrete Example

When you run 'python app.py', the OS creates a process: PID 1234, 100MB memory, 10% CPU. When the program finishes or crashes, the process ends and memory is freed.

## 🔗 Analogy

A process is like a student taking an exam - they get a desk (memory), time (CPU), and materials (files). When the exam is over, the desk is cleared for the next student.
