# Protocol

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A set of rules for communication. HTTP, HTTPS, FTP, WebSocket are protocols. Each defines how data is formatted and exchanged.

## 📋 Concrete Example

HTTP protocol: client sends 'GET /index.html'. Server responds with '200 OK' + HTML content. Both sides follow the HTTP rules. Different protocols for different needs.

## 🔗 Analogy

A protocol is like etiquette at a formal dinner - which fork to use first, how to address the host, when to start eating. Both sides know the rules, so everything goes smoothly. Network protocols ensure computers communicate correctly.
