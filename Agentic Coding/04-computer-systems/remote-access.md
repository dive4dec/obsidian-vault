# Remote Access

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Accessing a computer over a network. SSH, VNC, RDP are remote access methods.

## 📋 Concrete Example

Remote access: you are at home in Hong Kong, accessing a server in Tokyo. SSH gives you the command line. VNC gives you the desktop. You work as if you were there.

## 🔗 Analogy

Remote access is like a drone with a camera - you control it from far away, see what it sees, do what it does. Remote access lets you use a distant computer as if you were there.
