# Shell

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

The program that interprets terminal commands. Bash, zsh, PowerShell are shells.

## 📋 Concrete Example

Shell (bash): you type 'ls -la'. Bash interprets: list all files with details. It translates your commands into OS actions.

## 🔗 Analogy

The shell is like a translator between you and the OS - you speak human (commands), the shell translates to OS language (system calls), and translates the response back to you.
