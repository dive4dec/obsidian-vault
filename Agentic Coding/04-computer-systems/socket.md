# Socket

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A communication endpoint: IP address + port. Programs use sockets to send and receive data.

## 📋 Concrete Example

Socket: 192.168.1.100:8080. Client connects to this socket. Server listens on this socket. Data flows through the socket. The connection is a socket pair (client + server).

## 🔗 Analogy

A socket is like a phone extension - you call the main number (IP), then dial the extension (port). The socket connects your phone to the right person. Sockets connect programs.
