# SSD

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Solid State Drive - storage with no moving parts. Much faster than HDD. Uses flash memory.

## 📋 Concrete Example

SSD boot time: 10 seconds. HDD boot time: 60 seconds. SSD reads files instantly; HDD clicks and whirs. SSD is like a bookshelf - grab any book instantly. HDD is like a library - walk to the shelf.

## 🔗 Analogy

SSD is like a bookshelf where you can grab any book instantly. An HDD is like a vinyl record player - a needle physically moves to find data. No moving parts in SSD means faster access.
