# SSH

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Secure Shell - a protocol for securely accessing a remote computer's command line.

## 📋 Concrete Example

SSH: 'ssh user@server.com' from your laptop. You get the server's terminal as if you were sitting in front of it. Encrypted, secure. Used for managing remote servers.

## 🔗 Analogy

SSH is like a remote control for a computer - you sit at home and control a server in a data center. You see its terminal, type commands, run programs. All encrypted so no one can eavesdrop.
