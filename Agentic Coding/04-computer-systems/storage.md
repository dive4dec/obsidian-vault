# Storage

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Storage (SSD/HDD) keeps data permanently. SSDs are fast, HDDs are slow but cheap. Programs and files live here when not in use.

## 📋 Concrete Example

Your Python file is on SSD. When you run it, it is copied to RAM. When you save results, they go back to SSD. 512GB SSD holds 512 billion bytes - enough for millions of files.

## 🔗 Analogy

Storage is like a pantry - it holds all ingredients (files) permanently. The pantry is bigger than the counter (RAM), but getting something from the pantry takes longer than picking it up from the counter.
