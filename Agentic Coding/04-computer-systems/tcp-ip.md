# TCP-IP

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

The protocol suite that runs the internet. TCP ensures reliable delivery; IP routes packets to the right address.

## 📋 Concrete Example

TCP/IP: you send `Hello` to a server. TCP breaks it into packets, numbers them, sends them. IP routes each packet to the server. TCP reassembles them. If a packet is lost, TCP resends it. Reliable.

## 🔗 Analogy

TCP/IP is like the postal system - IP is the address system (where does this letter go?), TCP is the delivery guarantee (was it received? if not, resend). Together, they ensure reliable data delivery.
