# Terminal

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

A text-based interface to the OS. You type commands, the OS executes them. Also called shell or command line.

## 📋 Concrete Example

Terminal: $ ls (list files). $ cd documents (change directory). $ python app.py (run program). $ git commit (version control). Text-based control of the computer.

## 🔗 Analogy

The terminal is like a walkie-talkie to the OS - you type commands, the OS does them and reports back. No mouse, no clicking - just text commands.
