# TLS

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Transport Layer Security - encrypts data between client and server. The `S` in HTTPS.

## 📋 Concrete Example

TLS: handshake -> agree on encryption keys -> all subsequent data is encrypted. Even if someone intercepts the data, they cannot read it without the keys.

## 🔗 Analogy

TLS is like a secret handshake between spies - they verify each other's identity, agree on a code, then communicate in that code. TLS secures communication between client and server.
