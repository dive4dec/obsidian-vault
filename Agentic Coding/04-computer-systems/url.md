# URL

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

Uniform Resource Locator - a web address. Contains protocol, domain, path, and parameters.

## 📋 Concrete Example

URL: https://example.com/articles/python?page=2. Protocol: https. Domain: example.com. Path: /articles/python. Parameter: page=2. Everything needed to find a web resource.

## 🔗 Analogy

A URL is like a full postal address - protocol (delivery method: airmail), domain (city), path (street and building), parameter (apartment number). Everything needed to find a specific web resource.
