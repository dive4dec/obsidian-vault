# Working Directory

> **Domain:** [[_computer-systems-moc|Computer Systems]]

## 🎯 Motivation

The current directory your program is running in. Relative paths are resolved from here.

## 📋 Concrete Example

Working directory: /home/user/. Relative path 'documents/essay.txt' resolves to '/home/user/documents/essay.txt'. Change with `cd` in terminal or os.chdir() in Python.

## 🔗 Analogy

The working directory is like where you are standing in a building - relative directions ('go to the room on the left') depend on where you currently are. The working directory is your current position.
