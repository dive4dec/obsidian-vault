# Access Control

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Rules defining who can access what. Read, write, execute permissions for each resource.

## 📋 Concrete Example

Access control: document `grades.pdf`: Alice (read, write), Bob (read), Carol (none). Each user has specific permissions for each resource. Enforced by the system.

## 🔗 Analogy

Access control is like room keycards in a school - students can enter classrooms, teachers can enter the staff room, the principal can enter anywhere. Each person has different access to different rooms.
