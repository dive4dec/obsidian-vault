# API Endpoint

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A specific URL where an API can be accessed. Each endpoint does one thing.

## 📋 Concrete Example

Endpoints: GET /api/users (list users), POST /api/users (create user), PUT /api/users/123 (update user 123), DELETE /api/users/123 (delete user 123). Each URL + method combination is an endpoint.

## 🔗 Analogy

An API endpoint is like a department in a store - 'Customer Service' handles returns, `Cashier` handles payments, `Information` handles questions. Each endpoint handles one type of request.
