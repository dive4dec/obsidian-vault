# Authorization

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Checking what an authenticated user is allowed to do. Permissions and access control.

## 📋 Concrete Example

Authorization: Alice is authenticated. Can she delete users? Check permissions: Alice is `admin` -> yes. Bob is `student` -> no. Authorization determines what each user can do.

## 🔗 Analogy

Authorization is like keycard access in a hotel - your card (authentication) gets you into the building. But does it open the gym? The VIP lounge? The staff room? Authorization checks what your card allows.
