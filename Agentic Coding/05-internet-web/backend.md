# Backend

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The part of a web application that runs on the server: databases, business logic, APIs. The server side.

## 📋 Concrete Example

Backend: when user logs in, the backend: receives credentials, checks database, generates token, returns response. The user never sees this code. It runs on the server.

## 🔗 Analogy

The backend is like a restaurant's kitchen - the customer (user) sees the dining area (frontend) but the cooking (business logic) happens in the kitchen (backend). The chef (server) prepares the food (data) and sends it out.
