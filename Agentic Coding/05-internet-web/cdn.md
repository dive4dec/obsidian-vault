# CDN

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Content Delivery Network - servers around the world that cache content close to users. Faster delivery.

## 📋 Concrete Example

CDN: your server is in Hong Kong. User in New York: 200ms latency. CDN has a copy in New York: 20ms latency. 10x faster. CDN caches content globally.

## 🔗 Analogy

A CDN is like franchise stores around the world - instead of buying from the one factory in Hong Kong (slow delivery), you buy from the local franchise (fast delivery). Same product, closer source.
