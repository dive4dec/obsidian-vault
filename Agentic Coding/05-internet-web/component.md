# Component

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A reusable UI piece in frontend frameworks. Encapsulates HTML, CSS, and JavaScript.

## 📋 Concrete Example

Component: <UserCard name=`Alice` avatar=`pic.jpg` />. Renders a card with Alice's name and photo. Reuse: <UserCard name=`Bob` avatar=`bob.jpg` />. Same component, different data.

## 🔗 Analogy

A component is like a stamp - you design it once, then stamp it with different ink (data) on different papers (pages). Same design, different results. Components are reusable UI stamps.
