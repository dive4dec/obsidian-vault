# CSS

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Cascading Style Sheets - controls how web pages look: colors, fonts, layout, animation.

## 📋 Concrete Example

CSS: 'h1 { color: blue; font-size: 24px; } .button { background: green; border-radius: 5px; }'. The browser applies these styles. Headings are blue, buttons are green with rounded corners.

## 🔗 Analogy

CSS is like interior design - the frame (HTML) is there, but CSS chooses the paint colors, furniture style, and lighting. Same frame, completely different look with different CSS.
