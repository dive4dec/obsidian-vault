# CSV

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Comma-Separated Values - a simple data format. Each line is a row, columns separated by commas.

## 📋 Concrete Example

CSV: name,age,city\nAlice,14,Hong Kong\nBob,15,Tokyo\nCarol,16,Seoul. Simple, compact, opens in Excel. Good for tabular data.

## 🔗 Analogy

CSV is like a simple list on lined paper - each line is a row, columns separated by commas. No formatting, no complexity. Just data in rows and columns. Perfect for spreadsheets.
