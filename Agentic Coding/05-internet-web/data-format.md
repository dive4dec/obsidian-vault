# Data Format

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

How data is structured for storage or transmission: JSON, XML, CSV, YAML. Each has different use cases.

## 📋 Concrete Example

JSON: web APIs. CSV: spreadsheets. XML: enterprise systems. YAML: configuration files. Each format structures data differently, optimized for different needs.

## 🔗 Analogy

Data formats are like different envelope types - business envelope (JSON) for letters, padded envelope (XML) for fragile items, large envelope (CSV) for bulk documents. Each format suits different data types.
