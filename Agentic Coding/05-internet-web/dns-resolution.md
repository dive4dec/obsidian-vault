# DNS Resolution

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The process of looking up a domain name's IP address via DNS. Happens every time you visit a website.

## 📋 Concrete Example

DNS resolution: type `google.com` -> DNS server: 'google.com is 142.250.80.46' -> browser connects to that IP. Takes 1-10ms. Cached for future visits. Happens behind the scenes.

## 🔗 Analogy

DNS resolution is like looking up a phone number in your contacts - you type `Mom` -> contacts app shows her number -> you call. DNS resolves domain names to IP addresses the same way.
