# DOM

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Document Object Model - the browser's internal representation of a web page. JavaScript manipulates the DOM to change the page.

## 📋 Concrete Example

DOM: the browser parses HTML into a tree. <html> -> <body> -> <h1>, <p>, <button>. JavaScript: document.getElementById(`myButton`).innerHTML = 'Clicked!'. The DOM tree is updated, and the page changes instantly.

## 🔗 Analogy

The DOM is like a blueprint of a house that the builder (browser) holds. JavaScript can modify the blueprint: 'change this room's color, add a door here.' The builder immediately reflects the changes.
