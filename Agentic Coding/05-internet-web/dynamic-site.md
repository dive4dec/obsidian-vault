# Dynamic Site

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A website with content generated on the server. Personalized, interactive, database-driven.

## 📋 Concrete Example

Dynamic site: you log in. Server: queries database, builds a personalized page with your name, recommendations, and history. Each user sees different content. Powered by a backend.

## 🔗 Analogy

A dynamic site is like a personal tutor - it adapts to each student. Different content for different people. Requires more processing (server) but provides personalized experiences.
