# Frontend

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The part of a web application users see and interact with: HTML, CSS, JavaScript. The client side.

## 📋 Concrete Example

Frontend: the login page - input fields, buttons, animations, error messages. Everything the user sees and clicks. Built with HTML, CSS, JavaScript (or frameworks like React).

## 🔗 Analogy

The frontend is like a restaurant's dining area - the decor, menu, tables, and waiters. Everything the customer sees and interacts with. The kitchen (backend) is behind the scenes.
