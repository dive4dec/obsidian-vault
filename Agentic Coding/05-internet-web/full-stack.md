# Full-Stack

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A developer who works on both frontend and backend. Full-stack agents can build entire web applications.

## 📋 Concrete Example

Full-stack agent: builds the frontend (React UI), backend (Flask API), and database (PostgreSQL). It handles everything from button clicks to data storage.

## 🔗 Analogy

A full-stack developer is like a solo restaurant owner - they cook (backend), serve (frontend), manage inventory (database), and clean up (DevOps). They do everything, end to end.
