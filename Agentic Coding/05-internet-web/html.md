# HTML

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

HyperText Markup Language - the structure of web pages. Tags define headings, paragraphs, links, images.

## 📋 Concrete Example

HTML: '<h1>Welcome</h1><p>This is a paragraph.</p><a href="page2.html">Link</a>'. The browser reads these tags and displays: a heading, a paragraph, and a clickable link.

## 🔗 Analogy

HTML is like the frame of a house - it defines rooms (sections), doors (links), and windows (images). The frame gives structure. CSS paints the walls; JavaScript adds electricity.
