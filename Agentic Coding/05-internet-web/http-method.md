# HTTP Method

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Verbs that define what to do with a resource: GET (read), POST (create), PUT (update), DELETE (remove).

## 📋 Concrete Example

GET /users: list all users. POST /users: create a new user. PUT /users/123: update user 123. DELETE /users/123: delete user 123. The method tells the server what action to perform.

## 🔗 Analogy

HTTP methods are like verbs in a sentence - GET (read), POST (create), PUT (update), DELETE (destroy). The resource (users) is the noun. Together, they form a complete instruction.
