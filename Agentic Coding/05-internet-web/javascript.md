# JavaScript

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The programming language of the web. Runs in the browser. Adds interactivity: clicks, animations, dynamic content.

## 📋 Concrete Example

JavaScript: button.addEventListener(`click`, () => { alert('Hello!'); }). When the user clicks the button, a popup appears. JavaScript makes web pages interactive, not just static.

## 🔗 Analogy

JavaScript is like electricity in a house - the frame (HTML) and decoration (CSS) are static. Electricity (JS) makes things move: lights turn on, the doorbell rings, the TV works. JavaScript brings web pages to life.
