# JSON

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

JavaScript Object Notation - a lightweight data format. The standard for API data exchange.

## 📋 Concrete Example

JSON: {"name": "Alice", "age": 14, "hobbies": ["coding", "gaming"]}. Easy for humans to read, easy for machines to parse. The lingua franca of web APIs.

## 🔗 Analogy

JSON is like a standardized form - everyone fills it out the same way: name, age, hobbies. Any system can read it. JSON is the standard form for data exchange on the web.
