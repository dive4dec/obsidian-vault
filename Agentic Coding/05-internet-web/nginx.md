# Nginx

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A popular web server and reverse proxy. Handles high traffic efficiently. Used for load balancing and serving static files.

## 📋 Concrete Example

Nginx: receives 10,000 requests/second. Serves static files (images, CSS) directly - fast. For dynamic content, forwards to the backend application. Also load balances across multiple backend instances.

## 🔗 Analogy

Nginx is like an efficient traffic cop - they handle simple requests (static files) themselves instantly. Complex requests (dynamic content) are forwarded to specialists (backend). They also direct traffic to less busy lanes (load balancing).
