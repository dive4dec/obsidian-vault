# Offline Mode

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

When a web app works without internet. Achieved through caching and service workers.

## 📋 Concrete Example

Offline mode: you open the app. No internet. The service worker serves cached files. You can read saved articles, see cached data. When internet returns, the app syncs.

## 🔗 Analogy

Offline mode is like a downloaded movie - you download it once (online), then watch it anytime (offline). No internet needed. Offline mode lets web apps work like downloaded content.
