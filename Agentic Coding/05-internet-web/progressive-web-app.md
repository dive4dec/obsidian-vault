# Progressive Web App

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A web app that works like a native app: offline, push notifications, home screen icon.

## 📋 Concrete Example

PWA: you visit a website. Browser asks: 'Add to home screen?' You accept. Now it has an icon, works offline, and sends push notifications - like a real app. But it is still a website.

## 🔗 Analogy

A PWA is like a food truck that becomes a restaurant - it starts mobile (website) but can set up a permanent location (home screen), serve customers even when the road is closed (offline), and send promotions (push notifications).
