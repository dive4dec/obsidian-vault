# React

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A JavaScript library for building user interfaces. Component-based, declarative. Very popular.

## 📋 Concrete Example

React: build a Button component. Reuse it everywhere: <Button color=`red` onClick={handleClick}>. Components are like Lego bricks - build once, reuse everywhere. React manages the UI efficiently.

## 🔗 Analogy

React is like Lego - you build small pieces (components) and combine them into complex structures (UIs). Each piece is reusable. Change one piece, and React efficiently updates only what changed.
