# Real-Time Communication

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Exchanging data instantly, with minimal delay. Chat, gaming, live streaming, collaborative editing.

## 📋 Concrete Example

Real-time: you type a message. Your friend sees it in 50ms. You move a game character. Other players see it instantly. No page refresh, no delay. WebSocket enables this.

## 🔗 Analogy

Real-time communication is like a walkie-talkie - you speak and the other person hears instantly. No waiting, no delays. Essential for chat, gaming, and live collaboration.
