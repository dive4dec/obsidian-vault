# Rendering

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The process of generating the visual output from code. Browser rendering: HTML + CSS -> pixels on screen.

## 📋 Concrete Example

Rendering: browser receives HTML, builds DOM tree. Applies CSS styles. Lays out elements. Paints pixels on screen. 60 times per second for smooth animation. The browser's core job.

## 🔗 Analogy

Rendering is like a painter translating a sketch into a finished painting - they take the outline (HTML), apply colors (CSS), and produce the final artwork (pixels on screen). The browser renders web pages.
