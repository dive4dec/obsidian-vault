# Responsive Design

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Designing websites that work on all screen sizes: phone, tablet, desktop.

## 📋 Concrete Example

Responsive: CSS media queries: '@media (max-width: 768px) { .menu { display: none; } }'. On mobile, the menu is hidden; a hamburger icon appears. On desktop, the full menu shows. One website, all devices.

## 🔗 Analogy

Responsive design is like a transformer toy - it changes shape depending on the situation. On a small screen (phone), it is compact. On a large screen (desktop), it expands. Same toy, different forms.
