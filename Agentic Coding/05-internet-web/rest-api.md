# REST API

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Representational State Transfer - a style of API design using HTTP methods (GET, POST, PUT, DELETE) on resources.

## 📋 Concrete Example

REST API: GET /books (list), POST /books (create), GET /books/123 (detail), PUT /books/123 (update), DELETE /books/123 (delete). Standard, predictable, widely used.

## 🔗 Analogy

REST is like a library system - GET (read a book), POST (add a new book), PUT (update a book), DELETE (remove a book). Standard operations on resources (books). Clear and predictable.
