# Reverse Proxy

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A server that sits in front of other servers, forwarding requests. Provides security, load balancing, and caching.

## 📋 Concrete Example

Reverse proxy: all requests go to proxy.example.com. Proxy forwards to backend1, backend2, or backend3. Users never see the backend servers directly. Security + load balancing + caching.

## 🔗 Analogy

A reverse proxy is like a building receptionist - all visitors go to reception first. Reception directs them to the right office (backend server). Visitors never know the actual office number. Security and organization.
