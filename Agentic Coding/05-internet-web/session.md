# Session

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A period of interaction between user and server. The server remembers the user across multiple requests.

## 📋 Concrete Example

Session: user logs in at 2pm. Session starts. User browses for 30 minutes. Server remembers: this is Alice, she is logged in, she has items in her cart. Session ends at 2:30pm (timeout or logout).

## 🔗 Analogy

A session is like a gym membership - you check in (login), use the gym (browse), and the staff knows who you are the whole time. When you leave (logout), the session ends. Next visit, you check in again.
