# Single Page Application

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A web app that loads once and updates dynamically without page reloads. Smooth, app-like experience.

## 📋 Concrete Example

SPA: you click `Profile`. Instead of loading a new page, JavaScript: 1) fetches profile data (API). 2) Updates the DOM. 3) URL changes to /profile. No page reload. Smooth, instant.

## 🔗 Analogy

SPA is like a magic book - you turn to a new chapter, but the book does not close and reopen. The content changes instantly. No loading screen. Smooth transitions between `pages`.
