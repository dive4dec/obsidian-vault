# Static Site

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A website with fixed content. No server-side processing. Fast, cheap, secure.

## 📋 Concrete Example

Static site: HTML, CSS, JS files on a server. No database, no server code. Just files. Extremely fast (no processing), cheap (no server needed), secure (no server to hack). Good for blogs and portfolios.

## 🔗 Analogy

A static site is like a printed brochure - the content is fixed. Everyone sees the same thing. No interactivity, but fast, cheap, and reliable. Contrast with a dynamic site, which is like a live conversation.
