# Web API

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

An API accessed over HTTP. The most common way for applications to communicate on the internet.

## 📋 Concrete Example

Web API: your app calls 'GET https://api.weather.com/today?city=HongKong'. Returns JSON: {temp: 28, condition: `sunny`}. Your app uses this data to show weather. APIs connect applications.

## 🔗 Analogy

A web API is like a restaurant's takeout window - you (application) ask for food (data) through the window (API). The kitchen (server) prepares it and hands it out. You do not need to go inside.
