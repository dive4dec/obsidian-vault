# Web Browser

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A program that fetches and displays web pages. Chrome, Safari, Firefox are browsers.

## 📋 Concrete Example

Browser: you type `google.com`. Browser sends HTTP request, receives HTML, CSS, JavaScript, and renders the page. It interprets the code and displays the visual result.

## 🔗 Analogy

A web browser is like a translator and decorator - it fetches raw materials (HTML, CSS, JS) from a server, translates them, and presents a beautifully decorated page. Without the browser, web code is just text.
