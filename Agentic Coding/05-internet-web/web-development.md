# Web Development

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Building websites and web applications. Involves frontend, backend, databases, and deployment.

## 📋 Concrete Example

Web development: 1) Design UI (frontend). 2) Build API (backend). 3) Set up database. 4) Deploy to server. 5) Maintain and update. The full process of creating a web application.

## 🔗 Analogy

Web development is like building a house - design the layout (frontend), install plumbing and electricity (backend), set up storage (database), get permits (deployment), and maintain it. A complete construction project.
