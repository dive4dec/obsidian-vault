# Web Scraping

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Extracting data from web pages by parsing HTML. Useful when no API is available.

## 📋 Concrete Example

Scraping: fetch 'https://news.com', parse HTML, extract all <h2> tags (headlines). Return: ['AI Breakthrough', 'New Phone Released', ...]. Get data from any website, even without an API.

## 🔗 Analogy

Web scraping is like clipping newspaper articles - you go to the newsstand (website), find the articles you want (headlines), and clip them (extract). No subscription (API) needed, but you must do the work yourself.
