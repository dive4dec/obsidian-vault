# Web Server

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

Software that receives HTTP requests and sends HTTP responses. Apache, Nginx are web servers.

## 📋 Concrete Example

Web server: receives 'GET /index.html'. Finds the file. Sends '200 OK' + HTML. Receives 'GET /api/data'. Calls the application. Sends JSON. The middleman between client and application.

## 🔗 Analogy

A web server is like a restaurant host - they greet customers (requests), find them a table (route to the right resource), and bring the menu (response). They handle the flow of customers.
