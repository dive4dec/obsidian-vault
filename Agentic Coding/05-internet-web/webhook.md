# Webhook

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A URL that receives HTTP POST requests when an event occurs. Like a callback for web services.

## 📋 Concrete Example

Webhook: when a GitHub push happens, GitHub sends a POST to your webhook URL: https://yourapp.com/webhook. Your app receives it and triggers a build. Automated, event-driven.

## 🔗 Analogy

A webhook is like an automatic phone call from a store - 'Your order is ready.' You do not need to call and ask; they call you when it is ready. Webhooks call your app when events happen.
