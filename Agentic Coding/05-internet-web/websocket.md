# WebSocket

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

A protocol for real-time, two-way communication between client and server. Unlike HTTP, the connection stays open.

## 📋 Concrete Example

WebSocket: chat app. Client connects to server. Connection stays open. Client sends message -> server receives instantly. Server sends new message -> client receives instantly. Real-time, bidirectional.

## 🔗 Analogy

WebSocket is like a phone call - once connected, both sides can talk anytime. No need to dial again. HTTP is like a text message - each message is separate. WebSocket keeps the line open for real-time chat.
