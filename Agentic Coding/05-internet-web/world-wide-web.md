# World Wide Web

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

The Web is the part of the internet accessed through browsers. Websites, web apps, and web APIs. Not the same as the internet (which also includes email, gaming, etc.).

## 📋 Concrete Example

The internet: roads, bridges, tunnels. The Web: shops and buildings on those roads. Email, online games, and file transfers use the internet but are not the Web.

## 🔗 Analogy

The internet is the road network; the Web is the buildings along the roads. You use roads (internet) to reach buildings (websites). But roads also reach places that are not buildings (email servers, game servers).
