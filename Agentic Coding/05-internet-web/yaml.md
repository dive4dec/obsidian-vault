# YAML

> **Domain:** [[_internet-web-moc|Internet & Web]]

## 🎯 Motivation

YAML Ain't Markup Language - a human-friendly data format used for configuration files.

## 📋 Concrete Example

YAML: name: Alice\nage: 14\nhobbies:\n  - coding\n  - gaming. Clean, readable, uses indentation for structure. Common for config files and CI-CD pipelines.

## 🔗 Analogy

YAML is like a neatly organized outline - indentation shows hierarchy, no brackets or commas. Clean and readable. Perfect for configuration files that humans need to read and edit.
