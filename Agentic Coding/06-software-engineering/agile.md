# Agile

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

An approach to software development: iterative, flexible, customer-focused. Deliver working software in short cycles.

## 📋 Concrete Example

Agile: 2-week sprints. Each sprint: plan -> build -> test -> demo -> reflect. Deliver a small, working feature every 2 weeks. Adapt based on feedback. Flexible, not rigid.

## 🔗 Analogy

Agile is like cooking a meal one course at a time - you make the appetizer, serve it, get feedback, then make the soup, adjust based on feedback, then the main course. You adapt as you go, rather than cooking everything at once and hoping for the best.
