# Backlog

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A prioritized list of tasks, features, and bug fixes waiting to be worked on.

## 📋 Concrete Example

Backlog: 1) [HIGH] Fix login crash. 2) [HIGH] Add password reset. 3) [MED] Dark mode. 4) [LOW] Change button color. Prioritized by importance. Tasks are pulled from the top during sprint planning.

## 🔗 Analogy

A backlog is like a to-do list sorted by priority - the most urgent tasks at the top, nice-to-haves at the bottom. You work from the top down. The backlog keeps track of everything that needs to be done.
