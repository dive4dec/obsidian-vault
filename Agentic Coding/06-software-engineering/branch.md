# Branch

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A parallel line of development. You can experiment on a branch without affecting the main code.

## 📋 Concrete Example

Branch: 'git checkout -b feature/dark-mode'. You are now on the dark-mode branch. Changes here do not affect main. When dark mode is ready, merge it into main. Safe experimentation.

## 🔗 Analogy

A branch is like a copy of a document - you edit the copy freely. If it turns out great, replace the original. If not, throw away the copy. The original is safe. Branches let developers experiment safely.
