# Breakpoint

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A marker in code where execution pauses. Lets you inspect variables and step through code.

## 📋 Concrete Example

Breakpoint: set at line 10. Run code. It pauses at line 10. Inspect: x = 5, y = 3, result = 15 (wrong, should be 8). Step to line 11. result = 15 + 3 = 18. Found the bug: wrong calculation on line 10.

## 🔗 Analogy

A breakpoint is like a pause button on a video - you freeze the action at a specific frame and examine everything: 'What is the score? Where are the players? What just happened?' A breakpoint freezes code for inspection.
