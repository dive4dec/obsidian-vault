# Bug

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

An error in code that causes wrong behavior. Bugs range from cosmetic to critical.

## 📋 Concrete Example

Bug: sort function returns [3, 1, 2] instead of [1, 2, 3]. The code has a bug. Debug: find the cause (wrong comparison), fix it, test. Bugs are inevitable; the goal is to find and fix them quickly.

## 🔗 Analogy

A bug is like a flat tire - it stops you from reaching your destination. You must find the hole (root cause), patch it (fix), and continue. Bugs are software flat tires.
