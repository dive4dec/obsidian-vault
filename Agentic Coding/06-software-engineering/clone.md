# Clone

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Making a local copy of a remote repository. You get all files and full history.

## 📋 Concrete Example

Clone: 'git clone https://github.com/user/project.git'. You now have a full copy on your computer. You can edit, commit, and push changes back. Full local copy of the remote repo.

## 🔗 Analogy

Cloning is like borrowing a book from the library - you get a complete copy. You can read it, write notes, and when you return it, your notes are shared (push). You have the full book locally.
