# Code Review

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Having teammates review your code before it is merged. Catches bugs, improves quality, shares knowledge.

## 📋 Concrete Example

Code review: Bob reviews Alice's PR. 'Line 15: no error handling. Line 30: variable name is unclear. Line 45: good test coverage.' Alice addresses feedback. Better code through peer review.

## 🔗 Analogy

Code review is like peer grading - a classmate reads your essay and gives feedback: 'unclear thesis, great conclusion.' You improve it before submitting. Code review improves code before merging.
