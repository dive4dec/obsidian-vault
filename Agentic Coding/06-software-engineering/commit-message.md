# Commit Message

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A description of what a commit does. Good messages explain why, not just what.

## 📋 Concrete Example

Good: 'Fix: sort function crashes on empty list. Added check for len(list) == 0.' Bad: 'fixed stuff.' The message helps teammates (and future you) understand the change.

## 🔗 Analogy

A commit message is like a diary entry for your code - 'Today I fixed the sort function because it crashed on empty lists.' Future developers read these entries to understand why changes were made.
