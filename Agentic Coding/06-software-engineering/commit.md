# Commit

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A saved snapshot of changes in Git. Each commit has a message describing what changed and why.

## 📋 Concrete Example

Commit: 'git commit -m "Fix: handle empty list in sort function"'. This saves the change with a message. History: commit a1b2c3, 'Fix: handle empty list in sort function', Alice, 2025-08-01.

## 🔗 Analogy

A commit is like saving a video game - your progress is saved at this point. You can continue, and if you make a mistake, reload this save. Each commit is a save point for your code.
