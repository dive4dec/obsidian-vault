# Debugger

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A tool that lets you pause code, inspect variables, and step through execution. Essential for debugging.

## 📋 Concrete Example

Debugger (pdb in Python): set breakpoint, step line by line, inspect variables, evaluate expressions. 'Why is x = 15 instead of 8?' Step through to find where it went wrong. Far better than print statements.

## 🔗 Analogy

A debugger is like a slow-motion camera for code - you replay the execution frame by frame, seeing exactly what happens at each step. Where did the value change? Why? The debugger shows you.
