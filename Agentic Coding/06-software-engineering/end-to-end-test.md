# End-to-End Test

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Testing the entire application from user's perspective: click button -> see result. Most realistic but slowest.

## 📋 Concrete Example

E2E test: 1) Open browser. 2) Navigate to login page. 3) Enter username and password. 4) Click login. 5) Verify dashboard appears. 6) Click `Profile.` 7) Verify profile page. Tests the real user experience.

## 🔗 Analogy

An E2E test is like a full preview performance - real audience, real stage, real lighting. Everything is tested as the audience (user) would experience it. Most realistic, but takes the most effort.
