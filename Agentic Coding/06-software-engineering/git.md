# Git

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

The most popular version control system. Distributed: every developer has a full copy of the repository.

## 📋 Concrete Example

Git: 'git init' (start), 'git add' (stage changes), 'git commit' (save), 'git push' (upload), 'git pull' (download). Every change is tracked. Branches allow parallel work. Merges combine work.

## 🔗 Analogy

Git is like a sophisticated library system - every book (file) has a history of edits. You can see any past version. Multiple authors can work on different chapters (branches) and combine them (merge).
