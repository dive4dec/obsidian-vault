# GitHub

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A platform for hosting Git repositories online. Adds collaboration features: pull requests, issues, code review.

## 📋 Concrete Example

GitHub: push your repo. Others can: clone it, suggest changes (PRs), report bugs (issues), review code. Collaboration platform built on Git. Used by most open-source projects.

## 🔗 Analogy

GitHub is like a collaborative workspace - your project is there, and anyone you invite can view, suggest changes, discuss, and contribute. It is the office for code collaboration.
