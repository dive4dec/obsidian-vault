# MVC

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Model-View-Controller - an architecture pattern. Model: data. View: UI. Controller: business logic.

## 📋 Concrete Example

MVC: Model: User database. View: login page. Controller: handles login request, checks model, returns view. Each part is separate. Change the view (redesign login page) without touching the model or controller.

## 🔗 Analogy

MVC is like a restaurant: Model (kitchen/ingredients), View (menu/dining area), Controller (waiter). The waiter takes orders, the kitchen prepares food, the dining area displays it. Each part is separate but works together.
