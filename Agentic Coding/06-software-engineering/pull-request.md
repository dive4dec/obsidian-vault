# Pull Request

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A request to merge your branch into the main code. Enables code review before merging.

## 📋 Concrete Example

PR: Alice opens 'PR: Add dark mode feature.' Team reviews the code: 'Looks good, but add a test for the toggle button.' Alice adds the test. Team approves. PR is merged. Code is reviewed before it goes live.

## 🔗 Analogy

A pull request is like submitting an article to a magazine - you write the article (branch), submit it (PR), the editor reviews it (code review), suggests changes, you revise, and when approved, it is published (merged).
