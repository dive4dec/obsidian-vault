# Pull

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Downloading the latest changes from a remote repository. Keeps your local copy up to date.

## 📋 Concrete Example

Pull: 'git pull origin main'. Downloads Alice's latest commits from GitHub. Your local code is now up to date with the remote. You have Alice's changes.

## 🔗 Analogy

Pulling is like checking the class bulletin board - you read the latest announcements (commits) so you are up to date. If you do not pull, you miss your teammates' changes.
