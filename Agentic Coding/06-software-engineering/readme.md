# README

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

The first file people read in a project. Explains what the project is, how to set it up, and how to use it.

## 📋 Concrete Example

README.md: '# Todo App. A simple task manager built with React. ## Setup. npm install. npm start. ## Usage. Click Add to create a task. ## Features. - Add, edit, delete tasks. - Categories. - Due dates.'

## 🔗 Analogy

A README is like a book's back cover and first chapter - it tells you what the book is about and how to get started. Without it, people do not know what the project does or how to use it.
