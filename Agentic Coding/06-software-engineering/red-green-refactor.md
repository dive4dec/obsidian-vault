# Red-Green-Refactor

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

The TDD cycle: Red (test fails), Green (test passes), Refactor (improve code quality).

## 📋 Concrete Example

Cycle: 1) Red: write test, run, fail. 2) Green: write minimal code to pass, run, pass. 3) Refactor: improve code without breaking tests. Repeat. Each cycle adds one piece of functionality.

## 🔗 Analogy

Red-green-refactor is like sculpting - rough shape (red: test defines the goal), refine until it looks right (green: code works), then polish (refactor: clean up). Cycle by cycle, the sculpture (code) takes shape.
