# Repository

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A storage location for a project. Contains all files, history, and metadata. Often called a repo.

## 📋 Concrete Example

Repository: 'my-project/' contains: source code, tests, documentation, .git/ (history). Hosted on GitHub, GitLab, or local. The complete project with full history.

## 🔗 Analogy

A repository is like a project folder with a built-in time machine - it contains all current files and every past version. You can travel back to any point in the project's history.
