# Scrum

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A specific Agile framework: sprints, daily standups, sprint planning, retrospectives.

## 📋 Concrete Example

Scrum: 2-week sprints. Daily 15-minute standup: 'What did I do? What will I do? Any blockers?' Sprint planning: choose tasks. Retrospective: what went well, what to improve. Structured Agile.

## 🔗 Analogy

Scrum is like a basketball team's practice system - daily practice (standup), game plan (sprint planning), post-game analysis (retrospective). Structured, repetitive, focused on continuous improvement.
