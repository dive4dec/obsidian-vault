# Software Engineering

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Writing one function is easy; building a large system is hard. Software engineering provides methods to design, build, test, and maintain complex software reliably.

## 📋 Concrete Example

A team of 10 developers building a banking app: they need architecture, version control, code review, testing, CI-CD, documentation. Without engineering practices, the project collapses into chaos.

## 🔗 Analogy

Software engineering is like city planning - building one house is simple, but planning a city requires zoning, infrastructure, traffic management, and building codes. Software engineering plans and builds large software systems.
