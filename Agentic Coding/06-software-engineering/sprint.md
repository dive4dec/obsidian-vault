# Sprint

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A fixed period (usually 1-4 weeks) for completing a set of tasks. At the end, working software is delivered.

## 📋 Concrete Example

Sprint: 2 weeks. Tasks: implement login, write tests, fix 3 bugs. At the end: all done, demoed, deployed. Next sprint: new tasks. Predictable, iterative delivery.

## 🔗 Analogy

A sprint is like a study week before exams - you plan what to study, study intensively for a week, take the exams (demo), and then review what worked (retrospective). Focused, time-boxed effort.
