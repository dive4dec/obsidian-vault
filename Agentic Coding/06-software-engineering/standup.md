# Standup

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A short daily meeting: what did you do, what will you do, any blockers? Keeps the team aligned.

## 📋 Concrete Example

Standup (15 min): Alice: 'Finished login UI, starting API integration, no blockers.' Bob: 'API is ready, need to write tests, blocked by missing test data.' Quick, focused, action-oriented.

## 🔗 Analogy

A standup is like a hockey team's quick huddle between periods - 'I played defense, next I am on offense. Our goalie needs rest.' Quick update, everyone aligned, back to work.
