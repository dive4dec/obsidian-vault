# Step Through

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Executing code one line at a time in a debugger. See exactly what happens at each step.

## 📋 Concrete Example

Step through: line 1: x = 5. line 2: y = 3. line 3: result = x * y (result = 15). line 4: return result. You see: the bug is on line 3: it multiplies instead of adds. Found it by stepping.

## 🔗 Analogy

Stepping through is like replaying a video one frame at a time - you see exactly what happens in each frame (line). 'Frame 3: the player kicks the ball.' 'Frame 4: the ball goes in the wrong direction.' Stepping through reveals the exact moment things go wrong.
