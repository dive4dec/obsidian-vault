# Team Workflow

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

How a team organizes work: who does what, how changes are reviewed, how releases happen.

## 📋 Concrete Example

Workflow: 1) Pick a task from the board. 2) Create a branch. 3) Code. 4) Write tests. 5) Open PR. 6) Code review. 7) Merge. 8) Deploy. Structured, repeatable process.

## 🔗 Analogy

A team workflow is like a kitchen brigade system - the head chef assigns tasks, each cook prepares their dish, the sous-chef checks quality, and the expediter sends orders out. Everyone has a role; the process is structured.
