# Technical Debt

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Quick-and-dirty code saves time now but creates debt that must be paid back later with interest (harder maintenance).

## 📋 Concrete Example

Rushing: copy-paste code 5 times (fast now). Debt: when you need to change the logic, you must change 5 places (slow later). The model can identify and help pay down debt.

## 🔗 Analogy

Technical debt is like using a credit card - buy now (fast), pay later with interest (expensive). Quick code is like credit card debt: convenient now, costly later. Pay it down by refactoring.
