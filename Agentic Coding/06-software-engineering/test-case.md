# Test Case

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

A specific scenario to test: input + expected output. Many test cases cover different scenarios.

## 📋 Concrete Example

Test cases for sort(): 1) Empty list -> []. 2) One item -> same. 3) Sorted list -> same. 4) Reverse sorted -> sorted. 5) Duplicates -> sorted. 6) Negative numbers -> sorted. 7) Large list -> sorted. Each case checks a scenario.

## 🔗 Analogy

A test case is like a specific exam question - 'Solve x + 5 = 10.' One question, one expected answer. Many questions (test cases) cover the full topic. Each case checks one specific scenario.
