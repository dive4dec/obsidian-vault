# Testing

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Verifying that code works correctly. Unit tests, integration tests, end-to-end tests. Essential for quality.

## 📋 Concrete Example

Testing: write test_add(): assert add(2, 3) == 5. Run it. Pass! Now test edge cases: assert add(0, 0) == 0, assert add(-1, 1) == 0. Each test verifies a specific behavior. Catches bugs early.

## 🔗 Analogy

Testing is like a dress rehearsal before a play - you practice everything to find problems before the real performance (production). Each test checks one aspect. Finding bugs in rehearsal is better than during the show.
