# Version Control

> **Domain:** [[_software-engineering-moc|Software Engineering]]

## 🎯 Motivation

Tracking changes to code over time. Who changed what, when, and why. Essential for team collaboration.

## 📋 Concrete Example

Git: Alice changes line 10. Bob changes line 20. Both commit. Git merges the changes. History: 'Alice: fixed login bug, 2025-08-01 14:00.' Full traceability. Rollback if needed.

## 🔗 Analogy

Version control is like a time machine for your code - you can see what the code looked like at any point in history, who made each change, and why. If something breaks, you can go back in time.
