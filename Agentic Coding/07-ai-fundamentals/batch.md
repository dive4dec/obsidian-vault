# Batch

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

A small chunk of data processed before updating weights. Makes training faster and more stable.

## 📋 Concrete Example

With 1000 images and batch size 50, each batch has 50 images, giving 20 updates per epoch.

## 🔗 Analogy

Like eating a big meal in small bites instead of all at once - easier to digest.
