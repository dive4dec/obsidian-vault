# Classification

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Predicting a category label from a fixed set of options.

## 📋 Concrete Example

Given an email, predict spam or not spam. Given a photo, predict which of 10 animals.

## 🔗 Analogy

Like sorting mail into labeled bins - each item goes into exactly one category.
