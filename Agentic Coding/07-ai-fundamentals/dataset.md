# Dataset

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

The collection of examples used to train and test a model. Bigger and cleaner is usually better.

## 📋 Concrete Example

ImageNet is a dataset with over 14 million labeled images across 1000 categories.

## 🔗 Analogy

Like a library - the bigger and better organized it is, the more you can learn from it.
