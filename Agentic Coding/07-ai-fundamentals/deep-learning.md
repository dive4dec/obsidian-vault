# Deep Learning

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Machine learning using neural networks with many layers. Deep means many layers.

## 📋 Concrete Example

A 50-layer network classifying medical X-rays is deep learning. A 2-layer network is shallow.

## 🔗 Analogy

Like a multi-story factory: the more floors (layers), the more complex the product it can make.
