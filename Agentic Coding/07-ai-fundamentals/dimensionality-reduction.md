# Dimensionality Reduction

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Squeezing data with many features into fewer dimensions while keeping the important info.

## 📋 Concrete Example

Reduce 1000-pixel images to a 50-number summary that still captures the key shapes.

## 🔗 Analogy

Like summarizing a 300-page book into a 1-page synopsis that keeps the main plot.
