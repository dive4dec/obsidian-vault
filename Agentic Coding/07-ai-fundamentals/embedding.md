# Embedding

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Turning things like words or images into lists of numbers so a computer can compare them.

## 📋 Concrete Example

The word king might become [0.5, -0.2, 0.9, ...]. Similar words like queen get similar vectors.

## 🔗 Analogy

Like giving each student a ID badge with numbers - students with similar interests get similar numbers.
