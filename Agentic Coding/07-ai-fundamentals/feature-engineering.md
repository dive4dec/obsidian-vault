# Feature Engineering

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Creating useful new features from raw data to help the model learn better.

## 📋 Concrete Example

From date of birth, engineer an age feature. From address, engineer distance-to-MTR feature.

## 🔗 Analogy

Like a chef prepping ingredients before cooking - cutting and seasoning well makes the dish better.
