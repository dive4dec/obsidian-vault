# Feature

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

An individual measurable property used as input. Good features make learning easier.

## 📋 Concrete Example

For predicting house price, features might be area, number of rooms, age, and location.

## 🔗 Analogy

Like the clues a detective collects - each clue (feature) helps solve the case.
