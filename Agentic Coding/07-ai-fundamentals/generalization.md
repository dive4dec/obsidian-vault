# Generalization

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

How well a model performs on new unseen data, not just the data it trained on.

## 📋 Concrete Example

A model that gets 99% on training data but only 60% on test data generalizes poorly.

## 🔗 Analogy

Like a student who truly understands the topic can solve new problems, not just the ones they memorized.
