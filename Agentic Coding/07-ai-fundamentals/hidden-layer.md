# Hidden Layer

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Layers between input and output where the network learns internal representations.

## 📋 Concrete Example

A hidden layer might detect edges in an image; a deeper one might detect shapes like ears or eyes.

## 🔗 Analogy

Like the kitchen of a restaurant - customers do not see it, but that is where the real work happens.
