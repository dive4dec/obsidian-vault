# Hyperparameters

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Settings chosen by the human before training, not learned from data.

## 📋 Concrete Example

Learning rate, number of layers, batch size, and number of epochs are hyperparameters you set before training starts.

## 🔗 Analogy

Like the rules of a game set before playing - the players (parameters) play within those rules.
