# Input Layer

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Receives the raw data, one neuron per feature. No computation - just passes values in.

## 📋 Concrete Example

For a 28x28 image, the input layer has 784 neurons, one per pixel.

## 🔗 Analogy

Like the front desk of a company - it receives visitors (data) and routes them inside.
