# Layers

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

A neural network is built from stacked layers, each transforming the data step by step.

## 📋 Concrete Example

A cat classifier might have an input layer (pixels), 3 hidden layers (features), and an output layer (cat or dog).

## 🔗 Analogy

Like a relay race: each runner (layer) takes the baton (data), transforms it, and hands it to the next runner.
