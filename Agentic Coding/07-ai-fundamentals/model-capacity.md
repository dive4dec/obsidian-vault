# Model Capacity

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

How complex a pattern the model can learn. More parameters usually means higher capacity.

## 📋 Concrete Example

A linear model has low capacity (straight lines only). A 100-layer network has very high capacity.

## 🔗 Analogy

Like a toolbox: a small kit can fix simple things, a big workshop can build complex machines.
