# Neural Network

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

A model inspired by the brain that can learn very complex patterns when given enough data.

## 📋 Concrete Example

A network with layers of connected neurons takes pixel values of a photo and outputs the probability it is a cat.

## 🔗 Analogy

Like a factory assembly line: each station (layer) processes the product a bit and passes it on until the final station gives the answer.
