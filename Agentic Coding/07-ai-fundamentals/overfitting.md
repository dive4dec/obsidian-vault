# Overfitting

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

The model memorizes training data including noise, so it fails on new data.

## 📋 Concrete Example

A student memorizes past-paper answers word for word but cannot solve a slightly different exam question.

## 🔗 Analogy

Like memorizing a map of your own neighborhood so well that you get lost anywhere else.
