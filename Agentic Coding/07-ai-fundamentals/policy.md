# Policy

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

In reinforcement learning, the strategy the agent uses to choose actions based on the current state.

## 📋 Concrete Example

A self-driving car policy might say: if the light is red, brake; if green and clear, go.

## 🔗 Analogy

Like a personal rulebook the agent follows, which it keeps rewriting to get more rewards.
