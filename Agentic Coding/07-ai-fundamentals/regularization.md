# Regularization

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Techniques that prevent overfitting by keeping the model simple or robust.

## 📋 Concrete Example

L2 regularization adds a penalty for large weights, encouraging the model to spread importance out.

## 🔗 Analogy

Like packing only essentials for a trip so you do not overpack and get slowed down.
