# Reward Signal

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

In reinforcement learning, the feedback (positive or negative) the agent receives after each action.

## 📋 Concrete Example

A game-playing agent gets +1 reward for winning a level and -1 for losing a life.

## 🔗 Analogy

Like a video game score - the player adjusts strategy to maximize points.
