# Sigmoid

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Squashes any number into the range 0 to 1, useful for probabilities and binary outputs.

## 📋 Concrete Example

Sigmoid(0) = 0.5, Sigmoid(10) is about 0.99995, Sigmoid(-10) is about 0.00005.

## 🔗 Analogy

Like a dimmer switch that can only go from off (0) to fully on (1), no matter how hard you twist.
