# Supervised Learning

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

We want the computer to learn a rule from labeled examples so it can predict on new data.

## 📋 Concrete Example

Show 100 photos of cats and dogs each labeled. The model learns to tell cats from dogs. Then it can label a new photo.

## 🔗 Analogy

Like a student doing past papers with answer keys - they learn the pattern, then tackle the exam.
