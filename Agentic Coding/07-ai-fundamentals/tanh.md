# Tanh

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Like sigmoid but outputs range -1 to 1, centered at zero. Often works better in hidden layers.

## 📋 Concrete Example

Tanh(0) = 0, Tanh(2) is about 0.964, Tanh(-2) is about -0.964.

## 🔗 Analogy

Like a steering wheel that can turn left (negative) or right (positive) but only so far each way.
