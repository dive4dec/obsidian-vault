# Transfer Learning

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Reuse knowledge learned on one task to help learn another task faster and better.

## 📋 Concrete Example

A model trained to recognize cars can be adapted to recognize trucks with much less data.

## 🔗 Analogy

Like learning to ride a bicycle first - that balance skill transfers when you learn a motorcycle.
