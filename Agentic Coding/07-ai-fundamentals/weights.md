# Weights

> **Domain:** [[_ai-fundamentals-moc|AI Fundamentals]]

## 🎯 Motivation

Weights decide how important each input is. Learning means adjusting weights to reduce errors.

## 📋 Concrete Example

If predicting house price, the weight on location might be large (important) and the weight on paint color small.

## 🔗 Analogy

Like volume sliders on a mixing desk - you turn up the inputs that matter and turn down the ones that do not.
