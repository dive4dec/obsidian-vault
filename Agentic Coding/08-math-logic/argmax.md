# Argmax

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Returns the index of the largest value. Used to pick the predicted class.

## 📋 Concrete Example

Scores [0.1, 0.7, 0.2]. Argmax = 1 (index of 0.7), so the prediction is class 1.

## 🔗 Analogy

Like picking the tallest student in class by their position in line, not by their height value.
