# Bayes Theorem

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Updates our belief when we see new evidence. The backbone of many reasoning systems.

## 📋 Concrete Example

If 1% of people are sick, and a test is 99% accurate, a positive test does not mean 99% chance of being sick - Bayes adjusts it.

## 🔗 Analogy

Like a detective updating the suspect list each time a new clue arrives.
