# Boolean Algebra

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Algebra of true/false values. The math behind computer logic gates and binary operations.

## 📋 Concrete Example

true AND false = false. true OR false = true. NOT true = false.

## 🔗 Analogy

Like light switches - two switches in series (AND) need both on; in parallel (OR) need at least one on.
