# Calculus

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The math of continuous change. Derivatives measure change; integrals accumulate it.

## 📋 Concrete Example

Calculus lets us compute how loss changes as weights change, which is how neural networks learn.

## 🔗 Analogy

Like the math of motion - derivatives are speed (instant change), integrals are distance (total accumulation).
