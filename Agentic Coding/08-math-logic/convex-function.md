# Convex Function

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A bowl-shaped function with one global minimum. Easy to optimize - any downhill path reaches the bottom.

## 📋 Concrete Example

f(x) = x squared is convex. Gradient descent always finds the bottom, no matter where you start.

## 🔗 Analogy

Like a smooth bowl - a marble rolled from anywhere will settle at the lowest point.
