# Derivative

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Measures how fast a function changes at a point. The slope of the tangent line.

## 📋 Concrete Example

For f(x) = x squared, the derivative is 2x. At x=3, slope is 6.

## 🔗 Analogy

Like a speedometer showing how fast your position changes at this instant.
