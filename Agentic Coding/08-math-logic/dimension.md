# Dimension

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The number of independent directions in a space. Each feature adds a dimension.

## 📋 Concrete Example

A 3-feature dataset (height, weight, age) is 3-dimensional. An image with 784 pixels is 784-dimensional.

## 🔗 Analogy

Like the axes on a graph - 2 axes is a flat plane, 3 axes is a 3D space, more axes are beyond what we can picture.
