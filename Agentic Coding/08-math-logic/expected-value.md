# Expected Value

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The long-run average of a random variable. What you would expect on average over many trials.

## 📋 Concrete Example

Rolling a fair 6-sided die: expected value = (1+2+3+4+5+6)/6 = 3.5. You won't roll 3.5, but over many rolls the average approaches it.

## 🔗 Analogy

Like the average score you would get playing a game many, many times - not any single game's score.
