# Function Composition

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Applying one function after another. Neural networks are deep compositions of simple functions.

## 📋 Concrete Example

If f(x) = x+1 and g(x) = x*2, then g(f(x)) = (x+1)*2. A 10-layer network composes 10 functions.

## 🔗 Analogy

Like a series of filters on a photo app - each filter feeds into the next, building the final image.
