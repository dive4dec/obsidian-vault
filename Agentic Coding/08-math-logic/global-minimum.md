# Global Minimum

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The absolute lowest point of the function. The goal of optimization.

## 📋 Concrete Example

For f(x) = x squared, the global minimum is at x=0, f(x)=0.

## 🔗 Analogy

Like the deepest point in the ocean - the true bottom, not just a local trench.
