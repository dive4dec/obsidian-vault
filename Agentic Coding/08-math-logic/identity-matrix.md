# Identity Matrix

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A matrix with 1s on the diagonal and 0s elsewhere. Multiplying by it changes nothing.

## 📋 Concrete Example

The 3x3 identity is [[1,0,0],[0,1,0],[0,0,1]]. Any matrix times identity equals itself.

## 🔗 Analogy

Like multiplying a number by 1 - the value stays exactly the same.
