# Independent Events

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Two events are independent if one happening does not change the probability of the other.

## 📋 Concrete Example

Coin flips are independent - getting heads on flip 1 does not change the odds for flip 2.

## 🔗 Analogy

Like two friends flipping coins separately - neither result affects the other.
