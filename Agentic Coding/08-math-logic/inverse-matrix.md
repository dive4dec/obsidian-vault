# Inverse Matrix

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A matrix that undoes another matrix. Multiplying them gives the identity matrix.

## 📋 Concrete Example

If A times B = identity, then B is the inverse of A. Used to solve linear systems.

## 🔗 Analogy

Like an undo button - apply matrix A, then its inverse, and you are back where you started.
