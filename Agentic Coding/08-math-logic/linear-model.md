# Linear Model

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The simplest model: output is a weighted sum of inputs plus a bias. A straight-line or flat-plane relationship.

## 📋 Concrete Example

Predict house price = 10000*area + 5000*rooms - 1000*age + 50000. A linear combination of features.

## 🔗 Analogy

Like a recipe: a fixed amount of each ingredient gives the result. No complex interactions.
