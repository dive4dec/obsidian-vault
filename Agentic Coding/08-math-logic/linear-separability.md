# Linear Separability

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

When classes can be separated by a straight line (or flat plane). Simple models can handle this; complex data needs more.

## 📋 Concrete Example

Cats vs dogs on a height-weight graph might be separable by a line. Cats vs dogs photos cannot.

## 🔗 Analogy

Like sorting coins by drawing a line - easy if they are clearly separated, impossible if mixed.
