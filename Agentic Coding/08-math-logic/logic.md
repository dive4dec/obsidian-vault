# Logic

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The formal rules of reasoning. AND, OR, NOT combine statements to reach conclusions.

## 📋 Concrete Example

If it is raining AND I have an umbrella, then I go out. If NOT raining, I go out without one.

## 🔗 Analogy

Like the rules of a board game - clear yes/no decisions that combine to determine the outcome.
