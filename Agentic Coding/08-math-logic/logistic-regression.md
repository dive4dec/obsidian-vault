# Logistic Regression

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A simple classification model using sigmoid to predict probabilities. The building block before neural networks.

## 📋 Concrete Example

Predict whether a student passes (1) or fails (0) based on study hours, using a sigmoid on a linear combination.

## 🔗 Analogy

Like a bouncer with a sliding scale - the more study hours you have, the higher your chance of getting in.
