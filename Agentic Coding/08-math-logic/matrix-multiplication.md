# Matrix Multiplication

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Combines two matrices to produce a new one. The core operation in every neural network layer.

## 📋 Concrete Example

A 3x2 matrix times a 2x4 matrix gives a 3x4 matrix. Each output cell is a dot product of a row and column.

## 🔗 Analogy

Like a factory assembly line where each station combines parts from two supply lines to make a new product.
