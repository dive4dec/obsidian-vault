# Matrix

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A grid of numbers. Used to store data and perform many calculations at once.

## 📋 Concrete Example

A class of 30 students each with 5 subject scores is a 30-row by 5-column matrix.

## 🔗 Analogy

Like a spreadsheet - rows are students, columns are subjects, each cell holds a number.
