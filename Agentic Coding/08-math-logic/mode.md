# Mode

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The most frequently occurring value in a dataset.

## 📋 Concrete Example

Shoe sizes sold: [36, 37, 38, 38, 38, 39]. Mode = 38 because it appears most.

## 🔗 Analogy

Like the most popular dish at a canteen - the one ordered most often.
