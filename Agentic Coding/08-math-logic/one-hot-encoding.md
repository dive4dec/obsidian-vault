# One-Hot Encoding

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Represents a category as a vector with a single 1 and the rest 0s. Lets models handle categorical data.

## 📋 Concrete Example

Three colors red, green, blue become [1,0,0], [0,1,0], [0,0,1]. No implied ordering.

## 🔗 Analogy

Like a multiple choice answer sheet - you fill exactly one bubble, leaving the rest blank.
