# Partial Derivative

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The derivative with respect to one variable while keeping others fixed. Used when functions have many inputs.

## 📋 Concrete Example

For f(x, y) = x*y, partial derivative with respect to x is y (treat y as constant).

## 🔗 Analogy

Like adjusting only the volume on a mixing desk while leaving all other sliders alone, to see the effect.
