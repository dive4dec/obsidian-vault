# Set Theory

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

The study of collections of objects. Foundation for logic, probability, and data operations.

## 📋 Concrete Example

The set of students who like math intersected with the set who like music gives students who like both.

## 🔗 Analogy

Like sorting toys into labeled boxes and then finding what is in common or different between boxes.
