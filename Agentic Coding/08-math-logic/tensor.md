# Tensor

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A generalization of vectors and matrices to any number of dimensions. The data format deep learning uses.

## 📋 Concrete Example

A color image is a 3D tensor: height x width x 3 color channels (RGB). A batch of 32 images is a 4D tensor.

## 🔗 Analogy

Like a cube of data, or even a hypercube - you can keep adding dimensions as needed.
