# Uniform Distribution

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

Every outcome has equal probability. No value is more likely than another.

## 📋 Concrete Example

Rolling a fair 6-sided die: each face has exactly 1/6 chance. Flat, not bell-shaped.

## 🔗 Analogy

Like a lottery where every ticket has the same chance of winning - no favorites.
