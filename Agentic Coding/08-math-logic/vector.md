# Vector

> **Domain:** [[_math-logic-for-ai-moc|Math & Logic for AI]]

## 🎯 Motivation

A list of numbers that represents a point or direction in space. The basic building block of data in AI.

## 📋 Concrete Example

A student can be represented as a vector: [Math=85, English=72, Science=90]. Each number is a feature.

## 🔗 Analogy

Like a GPS coordinate with three numbers (lat, long, altitude) that pinpoints a spot.
