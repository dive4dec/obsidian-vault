# Evaluation

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Measuring how good an NLP model is. Metrics include accuracy, F1, BLEU, and perplexity.

## 📋 Concrete Example

A translation model is evaluated with BLEU score comparing its output to human translations.

## 🔗 Analogy

Like a report card with different grades for different subjects - each metric measures a different aspect.
