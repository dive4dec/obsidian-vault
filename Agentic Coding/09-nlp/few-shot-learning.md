# Few-Shot Learning

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Giving the model a few examples in the prompt to help it understand the task before asking it to perform.

## 📋 Concrete Example

Prompt: Here are 3 examples of formal vs informal text... Now classify this new sentence. The model follows the pattern.

## 🔗 Analogy

Like showing a new employee 3 example emails before asking them to write one - they learn the style quickly.
