# Hallucination

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

When a language model confidently states false information as if it were true. A major challenge in NLP.

## 📋 Concrete Example

A model might say Hong Kong was founded in 1843 (wrong, it was 1842) with full confidence.

## 🔗 Analogy

Like a student who makes up an answer on an exam and writes it confidently - sounds right, but is wrong.
