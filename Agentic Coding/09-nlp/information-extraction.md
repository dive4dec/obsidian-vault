# Information Extraction

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Pulling structured facts from unstructured text. NER, relation extraction, and event extraction.

## 📋 Concrete Example

From Apple was founded in 1976, extract: (Apple, founded, 1976). Turns text into a database.

## 🔗 Analogy

Like panning for gold - you sift through raw text to find the valuable structured nuggets.
