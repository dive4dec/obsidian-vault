# Language Model

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

A model that assigns probabilities to sequences of text. Can predict the next word. The core of chatbots.

## 📋 Concrete Example

Given The sky is, a language model says blue is most likely (0.8), green less likely (0.05).

## 🔗 Analogy

Like a super-smart autocomplete on your phone that has read millions of books.
