# Machine Translation

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Automatically translates text from one language to another. Google Translate and DeepL use this.

## 📋 Concrete Example

Input: Good morning. Output (Chinese): zao shang hao. The model learns mappings between languages.

## 🔗 Analogy

Like a bilingual friend who reads a Chinese text and tells you what it means in English.
