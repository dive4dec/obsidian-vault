# Prompt Engineering

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Crafting the input prompt to get the best output from a language model. A key skill for using LLMs.

## 📋 Concrete Example

Adding Be specific and give 3 examples to a prompt can dramatically improve the response quality.

## 🔗 Analogy

Like asking a teacher the right question - a well-phrased question gets a much better answer.
