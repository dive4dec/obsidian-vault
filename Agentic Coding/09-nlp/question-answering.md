# Question Answering

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Given a question and a context passage, the model finds or generates the answer.

## 📋 Concrete Example

Question: When was Hong Kong established? Context: Hong Kong was established in 1842. Answer: 1842.

## 🔗 Analogy

Like a student reading a passage then answering comprehension questions from it.
