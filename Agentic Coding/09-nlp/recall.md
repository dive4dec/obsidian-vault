# Recall

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Of all the actual positive items, how many the model found. Measures completeness.

## 📋 Concrete Example

There are 15 real spam emails. Model finds 8. Recall = 8/15 = 0.53. It missed 7.

## 🔗 Analogy

Like a search and rescue team - of all the lost hikers, how many did they find.
