# Relation Extraction

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Finding relationships between entities in text. Builds knowledge graphs.

## 📋 Concrete Example

From Steve Jobs co-founded Apple, extract: (Steve Jobs, co-founded, Apple).

## 🔗 Analogy

Like connecting dots in a detective board - link people, companies, and events with strings.
