# Sentiment Analysis

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Determines if text is positive, negative, or neutral. Used for reviews, social media, and feedback.

## 📋 Concrete Example

This movie is great! is positive. The food was terrible and cold is negative.

## 🔗 Analogy

Like a mood ring for text - it tells you if the writer is happy, angry, or neutral.
