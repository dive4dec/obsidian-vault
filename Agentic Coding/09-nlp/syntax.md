# Syntax

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

The rules governing sentence structure and word order. Different from semantics (meaning).

## 📋 Concrete Example

Colorless green ideas sleep furiously is syntactically valid but semantically nonsensical.

## 🔗 Analogy

Like the grammar rules of a language - they tell you if a sentence is well-formed, not if it makes sense.
