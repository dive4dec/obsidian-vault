# Text Classification

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Assigning a category to a piece of text. Spam detection, sentiment analysis, and topic labeling are examples.

## 📋 Concrete Example

Email text -> model -> spam or not spam. News article -> model -> sports, politics, or tech.

## 🔗 Analogy

Like sorting mail into labeled folders - each piece of text goes into one category.
