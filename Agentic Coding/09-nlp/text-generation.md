# Text Generation

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

Producing new text token by token. The core capability of chatbots and writing assistants.

## 📋 Concrete Example

Prompt: Write a poem about Hong Kong. The model generates: Victoria Harbour gleams at night ...

## 🔗 Analogy

Like an author writing a story - each sentence builds on the last, creating something new.
