# Zero-Shot Learning

> **Domain:** [[_nlp-fundamentals-moc|NLP Fundamentals]]

## 🎯 Motivation

The model performs a task it has never been explicitly trained on, using only its general knowledge and the prompt.

## 📋 Concrete Example

Ask a model to classify sentiment of Cantonese text even if it was never trained on a sentiment task in Cantonese.

## 🔗 Analogy

Like a student tackling a brand new question type on an exam using general reasoning, never having practiced it.
