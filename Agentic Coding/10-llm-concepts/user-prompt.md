# User Prompt

> **Domain:** [[_llm-concepts-moc|LLM Concepts]]

## 🎯 Motivation

The user prompt is what you type - your actual question or request. The model responds based on both the system prompt and your user prompt.

## 📋 Concrete Example

User: 'How do I sort a list in Python?' - this is the user prompt. The model generates a response that follows the system prompt's rules while answering this question.

## 🔗 Analogy

What you say to a shop assistant - `I`m looking for red sneakers size 8'. The system prompt (training manual) tells the assistant how to behave, but your words (user prompt) determine what they help you with.
