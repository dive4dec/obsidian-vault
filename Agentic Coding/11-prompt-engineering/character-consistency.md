# Character Consistency

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

In role-play or long conversations, the model might break character. Techniques to maintain consistency include system prompts and periodic reminders.

## 📋 Concrete Example

System: 'You are Captain Hook. Stay in character.' After 10 turns, add: 'Remember, you are Captain Hook - use pirate language, reference Neverland.' The reminder maintains character consistency.

## 🔗 Analogy

An actor staying in character during a long play - between scenes, the director whispers 'stay in character' to prevent them from slipping. Character consistency techniques do this for LLMs.
