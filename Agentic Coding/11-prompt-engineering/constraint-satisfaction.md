# Constraint Satisfaction

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

The model must satisfy all constraints simultaneously. More constraints = harder for the model, but more precise output.

## 📋 Concrete Example

Constraints: 'Max 100 words, include the word pineapple, use second person, no questions, end with an exclamation mark.' The model must meet ALL constraints. Checking each one is constraint satisfaction.

## 🔗 Analogy

Following all traffic rules at once - speed limit, lane discipline, signals, seatbelt, no phone. You must satisfy ALL constraints simultaneously. Constraint satisfaction in prompting is the same challenge.
