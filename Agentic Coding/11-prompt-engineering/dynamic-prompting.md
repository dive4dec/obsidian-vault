# Dynamic Prompting

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Building prompts dynamically based on context, user profile, or previous interactions, rather than using a fixed template.

## 📋 Concrete Example

If the user is a beginner: prompt includes 'explain simply'. If advanced: 'be technical'. If they asked about Python before: 'continue with Python examples'. The prompt adapts.

## 🔗 Analogy

A tour guide adjusting their talk - for kids, they make it fun and simple. For adults, more detailed. For experts, they skip basics. Dynamic prompting adapts the LLM's `talk` to the audience.
