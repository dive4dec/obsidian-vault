# Edge Case

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Inputs that are unusual, extreme, or tricky - empty strings, very long text, special characters, multiple languages. Edge cases often break prompts.

## 📋 Concrete Example

Edge cases for a summarizer: empty text (nothing to summarize), 1-word text (already minimal), 100-page text (too long), text in mixed languages, text with only punctuation. A robust prompt handles all.

## 🔗 Analogy

The weird situations in driving - a roundabout with 5 exits, a traffic light that is both red and green, a road with no lines. Edge cases are the weird situations that test if your prompt truly works.
