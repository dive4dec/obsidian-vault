# Emotional Prompting

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Adding emotional language ('This is really important to me', 'I will tip $200 for a good answer') can surprisingly improve model performance.

## 📋 Concrete Example

'I desperately need this code to work for my final project. Please be extra careful and thorough.' Studies show emotional prompts can improve accuracy and thoroughness.

## 🔗 Analogy

Asking a friend for a favor - 'This means the world to me' vs 'Do this.' The emotional appeal makes your friend try harder. LLMs, trained on human text, respond similarly to emotional language.
