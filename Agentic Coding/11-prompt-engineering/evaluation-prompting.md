# Evaluation Prompting

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Using the model to evaluate its own or another model's output. A separate evaluation prompt scores the quality.

## 📋 Concrete Example

Prompt 1 generates an essay. Prompt 2: 'Rate this essay on clarity (1-5), grammar (1-5), and creativity (1-5). Explain each score.' The evaluation prompt provides structured quality assessment.

## 🔗 Analogy

A peer review system - one student writes the essay, another reviews and scores it. Evaluation prompting has the LLM play both roles: creator and reviewer.
