# Implicit Instruction

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Sometimes the model picks up instructions from context without them being explicitly stated - from examples, tone, or format of the prompt.

## 📋 Concrete Example

If your prompt is formatted as a table with headers, the model infers it should respond in table format - without you saying 'respond as a table.' The format implicitly instructs.

## 🔗 Analogy

Dressing formally to a meeting - nobody told you to wear a suit, but the context (fancy venue, executives present) implicitly instructs formal dress. The model reads implicit cues from the prompt.
