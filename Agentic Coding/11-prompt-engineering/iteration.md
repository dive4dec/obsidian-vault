# Iteration

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Rarely is the first prompt perfect. Iteration means testing, analyzing results, and refining the prompt until it works reliably.

## 📋 Concrete Example

Version 1: 'Summarize this.' -> Too long. Version 2: 'Summarize in 3 bullet points.' -> Better but misses key points. Version 3: 'Summarize the 3 most important points as bullet points.' -> Perfect.

## 🔗 Analogy

Editing an essay - the first draft is rarely good. You revise, get feedback, revise again. Each iteration improves the essay. Prompt iteration works the same way: each version is better than the last.
