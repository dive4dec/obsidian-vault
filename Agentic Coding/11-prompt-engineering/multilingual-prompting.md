# Multilingual Prompting

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

LLMs can handle multiple languages, but phrasing prompts in the target language or specifying language improves quality.

## 📋 Concrete Example

Instead of 'Translate this to Chinese' use 'Translate this to Traditional Chinese, as spoken in Hong Kong.' Or write the prompt in Chinese directly: 'Summarize this article in 3 points, in Cantonese.'

## 🔗 Analogy

Asking a bilingual friend for help - if you want a Chinese translation, you get better results asking in Chinese ('how do you say... in Chinese?') than in English. Specifying the language and variant helps.
