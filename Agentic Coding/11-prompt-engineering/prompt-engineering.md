# Prompt Engineering

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

The quality of an LLM's response depends heavily on how you ask. Prompt engineering is the skill of crafting inputs to get the best outputs.

## 📋 Concrete Example

Bad: 'Write code.' Good: 'Write a Python function that takes a list of numbers and returns the median. Include error handling for empty lists. Add comments explaining each step.'

## 🔗 Analogy

Giving directions to a taxi driver - 'Go that way' is useless. 'Turn left at the bank, go straight for 2 blocks, turn right at the red building' gets you there. Precision in the prompt gets precision in the result.
