# Prompt Library

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

A collection of tested, documented prompts organized by task, ready to reuse. Saves time and ensures quality.

## 📋 Concrete Example

Library categories: 'Summarization prompts', 'Code generation prompts', 'Classification prompts'. Each entry: prompt text, best temperature, example output, performance notes. Team members reuse and contribute.

## 🔗 Analogy

A recipe book in a restaurant - tested recipes, organized by category (appetizers, mains, desserts), with notes on each. New chefs use the book instead of inventing from scratch. A prompt library does this for prompts.
