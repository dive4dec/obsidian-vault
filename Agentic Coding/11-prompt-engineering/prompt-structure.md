# Prompt Structure

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

A well-structured prompt has clear sections: role, context, instruction, format, constraints. Structure helps the model parse the prompt correctly.

## 📋 Concrete Example

Structure: [Role] You are a tutor. [Context] Student is 14, learning Python. [Instruction] Explain for loops. [Format] Use code examples. [Constraints] Max 200 words. Each section is clearly delineated.

## 🔗 Analogy

A well-organized essay - Introduction, Body, Conclusion. Each section has a clear purpose. A jumbled essay is confusing. A structured prompt is like a well-organized essay: easy to follow.
