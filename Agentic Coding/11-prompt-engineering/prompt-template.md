# Prompt Template

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

When you use the same prompt structure repeatedly with different inputs, a prompt template saves time and ensures consistency.

## 📋 Concrete Example

Template: 'Summarize the following text in {n} bullet points: {text}'. Fill in n=3 and text=article. Reusable for any text and any number of points.

## 🔗 Analogy

A form letter template - 'Dear {name}, your appointment is on {date} at {time}.' You fill in the blanks. Same structure, different content each time. Efficient and consistent.
