# Prompt Versioning

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Keeping track of different prompt versions, their performance, and when to use which. Like version control for prompts.

## 📋 Concrete Example

v1.0: basic prompt (70% accuracy). v1.1: added examples (75%). v2.0: restructured with CoT (88%). Document each version's performance. When accuracy drops, revert to a known-good version.

## 🔗 Analogy

Saving game files - before a big boss fight, you save (version). If you lose, you reload the previous save. Prompt versioning saves good prompts so you can always revert if a new version is worse.
