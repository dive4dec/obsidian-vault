# Step-by-Step

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

The phrase `Let`s think step by step' is a powerful prompt addition that triggers chain-of-thought reasoning without explicit examples.

## 📋 Concrete Example

'A jacket costs $300 after a 20% discount. What was the original price? Let's think step by step.' Model: 'If current price is 80% of original, then original = 300 / 0.8 = $375.' The phrase triggers step-by-step reasoning.

## 🔗 Analogy

A coach saying 'slow down and think through each play' - just saying it causes the team to be more methodical. `Let`s think step by step' does the same for the LLM.
