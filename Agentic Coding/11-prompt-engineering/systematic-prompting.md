# Systematic Prompting

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Approaching prompt design systematically: define the task, identify required components, test, iterate, and document what works.

## 📋 Concrete Example

1) Task: classify emails. 2) Components: system role, examples, output format. 3) Test with 20 emails. 4) Iterate: add edge case examples. 5) Document: 'Best prompt: 5 examples, temperature 0, JSON output.'

## 🔗 Analogy

The scientific method for prompts - hypothesize (design prompt), experiment (test), analyze (check results), iterate (improve). Systematic prompting treats prompt design as a science, not guesswork.
