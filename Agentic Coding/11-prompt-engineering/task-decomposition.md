# Task Decomposition

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Breaking a complex task into smaller, manageable sub-tasks. Each sub-task gets its own prompt, and results are combined.

## 📋 Concrete Example

Instead of 'Build a website', decompose: 1) 'Design the layout', 2) 'Write the HTML', 3) 'Write the CSS', 4) 'Write the JavaScript'. Each is simpler and more reliable.

## 🔗 Analogy

Building IKEA furniture - instead of 'build a bookshelf', you follow steps: 1) assemble frame, 2) add shelves, 3) attach back panel. Each step is simple. Together they build the bookshelf.
