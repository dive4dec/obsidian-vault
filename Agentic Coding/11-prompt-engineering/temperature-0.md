# Temperature 0

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Temperature 0 means the model always picks the most likely token. Output is deterministic - same prompt gives same result every time.

## 📋 Concrete Example

Use temperature 0 for: code generation (you want reliable, reproducible code), data extraction (consistent format), factual answers (no creativity needed), testing (reproducible results).

## 🔗 Analogy

A straightforward delivery route - the driver takes the exact same route every time (temperature 0). No variation, no surprises. Perfect when you need reliability and reproducibility.
