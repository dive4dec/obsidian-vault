# Temperature Selection

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

Choosing the right temperature for the task: 0 for factual/code, 0.3-0.7 for balanced, 0.7-1.0 for creative writing.

## 📋 Concrete Example

Code generation: temperature 0 (deterministic, same code every time). Creative writing: temperature 0.8 (varied, creative). Data extraction: temperature 0 (consistent format).

## 🔗 Analogy

A thermostat - for sleeping, you set it cool (temperature 0, focused). For a party, warmer (temperature 0.8, lively). For precision tasks, low; for creativity, high. Match the temperature to the activity.
