# Variable

> **Domain:** [[_prompt-engineering-moc|Prompt Engineering]]

## 🎯 Motivation

In prompt templates, variables are placeholders filled with dynamic values at runtime - like function parameters.

## 📋 Concrete Example

Template: 'Translate {text} from {source_lang} to {target_lang}.' Variables: text=`Hello`, source_lang=`English`, target_lang=`French`. Filled: 'Translate Hello from English to French.'

## 🔗 Analogy

Blanks on a form - Name: ____, Date: ____, Signature: ____. You fill them in at runtime. Variables in prompt templates work the same way - placeholders for dynamic content.
