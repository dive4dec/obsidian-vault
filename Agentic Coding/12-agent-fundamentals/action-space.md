# Action Space

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The set of all possible actions an agent can take. A larger action space = more capable but harder to choose correctly.

## 📋 Concrete Example

A coding agent's action space: {read_file, write_file, run_command, search_web, call_api}. Each action has parameters. The agent must choose which action, with which parameters, at each step.

## 🔗 Analogy

A chess player's action space - all legal moves. Early in the game, about 20 moves. The player must choose the best one. Agents choose from their action space at each step.
