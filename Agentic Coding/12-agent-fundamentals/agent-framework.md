# Agent Framework

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

A software framework that provides the infrastructure for building agents: tool management, memory, planning, communication, and the agent loop.

## 📋 Concrete Example

LangChain, AutoGPT, CrewAI, and Hermes Agent are frameworks. They provide: tool registration, memory backends, planning strategies, multi-agent coordination, and the core agent loop - so you focus on the task, not infrastructure.

## 🔗 Analogy

A stage production framework - the theater provides lighting, sound, stage, and backstage infrastructure. You just bring the script and actors. Agent frameworks provide the infrastructure; you bring the goals and tools.
