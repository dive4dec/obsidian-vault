# Agent Lifecycle

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The full lifecycle: initialization -> planning -> execution -> monitoring -> termination -> cleanup.

## 📋 Concrete Example

1) Init: load config, tools, memory. 2) Plan: decompose goal. 3) Execute: run agent loop. 4) Monitor: track progress, errors. 5) Terminate: goal reached or stop condition. 6) Cleanup: save state, free resources.

## 🔗 Analogy

The lifecycle of a caterpillar - egg (init), caterpillar (execute), chrysalis (monitor), butterfly (terminate), egg-laying (cleanup). Each phase has a purpose. The agent lifecycle structures an agent's existence.
