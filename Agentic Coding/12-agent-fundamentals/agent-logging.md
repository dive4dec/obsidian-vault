# Agent Logging

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Recording every agent action, thought, and observation to a log file for debugging, auditing, and improvement.

## 📋 Concrete Example

Log entry: '[2025-08-03 14:32:01] THOUGHT: Need to read file. ACTION: read_file(main.py). OBSERVATION: 150 lines, contains function sort_data. NEXT: Check sort_data for bugs.'

## 🔗 Analogy

A ship's logbook - the captain records every course change, weather condition, and event. If something goes wrong later, the log shows what happened. Agent logging does this for AI actions.
