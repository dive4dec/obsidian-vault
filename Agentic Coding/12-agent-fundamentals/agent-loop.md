# Agent Loop

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The core cycle: perceive -> think -> act -> observe -> think -> act... until the goal is reached or a stop condition is met.

## 📋 Concrete Example

The loop: 1) Read user request. 2) Think about plan. 3) Execute action 1. 4) Observe result. 5) Think again. 6) Execute action 2. 7) Observe. 8) Think: goal reached? 9) Respond to user.

## 🔗 Analogy

Washing dishes - pick up plate (act), check if clean (observe), scrub more if needed (think + act), rinse (act), check (observe), put away (act), next plate. The loop continues until all dishes are done.
