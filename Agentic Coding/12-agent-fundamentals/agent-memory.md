# Agent Memory

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Agents need to remember facts, past actions, and context across steps and sessions. Memory makes them more capable over time.

## 📋 Concrete Example

Without memory, the agent re-explains the same concept every time. With memory, it remembers 'I explained for loops to this user already' and builds on that. Memory enables continuity.

## 🔗 Analogy

A student's notebook - without it, they relearn every lesson. With it, they build on previous knowledge. Agent memory is the notebook that lets agents accumulate knowledge.
