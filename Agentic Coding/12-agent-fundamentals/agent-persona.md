# Agent Persona

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The personality and communication style the agent adopts, shaped by its system prompt and training.

## 📋 Concrete Example

Persona: 'I am a patient, encouraging coding tutor who uses gaming analogies. I celebrate progress and never make students feel bad for mistakes.' This persona shapes every interaction.

## 🔗 Analogy

A teacher's classroom persona - some are strict and formal, others are warm and joke-filled. The persona shapes how students experience the class. Agent personas shape how users experience the agent.
