# Agent Termination

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

How and when an agent stops: goal achieved, max steps, error, timeout, or human stop command.

## 📋 Concrete Example

Goal achieved: 'Task complete, exiting.' Max steps: '50/50 steps used, stopping.' Error: 'Critical error, cannot continue.' Timeout: '30-minute limit reached.' Human: user clicks `Stop.`

## 🔗 Analogy

A train reaching its final station - it stops because it arrived (goal), ran out of track (max steps), had a breakdown (error), or the operator stopped it (human). Termination conditions are the station stops for agents.
