# Audit Trail

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

A complete, tamper-proof record of all agent actions for accountability, compliance, and security review.

## 📋 Concrete Example

Audit trail: 'Agent deleted file temp.log at 14:32. Approved by user Alice at 14:31. Reason: cleanup.' If something goes wrong, the audit trail shows who approved what and when.

## 🔗 Analogy

Bank transaction records - every deposit, withdrawal, and transfer is logged permanently. If there is a dispute, the records prove what happened. An agent audit trail does this for AI actions.
