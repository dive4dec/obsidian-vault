# Autonomy

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The degree to which an agent can operate without human intervention. More autonomy = more useful but also more risk.

## 📋 Concrete Example

Level 0: suggests actions for human approval. Level 5: takes actions independently. Most practical agents are Level 2-3: act with guardrails.

## 🔗 Analogy

A self-driving car - Level 0 is cruise control, Level 5 is fully autonomous. Most current driving assistants are Level 2-3. Same spectrum applies to AI agents.
