# Concurrency

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Multiple agents running simultaneously, doing different tasks in parallel. Faster than sequential but requires coordination.

## 📋 Concrete Example

Agent A researches while Agent B writes code while Agent C sets up tests - all simultaneously. When they finish, results are combined. Parallel work is faster than doing one task at a time.

## 🔗 Analogy

A kitchen with multiple chefs - one chops vegetables, one prepares sauce, one cooks rice - all at the same time. Dinner is ready faster than if one chef did everything sequentially.
