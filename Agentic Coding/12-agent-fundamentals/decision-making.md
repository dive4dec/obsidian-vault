# Decision Making

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

At each step, the agent must decide what to do next. This involves reasoning about the goal, observations, and available actions.

## 📋 Concrete Example

The agent observes: 'compilation failed with SyntaxError on line 5.' It reasons: 'There is a syntax error. I should read line 5 and fix it.' Decision: call read_file with line 5.

## 🔗 Analogy

A doctor diagnosing a patient - they observe symptoms, consider possible treatments (actions), and decide on the best one. Agents do this with information and tools.
