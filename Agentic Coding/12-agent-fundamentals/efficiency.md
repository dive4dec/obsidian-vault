# Efficiency

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Minimizing wasted resources - tokens, time, API calls - while achieving the goal. Efficient agents do more with less.

## 📋 Concrete Example

Inefficient: 50 API calls to write a simple function. Efficient: 5 API calls with better planning. Efficiency means choosing the right actions, avoiding redundant steps, and using cheaper models when possible.

## 🔗 Analogy

Fuel-efficient driving - smooth acceleration, planning routes, not idling. You reach the same destination using less fuel. Efficient agents reach the same goal using fewer resources.
