# Environment

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The world the agent operates in - it could be a filesystem, a web browser, a database, or a physical space via robots.

## 📋 Concrete Example

A coding agent's environment: the filesystem, terminal, code repos, web search. A web agent's environment: the browser, URLs, page content. The environment defines what the agent can perceive and affect.

## 🔗 Analogy

A fish tank vs a forest - a fish (agent) in a tank (environment) can swim and eat flakes. A fox in a forest can run and hunt. The environment shapes what actions are possible.
