# Goal Decomposition

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Complex goals need breaking down. The agent decomposes 'Build a website' into design, frontend, backend, testing, deployment.

## 📋 Concrete Example

Goal: 'Organize a workshop.' Sub-goals: book venue, send invitations, prepare materials, order food. Each sub-goal might further decompose: 'send invitations' -> email, social media, posters.

## 🔗 Analogy

Breaking a big LEGO build into sub-builds - the instruction manual breaks a 2000-piece castle into sections: build the walls, then the tower, then the gate. Each section is achievable.
