# Improvement Loop

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The cycle: attempt -> evaluate -> reflect -> improve -> attempt again. Each iteration makes the agent better at the task.

## 📋 Concrete Example

Loop 1: write code, test, fail, reflect. Loop 2: fix code, test, pass partially, reflect. Loop 3: fix remaining, test, all pass, reflect on lessons. Each loop improves the result.

## 🔗 Analogy

Practice in sports - swing (attempt), check form (evaluate), get coaching (reflect), adjust (improve), swing again. Each practice loop makes the swing better. The improvement loop does this for agents.
