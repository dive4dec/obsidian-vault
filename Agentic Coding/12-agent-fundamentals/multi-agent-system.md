# Multi-Agent System

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Multiple agents working together, each with different roles, communicating and coordinating to solve complex problems.

## 📋 Concrete Example

Agent A: researcher (finds information). Agent B: coder (writes code). Agent C: reviewer (checks quality). They pass results to each other: A finds API docs, B writes code using them, C reviews B's code.

## 🔗 Analogy

A restaurant kitchen - chef (plans), sous-chef (prepares), line cook (cooks), expediter (checks quality). Each has a role; they coordinate to produce the meal. Multi-agent systems do this with AI agents.
