# Parallel Processing

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Running multiple agent actions or multiple agents simultaneously to complete tasks faster.

## 📋 Concrete Example

Instead of: search (10s) -> read (5s) -> analyze (10s) = 25s total. Parallel: search + read + analyze simultaneously = 10s total. Parallel processing cuts time when tasks are independent.

## 🔗 Analogy

Doing laundry - instead of washing, then drying, then folding one load at a time (sequential), you wash load 2 while drying load 1 while folding load 0 (parallel). Everything finishes faster.
