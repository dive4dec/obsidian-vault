# Performance Metric

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Quantitative measures of agent quality: success rate, steps taken, tokens used, time elapsed, cost incurred.

## 📋 Concrete Example

Metrics: 'Task completed: Yes. Steps: 12. Tokens: 4500. Time: 45s. Cost: $0.09.' These numbers let you compare agents and track improvements over time.

## 🔗 Analogy

School report card - Math: A, English: B, Science: A-. Each grade (metric) measures a specific subject. Performance metrics do this for agents: success rate, efficiency, speed.
