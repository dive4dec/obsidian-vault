# Planning Algorithm

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The method an agent uses to create and refine plans. Common approaches: tree search, graph search, LLM-based planning.

## 📋 Concrete Example

ReAct: think-act-observe loop. Tree of Thoughts: explore multiple plans, pick the best. Plan-and-Execute: create full plan, then execute each step.

## 🔗 Analogy

A GPS navigation system computing routes - it explores multiple paths (planning algorithm), estimates traffic, and picks the best route. Agents do this with tasks instead of roads.
