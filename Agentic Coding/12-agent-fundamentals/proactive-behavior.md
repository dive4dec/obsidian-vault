# Proactive Behavior

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Instead of only responding to requests, a proactive agent anticipates needs and takes initiative.

## 📋 Concrete Example

The agent notices the user's code has no tests. Without being asked, it suggests: 'I notice there are no unit tests. Would you like me to write some?' It anticipates a need.

## 🔗 Analogy

A good assistant who notices your desk is cluttered and organizes it before you ask. Proactive agents do things before being told, when they see a need.
