# Reactive Behavior

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The agent responds to events - a new message, a file change, an error - in real-time. Reactive agents are event-driven.

## 📋 Concrete Example

A file watcher: when a file changes, the agent automatically re-runs tests. When a new email arrives, it auto-summarizes. It reacts to events rather than waiting for instructions.

## 🔗 Analogy

A motion-sensor light - it turns on when it detects movement (reactive). It does not wait for someone to flip the switch. Reactive agents respond to events automatically.
