# Responsibility

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

With autonomous agents, defining who is responsible for outcomes - the developer, the user, the agent itself - is a key ethical question.

## 📋 Concrete Example

If an agent books a wrong flight, who pays? The developer (bug in code)? The user (gave wrong instructions)? The agent (made wrong decision)? Clear responsibility assignment prevents confusion.

## 🔗 Analogy

A delivery driver damages a package - is it the driver's fault (they were careless), the company's fault (no training), or the customer's fault (bad address)? Responsibility in agent systems is similarly complex.
