# Role Assignment

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

In multi-agent systems, each agent gets a specific role with specialized capabilities and responsibilities.

## 📋 Concrete Example

Roles: Planner (creates task breakdown), Researcher (finds information), Coder (writes code), Tester (runs tests), Reviewer (checks quality). Each role has specific tools and instructions.

## 🔗 Analogy

Positions on a football team - quarterback (throws), receiver (catches), lineman (blocks). Each position has specific skills and responsibilities. Role assignment does this for agents.
