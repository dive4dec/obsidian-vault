# Self-Evaluation

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The agent assesses its own output quality before presenting it to the user. This catches errors and improves reliability.

## 📋 Concrete Example

The agent writes code, then self-evaluates: 'Does this handle empty input? No - I need to add a check. Is the variable naming clear? Yes.' It fixes issues before showing the user.

## 🔗 Analogy

A student proofreading their essay before submitting - they check for errors, clarity, and completeness. Self-evaluation is the agent proofreading its own work.
