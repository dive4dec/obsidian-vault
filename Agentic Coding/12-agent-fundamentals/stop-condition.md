# Stop Condition

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The agent needs to know when to stop - goal achieved, max steps reached, error detected, or human intervention.

## 📋 Concrete Example

Stop conditions: 'Task complete' (goal achieved), '50 steps done' (max iterations), 'API error 3 times' (error threshold), 'User said stop' (human override). Without stop conditions, agents loop forever.

## 🔗 Analogy

A runner's finish conditions - crossing the finish line (goal), collapsing from exhaustion (max limit), injury (error), or a red flag (human override). The agent needs similar stopping rules.
