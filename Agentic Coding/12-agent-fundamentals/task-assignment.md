# Task Assignment

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

In a multi-agent system, tasks must be assigned to the right agent based on capabilities, availability, and workload.

## 📋 Concrete Example

Agent A (researcher) gets 'find API documentation.' Agent B (coder) gets 'implement the API.' Agent C (tester) gets 'write tests.' Assignment matches agent capabilities to task requirements.

## 🔗 Analogy

A coach assigning positions - the tall player gets center, the fast player gets wing, the accurate shooter gets point guard. Task assignment matches agent skills to task needs.
