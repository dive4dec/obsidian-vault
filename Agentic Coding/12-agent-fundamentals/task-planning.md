# Task Planning

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

To achieve a goal, the agent must break it into sub-tasks and decide the order. Planning is creating that roadmap.

## 📋 Concrete Example

Goal: 'Write a blog post about AI.' Plan: 1) Research topic, 2) Create outline, 3) Write draft, 4) Edit, 5) Publish. Each sub-task is manageable; together they achieve the goal.

## 🔗 Analogy

A project manager creating a Gantt chart - breaking a big project into phases, tasks, and sub-tasks with dependencies. The agent does this mentally before acting.
