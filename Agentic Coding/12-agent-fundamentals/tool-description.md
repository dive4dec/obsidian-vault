# Tool Description

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

The description tells the agent what a tool does and when to use it. A good description is crucial - the agent chooses tools based on descriptions.

## 📋 Concrete Example

Bad: 'Calculator tool.' Good: 'Performs exact arithmetic calculations. Use when you need precise math (addition, subtraction, multiplication, division, percentages). Do not use for estimation.'

## 🔗 Analogy

A menu description at a restaurant - 'Spicy Sichuan noodles with chili oil and peanuts' tells you exactly what you get. A vague `noodles` does not help you choose. Tool descriptions guide the agent's choice.
