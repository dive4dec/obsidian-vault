# Tool Use

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

Agents extend their capabilities by using tools - APIs, calculators, search engines, code interpreters, file systems.

## 📋 Concrete Example

Without tools, an LLM can only generate text. With a calculator tool, it can do exact math. With a search tool, it can find current information. With a code tool, it can run programs.

## 🔗 Analogy

A person using tools - without a hammer, you can't drive a nail. Without a phone, you can't call someone. Tools extend what agents can do beyond just talking.
