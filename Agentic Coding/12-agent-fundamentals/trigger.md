# Trigger

> **Domain:** [[_agent-fundamentals-moc|Agent Fundamentals]]

## 🎯 Motivation

A specific event or condition that starts the agent's action. Triggers can be time-based, event-based, or condition-based.

## 📋 Concrete Example

Triggers: 'Every Monday 9am' (time), 'When a file is uploaded' (event), 'When CPU > 90%' (condition). The trigger starts the agent's workflow.

## 🔗 Analogy

A starting pistol at a race - the pistol (trigger) starts the runners. Different triggers start different agent workflows: a timer, a webhook, a threshold.
