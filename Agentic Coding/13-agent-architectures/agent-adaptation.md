# Agent Adaptation

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The agent adjusts its behavior based on the current task, user, or context - not one-size-fits-all.

## 📋 Concrete Example

For a beginner user: agent explains step by step with simple language. For an expert: agent is concise and technical. Same agent, different behavior based on context.

## 🔗 Analogy

A teacher adapting to different classes - for beginners, they explain basics slowly. For advanced students, they go fast and deep. Agent adaptation customizes behavior to the situation.
