# Agent Benchmarking

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Systematically comparing different agent architectures on standardized tasks to find the best design.

## 📋 Concrete Example

Benchmark: 5 architectures x 10 tasks x 3 runs = 150 evaluations. Measure: success rate, steps, tokens, time. Architecture X wins on coding, Architecture Y wins on research.

## 🔗 Analogy

Car comparison testing - 5 cars x 10 road types (highway, city, off-road). Measure speed, fuel, comfort. Find the best car for each road type. Agent benchmarking finds the best architecture for each task type.
