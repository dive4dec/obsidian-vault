# Agent Composition

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Building complex agents by combining simpler agents, like building with blocks.

## 📋 Concrete Example

Compose: SearchAgent + SummarizeAgent + TranslateAgent = NewsTranslator. SearchAgent finds news, SummarizeAgent condenses, TranslateAgent translates. Three simple agents composed into one complex agent.

## 🔗 Analogy

Building with Lego - a wheel + axle + chassis = a car. Simple pieces composed into complex structures. Agent composition builds complex agents from simpler ones.
