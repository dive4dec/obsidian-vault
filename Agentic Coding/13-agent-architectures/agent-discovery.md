# Agent Discovery

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Finding and selecting the right agent for a task from the registry. May involve capability matching and availability checks.

## 📋 Concrete Example

Task: 'Write Python tests.' Discovery: search registry for agents with `python` and `testing` skills, that are available. Find TestAgent. Assign task.

## 🔗 Analogy

Finding a plumber - you search online directories for 'plumber near me, available today.' You find one with good reviews and assign the job. Agent discovery does this for AI agents.
