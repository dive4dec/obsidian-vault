# Agent Feedback Loop

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Collecting user feedback on agent performance and using it to improve future behavior.

## 📋 Concrete Example

User rates agent's code: '4/5, good but missing comments.' Feedback stored. Next time, agent adds comments. The feedback loop improves the agent over time.

## 🔗 Analogy

Restaurant comment cards - customers rate food and service. The manager reads them and improves. Next time, the food is better. Agent feedback loops use user ratings to improve.
