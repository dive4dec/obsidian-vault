# Agent Registry

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

A directory of available agents, their capabilities, and how to contact them. Essential for multi-agent coordination.

## 📋 Concrete Example

Registry: {`CoderAgent`: {skills: [`python`, `javascript`], endpoint: 'agent://coder', available: true}, `TestAgent`: {skills: [`pytest`, `unittest`], endpoint: 'agent://tester', available: false}}

## 🔗 Analogy

A company directory - 'Marketing: Jane (SEO, social media), Engineering: Bob (Python, Java).' You look up who has the skills you need. An agent registry does this for AI agents.
