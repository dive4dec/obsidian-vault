# Agent Specialization

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Designing each agent to excel at one specific type of task rather than being a generalist.

## 📋 Concrete Example

A general coding agent: writes code at 70% quality. A specialized Python agent: writes Python at 95%. A specialized SQL agent: writes SQL at 95%. Specialization makes each agent an expert in its domain.

## 🔗 Analogy

Medical specialists - a general doctor treats common illnesses, but a cardiologist treats hearts better, and a neurologist treats brains better. Specialization makes each agent an expert in its narrow field.
