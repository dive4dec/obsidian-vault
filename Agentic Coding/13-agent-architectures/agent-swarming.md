# Agent Swarming

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Many simple agents working together like a swarm, each doing small tasks, with emergent collective intelligence.

## 📋 Concrete Example

100 simple agents each search one page of documentation. Individually simple, but together they cover 100 pages. The collective result is comprehensive.

## 🔗 Analogy

Ants building a colony - each ant does simple tasks (carry dirt, feed larvae). No single ant knows the plan. Together, they build a complex colony. Agent swarms achieve complex results through simple individual actions.
