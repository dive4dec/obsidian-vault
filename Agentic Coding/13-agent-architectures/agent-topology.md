# Agent Topology

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The communication structure between agents: star (hub-spoke), ring, mesh, tree, or custom.

## 📋 Concrete Example

Star: all agents talk to orchestrator only. Ring: A->B->C->A. Mesh: every agent talks to every other. Tree: hierarchical parent-child. Topology affects speed, reliability, and complexity.

## 🔗 Analogy

Office communication structures - star (everyone goes through the boss), ring (pass messages around the team), mesh (everyone talks to everyone), tree (managers and subordinates). Topology shapes how agents communicate.
