# Agentic Workflow

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The designed flow of an agent's actions: what triggers it, what steps it takes, what tools it uses, and how it terminates.

## 📋 Concrete Example

Workflow: 1) Receive code review request. 2) Read code files. 3) Run static analysis. 4) Check for security issues. 5) Write review comments. 6) Submit. Each step is designed and documented.

## 🔗 Analogy

A restaurant's order-to-table workflow - receive order, prep ingredients, cook, plate, garnish, serve. Each step is designed. Agentic workflows structure how agents work from start to finish.
