# Architecture Selection

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Choosing the right agent architecture for a specific task based on requirements.

## 📋 Concrete Example

Simple Q&A: Reflex agent (fast, simple). Multi-step coding: ReAct (adaptive). Large project: Hierarchical (delegates). High-stakes: Semi-autonomous (human approval). Match architecture to needs.

## 🔗 Analogy

Choosing transportation - to school: walk (simple). To Kowloon: MTR (medium). To Shenzhen: high-speed rail (complex). Match the vehicle to the distance. Architecture selection matches the agent to the task.
