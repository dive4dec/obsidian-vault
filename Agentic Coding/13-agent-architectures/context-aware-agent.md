# Context-Aware Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The agent considers context - who the user is, what they asked before, what tools are available - when deciding actions.

## 📋 Concrete Example

Context: user is 14 years old, asked 3 Python questions today, prefers short answers. Agent adapts: gives brief, Python-specific, teen-friendly answers. Context shapes every decision.

## 🔗 Analogy

A tour guide who reads their group - families with kids get fun, simple tours. Adult history buffs get detailed, academic tours. Context-aware agents adapt to their user and situation.
