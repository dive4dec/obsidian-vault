# Deterministic Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent whose behavior is fully predictable - same input always produces same actions. Useful for testing and safety.

## 📋 Concrete Example

With temperature 0 and fixed seed, the agent always takes the same actions for the same input. Deterministic agents are reproducible and auditable.

## 🔗 Analogy

A vending machine - press A1, always get the same snack. No randomness. Deterministic agents are like vending machines: same input, same output, every time.
