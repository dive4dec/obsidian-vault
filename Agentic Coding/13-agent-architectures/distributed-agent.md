# Distributed Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent that runs across multiple machines, coordinating over a network. Enables larger-scale tasks.

## 📋 Concrete Example

A web-crawling agent runs on 10 servers: Server 1 crawls pages 1-1000, Server 2 crawls 1001-2000, etc. Results are merged centrally. One task, distributed across machines.

## 🔗 Analogy

A chain of restaurants - each branch (machine) cooks the same menu but serves a different area. Together, they serve the whole city. Distributed agents scale across machines.
