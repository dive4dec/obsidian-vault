# Emergent Behavior

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Complex, intelligent behavior arising from many simple agents following simple rules - without any central controller.

## 📋 Concrete Example

Each agent: 'if you find a bug, fix it and tell neighbors.' 100 agents on a codebase: they find and fix 500 bugs, coordinate without overlap, and clean up the codebase. No one directed this - it emerged.

## 🔗 Analogy

A flock of birds - each bird follows simple rules (stay close, do not collide, match speed). No leader. Yet the flock moves as one fluid shape. Emergent behavior is complexity from simplicity.
