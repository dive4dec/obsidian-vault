# Expert System

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent (or system) that encodes human expert knowledge in a specific domain and uses it to make expert-level decisions.

## 📋 Concrete Example

Medical expert system: symptoms -> possible diagnoses -> recommended tests -> treatment options. It encodes a doctor's decision-making process.MYCIN was an early expert system for bacterial infections.

## 🔗 Analogy

A senior doctor who has seen 10,000 patients - their experience (encoded knowledge) lets them diagnose quickly. Expert systems encode this experience as rules or patterns.
