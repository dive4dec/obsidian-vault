# Goal-Based Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The agent has explicit goals and searches for action sequences that achieve them, rather than just reacting.

## 📋 Concrete Example

Goal: 'deploy the app.' The agent searches for a path: build -> test -> containerize -> push -> deploy. It evaluates which actions move toward the goal.

## 🔗 Analogy

A navigator with a destination - they do not just turn left when they see a left sign. They plan a route to their destination (goal) and follow it. Goal-based agents navigate toward goals.
