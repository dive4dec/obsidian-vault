# Hierarchical Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Complex tasks are managed by a top-level agent that delegates sub-tasks to lower-level specialist agents.

## 📋 Concrete Example

Top agent: 'Build a web app.' Delegates to: Design Agent (UI), Backend Agent (API), Database Agent (schema). Each sub-agent handles its specialty and reports back.

## 🔗 Analogy

A CEO delegating to department heads - the CEO (top agent) says 'launch a product.' Engineering (sub-agent) builds it, Marketing (sub-agent) promotes it, Sales (sub-agent) sells it. Each department reports to the CEO.
