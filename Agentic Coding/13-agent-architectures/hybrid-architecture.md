# Hybrid Architecture

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Combining multiple architectures: e.g., a hierarchical agent that uses ReAct for planning and rule-based for safety checks.

## 📋 Concrete Example

Top: Orchestrator (hierarchical). Middle: Specialist agents (multi-agent). Each specialist: ReAct loop with rule-based safety guardrails. Combines strengths of each architecture.

## 🔗 Analogy

A hybrid car - it uses both gasoline engine and electric motor, switching between them for optimal performance. Hybrid architectures combine multiple approaches for the best overall result.
