# Mesh Topology

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Every agent can communicate with every other agent directly. Most flexible but most complex.

## 📋 Concrete Example

Agent A can talk to B, C, D directly. B can talk to A, C, D. No hub needed. Great for collaboration but many communication channels to manage.

## 🔗 Analogy

A group chat where everyone can message everyone - fast and flexible, but with 20 people, there are 190 possible conversations. Hard to track. Mesh topology is flexible but complex at scale.
