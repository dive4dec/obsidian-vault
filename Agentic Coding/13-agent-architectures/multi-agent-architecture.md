# Multi-Agent Architecture

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

Multiple agents collaborate, each with specialized roles. More complex but handles larger, more diverse tasks.

## 📋 Concrete Example

Team: Researcher Agent (finds info), Coder Agent (writes code), Tester Agent (tests), Reviewer Agent (reviews). They communicate and coordinate to build software together.

## 🔗 Analogy

A film crew - director, camera operator, sound engineer, editor. Each specializes. Together they make a movie that no single person could make alone. Multi-agent architectures work the same way.
