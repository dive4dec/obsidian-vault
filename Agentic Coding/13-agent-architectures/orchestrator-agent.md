# Orchestrator Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

A central agent that coordinates other agents - deciding who does what, when, and combining results.

## 📋 Concrete Example

Orchestrator receives: 'Build a landing page.' Assigns: Design Agent (mockup), Coder Agent (HTML/CSS), Copy Agent (text). Collects results, combines them, delivers final page.

## 🔗 Analogy

A symphony conductor - they do not play any instrument, but they coordinate all musicians. Each musician plays their part; the conductor ensures they work together. The orchestrator conducts the agent orchestra.
