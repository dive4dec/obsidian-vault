# Reflex Architecture

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

The simplest agent: no planning, no memory. It directly maps observations to actions. Fast but limited.

## 📋 Concrete Example

Observation: 'user says hello' -> Action: 'respond with greeting'. No planning, no memory of past interactions. Like a reflex - knee tap triggers kick.

## 🔗 Analogy

A reflex action - doctor taps your knee, your leg kicks. No thinking involved. Reflex agents map input to output directly, like a reflex.
