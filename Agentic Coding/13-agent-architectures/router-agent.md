# Router Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent that classifies incoming requests and routes them to the right specialist agent.

## 📋 Concrete Example

Router sees: 'Fix this Python bug.' Routes to: Coding Agent. Sees: 'Translate this.' Routes to: Translation Agent. Sees: 'Summarize this.' Routes to: Summarization Agent.

## 🔗 Analogy

A hospital triage nurse - they assess each patient and route them to the right department: broken bone to orthopedics, chest pain to cardiology. The router agent triages requests to specialists.
