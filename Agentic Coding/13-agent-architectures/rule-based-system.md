# Rule-Based System

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent that follows explicit if-then rules. Predictable and explainable but limited to what the rules cover.

## 📋 Concrete Example

Rules: IF temp > 38 AND cough = true THEN suggest 'see doctor'. IF temp < 37 AND cough = false THEN suggest `healthy`. Each rule covers a specific scenario.

## 🔗 Analogy

A recipe - IF water boils THEN add pasta. IF pasta is soft THEN drain. Each step is an if-then rule. Rule-based systems follow recipes of rules, predictable but inflexible.
