# Semi-Autonomous Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent that works independently on safe tasks but asks for human approval on risky ones.

## 📋 Concrete Example

Agent auto-reads files, searches, and drafts code (autonomous). But to delete a file or deploy to production, it asks: 'I want to delete old_logs/. Approve?' (semi-autonomous).

## 🔗 Analogy

A learner driver with a permit - they drive independently on quiet roads but must have a licensed adult for highways. Semi-autonomous agents handle easy tasks alone, ask for help on risky ones.
