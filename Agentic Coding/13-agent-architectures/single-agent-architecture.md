# Single-Agent Architecture

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

One agent handles everything: planning, tool use, memory, response. Simple to build but can be overwhelmed by complex tasks.

## 📋 Concrete Example

One agent: reads the request, plans, searches the web, writes code, tests it, fixes bugs, and responds. No delegation - all roles in one agent.

## 🔗 Analogy

A solo entrepreneur - they do marketing, coding, accounting, and customer service all by themselves. It works for small projects but gets overwhelming for large ones.
