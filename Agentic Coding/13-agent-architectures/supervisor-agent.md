# Supervisor Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

An agent that monitors other agents, ensuring they stay on task, follow rules, and produce quality output.

## 📋 Concrete Example

Supervisor watches: CoderAgent is spending too many tokens. Supervisor intervenes: 'You are over budget. Wrap up and submit what you have.' It oversees and corrects.

## 🔗 Analogy

A floor manager in a factory - they walk around, check that workers are productive and safe, and intervene if something is wrong. Supervisor agents oversee other agents' work.
