# Utility-Based Agent

> **Domain:** [[_agent-architectures-moc|Agent Architectures]]

## 🎯 Motivation

When multiple actions could achieve a goal, the agent picks the one with the highest utility (best outcome).

## 📋 Concrete Example

Two paths to deploy: Path A (fast but risky) utility=0.6, Path B (slower but safe) utility=0.8. The agent chooses Path B because it has higher utility.

## 🔗 Analogy

A shopper comparing products - two phones meet your needs (goal), but you pick the one with better battery life and lower price (higher utility). Utility-based agents optimize for the best outcome.
