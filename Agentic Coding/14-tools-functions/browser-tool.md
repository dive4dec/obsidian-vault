# Browser Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that lets the agent browse websites, click links, fill forms, and extract information - like a human using a browser.

## 📋 Concrete Example

Agent: navigate to `amazon.com`, search for `laptop`, filter by price < 5000, extract top 5 results with prices. It can comparison shop autonomously.

## 🔗 Analogy

A personal shopper going to stores - they walk in, browse shelves, compare prices, and pick the best deal. Browser tools let agents be personal shoppers on the web.
