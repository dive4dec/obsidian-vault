# Budget Management

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Setting and enforcing spending limits for tools. The agent stops using paid tools when the budget is reached.

## 📋 Concrete Example

Budget: $1.00/day. At $0.85 spent, agent warns: 'Approaching budget limit.' At $1.00, it stops: 'Budget exhausted. Free tools only.' It manages its own spending.

## 🔗 Analogy

A prepaid phone card - you have $50 credit. Each call costs money. When credit runs out, you cannot call anymore. Budget management gives agents a prepaid card for tool spending.
