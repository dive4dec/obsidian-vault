# Calculator Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool for exact arithmetic. LLMs are bad at math (they approximate); calculators are exact.

## 📋 Concrete Example

LLM alone: 'What is 2347 * 891?' might say '2,091,000' (wrong). With calculator: exact answer 2,091,177. The calculator tool eliminates math errors.

## 🔗 Analogy

A student using a calculator vs mental math - mental math might give 'about 2 million' (LLM approximation). A calculator gives the exact answer. Calculator tools make agents precise at math.
