# Calendar Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that lets the agent view, create, and manage calendar events. Useful for scheduling and reminders.

## 📋 Concrete Example

Agent: check calendar for free slots, schedule a meeting at 3pm Friday, send invites. It manages time and scheduling.

## 🔗 Analogy

A personal assistant with a planner - they check your schedule, find free time, book appointments, and remind you. Calendar tools let agents manage schedules.
