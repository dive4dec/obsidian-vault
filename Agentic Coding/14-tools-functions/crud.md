# CRUD

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Create, Read, Update, Delete - the four basic operations for managing data. Most tools and APIs revolve around CRUD.

## 📋 Concrete Example

A student database tool: create_student (C), get_student (R), update_student (U), delete_student (D). Every data management tool does these four operations.

## 🔗 Analogy

Managing a contact list - add a contact (Create), look up a number (Read), change an address (Update), remove a contact (Delete). CRUD covers all data operations.
