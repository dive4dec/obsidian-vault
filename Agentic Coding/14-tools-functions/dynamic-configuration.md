# Dynamic Configuration

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

The agent's tools, memory, and behavior can be changed at runtime without restarting. Enables flexible, adaptive agents.

## 📋 Concrete Example

At runtime: add a new tool `translate_text`, change temperature to 0.5, increase max_steps to 100. The agent adapts without restarting.

## 🔗 Analogy

Adjusting your phone settings - turn on WiFi, change brightness, add a new app. All without restarting the phone. Dynamic configuration lets agents adjust on the fly.
