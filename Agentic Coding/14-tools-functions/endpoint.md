# Endpoint

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A specific URL where an API can be accessed. Each endpoint handles a different operation.

## 📋 Concrete Example

GET /api/students -> list all. GET /api/students/123 -> get one. POST /api/students -> create. PUT /api/students/123 -> update. Each URL is a different endpoint.

## 🔗 Analogy

Extensions in an office phone system - dial 101 for Sales, 102 for Engineering, 103 for HR. Each extension (endpoint) reaches a different department. API endpoints work the same way.
