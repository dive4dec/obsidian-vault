# File System Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Tools that let the agent read, write, and manage files on disk. Essential for coding agents.

## 📋 Concrete Example

Tools: read_file(path), write_file(path, content), list_dir(path), delete_file(path). A coding agent uses these to navigate code, edit files, and manage projects.

## 🔗 Analogy

A filing cabinet - you can open drawers (list_dir), take out files (read_file), put in new files (write_file), and throw away old ones (delete_file). File system tools give agents a digital filing cabinet.
