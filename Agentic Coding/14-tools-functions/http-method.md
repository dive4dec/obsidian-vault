# HTTP Method

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

The type of action in an HTTP request: GET (read), POST (create), PUT (update), DELETE (remove).

## 📋 Concrete Example

GET /users/123: retrieve user 123. POST /users: create a new user. PUT /users/123: update user 123. DELETE /users/123: delete user 123. Each method is a different action.

## 🔗 Analogy

CRUD operations in a library - Read (GET a book), Create (POST a new book record), Update (PUT new info on a book), Delete (DELETE a book). HTTP methods are CRUD for the web.
