# Image Generation Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that lets the agent generate images from text descriptions. Combines language understanding with visual creation.

## 📋 Concrete Example

Agent calls: generate_image(prompt='a red panda wearing a space suit, digital art') -> returns an image URL. The agent can create visual content.

## 🔗 Analogy

A graphic designer - you describe what you want ('a logo with a blue circle and white text'), and they create it. Image generation tools let agents be graphic designers.
