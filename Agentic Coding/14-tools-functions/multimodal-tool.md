# Multimodal Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that handles multiple types of input/output: text, images, audio, video. Makes the agent capable beyond text.

## 📋 Concrete Example

A multimodal agent: reads text (articles), views images (diagrams), listens to audio (podcasts), and watches video (lectures). It can process any content type.

## 🔗 Analogy

An all-in-one media center - it plays music (audio), shows movies (video), displays photos (images), and reads text (news). Multimodal tools give agents all-media capabilities.
