# SQL

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Structured Query Language - the standard language for querying relational databases. A powerful tool for data retrieval.

## 📋 Concrete Example

`SELECT name, age FROM students WHERE age > 15 ORDER BY name` - gets names and ages of students over 15, sorted alphabetically. SQL lets you ask precise data questions.

## 🔗 Analogy

Asking a librarian in their specialized language - 'Find me all fiction books published after 2020 by Chinese authors, sorted by title.' SQL is the specialized language for asking databases questions.
