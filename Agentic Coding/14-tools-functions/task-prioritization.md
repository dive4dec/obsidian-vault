# Task Prioritization

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Deciding which tasks are most important or urgent and should be done first.

## 📋 Concrete Example

Priority 1 (urgent): fix production bug. Priority 2 (important): write tests. Priority 3 (nice to have): refactor code. The agent does P1 first, then P2, then P3 if time allows.

## 🔗 Analogy

A fire brigade triage - rescue trapped people first (P1), then put out the fire (P2), then investigate the cause (P3). Task prioritization orders work by urgency and importance.
