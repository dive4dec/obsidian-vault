# Text-to-Speech Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that converts text to audio. Useful for accessibility, language learning, and content creation.

## 📋 Concrete Example

Agent calls: text_to_speech(text='Hello, how are you?', voice=`en-US`) -> returns an audio file. The agent can produce spoken content.

## 🔗 Analogy

A radio announcer reading a script - the text (script) is converted to audio (broadcast). Text-to-speech tools let agents convert their text responses into spoken audio.
