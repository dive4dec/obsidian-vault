# Tool Combination

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Using multiple tools together to accomplish a task that no single tool could handle alone.

## 📋 Concrete Example

Agent: search_web (find article) + code_interpreter (analyze data from article) + write_file (save results). Three tools combined accomplish a research task.

## 🔗 Analogy

Using multiple kitchen tools - blender (mix), oven (bake), fridge (chill). No single tool makes a cake. Tool combination lets agents tackle complex, multi-step tasks.
