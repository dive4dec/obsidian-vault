# Tool Cost Tracking

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

Some tools cost money per use (API calls, cloud services). Tracking cost per tool call helps manage budgets.

## 📋 Concrete Example

Cost log: search_web: $0.001/call x 50 calls = $0.05. Image generation: $0.02/call x 5 = $0.10. Total: $0.15. If budget is $0.20, 5 more searches are OK. Cost tracking prevents overspending.

## 🔗 Analogy

Tracking spending on a trip - taxi: $30, lunch: $50, tickets: $20. Total: $100. If budget is $150, you have $50 left. Tool cost tracking budgets agent spending.
