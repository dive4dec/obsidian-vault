# Web Search Tool

> **Domain:** [[_tools-function-calling-moc|Tools & Function Calling]]

## 🎯 Motivation

A tool that lets the agent search the internet for current information. Overcomes the knowledge cutoff limitation.

## 📋 Concrete Example

Agent searches: 'latest Python version 2025' -> results: 'Python 3.13 released October 2025.' The agent uses this to give an accurate, current answer.

## 🔗 Analogy

A student using the library - instead of relying only on their textbook (training data), they search the library (web search) for the latest information. Web search gives agents access to current knowledge.
