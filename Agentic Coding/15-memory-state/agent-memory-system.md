# Agent Memory System

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Without memory, an agent is stuck in the present - it cannot learn from past interactions or plan for the future. A memory system gives it continuity.

## 📋 Concrete Example

The agent remembers: 'User Alice prefers Python, is a beginner, and we covered loops last week.' Next session, it continues from where they left off, rather than starting over.

## 🔗 Analogy

A student's notebook and brain - the notebook (external memory) stores facts, the brain (internal memory) remembers experiences. Together, they let the student build on past learning. Agent memory systems do this digitally.
