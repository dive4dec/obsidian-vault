# Associative Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Memories retrieved by association/similarity rather than by exact key or position. 'Reminds me of...' retrieval.

## 📋 Concrete Example

User mentions `recursion.` Agent retrieves memories associated with `recursion`: the nesting doll analogy used last week, the factorial example, the student's question about infinite loops. Associative retrieval by topic.

## 🔗 Analogy

Smell of cookies reminding you of grandma - the smell (query) triggers memories of grandma (associative retrieval). You did not search by date or name; the association triggered the memory. Associative memory works by similarity.
