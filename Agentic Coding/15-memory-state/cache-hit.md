# Cache Hit

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

When needed information is found in fast memory (cache/context window) without needing to search slower memory.

## 📋 Concrete Example

User asks about `loops` - this was discussed 5 minutes ago, still in context window. Cache hit! No need to search long-term memory. Instant response.

## 🔗 Analogy

Finding the book you need already on your desk (cache hit) vs having to go to the library to find it (cache miss). Cache hits are fast and efficient.
