# Conversation Summary

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

A compressed version of the conversation history. Captures key points without keeping every word.

## 📋 Concrete Example

Summary: 'User is learning Python. Covered: variables (understood), loops (needs practice), functions (not yet covered). User is 14, likes games.' 50 tokens instead of 5000.

## 🔗 Analogy

CliffsNotes for a novel - instead of reading 300 pages, you read a 10-page summary that captures the key plot points. Conversation summaries do this for chat history.
