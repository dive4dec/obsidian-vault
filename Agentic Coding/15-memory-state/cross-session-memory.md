# Cross-Session Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Memories that persist across multiple sessions. The agent remembers past sessions and builds on them.

## 📋 Concrete Example

Session 1: user learns loops. Session 2 (next day): agent recalls 'we did loops yesterday, ready for functions today.' Cross-session memory creates continuity.

## 🔗 Analogy

A TV series - each episode (session) builds on previous ones. You remember what happened in episode 1 when watching episode 2. Cross-session memory gives agents episodic continuity.
