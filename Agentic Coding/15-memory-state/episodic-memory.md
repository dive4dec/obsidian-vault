# Episodic Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Remembering specific past events - what happened, when, and in what context. Like remembering a specific conversation.

## 📋 Concrete Example

Episodic: 'On August 1, user asked about recursion. I explained with nesting dolls. They understood.' This specific event is stored and can be recalled.

## 🔗 Analogy

Your memory of your first day at school - you remember the specific event, what happened, how you felt. Episodic memory stores specific experiences for the agent.
