# Fact Checking

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Verifying that stored memories/facts are still accurate. The agent should not blindly trust old memories.

## 📋 Concrete Example

Agent recalls: 'User said they like Java.' But user just said 'I hate Java.' Fact check: update memory. The agent verifies memories against current evidence.

## 🔗 Analogy

A journalist verifying a source - they do not just trust a claim; they check it against other evidence. Fact checking ensures the agent's memories remain accurate.
