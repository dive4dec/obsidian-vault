# Forgetting

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Intentionally discarding memories that are no longer useful. Just as important as remembering - prevents clutter and confusion.

## 📋 Concrete Example

The agent forgets: 'temporary variable name from last debugging session.' It remembers: 'user prefers Python.' Forgetting prevents memory overload and keeps retrieval fast.

## 🔗 Analogy

Cleaning your locker - you throw away old scratch paper (forget) but keep your textbooks (remember). Forgetting keeps the agent's memory clean and relevant.
