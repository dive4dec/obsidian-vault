# Importance Filtering

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Not all information is equally valuable. The agent must decide what to remember and what to forget.

## 📋 Concrete Example

Score each piece of information: 'User name' = high importance (always remember). 'User said thanks' = low importance (forget). 'User is learning Python' = high importance. Filter by score.

## 🔗 Analogy

Sorting mail - bills and important letters go in the filing cabinet (high importance). Junk mail goes in the trash (low importance). Importance filtering does this for agent memories.
