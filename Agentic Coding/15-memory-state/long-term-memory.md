# Long-Term Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Persistent storage that survives across sessions. The agent can recall facts, preferences, and past experiences days or months later.

## 📋 Concrete Example

Agent stores in a database: 'Alice is learning Python. She struggles with recursion. She likes game analogies.' Next month, the agent retrieves this and tailors its teaching.

## 🔗 Analogy

A diary you keep for years - you write down important events. Years later, you read it and remember. Long-term memory lets the agent recall past experiences across sessions.
