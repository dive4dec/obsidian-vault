# Memory Access Pattern

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

How the agent accesses memory - sequential (reading history in order), random (jumping to specific memories), or associative (finding by similarity).

## 📋 Concrete Example

Sequential: read last 5 messages. Random: get memory by key `user_name`. Associative: find memories similar to 'Python loops'. Different patterns for different needs.

## 🔗 Analogy

How you use a library - browsing shelves in order (sequential), looking up a specific book by call number (random), or asking 'books about space' (associative). Different access patterns for different needs.
