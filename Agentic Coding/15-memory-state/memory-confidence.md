# Memory Confidence

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

How sure the agent is about a memory. High confidence = trust it. Low confidence = verify before using.

## 📋 Concrete Example

Confidence: 'User name is Alice' = 0.99 (stated clearly). 'User might be interested in AI' = 0.4 (inferred from a vague comment). Low-confidence memories are used cautiously.

## 🔗 Analogy

A witness's certainty - 'I saw the red car' (high confidence) vs 'I think it might have been red' (low confidence). Memory confidence helps the agent decide how much to trust each memory.
