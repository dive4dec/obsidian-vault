# Memory Conflict

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

When memories contradict each other. The agent must resolve which is correct.

## 📋 Concrete Example

Memory A: 'User likes Python.' Memory B: 'User said they prefer Java.' Conflict! Resolution: check recency (B is newer), check context (B was about a specific project). Resolve: 'User generally likes Python but used Java for one project.'

## 🔗 Analogy

Two friends giving conflicting directions - 'turn left' vs 'turn right.' You resolve by checking: who knows the area better? Who is more recent? Memory conflict resolution picks the most reliable memory.
