# Memory Consolidation

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

The process of moving important information from short-term to long-term memory. Not everything is worth remembering.

## 📋 Concrete Example

After a productive session: 'User learned about loops. This is important.' -> consolidate to long-term memory. 'User said hi' -> not important, discard.

## 🔗 Analogy

A student reviewing notes after class - they highlight important points (consolidate to long-term memory) and ignore casual chatter (discard). Memory consolidation filters what is worth remembering.
