# Memory Decay

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Old, unused memories fade over time. This prevents memory overflow and keeps the most relevant memories fresh.

## 📋 Concrete Example

Memory from 6 months ago that has not been accessed: importance score drops from 0.9 to 0.3. Eventually, it is archived or deleted. Recent, frequently accessed memories stay strong.

## 🔗 Analogy

Forgetting old phone numbers - you used to know your friend's old number, but since they changed it, the old one fades. Memory decay lets agents forget irrelevant old information.
