# Memory Indexing

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Organizing memories with tags, timestamps, and metadata so they can be found quickly when needed.

## 📋 Concrete Example

Each memory has: {timestamp, tags, importance, type}. Example: {time: '2025-08-01', tags: [`python`, `loops`, `teaching`], importance: 0.9, type: `episodic`}. Indexed for fast retrieval.

## 🔗 Analogy

A library catalog system - each book has a catalog entry (index) with author, title, subject, date. You search the catalog to find the book. Memory indexing catalogs memories for fast search.
