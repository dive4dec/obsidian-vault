# Memory Key

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

A label or tag used to store and retrieve memories. Like a filename for a memory.

## 📋 Concrete Example

Store memory with key: `user_preference_language`. Retrieve: get_memory(`user_preference_language`) -> `Python`. Keys make retrieval precise and fast.

## 🔗 Analogy

Labels on file folders - 'Taxes 2024', 'Medical Records', `Photos.` You find what you need by reading the labels. Memory keys label memories for easy retrieval.
