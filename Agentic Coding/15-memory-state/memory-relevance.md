# Memory Relevance

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

How relevant a stored memory is to the current task. The agent should retrieve the most relevant memories first.

## 📋 Concrete Example

Current task: 'debug Python code.' Relevant memories: 'past Python bugs' (relevance 0.9), 'user preferences' (0.3), 'yesterday lunch chat' (0.01). Retrieve most relevant first.

## 🔗 Analogy

A student studying for a math exam - they retrieve math notes (relevant) not history notes (irrelevant). Memory relevance ensures the agent finds the most useful memories for the current task.
