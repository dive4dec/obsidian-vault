# Memory Retrieval

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Finding relevant memories when needed. The agent must search its long-term memory for information related to the current task.

## 📋 Concrete Example

User asks about 'that Python thing we discussed.' Agent searches long-term memory: finds 'We discussed for loops on August 1.' Retrieves the relevant memory and uses it.

## 🔗 Analogy

Searching your memory for a fact - 'Where did I put my keys?' You mentally search through recent memories. Memory retrieval is the agent searching its stored memories for relevant information.
