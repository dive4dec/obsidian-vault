# Memory Staleness

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Memories that are outdated or no longer accurate. The agent must detect and update stale memories.

## 📋 Concrete Example

Stale memory: 'Python 3.11 is the latest version' (stored 2023). Reality: Python 3.13 is out. The memory is stale. The agent should update it.

## 🔗 Analogy

An old map - it shows a road that has been closed. The map (memory) is stale. You need a new map (update). Memory staleness is the agent's information going out of date.
