# Memory Update

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

When new information contradicts or supplements old memories, the agent must update its stored knowledge.

## 📋 Concrete Example

Old memory: 'User is a beginner.' New info: 'User just built a web app.' Update: 'User is intermediate - built a web app.' The memory is corrected, not just added to.

## 🔗 Analogy

Correcting a wrong note - you wrote 'Paris is the capital of Germany' (wrong). Later you learn it is France. You update the note. Memory updates correct and refine stored knowledge.
