# Metadata

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Data about data - information about a memory beyond its content: when it was created, who said it, importance level, tags.

## 📋 Concrete Example

Metadata for a memory: {source: `user_statement`, confidence: 0.9, tags: [`python`, `preference`], created: '2025-08-01', access_count: 5}. Metadata enriches the memory for better retrieval.

## 🔗 Analogy

A library catalog entry - beyond the book itself, it has metadata: author, publisher, year, genre, page count, ISBN. Metadata helps you find and evaluate the book. Memory metadata does this for agent memories.
