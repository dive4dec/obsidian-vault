# Personalization

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Tailoring the agent's behavior, language, and examples to the specific user based on their profile.

## 📋 Concrete Example

Alice (14, beginner, likes games): 'A for loop is like repeating a level in a game.' Bob (16, advanced, likes math): 'A for loop iterates over an iterable with O(n) complexity.' Same concept, different framing.

## 🔗 Analogy

A tutor adapting to each student - for a sporty kid, they use sports analogies. For a musical kid, they use music analogies. Personalization makes the agent relevant to each user.
