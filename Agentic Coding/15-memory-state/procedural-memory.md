# Procedural Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Knowing how to do things - skills, procedures, workflows. Like knowing how to ride a bike.

## 📋 Concrete Example

Procedural: 'To debug: 1) read error, 2) find the line, 3) understand the issue, 4) fix, 5) test.' This procedure is stored and applied whenever debugging is needed.

## 🔗 Analogy

Muscle memory for riding a bike - you do not think about each movement. Your body just knows how to do it. Procedural memory stores how-to knowledge for the agent.
