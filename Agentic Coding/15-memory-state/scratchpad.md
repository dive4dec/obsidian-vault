# Scratchpad

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

A temporary workspace where the agent writes intermediate results, plans, and notes during a task. Cleared when the task is done.

## 📋 Concrete Example

Scratchpad during debugging: 'Error on line 5. Check: variable types. Found: x is string, needs int. Fix: int(x). Test: passed.' Temporary notes that guide the current task.

## 🔗 Analogy

A whiteboard during a math exam - you write intermediate steps, cross things out, try different approaches. When the exam is over, the board is erased. A scratchpad is the agent's whiteboard.
