# Semantic Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

General knowledge and facts - not tied to a specific event. Like knowing that Python is a programming language.

## 📋 Concrete Example

Semantic: 'Python is a programming language. Lists are mutable. Recursion needs a base case.' These are facts, not specific events. The agent knows them regardless of when it learned them.

## 🔗 Analogy

Knowing that Paris is the capital of France - you do not remember when you learned this (episodic), you just know it (semantic). Semantic memory stores general facts for the agent.
