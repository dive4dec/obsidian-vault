# Short-Term Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

The current conversation context - recent messages, current task state. Limited by the context window. Resets when the conversation ends.

## 📋 Concrete Example

During a chat: the agent remembers the last 20 messages. This is short-term memory. When you start a new chat, it is gone - fresh start.

## 🔗 Analogy

Your working memory during a conversation - you remember what was said in the last few minutes. But tomorrow, you might forget the details. Short-term memory is the agent's working memory.
