# Temporal Ordering

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

Memories are stored with timestamps, allowing the agent to recall events in chronological order.

## 📋 Concrete Example

Memories: [14:00 'started task', 14:15 'read file', 14:20 'found bug', 14:25 'fixed bug']. Temporal ordering lets the agent reconstruct the timeline of events.

## 🔗 Analogy

A timeline in a history book - events are placed in order: 1997 handover, 2003 SARS, 2019 protests. Temporal ordering lets the agent understand the sequence of past events.
