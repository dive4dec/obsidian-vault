# Timestamp

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

A record of when an event or memory occurred. Essential for temporal ordering and memory decay.

## 📋 Concrete Example

Each memory: {content: 'user learned loops', timestamp: '2025-08-01T14:30:00Z', last_accessed: '2025-08-03T10:00:00Z'}. Timestamps enable ordering and decay.

## 🔗 Analogy

Date stamps on letters - each letter has a postmark date. You can sort letters chronologically and know which are old. Timestamps do this for agent memories.
