# User Profile

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

A stored model of the user - their preferences, skill level, goals, history. Enables personalized interactions.

## 📋 Concrete Example

Profile: {name: `Alice`, age: 14, skill: 'beginner Python', interests: [`gaming`, `music`], learning_style: `visual`, past_topics: [`loops`, `lists`]}. The agent uses this to tailor every response.

## 🔗 Analogy

A teacher's notes on each student - 'Alice: visual learner, likes games, struggling with recursion. Bob: fast learner, loves math.' The teacher adapts lessons. User profiles let agents do the same.
