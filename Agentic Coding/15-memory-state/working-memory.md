# Working Memory

> **Domain:** [[_memory-state-moc|Memory & State]]

## 🎯 Motivation

The active part of short-term memory - what the agent is currently thinking about. Analogous to human working memory.

## 📋 Concrete Example

The agent is debugging: working memory holds the error message, the relevant code, and the current fix attempt. Once the bug is fixed, this is cleared for the next task.

## 🔗 Analogy

Mental scratchpad - when doing mental math (23 x 17), you hold intermediate results (23, 17, 230, 161, 391) in your working memory. Once done, you forget the intermediate steps.
