# Bug Reproduction

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Consistently reproducing a bug is the first step to fixing it. The model can help create minimal reproduction cases.

## 📋 Concrete Example

Bug: 'App crashes sometimes.' Reproduction: 'Open app, click Settings, click Back, click Settings again -> crash.' Now reproducible. The model helps find the exact steps.

## 🔗 Analogy

Recreating a magic trick - the magician repeats the trick to see exactly where the rabbit disappears. Bug reproduction finds the exact steps that trigger the bug.
