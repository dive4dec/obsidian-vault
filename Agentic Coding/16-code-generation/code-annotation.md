# Code Annotation

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Adding explanatory notes to code. The model can annotate existing code for learning or documentation.

## 📋 Concrete Example

Annotation: 'line 5: This sorts by price because the user requested cheapest-first. The key=lambda uses the price field for sorting.' Explains why, not just what.

## 🔗 Analogy

Notes in a textbook margin - 'This formula is used in physics for calculating velocity.' The note explains the formula's purpose. Code annotations explain code's purpose.
