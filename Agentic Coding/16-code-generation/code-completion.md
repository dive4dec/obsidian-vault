# Code Completion

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

As you type code, the model predicts and suggests the rest of the line or block. Like autocomplete for programming.

## 📋 Concrete Example

You type 'for i in r' and the model suggests 'for i in range(len(list)):' with the rest of the loop body. Press Tab to accept.

## 🔗 Analogy

Autocomplete on your phone - you type 'See you' and it suggests `tomorrow`. Code completion is autocomplete for code, suggesting the next line or block.
