# Code Diff

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

A showing of what changed between two versions of code. Essential for reviewing AI-generated changes.

## 📋 Concrete Example

Diff: '+ def is_prime(n):' (added line) '- def prime(n):' (removed line). The diff shows exactly what the model changed, so you can review it.

## 🔗 Analogy

Before/after photos - you see what changed. Code diffs show what was added (+) and removed (-), so you can review the model's changes.
