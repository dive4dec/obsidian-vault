# Code Documentation

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

The model generates documentation for code: docstrings, README files, API docs, comments.

## 📋 Concrete Example

Model reads a function and generates: 'Args: n (int): number to check. Returns: bool: True if prime. Raises: ValueError if n < 2. Example: is_prime(7) -> True.'

## 🔗 Analogy

A technical writer creating a manual - they use the product, understand how it works, and write a guide. Code documentation is the model writing the manual for code.
