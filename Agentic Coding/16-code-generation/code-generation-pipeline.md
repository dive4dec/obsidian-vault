# Code Generation Pipeline

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

The end-to-end process: understand request -> plan -> generate code -> test -> fix -> deliver. Each step uses the LLM.

## 📋 Concrete Example

Pipeline: 1) User: 'Build a todo app.' 2) Plan: HTML, CSS, JS, localStorage. 3) Generate each file. 4) Run in browser. 5) Fix errors. 6) Deliver working app.

## 🔗 Analogy

A factory production line - raw materials -> shaping -> assembly -> painting -> quality check -> shipping. Each station adds value. The code generation pipeline is an assembly line for software.
