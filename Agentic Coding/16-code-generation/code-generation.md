# Code Generation

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Writing code is time-consuming. LLMs can generate code from natural language descriptions, speeding up development enormously.

## 📋 Concrete Example

You type: 'Write a Python function to check if a number is prime.' The model generates: 'def is_prime(n): ...' with correct logic, comments, and even tests.

## 🔗 Analogy

A master chef who can cook any dish from a description - 'I want something spicy with chicken and rice.' They produce a complete recipe and cook it. Code generation does this with programming.
