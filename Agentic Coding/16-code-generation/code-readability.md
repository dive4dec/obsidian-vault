# Code Readability

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

How easy code is to read and understand. Readable code is maintainable code. The model can improve readability.

## 📋 Concrete Example

Readable: 'def calculate_average(scores): return sum(scores) / len(scores)'. Unreadable: 'def avg(s): return sum(s)/len(s)'. Same logic, but the first is clearer.

## 🔗 Analogy

A well-formatted essay vs a wall of text - paragraphs, headings, and clear sentences make it readable. Code readability does this for code.
