# Code Review

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

The model reads code and provides feedback: bugs, security issues, style violations, improvement suggestions.

## 📋 Concrete Example

Model reviews: 'This function works but: 1) No error handling for empty lists, 2) Variable name x is unclear, 3) Could use a list comprehension for efficiency.' Specific, actionable feedback.

## 🔗 Analogy

A teacher grading an essay - they read it, identify errors, and suggest improvements. Code review is the model grading code and suggesting how to make it better.
