# Code Smell

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Signs that code might have deeper problems - not bugs, but warning signs. The model can identify smells.

## 📋 Concrete Example

Smells: 'Function is 200 lines long' (too complex), 'Variable named x1' (unclear), '5 levels of nesting' (hard to follow). Not bugs, but signs of trouble.

## 🔗 Analogy

A bad smell in a fridge - it might not be the milk; it could be something else. But the smell warns you to check. Code smells warn you to investigate.
