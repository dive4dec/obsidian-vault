# Code Snippet

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

A small piece of reusable code. The model can generate snippets for common tasks on demand.

## 📋 Concrete Example

Snippet request: 'How to read a CSV file in Python?' Model: 'import csv; with open("data.csv") as f: reader = csv.reader(f); for row in reader: print(row)' Ready to use.

## 🔗 Analogy

Pre-cut ingredients at a supermarket - instead of chopping vegetables yourself, you buy pre-cut ones. Code snippets are pre-cut code pieces, ready to use.
