# Code Translation

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Converting code from one programming language to another. The model understands the logic and rewrites it in a different language.

## 📋 Concrete Example

Python: 'def greet(name): return f"Hello, {name}"' -> JavaScript: 'function greet(name) { return `Hello, ${name}`; }'. Same logic, different language.

## 🔗 Analogy

A translator converting a book from Chinese to English - the story stays the same, but the language changes. Code translation does this with programming languages.
