# Debugging

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Finding and fixing bugs in code. The model can help identify the source of errors and suggest fixes.

## 📋 Concrete Example

Debugging process: 1) Reproduce the error. 2) Read the error message. 3) Find the problematic code. 4) Understand the cause. 5) Fix it. 6) Test the fix. The model assists at each step.

## 🔗 Analogy

A detective solving a crime - find evidence (error message), identify the suspect (buggy code), understand the motive (root cause), and make an arrest (fix). Debugging is detective work.
