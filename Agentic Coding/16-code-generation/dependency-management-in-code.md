# Dependency Management in Code

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Managing external libraries and their versions. The model can suggest and install dependencies.

## 📋 Concrete Example

Model: 'You need requests for HTTP. I added it to requirements.txt. Also, you need Python 3.10+ for the match statement you are using.' Manages dependencies automatically.

## 🔗 Analogy

Managing ingredients for a bakery - you need flour, sugar, eggs. You track what you have and what you need. Dependency management tracks code libraries the same way.
