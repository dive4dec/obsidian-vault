# IDE Integration

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Code generation tools integrated into the development environment (VS Code, PyCharm). Suggestions appear as you type.

## 📋 Concrete Example

GitHub Copilot in VS Code: you type a comment '// sort by price', and it generates the sorting code inline. Cursor IDE: chat with the model about your code right in the editor.

## 🔗 Analogy

A calculator built into a cash register - instead of using a separate calculator, it is integrated. IDE integration puts code generation directly in the editor.
