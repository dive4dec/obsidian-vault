# IDE

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Integrated Development Environment - a software app for coding that includes editor, debugger, compiler, and tools.

## 📋 Concrete Example

VS Code, PyCharm, JupyterLab are IDEs. They provide: code editing, syntax highlighting, debugging, git integration, terminal, and now AI code generation.

## 🔗 Analogy

A fully equipped kitchen - stove, oven, fridge, microwave, dishwasher all in one room. An IDE puts all coding tools in one application.
