# Linting

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Automated checking of code style and common errors. Like a grammar checker for code.

## 📋 Concrete Example

Linter (flake8): 'Line 5: line too long (90 > 79 chars). Line 10: unused import. Line 15: missing space around operator.' Style and common error checks.

## 🔗 Analogy

A spell checker for an essay - it underlines spelling and grammar mistakes. A linter does this for code, flagging style and common errors.
