# Naming Convention

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Rules for naming variables, functions, classes. Good names make code self-documenting.

## 📋 Concrete Example

Python: variables are snake_case (student_name), classes are PascalCase (StudentDatabase), constants are UPPER_CASE (MAX_SIZE). Clear names communicate intent.

## 🔗 Analogy

Name tags at a conference - 'Dr. Chan - Cardiologist' tells you who they are and what they do. Naming conventions make variable names similarly informative.
