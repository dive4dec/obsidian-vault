# Natural Language to Code

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Describing what you want in plain language and getting working code. The core promise of AI code generation.

## 📋 Concrete Example

Natural language: 'Create a web page with a red button that counts clicks.' Model generates: HTML + CSS + JavaScript for a red click-counter button. No coding knowledge needed.

## 🔗 Analogy

Ordering food at a restaurant - 'I want a burger with cheese, no onions.' The kitchen makes it. You do not need to know how to cook. Natural language to code lets you order code like food.
