# Pair Programming

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Two developers working together: one writes code, one reviews. AI pair programming: the model is your partner.

## 📋 Concrete Example

You write the function signature; the model fills in the body. You write a test; the model writes another. You get stuck; the model suggests an approach. Constant collaboration.

## 🔗 Analogy

Two students doing a project together - one writes, one checks. They discuss and improve. AI pair programming makes the model your coding partner.
