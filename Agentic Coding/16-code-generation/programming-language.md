# Programming Language

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Different languages (Python, JavaScript, C++, Java) are suited for different tasks. The model can code in many languages.

## 📋 Concrete Example

Python: data science, AI. JavaScript: web. C++: games, systems. Java: enterprise. The model knows dozens of languages and can choose the right one for the task.

## 🔗 Analogy

Different tools for different jobs - a hammer for nails, a screwdriver for screws, a saw for cutting. Programming languages are tools, each suited for specific tasks.
