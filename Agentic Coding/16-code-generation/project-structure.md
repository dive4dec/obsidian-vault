# Project Structure

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

How files and directories are organized in a project. Good structure makes code navigable.

## 📋 Concrete Example

Structure: src/ (source code), tests/ (test files), docs/ (documentation), config/ (configuration), README.md (overview). Clear organization.

## 🔗 Analogy

A filing cabinet structure - drawers for Finance, HR, Legal. Each drawer has folders. Project structure organizes code files similarly.
