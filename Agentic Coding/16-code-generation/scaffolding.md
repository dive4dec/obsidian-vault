# Scaffolding

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Generating the basic structure of a project - boilerplate code, directory structure, config files.

## 📋 Concrete Example

Model: 'Create Flask app scaffold.' Generates: app/ (routes.py, models.py), tests/, requirements.txt, README.md, config.py. The skeleton is ready; you fill in the specifics.

## 🔗 Analogy

Scaffolding on a building site - the metal framework goes up first. Workers then add walls, windows, and finishes. Code scaffolding builds the framework; you add the details.
