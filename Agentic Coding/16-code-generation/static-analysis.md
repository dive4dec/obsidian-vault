# Static Analysis

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Analyzing code without running it to find bugs, style issues, and security vulnerabilities. The model can perform this.

## 📋 Concrete Example

Model scans code: 'Line 10: unused variable. Line 25: possible null reference. Line 40: SQL injection vulnerability.' Finds issues without executing the code.

## 🔗 Analogy

A building inspector checking blueprints - they find structural issues by reading the plans, not by building the house. Static analysis inspects code without running it.
