# Style Guide

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Rules for how code should look: naming conventions, indentation, line length. Consistent style makes code readable.

## 📋 Concrete Example

PEP 8 (Python): 'Use 4 spaces for indentation. Function names are lowercase with underscores. Limit lines to 79 characters.' Everyone follows the same rules.

## 🔗 Analogy

A school uniform policy - all students wear the same colors and style. Consistent appearance. Style guides ensure all code looks consistent.
