# Technical Debt

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

Quick-and-dirty code saves time now but creates `debt` that must be paid back later with interest (harder maintenance).

## 📋 Concrete Example

Rushing: copy-paste code 5 times (fast now). Debt: when you need to change the logic, you must change 5 places (slow later). The model can identify and help pay down debt.

## 🔗 Analogy

Using a credit card - buy now (fast), pay later with interest (expensive). Quick code is like credit card debt: convenient now, costly later.
