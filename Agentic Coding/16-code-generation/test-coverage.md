# Test Coverage

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

The percentage of code paths that are covered by tests. Higher coverage means more thorough testing.

## 📋 Concrete Example

Coverage: 80% means 80% of code lines are executed during tests. The remaining 20% might have hidden bugs. Tools like pytest-cov measure this automatically.

## 🔗 Analogy

A safety inspection covering 80% of a building - 80% is checked, but 20% might have issues. Higher coverage = more confidence. Test coverage measures how thoroughly code is tested.
