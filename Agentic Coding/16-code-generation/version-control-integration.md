# Version Control Integration

> **Domain:** [[_code-generation-moc|Code Generation]]

## 🎯 Motivation

AI code generation integrated with git - the model can commit, branch, and create PRs.

## 📋 Concrete Example

Model: 'I fixed the bug and wrote tests. Should I commit this?' You: `Yes.` Model: git commit -m 'Fix: handle empty list in sort function. Add 3 unit tests.' Automated version control.

## 🔗 Analogy

A filing system that tracks every change - every document version is saved. You can see who changed what and when. Version control integration lets the model manage code history.
