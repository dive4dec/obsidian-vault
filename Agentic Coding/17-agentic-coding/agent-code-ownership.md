# Agent Code Ownership

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent takes responsibility for the code it writes - maintaining, updating, and fixing it over time.

## 📋 Concrete Example

The agent wrote the auth module. A month later, a security vulnerability is found. The agent: 'I wrote this. I will fix it.' It takes ownership and maintains its code.

## 🔗 Analogy

A gardener who planted a garden - they do not just plant and leave. They water, prune, and maintain it. Agent code ownership means the agent maintains its code over time.
