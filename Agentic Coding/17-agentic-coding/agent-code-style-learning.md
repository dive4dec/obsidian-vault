# Agent Code Style Learning

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent learns the coding style of a project or developer and generates code that matches.

## 📋 Concrete Example

Agent reads 20 files: 'This project uses: 4-space indent, snake_case, type hints, comprehensive docstrings, pytest fixtures.' Generated code matches this style perfectly.

## 🔗 Analogy

A new employee learning company style - they read existing documents, learn the tone and format, and write new documents that match. The agent learns code style similarly.
