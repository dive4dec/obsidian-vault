# Agent Development Speed

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent can develop software much faster than humans - minutes vs days. But speed must be balanced with quality.

## 📋 Concrete Example

Human: 2 days to build a feature. Agent: 20 minutes. 10x faster. But the agent's code must be reviewed and tested to ensure quality. Speed without quality is dangerous.

## 🔗 Analogy

A power tool vs hand tool - a power drill is 10x faster than a hand drill. But you must still measure and align correctly. Agent development speed is the power tool; quality checks ensure precision.
