# Agent-Human Collaboration

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent and human work together: the agent does the heavy lifting, the human provides direction and reviews.

## 📋 Concrete Example

Human: 'Add a search feature.' Agent: [plans, codes, tests]. Human: 'The search should also filter by date.' Agent: [updates code, tests]. Human: 'Looks good, deploy.' Agent: [deploys]. Collaboration.

## 🔗 Analogy

A captain and crew on a ship - the captain (human) sets the destination and reviews progress. The crew (agent) handles sailing. Neither can do it alone. Agent-human collaboration combines their strengths.
