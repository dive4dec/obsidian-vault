# Agent Learning from Codebase

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent reads the existing codebase and learns its patterns, conventions, and architecture before writing new code.

## 📋 Concrete Example

Agent: 'I read 30 files. This project uses: repository pattern, dependency injection, pytest, dataclasses. I will follow these patterns in my new code.' Learns from existing code.

## 🔗 Analogy

A new student observing class culture - they watch how others behave, what the norms are, and adapt. The agent observes the codebase and adapts to its patterns.
