# Agent Pair Programming

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent works alongside a human developer, suggesting code, catching bugs, and learning from the human's style.

## 📋 Concrete Example

Human types: 'def calculate_' Agent suggests: 'def calculate_bmi(weight, height):' based on the file context. Human accepts. Agent learns: this developer prefers descriptive names.

## 🔗 Analogy

Two programmers at one keyboard - one types, one reviews. They catch each other's mistakes and share ideas. Agent pair programming is this with an AI partner.
