# Agentic Coding

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An AI agent that can write, test, debug, and deploy software autonomously. Not just code generation - full software development by AI.

## 📋 Concrete Example

You say 'Build a todo app with React.' The agent: plans architecture, writes frontend + backend, sets up database, writes tests, fixes bugs, deploys. End-to-end software development.

## 🔗 Analogy

A construction company - you say 'build me a house.' They handle everything: design, foundation, walls, plumbing, electricity, inspection. You just move in. Agentic coding is a construction company for software.
