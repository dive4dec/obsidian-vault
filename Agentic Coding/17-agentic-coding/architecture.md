# Architecture

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The high-level structure of a software system: components, their relationships, and principles guiding design.

## 📋 Concrete Example

Architecture: 'MVC pattern. Model: data layer. View: UI layer. Controller: business logic. Separation of concerns.' The architecture defines how the system is organized.

## 🔗 Analogy

The structure of a house - foundation, walls, roof, rooms, hallways. The architecture defines how the house is organized. Software architecture does this for code.
