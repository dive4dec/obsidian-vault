# Autonomous Bug Resolution

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

From bug report to fix, fully autonomous: read report, reproduce, diagnose, fix, test, commit.

## 📋 Concrete Example

Bug report: 'Cart total is wrong when quantity > 10.' Agent: reproduced, found: rounding error in bulk discount calculation. Fixed: use Decimal instead of float. Tested: 20 test cases pass. Committed. PR created.

## 🔗 Analogy

An auto mechanic with a robot arm - you report a noise, they diagnose, fix, test, and certify. All without you watching. Autonomous bug resolution does this for software bugs.
