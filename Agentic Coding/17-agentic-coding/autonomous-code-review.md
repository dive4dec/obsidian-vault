# Autonomous Code Review

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent reviews its own code before submitting, catching its own mistakes.

## 📋 Concrete Example

Agent writes code, then reviews: 'Wait, I did not handle empty input. And this variable name is unclear. Let me fix these.' Self-review before submitting. Catches mistakes independently.

## 🔗 Analogy

A student proofreading their essay before submitting - they catch their own typos and unclear sentences. Autonomous code review is the agent proofreading its own code.
