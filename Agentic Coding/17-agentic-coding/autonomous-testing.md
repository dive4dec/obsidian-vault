# Autonomous Testing

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent writes and runs tests without being asked, ensuring code quality continuously.

## 📋 Concrete Example

After writing code, the agent automatically: writes unit tests, writes integration tests, runs all tests, fixes any failures. Testing is built into its workflow, not an afterthought.

## 🔗 Analogy

A self-cleaning oven - it cleans itself after each use, automatically. You do not need to ask. Autonomous testing means the agent tests its own code without being told.
