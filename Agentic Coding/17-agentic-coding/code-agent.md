# Code Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An AI agent specialized for software development tasks: reading codebases, writing code, running tests, using git, deploying.

## 📋 Concrete Example

A code agent can: read a 50-file codebase, understand the architecture, find the function with a bug, fix it, run tests, commit the fix, and create a pull request. All autonomously.

## 🔗 Analogy

A mechanic who can diagnose, repair, test, and certify a car - they do not just identify the problem; they fix it end-to-end. A code agent does this for software.
