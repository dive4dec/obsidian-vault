# Code Generation Cost

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Generating code costs tokens and money. Managing cost per feature, per bug fix, per project is important.

## 📋 Concrete Example

Cost: 'Todo app feature: 50,000 tokens = $0.50. Bug fix: 5,000 tokens = $0.05. Full project: 500,000 tokens = $5.00.' Cost tracking helps budget agent development.

## 🔗 Analogy

Budgeting for a construction project - materials, labor, permits. Each has a cost. Code generation cost budgets the agent's token spending per task.
