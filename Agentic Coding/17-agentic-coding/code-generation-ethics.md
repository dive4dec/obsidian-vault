# Code Generation Ethics

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Ethical considerations: the agent should not generate malicious code, should respect licenses, and should be transparent about AI-generated code.

## 📋 Concrete Example

Ethics: 1) Refuse to generate malware. 2) Check open-source licenses before using code. 3) Label AI-generated code in commits. 4) Do not generate code that steals data.

## 🔗 Analogy

A doctor's ethics - do no harm, be transparent, respect patient privacy. Code generation ethics ensures the agent writes code responsibly.
