# Code Generation Iteration

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent generates code, tests it, finds issues, and iterates until the code works perfectly.

## 📋 Concrete Example

Iteration 1: code fails test (wrong return type). Iteration 2: fixes type, passes 8/10 tests. Iteration 3: fixes edge cases, passes 10/10. Three iterations to perfect code.

## 🔗 Analogy

A sculptor refining a statue - first rough shape, then details, then polish. Each iteration improves the result. Code generation iteration refines code until it works.
