# Code Migration Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that helps migrate code: Python 2 to 3, old framework to new, monolith to microservices.

## 📋 Concrete Example

Agent: 'Migrating from Flask to FastAPI. Changes: 1) Replace @app.route with @app.get. 2) Add async to handlers. 3) Update requirements. 4) Test all endpoints.' Automated migration.

## 🔗 Analogy

A moving company specializing in international relocations - they handle packing, shipping, customs, and setup in the new country. A code migration agent moves code to new frameworks.
