# Code Refactoring Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that identifies code quality issues and refactors code to be cleaner, faster, and more maintainable.

## 📋 Concrete Example

Agent scans codebase: 'Function process_data is 300 lines (code smell). I will split it into: parse_data, validate_data, transform_data, output_data. Same behavior, 4 focused functions.'

## 🔗 Analogy

A professional organizer - they come to your messy room, reorganize everything, and make it cleaner and more efficient. Same stuff, better arrangement. A refactoring agent reorganizes code.
