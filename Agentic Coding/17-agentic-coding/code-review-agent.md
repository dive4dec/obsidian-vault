# Code Review Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that reviews pull requests: checks code quality, security, tests, and provides feedback.

## 📋 Concrete Example

Review: 'PR looks good overall. Suggestions: 1) Add type hints to line 15. 2) Edge case: what if input is None? 3) Consider extracting the validation logic into a helper function. Approve after fixes.'

## 🔗 Analogy

A peer reviewer at a journal - they read the paper, check for errors, suggest improvements, and approve or reject. A code review agent is a peer reviewer for code.
