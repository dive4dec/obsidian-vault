# Codebase Navigation

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Moving through a large codebase efficiently - finding the right files, functions, and variables. The agent does this autonomously.

## 📋 Concrete Example

Agent: 'I need to find where user authentication happens.' It searches: grep for `auth`, finds auth.py, reads it, follows imports to models.py, finds the User model. Navigates like an experienced developer.

## 🔗 Analogy

A navigator on a ship - they read maps, identify landmarks, and guide the ship through waters. Codebase navigation is the agent guiding itself through a codebase.
