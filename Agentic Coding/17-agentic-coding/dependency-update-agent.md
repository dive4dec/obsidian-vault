# Dependency Update Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that updates dependencies, checks compatibility, fixes breaking changes, and tests.

## 📋 Concrete Example

Agent: 'Updating Flask from 2.0 to 3.0. Breaking changes: 1) url_for signature changed. 2) Removed deprecated functions. I fixed 3 files, updated tests, all pass.'

## 🔗 Analogy

A home renovation - replacing old pipes with new ones. You must check compatibility, fix connections, and test for leaks. A dependency update agent does this with code libraries.
