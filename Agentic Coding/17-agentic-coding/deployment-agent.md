# Deployment Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that handles deployment: building, packaging, configuring, and deploying to servers/cloud.

## 📋 Concrete Example

Agent: 1) Build: npm run build. 2) Package: Docker image. 3) Configure: set env vars. 4) Deploy: push to Kubernetes. 5) Verify: health check. 6) Monitor: watch logs for 10 minutes. All automated.

## 🔗 Analogy

A moving company - they pack, load, transport, unload, and set up your furniture in the new house. A deployment agent moves code from development to production.
