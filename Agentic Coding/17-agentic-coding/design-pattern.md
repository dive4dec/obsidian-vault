# Design Pattern

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Proven solutions to common software design problems. The agent knows and applies patterns.

## 📋 Concrete Example

Patterns: Singleton (one instance), Factory (create objects), Observer (notify changes), MVC (separate concerns). The agent applies the right pattern for each situation.

## 🔗 Analogy

Cooking techniques - saute, braise, roast, steam. Each is a proven method for a type of dish. Design patterns are proven methods for common software problems.
