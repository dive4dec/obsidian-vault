# Development Workflow

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The structured process the agent follows: requirements -> design -> code -> test -> review -> deploy -> monitor.

## 📋 Concrete Example

Workflow: 1) Read requirements. 2) Design architecture. 3) Write code. 4) Write tests. 5) Run tests. 6) Self-review. 7) Create PR. 8) Deploy after approval. 9) Monitor for issues. Structured and repeatable.

## 🔗 Analogy

A recipe with ordered steps - prep, cook, season, plate, serve. Each step in order. A development workflow structures the agent's work into ordered steps.
