# Documentation Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that reads code and generates/maintains documentation: README, API docs, code comments, architecture diagrams.

## 📋 Concrete Example

Agent: reads all files, generates README.md (project overview, setup, usage), API.md (endpoints, parameters, examples), inline docstrings for every function, and a Mermaid architecture diagram.

## 🔗 Analogy

A technical writer - they interview engineers, use the product, and write comprehensive documentation. A documentation agent does this automatically for code.
