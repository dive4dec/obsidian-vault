# Feature Implementation Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that takes a feature request and implements it: plans, writes code, writes tests, integrates with existing code.

## 📋 Concrete Example

Request: 'Add dark mode to the website.' Agent: 1) Plans: CSS variables for colors, toggle button, localStorage. 2) Writes CSS, JavaScript, HTML. 3) Writes tests. 4) Tests in browser. 5) Commits and PRs.

## 🔗 Analogy

An interior designer - you say 'I want a home office.' They plan the layout, buy furniture, install lighting, and set up the desk. A feature implementation agent does this with software features.
