# Legacy Code

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Old code that is hard to understand and maintain. The agent can help modernize and document legacy code.

## 📋 Concrete Example

Legacy: 15-year-old PHP codebase, no documentation, no tests. Agent: reads code, generates documentation, writes tests, suggests modernization plan (PHP to Python migration).

## 🔗 Analogy

An old building - it still stands but needs renovation: new wiring, better insulation, modern plumbing. Legacy code is old software that needs renovation. The agent helps modernize it.
