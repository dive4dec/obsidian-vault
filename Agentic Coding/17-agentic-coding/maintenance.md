# Maintenance

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Keeping software running: fixing bugs, updating dependencies, patching security, improving performance. The agent can handle this.

## 📋 Concrete Example

Maintenance tasks: 'Update dependencies (5 updates available), fix 3 bug reports, patch 1 security issue, optimize slow query.' The agent handles all maintenance autonomously.

## 🔗 Analogy

Car maintenance - oil change, tire rotation, brake check. Regular maintenance keeps the car running. Software maintenance keeps code running. The agent handles it autonomously.
