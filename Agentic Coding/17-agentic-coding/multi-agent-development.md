# Multi-Agent Development

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Multiple specialized agents working together on a software project: architect, coder, tester, reviewer, deployer.

## 📋 Concrete Example

Team: Architect Agent (designs system), Coder Agent (writes code), Tester Agent (writes and runs tests), Reviewer Agent (reviews code), DevOps Agent (deploys). They coordinate like a real dev team.

## 🔗 Analogy

A construction crew - architect draws plans, mason builds walls, electrician wires, plumber pipes, inspector checks. Each specialist does their part. Multi-agent development is a crew for software.
