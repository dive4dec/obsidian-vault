# Performance Optimization Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that profiles code, finds bottlenecks, and optimizes for speed and memory.

## 📋 Concrete Example

Agent: 'Profiled the app. 80% of time in database queries. Fix: 1) Add index on users.email. 2) Cache frequently accessed records. 3) Batch queries. Expected 5x speedup.'

## 🔗 Analogy

A mechanic tuning a car for racing - they find the slow parts (heavy exhaust, bad aerodynamics) and optimize them. A performance agent tunes code for speed.
