# Profiling

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

Measuring where a program spends time and memory. The agent profiles to find optimization targets.

## 📋 Concrete Example

Profile output: 'function A: 2.5s (50%), function B: 1.5s (30%), function C: 0.5s (10%). Optimize A first - it is the bottleneck.' Data-driven optimization.

## 🔗 Analogy

A time-and-motion study - you watch workers and time each task. 'Making coffee takes 5 minutes; filing takes 1 minute.' Optimize the slow tasks. Profiling times code functions.
