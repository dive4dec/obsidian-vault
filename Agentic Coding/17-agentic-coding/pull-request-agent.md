# Pull Request Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that creates, reviews, and manages pull requests. Can write code, create PRs, review other PRs, and merge.

## 📋 Concrete Example

Agent: 1) Writes new feature code. 2) Creates branch. 3) Commits. 4) Creates PR with description, test results. 5) Reviews its own PR. 6) Addresses feedback. 7) Merges after approval.

## 🔗 Analogy

A clerk who files paperwork, routes it for signatures, tracks progress, and archives when complete. A pull request agent manages the PR workflow.
