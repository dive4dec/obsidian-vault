# Requirements Analysis

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent reads requirements and breaks them into technical tasks: what data, what APIs, what UI, what tests.

## 📋 Concrete Example

Requirements: 'Todo app with categories.' Analysis: Data: Task(id, title, category, done). API: create_task, get_tasks, update_task, delete_task. UI: task list, add form, category filter. Tests: CRUD, category filter.

## 🔗 Analogy

A chef analyzing a menu - 'Appetizer, main, dessert.' They determine: ingredients needed, prep steps, cooking order, plating. Requirements analysis breaks software needs into technical tasks.
