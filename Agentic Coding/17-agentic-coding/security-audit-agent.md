# Security Audit Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that scans code for security vulnerabilities: SQL injection, XSS, authentication issues, data exposure.

## 📋 Concrete Example

Agent: 'Found 3 vulnerabilities: 1) SQL injection in search.py line 25 (use parameterized queries). 2) XSS in template.html (escape user input). 3) Hardcoded API key in config.py (use env var).' Detailed report.

## 🔗 Analogy

A building inspector checking safety - fire exits, structural integrity, electrical safety. A security audit agent checks code for digital safety issues.
