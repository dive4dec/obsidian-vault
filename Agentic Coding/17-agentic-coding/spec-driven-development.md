# Spec-Driven Development

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent develops software from a written specification: requirements -> architecture -> code -> tests -> deployment.

## 📋 Concrete Example

Spec: 'A todo app with: add/edit/delete tasks, categories, due dates, notifications. Web-based, mobile-responsive.' Agent: reads spec, plans, implements each feature, tests, deploys. Spec to working software.

## 🔗 Analogy

An architect building from blueprints - the blueprint (spec) defines everything. The builder (agent) constructs exactly what the blueprint specifies. Spec-driven development builds software from specifications.
