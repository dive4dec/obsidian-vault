# System Design

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

The agent designs the system architecture: what components, how they interact, what technologies.

## 📋 Concrete Example

Design: Frontend (React), Backend (FastAPI), Database (PostgreSQL), Cache (Redis), Deployment (Docker + Kubernetes). Architecture diagram showing how components interact.

## 🔗 Analogy

An architect designing a building - floor plan, structural design, electrical plan, plumbing plan. System design is the architectural plan for software.
