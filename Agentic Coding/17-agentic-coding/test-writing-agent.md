# Test Writing Agent

> **Domain:** [[_agentic-coding-moc|Agentic Coding]]

## 🎯 Motivation

An agent that reads code and writes comprehensive tests - unit tests, integration tests, edge cases.

## 📋 Concrete Example

Agent reads 'def sort(lst):' and writes: test_normal, test_empty, test_single, test_duplicates, test_negative, test_large, test_already_sorted, test_reverse_sorted. Comprehensive coverage.

## 🔗 Analogy

A quality assurance inspector - they design test plans to check every aspect of a product. A test writing agent designs tests to check every aspect of code.
