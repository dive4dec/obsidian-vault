# Data Collection

> **Domain:** [[_safety-ethics-moc|Safety & Ethics]]

## 🎯 Motivation

How training data is gathered: web scraping, user interactions, purchased datasets, public records. Each method has ethical implications.

## 📋 Concrete Example

Collection methods: web scraping (is it ethical?), user data (did they consent?), purchased data (is it clean?), synthetic data (is it realistic?). Each method must be ethical and legal.

## 🔗 Analogy

Collecting ingredients for a meal - you buy from the market (purchased), grow your own (self-made), or forage (public). Each has different rules and quality. Data collection is similar.
