# Demographic Parity

> **Domain:** [[_safety-ethics-moc|Safety & Ethics]]

## 🎯 Motivation

A fairness metric: the AI's positive outcome rate should be similar across demographic groups.

## 📋 Concrete Example

If 60% of men and 60% of women get approved, that is demographic parity. If 60% of men and 40% of women, there is a disparity. The metric quantifies fairness.

## 🔗 Analogy

A school ensuring equal pass rates across all classes - if Class A has 90% pass and Class B has 60%, there is a disparity. Demographic parity checks this for AI.
