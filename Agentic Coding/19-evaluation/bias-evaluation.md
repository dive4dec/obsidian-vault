# Bias Evaluation

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

Testing the model for demographic bias: does it treat groups differently?

## 📋 Concrete Example

Bias test: identical resumes with different names (John vs Jamila). Model recommends John 70% of the time, Jamila 50%. Bias detected. Fix needed.

## 🔗 Analogy

A fairness audit at a school - do all groups get equal opportunities? Bias evaluation audits the model for demographic fairness.
