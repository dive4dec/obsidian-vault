# Component Analysis

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

Breaking down the model into components and evaluating each one. Identifies which parts matter most.

## 📋 Concrete Example

Components: embedding (contribution: 10%), attention (15%), feed-forward (12%), layer norm (3%). Attention is the most important component. Focus improvement efforts there.

## 🔗 Analogy

A car engine analysis - which part contributes most to speed? Engine (40%), aerodynamics (30%), tires (15%), weight (15%). Component analysis finds the most impactful parts.
