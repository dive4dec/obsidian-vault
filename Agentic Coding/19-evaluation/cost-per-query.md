# Cost per Query

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

How much each query costs in compute resources. Lower cost = more sustainable.

## 📋 Concrete Example

Cost: 1000 queries = $1.00. Cost per query: $0.001. For 1M queries/day: $1000/day. Cost optimization matters at scale.

## 🔗 Analogy

The cost per meal at a restaurant - ingredients + labor + overhead per dish. Lower cost per meal = more profitable. Cost per query is the model's cost per question.
