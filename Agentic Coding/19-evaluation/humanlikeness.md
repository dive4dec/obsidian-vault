# Humanlikeness

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

Evaluating whether AI outputs are indistinguishable from human outputs. The Turing Test measures this.

## 📋 Concrete Example

Turing Test: a human chats with AI and a human. If they cannot tell which is AI, the AI passes. Modern LLMs often pass casual Turing Tests.

## 🔗 Analogy

A blind wine taste test - can you tell the cheap wine from the expensive one? If not, the cheap wine `passes.` Humanlikeness tests if AI is indistinguishable from human.
