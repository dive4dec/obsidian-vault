# Model Card

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

A documentation card describing a model: what it does, its performance, limitations, and ethical considerations.

## 📋 Concrete Example

Model card: 'Model: xyz-v2. Task: text classification. Accuracy: 88%. Limitations: struggles with sarcasm. Biases: favors formal language. Use cases: content moderation.'

## 🔗 Analogy

A nutrition label on food - calories, ingredients, allergens. A model card labels a model: capabilities, performance, limitations. Transparency for users.
