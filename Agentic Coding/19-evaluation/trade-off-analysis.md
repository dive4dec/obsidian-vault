# Trade-off Analysis

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

Evaluating trade-offs: accuracy vs speed, safety vs helpfulness, cost vs quality. No model is perfect on all dimensions.

## 📋 Concrete Example

Trade-off: Model A (95% accuracy, $10/query) vs Model B (85% accuracy, $0.10/query). For a medical app, choose A. For a chatbot, choose B. Context determines the best trade-off.

## 🔗 Analogy

Choosing a laptop - fast + light + cheap: pick two. You cannot have all three. Trade-off analysis evaluates which combination best fits the need.
