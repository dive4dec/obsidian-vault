# Turing Test

> **Domain:** [[_evaluation-moc|Evaluation]]

## 🎯 Motivation

Alan Turing's test: if a human cannot distinguish AI from human in conversation, the AI is considered intelligent.

## 📋 Concrete Example

Test: human chats with two entities via text. One is AI, one is human. If the human cannot reliably tell which is AI, the AI passes the Turing Test.

## 🔗 Analogy

A pen pal test - you exchange letters with two people. If you cannot tell which is a robot, the robot passes. The Turing Test checks if AI can mimic human conversation.
