# Curriculum Learning

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Training the model on easy examples first, then gradually harder ones. Like a school curriculum.

## 📋 Concrete Example

Curriculum: 1) Easy examples (simple sentences). 2) Medium (paragraphs). 3) Hard (complex essays). The model builds up skills gradually, like a student.

## 🔗 Analogy

A math curriculum: addition -> subtraction -> multiplication -> division -> algebra. Start easy, get harder. Curriculum learning trains AI step by step.
