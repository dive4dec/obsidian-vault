# Data Versioning

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Tracking changes to datasets over time, like git for data. Essential for reproducibility.

## 📋 Concrete Example

Dataset v1: 10K examples. v2: 15K examples (added 5K). v3: 14K examples (removed 1K bad ones). Versioning tracks what changed and when.

## 🔗 Analogy

Saving drafts of an essay - v1, v2, v3. You can see what changed. Data versioning tracks dataset changes like draft versions.
