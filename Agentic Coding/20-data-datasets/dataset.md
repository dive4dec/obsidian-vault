# Dataset

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

A structured collection of data used for training, testing, or evaluation. Can be text, images, audio, or mixed.

## 📋 Concrete Example

ImageNet: 1.4M labeled images across 1000 categories. Used to train image recognition models. The dataset defines what the model can recognize.

## 🔗 Analogy

A question bank for an exam - 10,000 questions organized by topic and difficulty. The dataset is the question bank for model training.
