# Embedding Dataset

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

A dataset of pre-computed embeddings (vector representations). Used for similarity search, clustering, and retrieval.

## 📋 Concrete Example

Embedding dataset: 1M sentences, each as a 768-dimension vector. Find similar sentences by computing vector distance. Fast similarity search.

## 🔗 Analogy

A library catalog with GPS coordinates - each book has a location. Find nearby books by distance. An embedding dataset has vectors for similarity search.
