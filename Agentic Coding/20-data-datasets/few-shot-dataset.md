# Few-Shot Dataset

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

A dataset with only a few examples per category (3-10). Tests the model's ability to learn from few examples.

## 📋 Concrete Example

Few-shot: 5 examples of each animal type. Can the model recognize new animals after seeing just 5 examples? Few-shot learning tests this.

## 🔗 Analogy

Learning a new card game - someone shows you 5 examples, then you play. Few-shot datasets test if the model can learn from just a few examples.
