# Instruction Dataset

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

A dataset of instruction-response pairs. Used to teach models to follow instructions (instruction tuning).

## 📋 Concrete Example

Instruction dataset: {`instruction`: 'Summarize this article', `input`: 'Article text...', `output`: `Summary...`}. 100K such pairs. Model learns to follow instructions.

## 🔗 Analogy

A workbook with example problems and solutions - the student learns the pattern. An instruction dataset teaches the model to follow instructions.
