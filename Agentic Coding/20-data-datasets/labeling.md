# Labeling

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Adding correct answers to training examples. Supervised learning needs labeled data.

## 📋 Concrete Example

Labeling: image of a cat -> label: `cat`. Image of a dog -> label: `dog`. 10,000 images labeled = dataset ready for supervised training.

## 🔗 Analogy

A teacher marking answer keys on practice exams - each question gets the correct answer. Labeling marks the correct answer for each training example.
