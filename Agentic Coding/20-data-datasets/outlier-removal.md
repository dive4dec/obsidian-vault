# Outlier Removal

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Removing data points that are very different from the rest. Outliers can mislead the model.

## 📋 Concrete Example

Outlier: one article is 500 pages (average is 2 pages). Remove it - it would skew training. Outlier removal keeps the dataset consistent.

## 🔗 Analogy

Removing a score of 0 from a test where everyone else scored 80-100 - the 0 is an outlier that would skew the average. Outlier removal keeps data consistent.
