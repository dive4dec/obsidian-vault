# Supervised Learning

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Learning from labeled examples: input -> correct output. The model learns to map inputs to outputs.

## 📋 Concrete Example

Training: 10,000 emails labeled `spam` or 'not spam.' Model learns patterns. New email -> model predicts `spam` or 'not spam.' Supervised = with labeled examples.

## 🔗 Analogy

A student learning with answer keys - they see questions and correct answers, then learn to solve new questions. Supervised learning uses labeled examples.
