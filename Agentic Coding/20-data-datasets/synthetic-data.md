# Synthetic Data

> **Domain:** [[_data-datasets-moc|Data & Datasets]]

## 🎯 Motivation

Artificially generated data that mimics real data. Used when real data is scarce, private, or expensive.

## 📋 Concrete Example

Need 100K medical records but privacy laws prevent using real ones. Generate synthetic records with similar patterns. No real patient data exposed. Training proceeds.

## 🔗 Analogy

A flight simulator - synthetic (fake) scenarios that mimic real flying. Pilots train without real risk. Synthetic data trains models without real data limitations.
