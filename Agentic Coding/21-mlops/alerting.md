# Alerting

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Automatic notifications when model performance degrades, errors spike, or anomalies are detected.

## 📋 Concrete Example

Alert: 'Model accuracy dropped from 88% to 75% in the last hour. Investigate.' The team gets a Slack message and investigates immediately.

## 🔗 Analogy

A smoke alarm - it detects smoke and alerts you immediately. Alerting notifies the team when model performance degrades.
