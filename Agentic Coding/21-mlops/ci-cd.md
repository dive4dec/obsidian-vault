# CI-CD

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Continuous Integration / Continuous Deployment - automatically building, testing, and deploying models when code changes.

## 📋 Concrete Example

CI-CD pipeline: code change -> run tests -> build model -> evaluate -> deploy to staging -> canary test -> deploy to production. All automated.

## 🔗 Analogy

A factory assembly line - raw materials go in, quality checks happen automatically, finished products come out. CI-CD is the assembly line for AI models.
