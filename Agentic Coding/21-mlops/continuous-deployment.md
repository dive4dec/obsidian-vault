# Continuous Deployment

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Automatically deploying code that passes CI. No manual intervention needed.

## 📋 Concrete Example

CD: code passes all tests -> automatically deployed to staging -> canary test (10% of traffic) -> if good, deployed to all users. Fully automated.

## 🔗 Analogy

An escalator - you step on and it automatically takes you to the next floor. No buttons, no waiting. Continuous deployment automatically moves code to production.
