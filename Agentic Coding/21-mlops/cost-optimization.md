# Cost Optimization

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Minimizing the cost of running models: right-sizing instances, using spot instances, optimizing batch sizes.

## 📋 Concrete Example

Optimization: 1) Use smaller model for simple queries. 2) Batch requests. 3) Use spot instances (cheaper). 4) Auto-scale. Cost reduced by 60%.

## 🔗 Analogy

Budgeting for a household - use cheaper brands, buy in bulk, turn off lights when not needed. Cost optimization reduces AI operating costs similarly.
