# Edge Deployment

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Running models on local devices (phones, IoT) instead of cloud servers. Lower latency, better privacy.

## 📋 Concrete Example

Edge: model runs on the phone. No data sent to cloud. Instant response. Private. But model must be small (compressed). Trade-off: size vs capability.

## 🔗 Analogy

A pocket dictionary vs a library - the dictionary (edge) is small and instant. The library (cloud) is comprehensive but requires travel. Edge deployment is the pocket dictionary.
