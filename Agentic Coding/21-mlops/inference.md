# Inference

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Using a trained model to make predictions. The model is running, not training.

## 📋 Concrete Example

Inference: user sends 'translate this text.' Model processes it and returns the translation. This is inference - using the model, not training it.

## 🔗 Analogy

A chef cooking from a recipe - the recipe (model) is already written. Cooking (inference) uses it to produce dishes (predictions).
