# MLOps

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Machine Learning Operations - deploying, monitoring, and maintaining ML models in production. Like DevOps but for ML.

## 📋 Concrete Example

MLOps: 1) Train model. 2) Package as Docker image. 3) Deploy to Kubernetes. 4) Monitor performance. 5) Retrain when performance drops. Full lifecycle management.

## 🔗 Analogy

A restaurant kitchen - the chef creates the dish (training), the kitchen staff plates and serves it (deployment), the manager monitors quality (monitoring), and the menu updates when needed (retraining). MLOps runs the AI kitchen.
