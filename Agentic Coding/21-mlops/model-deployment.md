# Model Deployment

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Making a trained model available for use. The model goes from development to production.

## 📋 Concrete Example

Deployment: model packaged as API. Users send requests: POST /predict {text: `Hello`}. Model returns: {sentiment: `positive`}. The model is now live.

## 🔗 Analogy

Opening a new store - you built the shop, stocked the shelves, trained the staff. Now you open the doors to customers. Model deployment opens the model to users.
