# Random Search

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Randomly sampling hyperparameter combinations. Often as good as grid search but faster.

## 📋 Concrete Example

Random search: try 20 random combinations. Found: lr=0.0015, batch=48 -> 89%. Faster than grid search, similar results. Efficient.

## 🔗 Analogy

Tasting random dishes at a buffet - instead of every combination, try 20 random ones. Often finds a great dish faster. Random search is efficient.
