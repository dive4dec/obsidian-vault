# Scalability

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

The ability to handle more requests by adding more resources. Critical for growing AI applications.

## 📋 Concrete Example

Scale: 100 users -> 1 model instance. 10,000 users -> 100 instances. Auto-scaling adds instances as demand grows. Handles any load.

## 🔗 Analogy

A restaurant expanding - 10 customers: 1 waiter. 100 customers: 10 waiters. Scales with demand. Model scalability adds instances as user demand grows.
