# SLA

> **Domain:** [[_mlops-moc|MLOps]]

## 🎯 Motivation

Service Level Agreement - a promise about model performance: 99.9% uptime, <200ms latency. If violated, consequences.

## 📋 Concrete Example

SLA: 99.9% uptime (max 43 min downtime/month), <200ms latency (99% of requests), <0.1% error rate. If violated, customers get refunds. Binding promise.

## 🔗 Analogy

A delivery guarantee - '30 minutes or free.' The restaurant promises a delivery time. An SLA promises model performance.
