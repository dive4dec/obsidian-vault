# Interactive Mode

> **Domain:** [[_dsh-cli-commands-moc|CLI & Commands]]

## Motivation

The interactive flow is what `dsh web` gives you: the Web GUI where you converse with the agent, approve operations, and manage sessions. It is the counterpart to the headless one-shot model.

## Concrete Example

`dsh web` opens the GUI; from there you chat, review tool actions, and keep the session open.

## Analogy

Sitting across the desk from the agent instead of leaving a request in a drop box.
