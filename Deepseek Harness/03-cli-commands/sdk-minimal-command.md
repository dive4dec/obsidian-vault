# dsh sdk-minimal

> **Domain:** [[_dsh-cli-commands-moc|CLI & Commands]]

## Motivation

`dsh --profile sdk-minimal` serves SDK clients with the standalone minimal agent tree — a lighter agent than the full SDK profile. The minimal SDK example selects this profile.

## Concrete Example

Run `dsh --profile sdk-minimal` when you want an SDK client wired to the minimal tree instead of the full `sdk` profile.

## Analogy

The compact car of the same brand's lineup — same driver's seat, smaller engine.
