# Agent UI

> **Domain:** [[_dsh-agent-architecture-moc|Agent Architecture]]

## Motivation

The agent UI is where a user selects and inspects agents in Web. `dsh-client-ui-agent-preset` lets you choose agent presets and the new-task default and read what each mode does and declares, while the trajectory and subagent panels expose a running agent's activity.

## Concrete Example

`dsh-client-ui-agent-preset` shows the available presets and the new-task default; authoring new presets is guided to Creator mode.

## Analogy

The control panel where you pick the worker profile before starting the task.
