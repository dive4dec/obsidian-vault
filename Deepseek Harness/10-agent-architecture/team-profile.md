# Team Profile

> **Domain:** [[_dsh-agent-architecture-moc|Agent Architecture]]

## Motivation

The team profile enables Agent Teams collaboration, its tools, and the Web roster and task board with one bundle. It delegates work to teammates and shows members, shared tasks, and teammate sessions in Web. It disables ordinary subagent delegation and overlapping global child controls, while Workflow can still create fresh children. It ships with dsh switched off.

## Concrete Example

Enable `dsh-experimental-agent-team-profile` from the Plugins page or add it to an initialized profile to turn on team mode.

## Analogy

A one-click "team mode" that swaps the solo setup for a shared-board roster.
