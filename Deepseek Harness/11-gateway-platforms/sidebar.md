# Sidebar

> **Domain:** [[_dsh-gateways-moc|Gateway & Platforms]]

## Motivation

The dsh web client sidebar lets users recognize the active build, start a new session, collapse navigation to a 56px rail, browse Workspaces and Sessions, and open Settings. New Session uses an explicitly selected Workspace, then the current Session's Workspace, then the most recently active Workspace; if none exists, it opens a blank New Session page. Deployments can replace the brand mark while retaining navigation controls and rail geometry.

## Concrete Example

Clicking New Session with no Workspace selected opens a blank New Session page instead of guessing a destination.

## Analogy

The reception desk: it tells you who's here, where you're going, and where the elevator is.
