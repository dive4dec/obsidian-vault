# Roadmap

> **Domain:** [[_dsh-development-moc|Development & Internals]]

## Motivation

dsh's direction is visible in its `dsh-experimental-*` surface: agent-team, voice input with SenseVoice, auto review, and the schedule bundle are all published under experimental names with no stability promise, each shipped switched off behind the plugin manager. Package READMEs mark Known Limitations and Deferred Work explicitly, distinguishing current constraints from a task backlog.

## Concrete Example

The agent-team README lists unsupported scenarios (separate working directories, cross-process teams, automatic task-owner release) as limits rather than backlog items; the Typert loader notes client-face discovery as deferred work.

## Analogy

It is a construction zone where every crane has a sign saying what is not built yet.
