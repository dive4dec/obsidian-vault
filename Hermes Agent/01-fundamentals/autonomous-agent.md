# Autonomous Agent

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

An autonomous agent can decide what steps to take on its own, without you spelling out every command. You give it a goal, and it figures out which tools to use and in what order.

## Concrete Example

You tell Hermes to back up your project folder to a USB drive. Hermes checks the folder size, copies the files, and confirms the backup finished.

## Analogy

Like a delivery rider who, once you give the address, picks the fastest route and delivers the food without you guiding every turn.
