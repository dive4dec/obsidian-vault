# Checkpoints

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Checkpoints are snapshots of your files at a moment in time. If Hermes makes a mess of your project, you can roll back to the last checkpoint and try again.

## Concrete Example

Hermes edits five files to add a feature. It goes wrong. You type /rollback and the files return to how they were.

## Analogy

Like a save point in a video game. If you die, you respawn at the save point.
