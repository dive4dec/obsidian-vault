# Command Approval

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

For safety, Hermes asks for your permission before running commands that could be destructive, like deleting files. You can also set it to auto-approve low-risk commands.

## Concrete Example

Hermes wants to run rm old_files. It shows you the command and waits for you to type yes before executing.

## Analogy

Like a bank app that asks you to confirm before transferring money. It protects you from mistakes.
