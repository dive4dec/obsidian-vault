# Config File

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The config file, usually config.yaml, is where all your Hermes settings live. It is a text file you can edit by hand or with the hermes config command.

## Concrete Example

You run hermes config edit and a text editor opens showing all your settings in neat sections.

## Analogy

Like the rulebook for a board game. Change a rule and the game plays differently.
