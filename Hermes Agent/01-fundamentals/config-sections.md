# Config Sections

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The Hermes config file is split into sections like model, terminal, memory, and display. Each section controls one part of how Hermes behaves. You edit them to customise your agent.

## Concrete Example

You open the config and change the display section to show the reasoning steps. Now you can see how Hermes thinks.

## Analogy

Like the settings menu on your phone, with sections for brightness, sound, and wallpaper.
