# Desktop App

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

For people who prefer a window with buttons, Hermes Desktop gives you a graphical installer and app. It sets up both the command-line tool and a friendly desktop window.

## Concrete Example

You download the Hermes Desktop installer, double-click it, and a wizard guides you through setup with pictures and buttons.

## Analogy

Like ordering food from a menu with photos, instead of typing your order in code.
