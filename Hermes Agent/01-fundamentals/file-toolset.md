# File Toolset

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The file toolset lets Hermes read, write, search, and patch files on your computer. This is how it edits code, updates configs, and organises documents.

## Concrete Example

Hermes reads your essay, finds a spelling mistake, and uses the patch tool to fix just that line.

## Analogy

Like a proofreader with a red pen who can also erase and rewrite for you.
