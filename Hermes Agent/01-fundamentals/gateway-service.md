# Gateway Service

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The gateway can run as a background service using systemd, so it stays on even after you close your terminal. This is how Hermes stays reachable 24/7 on messaging apps.

## Concrete Example

You install the gateway as a service. Even after you log off and sleep, your Telegram bot keeps answering.

## Analogy

Like a shop that stays open all night with a night-shift worker, even when the manager goes home.
