# Image Generation

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Hermes can create images from text descriptions using AI image generation tools. This is useful for making illustrations, icons, or just for fun.

## Concrete Example

You ask Hermes to draw a dragon eating dim sum. It generates a picture and saves it to your folder.

## Analogy

Like describing a scene to an artist who paints it for you on the spot.
