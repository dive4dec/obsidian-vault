# Kanban Board

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The Kanban board is a shared task list for multiple Hermes profiles. You create tasks, assign them to profiles, and track progress. It is used for bigger projects with several agents.

## Concrete Example

You create a board with three tasks: write tests, fix bugs, update docs. You assign each to a different profile and watch them complete in parallel.

## Analogy

Like a group project whiteboard where each teammate moves their sticky note from To Do to Done.
