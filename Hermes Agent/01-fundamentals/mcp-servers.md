# MCP Servers

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

MCP stands for Model Context Protocol. It is a standard way to connect external tools and data sources to Hermes. You add an MCP server and Hermes gains its tools automatically.

## Concrete Example

You add an MCP server for Google Drive. Hermes can now list and read files from your Drive.

## Analogy

Like plugging a USB device into your computer. The computer detects it and you can use it right away.
