# Memory Provider

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Memory can be stored in different ways, called providers. The built-in provider uses local files. Other providers like Honcho or Mem0 offer fancier databases. You choose what fits your needs.

## Concrete Example

You start with the built-in memory. Later, for a team project, you switch to Honcho so everyone shares the same memory.

## Analogy

Like choosing where to save your game: on the console, on a USB stick, or in the cloud.
