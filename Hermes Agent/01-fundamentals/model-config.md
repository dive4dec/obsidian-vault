# Model Config

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The model section of the config tells Hermes which AI model to use, which provider hosts it, and settings like context length. Changing the model changes how smart and how fast Hermes is.

## Concrete Example

You set the model to a fast, cheap one for daily chat, then switch to a powerful one for a big coding task.

## Analogy

Like choosing a character in a game. Each has different speed and strength stats.
