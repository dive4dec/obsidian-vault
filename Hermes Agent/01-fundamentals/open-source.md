# Open Source

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Hermes Agent is open source, meaning anyone can read, copy, and modify the code for free. This builds trust because experts can check how it works and even help improve it.

## Concrete Example

A student downloads the Hermes code from GitHub, reads how the agent loop works, and suggests an improvement.

## Analogy

Like a recipe posted online for everyone to see and tweak, instead of a secret formula locked in a kitchen.
