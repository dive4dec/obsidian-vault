# Plugins

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Plugins are extra packages that add new features to Hermes, such as a memory provider or a tool integration. You install them with a command and they hook into the system.

## Concrete Example

You install a plugin that adds Spotify control. Now Hermes can play songs and manage your playlists.

## Analogy

Like adding a mod to Minecraft. The base game stays the same, but you get new blocks and items.
