# Profiles

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

A profile is a separate Hermes instance with its own config, sessions, skills, and memory. You can have one for school, one for gaming, one for experiments. They never mix.

## Concrete Example

You create a profile called school with a serious model and a profile called fun with a cheaper model for casual chat.

## Analogy

Like having two Octopus cards: one personal, one for school trips. The balances stay separate.
