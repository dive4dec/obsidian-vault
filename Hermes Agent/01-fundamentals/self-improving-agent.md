# Self-Improving Agent

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Hermes gets better the more you use it. When it solves a tricky problem or learns a new workflow, it can save that knowledge as a skill. Next time it faces the same task, it loads the skill and works faster.

## Concrete Example

After Hermes helps you set up a Python project three times, it creates a skill called project-setup. The fourth time, it follows that saved recipe automatically.

## Analogy

Like a kitchen helper who writes down a recipe after cooking a dish once, so next time they do not need to ask how to make it.
