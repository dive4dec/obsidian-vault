# Session Search

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Session search is a tool that lets Hermes look through your past conversations for relevant context. This is separate from web search; it only looks at your own history.

## Concrete Example

You ask Hermes to continue a coding task from last week. It searches past sessions, finds the code you wrote, and picks up where you left off.

## Analogy

Like using Ctrl+F to find a word in your notes, but across all your notebooks at once.
