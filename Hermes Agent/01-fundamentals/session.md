# Session

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

A session is one conversation from start to finish. Hermes saves every session, so you can resume, search, or export it later. Sessions are stored in a local database.

## Concrete Example

You start a session on Monday about a history essay. On Wednesday you resume it and Hermes remembers everything you discussed.

## Analogy

Like a notebook where each conversation is a page. You can flip back to any page anytime.
