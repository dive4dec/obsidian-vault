# Sessions DB

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

All sessions are saved in a local SQLite database with full-text search. This means Hermes can search past conversations by keyword, not just list them.

## Concrete Example

You ask Hermes to recall what you said about climate change last month. It searches the database and finds the exact messages.

## Analogy

Like a diary with an index. You can search for a word and jump straight to that entry.
