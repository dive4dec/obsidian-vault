# Skill Creation

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

A skill is a saved set of instructions that Hermes can load when a similar task comes up. Anyone can create one, including Hermes itself. Skills are the main way Hermes improves.

## Concrete Example

You teach Hermes how to format a lab report. It saves a skill called lab-report. Next time you say write my lab report, it follows that saved format.

## Analogy

Like writing a cheat sheet for an exam. Once you write it, you can use it again and again.
