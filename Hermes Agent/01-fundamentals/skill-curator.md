# Skill Curator

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The curator is a background helper that keeps your skills tidy. It tracks which skills you use, marks unused ones as stale, and archives them. It never deletes, so nothing is lost.

## Concrete Example

You installed ten skills last month but only used three. The curator archives the seven idle ones to keep your list clean.

## Analogy

Like a librarian who moves books nobody borrows to the back shelf, but never throws them away.
