# Skill Hub

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The Skill Hub is an online library where the community shares skills. You can browse, search, and install skills with one command, so you do not have to write everything yourself.

## Concrete Example

You run hermes skills search git and find a skill that teaches Hermes how to resolve merge conflicts. You install it with one click.

## Analogy

Like the App Store, but for Hermes skills. Browse, tap install, and you are ready.
