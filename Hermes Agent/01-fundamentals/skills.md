# Skills

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Skills are reusable knowledge modules. Each skill is a folder with a SKILL.md file describing how to do something. Hermes scans your skills folder and loads relevant ones automatically.

## Concrete Example

You install a skill for making PowerPoint slides. When you ask Hermes to build a presentation, it reads that skill and follows the steps.

## Analogy

Like apps on your phone. You install the ones you need, and they are ready whenever you open them.
