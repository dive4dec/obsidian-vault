# Terminal Agent

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The most common way to use Hermes is in a terminal, a text-based screen where you type commands. This is fast, lightweight, and works on almost any computer, even a cheap server.

## Concrete Example

You open a terminal, type hermes, and start chatting. No mouse, no heavy window, just text.

## Analogy

Like a walkie-talkie compared to a smartphone. Simple, but quick and reliable.
