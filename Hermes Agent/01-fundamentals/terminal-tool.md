# Terminal Tool

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The terminal tool lets Hermes run shell commands on your computer. This is how it installs software, runs scripts, and manages files. It is the most powerful and most used tool.

## Concrete Example

You ask Hermes to check your Python version. It runs python3 --version and reads the output.

## Analogy

Like giving Hermes the keys to your computer keyboard. It can type any command you could.
