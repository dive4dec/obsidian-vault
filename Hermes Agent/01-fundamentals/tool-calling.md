# Tool Calling

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Tools are the hands and eyes of Hermes. Each tool does one job, like reading a file, running a command, or searching the web. Hermes picks the right tool for each step of a task.

## Concrete Example

Hermes uses the read_file tool to open your essay, then uses the write_file tool to save a corrected version.

## Analogy

Like a toolbox where you grab a screwdriver for screws and a hammer for nails. Hermes chooses the right tool automatically.
