# Toolsets

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Tools are grouped into toolsets, each covering a category: web, terminal, file, vision, and more. You can turn toolsets on or off depending on what you want Hermes to be able to do.

## Concrete Example

You turn off the browser toolset during an exam so Hermes can only read local files, not go online.

## Analogy

Like turning off data roaming on your phone when you travel, so you only use Wi-Fi.
