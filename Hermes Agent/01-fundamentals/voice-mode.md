# Voice Mode

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Hermes can listen to your voice and speak back. This uses speech-to-text and text-to-speech tools. It is handy when you cannot type, like when cooking or walking.

## Concrete Example

You send a voice message on Telegram asking Hermes to set a reminder. It replies with a spoken confirmation.

## Analogy

Like a walkie-talkie. You talk, it talks back, no typing needed.
