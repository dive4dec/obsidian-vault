# Web Toolset

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

The web toolset gives Hermes the ability to search the internet and read web pages. This is essential for research, looking up current events, or finding documentation.

## Concrete Example

You ask Hermes for the latest news about a typhoon. It searches the web, reads the Observatory website, and summarises the warning.

## Analogy

Like a librarian who can dash out to the newsstand, grab a paper, and read you the headline.
