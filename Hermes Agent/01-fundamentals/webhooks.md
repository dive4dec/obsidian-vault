# Webhooks

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Webhooks let external services trigger Hermes. When something happens on another website, it sends a message to Hermes, which then runs a task.

## Concrete Example

You set a webhook so that when a new GitHub issue is opened, Hermes reads it and posts a summary to your Discord.

## Analogy

Like a doorbell connected to a camera. When someone rings, the camera turns on automatically.
