# What is Hermes Agent

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Hermes Agent is an open-source AI agent made by Nous Research. Unlike a chatbot that only talks, Hermes can run commands, read and write files, search the web, and remember things across conversations. It lives in your terminal, on your phone through messaging apps, or on a server.

## Concrete Example

You type a message asking Hermes to summarise your homework notes into bullet points. Hermes reads the files, writes a summary file, and tells you it is done.

## Analogy

Think of Hermes like a class monitor who does not just listen but actually carries out tasks for you, like collecting homework and writing the summary on the board.
