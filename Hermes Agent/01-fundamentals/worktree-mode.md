# Worktree Mode

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

In worktree mode, Hermes works in a separate copy of your git project. This means it can make changes without touching your main files, which is great for parallel experiments.

## Concrete Example

You start two Hermes agents in worktree mode. One tries a new design, the other fixes bugs. Neither breaks the other.

## Analogy

Like photocopying your homework so you can try two different answers and keep the better one.
