# Yolo Mode

> **Domain:** [[_hermes-fundamentals-moc|Hermes Fundamentals]]

## Motivation

Yolo mode skips all command approval prompts. It is faster but riskier, because Hermes will run any command without asking. Use it only when you trust the task fully.

## Concrete Example

You turn on yolo mode for a quick file rename task. Hermes runs the command instantly without pausing to ask.

## Analogy

Like riding a bike with no helmet. Faster, but you had better be sure of the road.
