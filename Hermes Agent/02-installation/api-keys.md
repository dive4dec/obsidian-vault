# API Keys

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

An API key is a secret string that proves you are allowed to use a service. You get one from the AI provider website and put it in your .env file. Hermes uses it to call the AI model.

## Concrete Example

You sign up at OpenRouter, copy your API key, and paste it into .env as OPENROUTER_API_KEY.

## Analogy

Like the secret code for your locker. Only you have it, and it lets you open the door.
