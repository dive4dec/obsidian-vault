# Backup Before Update

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Before a major update, it is wise to back up your .hermes folder. This way, if the new version breaks something, you can restore the old setup.

## Concrete Example

You copy ~/.hermes to ~/.hermes-backup, then run hermes update. If something breaks, you restore the backup.

## Analogy

Like saving your game before a boss fight. If you lose, you reload and try again.
