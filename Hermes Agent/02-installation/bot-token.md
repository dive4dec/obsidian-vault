# Bot Token

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

A bot token is a secret string from a platform like Telegram that identifies your bot. You get it from BotFather on Telegram. Hermes uses it to receive and send messages as your bot.

## Concrete Example

On Telegram you message @BotFather, create a bot, and receive a token like 123456:ABC-DEF. You paste it into Hermes gateway setup.

## Analogy

Like the membership number on your Octopus card. It uniquely identifies your card to the system.
