# Code Execution Tool

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The code execution tool lets Hermes run Python code on demand. It can be sandboxed or run directly. This is how Hermes does maths, processes data, and writes scripts.

## Concrete Example

You ask Hermes to calculate the average of your test scores. It writes a Python script, runs it, and tells you the answer.

## Analogy

Like a calculator that can also write its own programs and run them.
