# Config YAML

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

config.yaml is the main settings file for Hermes. It uses a format called YAML, which is text with indentation. All your preferences, from model choice to display theme, live here.

## Concrete Example

You open config.yaml and see neat sections: model, terminal, memory, display. You change display.skin to dark.

## Analogy

Like the settings file for a video game. Edit a value and the game looks or plays differently.
