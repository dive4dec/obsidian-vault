# Curl Install

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

On Linux, macOS, WSL2, and Android Termux, you install Hermes using the curl command. Curl downloads the install script and bash runs it. This is the standard method for these platforms.

## Concrete Example

On your Linux laptop you run the curl command. The script prints progress as it downloads and configures Hermes.

## Analogy

Like using a vending machine. You press one button (curl) and the drink (Hermes) drops out ready.
