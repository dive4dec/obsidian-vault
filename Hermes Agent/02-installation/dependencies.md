# Dependencies

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Dependencies are other software packages that Hermes needs to run, like libraries for web requests, file handling, and AI model calls. The install script downloads and installs them all into the venv.

## Concrete Example

The install log shows dozens of packages being installed: requests, pyyaml, prompt_toolkit, and more.

## Analogy

Like the ingredients list for a recipe. You need flour, eggs, and sugar to bake a cake.
