# Environment Setup

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Environment setup means preparing your computer so Hermes can run. This includes having the right Python version, enough disk space, and the needed system tools. The install script handles most of this.

## Concrete Example

The install script checks that Python 3.11 is present. If not, it prints a message telling you to install it first.

## Analogy

Like packing your bag before a field trip. You need the right items or the trip will not go smoothly.
