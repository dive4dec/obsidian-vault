# First Run

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

After install, your first hermes command launches the setup wizard if no config exists. This ensures you pick a model and add at least one key before chatting.

## Concrete Example

You type hermes for the first time. Instead of chatting, the setup wizard opens to guide you.

## Analogy

Like turning on a new phone for the first time. It walks you through setup before you can use it.
