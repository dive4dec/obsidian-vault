# Gateway Setup

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Gateway setup (hermes gateway setup) connects Hermes to messaging platforms. It asks for bot tokens and configuration for each platform you want to use.

## Concrete Example

You run hermes gateway setup, choose Telegram, paste your bot token from BotFather, and now your Telegram bot is linked to Hermes.

## Analogy

Like pairing Bluetooth headphones. You put them in pairing mode and enter a code to connect.
