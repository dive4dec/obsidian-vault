# Hermes Desktop

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes Desktop is a graphical installer and app for Windows and macOS. If you prefer clicking buttons over typing commands, this is the easiest path. It installs both the CLI and the desktop window.

## Concrete Example

You download the Hermes Desktop installer from the website, double-click, and a wizard with pictures guides you through setup.

## Analogy

Like buying a computer from a store with setup included, versus building one yourself from parts.
