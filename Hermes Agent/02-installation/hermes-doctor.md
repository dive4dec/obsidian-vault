# Hermes Doctor

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

hermes doctor checks your Hermes installation for problems. It looks for missing dependencies, broken config, and missing API keys. It can even try to fix issues with the --fix flag.

## Concrete Example

You run hermes doctor and it reports that your Python version is too old. You update Python and run it again. All green.

## Analogy

Like a health check at the clinic. The doctor lists what is wrong and can prescribe fixes.
