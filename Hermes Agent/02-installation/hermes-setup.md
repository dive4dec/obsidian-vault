# Hermes Setup

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The hermes setup command launches the setup wizard. You can run it for all sections or just one, like hermes setup model to only configure the model.

## Concrete Example

You already have a model but want to add Telegram. You run hermes setup gateway and follow just that part.

## Analogy

Like going to a specific counter at the post office instead of waiting in the general line.
