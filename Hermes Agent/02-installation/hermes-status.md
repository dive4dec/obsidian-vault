# Hermes Status

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

hermes status shows you what parts of Hermes are running and connected. It tells you if the gateway is up, which tools are enabled, and which providers are set.

## Concrete Example

You run hermes status and see a table: Gateway running, Telegram connected, Model set to DeepSeek. Everything looks good.

## Analogy

Like the dashboard of a car. One glance tells you fuel, speed, and engine status.
