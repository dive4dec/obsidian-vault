# HERMES_HOME

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

HERMES_HOME is the folder where Hermes stores everything: config, sessions, skills, logs. By default it is ~/.hermes. You can change it to run multiple independent setups.

## Concrete Example

You set HERMES_HOME to /home/alex/my-hermes. Now all of Hermes data lives in that folder instead of the default.

## Analogy

Like choosing which locker to put your books in. Change the locker number and everything goes there instead.
