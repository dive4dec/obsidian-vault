# Install Logs

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

During installation, the script prints logs showing each step. If something fails, these logs tell you exactly where. Reading them helps you fix problems quickly.

## Concrete Example

The install log shows Downloading... Done. Creating venv... Done. Installing dependencies... Error: no disk space.

## Analogy

Like a receipt that lists every item. If the total is wrong, you check each line.
