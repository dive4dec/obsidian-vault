# Install Script

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The fastest way to get Hermes is the install script. It is one command you paste into your terminal. The script downloads Hermes, sets up a Python environment, and gets everything ready.

## Concrete Example

You paste curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash and wait about a minute. Then you type hermes and it works.

## Analogy

Like a meal kit delivered to your door. One delivery, and you have all the ingredients and the recipe.
