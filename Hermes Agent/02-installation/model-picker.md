# Model Picker

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The model picker (hermes model) is an interactive menu that lists available providers and models. You scroll, pick one, and Hermes saves it as your default.

## Concrete Example

You run hermes model. A menu shows OpenRouter, Anthropic, DeepSeek, and more. You pick DeepSeek and press Enter.

## Analogy

Like choosing your character in a fighting game. Each has different stats and abilities.
