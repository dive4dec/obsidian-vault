# Multi-Instance Setup

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

You can run more than one Hermes on the same machine using profiles or different HERMES_HOME values. This is useful for separating school and personal use.

## Concrete Example

You set HERMES_HOME=/home/alex/school-hermes for one terminal and the default for another. Two independent Hermes instances run side by side.

## Analogy

Like having two lockers in different buildings. Each holds different things and they never mix.
