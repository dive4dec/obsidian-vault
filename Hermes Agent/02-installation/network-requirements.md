# Network Requirements

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The install script needs internet access to download Hermes and its dependencies. If you are behind a firewall or proxy, you may need to configure it to allow the download.

## Concrete Example

On school Wi-Fi the install fails. You switch to mobile data and it works, because the school firewall blocked the download.

## Analogy

Like needing signal to send a message. No signal, no delivery.
