# Per-User vs Root Install

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes can be installed just for your user account (per-user) or for the whole system (root). Per-user is safer and recommended. Root install is for shared servers where many people use Hermes.

## Concrete Example

On your personal laptop you choose per-user install. Hermes lives in your home folder and only you can run it.

## Analogy

Like having your own locker versus a shared storeroom. Your own locker is safer and simpler.
