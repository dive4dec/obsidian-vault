# Platform Support

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes runs on Linux, macOS, Windows (native and WSL2), and Android (Termux). Each platform has a recommended install method. The docs have a full support matrix showing what works where.

## Concrete Example

You check the platform support table and see that your Chromebook running Linux works, but iOS does not yet.

## Analogy

Like a transit map showing which lines reach which stations. You check before you travel.
