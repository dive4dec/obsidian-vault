# PowerShell Install

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

On native Windows, you use PowerShell instead of curl. The command is slightly different but does the same thing: downloads and installs Hermes for you.

## Concrete Example

You open PowerShell, paste the install command, and watch it set up Hermes in your Windows user folder.

## Analogy

Like the same vending machine but with a different button layout for a different country.
