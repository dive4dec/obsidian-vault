# Prerequisites

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Before installing Hermes, your computer needs a few things: Python 3.11 or newer, curl or PowerShell, and basic build tools. The install script checks and warns you if anything is missing.

## Concrete Example

The install script prints: Python 3.11 found. git found. All prerequisites met. Installing...

## Analogy

Like checking you have your ID and ticket before entering Ocean Park. No ticket, no entry.
