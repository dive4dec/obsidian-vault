# Provider Setup

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Each provider may need different setup. Some need an API key in .env, others need an OAuth login via hermes auth. The setup wizard and docs guide you through each one.

## Concrete Example

For OpenRouter you paste a key into .env. For Nous Portal you run hermes auth add nous and log in via browser.

## Analogy

Like different MTR lines needing different tickets. The Airport Express needs a special ticket, the Tsuen Wan Line uses a standard one.
