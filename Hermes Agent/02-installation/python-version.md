# Python Version

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes needs Python 3.11 or newer. Python is the programming language Hermes is written in. If your system has an older version, you must upgrade before installing.

## Concrete Example

You run python3 --version and see 3.11.15. Good to go. If it said 3.9, you would need to upgrade first.

## Analogy

Like needing the latest game update to play online. Old version, no match.
