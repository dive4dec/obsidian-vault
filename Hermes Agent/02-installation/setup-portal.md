# Setup Portal

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

The setup portal (hermes setup --portal) is the fastest path to a working agent. One OAuth login covers a model plus web search, image generation, text-to-speech, and browser tools.

## Concrete Example

You run hermes setup --portal, log in once with Nous Portal, and all five tools are ready. No need to hunt for separate API keys.

## Analogy

Like an all-in-one transport pass. One tap opens MTR gates, bus doors, and ferry terminals.
