# Shell Completions

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes can install shell completions so that pressing Tab auto-fills commands and options. This saves typing and prevents typos. Supports bash and zsh.

## Concrete Example

You run hermes completion bash and add the output to your .bashrc. Now typing hermes c and pressing Tab shows chat, config, cron.

## Analogy

Like autocorrect on your phone. Start typing and it finishes the word for you.
