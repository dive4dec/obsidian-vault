# Systemd Service

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

On Linux, the gateway can run as a systemd service. This means it starts automatically when your computer boots and stays running in the background. Use hermes gateway install to set it up.

## Concrete Example

You run hermes gateway install. Now every time you boot your server, the Hermes gateway starts automatically and your Telegram bot is online.

## Analogy

Like the school bell that rings automatically at the same time every day, no one needs to press a button.
