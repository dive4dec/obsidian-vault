# Termux Install

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Termux is a terminal app for Android. You can install Hermes on your phone using the same curl method, turning your phone into a portable AI agent.

## Concrete Example

You open Termux on your Android phone, paste the curl command, and a minute later you are chatting with Hermes.

## Analogy

Like turning your phone into a mini computer. Same power, smaller screen.
