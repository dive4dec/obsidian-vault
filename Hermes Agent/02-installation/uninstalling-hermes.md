# Uninstalling Hermes

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

If you want to remove Hermes, the hermes uninstall command cleans up the installed files. Your config and sessions may remain unless you delete the .hermes folder yourself.

## Concrete Example

You run hermes uninstall. It removes the program. You then delete ~/.hermes to wipe all data.

## Analogy

Like uninstalling a game. The game is gone, but your save files stay until you delete them too.
