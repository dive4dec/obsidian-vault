# Updating Hermes

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

Hermes gets better over time with updates. You run hermes update to download and install the latest version. Updates can add new tools, fix bugs, and improve speed.

## Concrete Example

You run hermes update. It downloads the new version, restarts, and you now have the latest features.

## Analogy

Like updating an app from the App Store. New version, new improvements.
