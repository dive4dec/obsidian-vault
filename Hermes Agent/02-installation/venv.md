# Venv

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

A venv (virtual environment) is an isolated Python folder. Hermes installs its packages inside a venv so they do not clash with other Python projects on your computer.

## Concrete Example

The install script creates a venv at ~/.hermes/venv. All Hermes dependencies live there, separate from your school Python projects.

## Analogy

Like a lunch box with dividers. Your rice does not touch your soup. Each stays in its own section.
