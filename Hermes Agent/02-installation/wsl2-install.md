# WSL2 Install

> **Domain:** [[_installation-setup-moc|Installation & Setup]]

## Motivation

WSL2 lets you run Linux inside Windows. Installing Hermes on WSL2 means you use the Linux curl method, which often works more smoothly than the native Windows method for developers.

## Concrete Example

You open WSL2, run the curl install command, and Hermes works as if you were on a Linux machine.

## Analogy

Like running a Japanese app inside a Japanese-mode emulator on your English computer. It just works better.
