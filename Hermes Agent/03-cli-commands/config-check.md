# Config Check

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

hermes config check scans your config for missing or outdated settings. It tells you if something is wrong or if new options are available after an update.

## Concrete Example

After updating Hermes you run hermes config check. It says three new options are available and offers to add them.

## Analogy

Like a teacher checking your homework and marking the missing parts.
