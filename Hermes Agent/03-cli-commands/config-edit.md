# Config Edit

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

hermes config edit opens your config.yaml file in a text editor. You can change any setting directly. This is for users who want full control over every option.

## Concrete Example

You run hermes config edit. Your text editor opens. You change max_turns from 90 to 120 and save.

## Analogy

Like opening the hood of a car to tune the engine. Full control, but you need to know what you are doing.
