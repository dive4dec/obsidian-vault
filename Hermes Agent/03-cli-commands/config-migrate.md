# Config Migrate

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

hermes config migrate updates your config file to include new options added in recent Hermes versions. It preserves your existing settings and only adds the new defaults.

## Concrete Example

You update Hermes and run hermes config migrate. New sections appear in your config with default values, old settings untouched.

## Analogy

Like a phone update that adds new toggles to settings without resetting your old ones.
