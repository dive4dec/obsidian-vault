# Config Path

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

hermes config path prints the location of your config.yaml file. This is handy when you want to find, copy, or share your config.

## Concrete Example

You run hermes config path and it prints /home/alex/.hermes/config.yaml. You now know exactly where the file is.

## Analogy

Like a map pin showing where your locker is. One command, exact location.
