# Continue Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --continue flag (or -c) resumes the most recent session, or a named one. It is a shortcut when you do not remember the session ID but want to keep going.

## Concrete Example

You run hermes --continue. Your last chat opens. Hermes says Welcome back, we were talking about your essay.

## Analogy

Like pressing Continue on a game save screen. It loads your last save automatically.
