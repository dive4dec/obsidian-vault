# Global Flags

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

Global flags work with any hermes command. They include --resume, --continue, --worktree, --skills, --profile, --yolo, and --version. You combine them to control how Hermes starts.

## Concrete Example

You run hermes --profile school --skills lab-report --continue. Three flags at once: switch profile, load a skill, resume last session.

## Analogy

Like toppings on a pizza. Pick and combine the ones you want for this order.
