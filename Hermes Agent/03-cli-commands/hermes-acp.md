# Hermes ACP

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes acp command starts Hermes as an ACP server, which lets IDEs like VS Code connect to it. This is how Hermes integrates with your code editor.

## Concrete Example

You run hermes acp. Your VS Code extension connects to it. Now you can chat with Hermes inside the editor while coding.

## Analogy

Like plugging a second monitor into your laptop. Same computer, bigger workspace.
