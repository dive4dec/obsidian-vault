# Hermes Auth

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes auth command group manages credentials. Subcommands include add, list, and remove. You use it to add OAuth logins or API keys and see what is stored.

## Concrete Example

You run hermes auth add nous. A browser opens for login. Then hermes auth list shows the Nous token is saved.

## Analogy

Like the accounts section in your phone settings. Add, view, remove logins.
