# Hermes Chat

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes chat command starts an interactive conversation with Hermes. If you just type hermes with no command, it defaults to chat. This is the main way you talk to Hermes in the terminal.

## Concrete Example

You type hermes and a chat prompt opens. You type a question, press Enter, and Hermes replies. You can keep the conversation going for hours.

## Analogy

Like opening WhatsApp and starting to text a friend. The conversation stays open until you close it.
