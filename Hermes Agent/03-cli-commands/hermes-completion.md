# Hermes Completion

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes completion command generates shell completion scripts for bash or zsh. You add the output to your shell config file and Tab auto-fills Hermes commands.

## Concrete Example

You run hermes completion bash >> ~/.bashrc. Next time you open a terminal, typing hermes c and Tab shows chat, config, cron.

## Analogy

Like training your phone keyboard to predict your most-used words.
