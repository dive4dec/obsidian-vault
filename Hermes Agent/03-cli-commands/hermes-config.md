# Hermes Config

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes config command group lets you view, edit, and check your configuration. Subcommands include edit, set, path, and check. It is your control panel for all settings.

## Concrete Example

You run hermes config set display.skin dark. The theme changes. You run hermes config to see all current settings.

## Analogy

Like the settings app on your phone. One place to view and change everything.
