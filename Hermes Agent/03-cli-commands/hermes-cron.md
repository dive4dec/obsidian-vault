# Hermes Cron

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes cron command group manages scheduled tasks. Subcommands include list, create, edit, pause, resume, run, and remove. You set a schedule and Hermes runs tasks automatically.

## Concrete Example

You run hermes cron create every-9am with the prompt to check weather and message you. Every morning at 9, Hermes runs the task.

## Analogy

Like setting a recurring alarm. But instead of just ringing, it does a whole task.
