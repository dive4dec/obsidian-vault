# Hermes Curator

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes curator command manages the skill lifecycle in the background. Subcommands include status, run, pause, resume, pin, archive, restore, prune, backup, and rollback.

## Concrete Example

You run hermes curator status. It shows 3 skills are stale and 1 is pinned. You run hermes curator run to clean up.

## Analogy

Like a garden keeper. They prune dead branches, water the healthy plants, and keep everything tidy.
