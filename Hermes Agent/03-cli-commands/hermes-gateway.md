# Hermes Gateway

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes gateway command group controls the messaging gateway. Subcommands include run, install, start, stop, restart, status, and setup. This is how you connect Hermes to Telegram, Discord, etc.

## Concrete Example

You run hermes gateway start. The gateway begins. You run hermes gateway status and see Telegram connected.

## Analogy

Like the power switches for different appliances in your home. Turn on the TV, turn off the lamp.
