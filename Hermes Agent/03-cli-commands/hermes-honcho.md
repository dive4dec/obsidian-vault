# Hermes Honcho

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes honcho command manages the Honcho memory integration. Honcho is a more advanced memory provider. Subcommands include setup and status.

## Concrete Example

You run hermes honcho setup. It configures Honcho as your memory provider. Now memory uses Honcho instead of the built-in file store.

## Analogy

Like upgrading from a notebook to a filing cabinet. More space, better organisation.
