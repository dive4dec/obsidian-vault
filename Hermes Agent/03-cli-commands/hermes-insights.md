# Hermes Insights

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes insights command shows usage analytics: how many tokens you used, how many sessions, which tools were called. Use --days N to set the time range.

## Concrete Example

You run hermes insights --days 7. A summary shows you used 50,000 tokens and called the web tool 30 times this week.

## Analogy

Like a fitness tracker for your Hermes usage. See your stats over time.
