# Hermes Kanban

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes kanban command manages the multi-agent task board. Subcommands include init, create, list, show, assign, link, comment, complete, and archive.

## Concrete Example

You run hermes kanban init to create a board. Then hermes kanban create with the task title Write tests. You assign it to a worker profile.

## Analogy

Like a Trello board for a group project. Cards move from To Do to Doing to Done.
