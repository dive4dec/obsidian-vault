# Hermes Memory

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes memory command manages the memory system. Subcommands include setup, status, and off. You use it to choose a memory provider and check if memory is working.

## Concrete Example

You run hermes memory status. It shows memory is enabled, provider is built-in, and 42 facts are stored.

## Analogy

Like checking the capacity of your brain. How much do you remember and where is it stored.
