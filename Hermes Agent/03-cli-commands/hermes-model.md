# Hermes Model

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes model command opens an interactive menu to pick or change your AI model and provider. You can also use it to just see what is currently set.

## Concrete Example

You run hermes model. A menu appears. You scroll to Anthropic Claude and press Enter. Hermes now uses that model.

## Analogy

Like the character select screen in a game. Pick a character and the next match uses them.
