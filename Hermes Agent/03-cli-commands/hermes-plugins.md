# Hermes Plugins

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes plugins command manages plugins. Subcommands include list, install, and remove. Plugins add bundles of new features, tools, or integrations.

## Concrete Example

You run hermes plugins install spotify-control. The plugin adds Spotify tools. Now Hermes can play your playlists.

## Analogy

Like installing an expansion pack for a game. New content appears in the main menu.
