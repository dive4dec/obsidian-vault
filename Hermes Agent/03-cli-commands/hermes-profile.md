# Hermes Profile

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes profile command group manages multiple Hermes profiles. Subcommands include list, create, use, delete, show, rename, export, and import. Profiles keep different setups isolated.

## Concrete Example

You run hermes profile create school. Then hermes profile use school. Now all commands use the school profile.

## Analogy

Like having different user accounts on a shared computer. Each person has their own desktop and files.
