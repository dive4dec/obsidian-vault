# Hermes Sessions

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes sessions command group manages your saved conversations. Subcommands include list, browse, export, rename, delete, and prune. You never lose a conversation.

## Concrete Example

You run hermes sessions list and see your last ten chats. You run hermes sessions export homework.json to save one.

## Analogy

Like a photo album. Browse, rename, delete, or export your memories.
