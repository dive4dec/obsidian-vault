# Hermes Skills

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes skills command group manages your skill library. Subcommands include list, search, install, inspect, update, and uninstall. It is how you grow what Hermes can do.

## Concrete Example

You run hermes skills search git. A list of git-related skills appears. You run hermes skills install git-helper to add one.

## Analogy

Like browsing the App Store. Search, read reviews, install, update.
