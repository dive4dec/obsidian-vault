# Hermes Status Command

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

hermes status shows a quick snapshot of what is running and connected. It is faster than doctor and focuses on runtime state, not installation health.

## Concrete Example

You run hermes status. A table shows: Gateway running, Model DeepSeek, 3 tools enabled, 2 profiles exist.

## Analogy

Like glancing at the MTR next-train display. Quick, current, actionable.
