# Hermes Tools

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes tools command opens an interactive menu to enable or disable toolsets. You can also use list, enable, and disable subcommands for scripting.

## Concrete Example

You run hermes tools. A checklist appears. You toggle the browser toolset off and press Enter. Web browsing is now disabled.

## Analogy

Like the toggles in your phone settings. Turn Wi-Fi on, Bluetooth off, etc.
