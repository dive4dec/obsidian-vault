# Hermes Uninstall

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes uninstall command removes the Hermes program from your system. Your data in .hermes may remain. To fully clean up, delete that folder manually afterwards.

## Concrete Example

You run hermes uninstall. The program is removed. You then run rm -rf ~/.hermes to delete all data.

## Analogy

Like returning a library book and then clearing your bookmark file. Two steps to fully clean up.
