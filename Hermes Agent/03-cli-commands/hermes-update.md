# Hermes Update

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The hermes update command downloads and installs the latest version of Hermes. It is the easiest way to get new features and bug fixes. Run it every few weeks.

## Concrete Example

You run hermes update. It downloads, installs, and prints Version 2.2.0 installed. You restart Hermes to use it.

## Analogy

Like tapping Update in the App Store. A minute later, new version ready.
