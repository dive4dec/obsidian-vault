# Quiet Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --quiet flag (or -Q) hides the banner, spinner, and tool previews. Output is just the answer. This is great for scripts where you only want the result.

## Concrete Example

You run hermes chat -q -Q with the question what is 2 plus 2. It prints just 4, no banner, no extra text.

## Analogy

Like a library where everyone whispers. Only the essential words, nothing else.
