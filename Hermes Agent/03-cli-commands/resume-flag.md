# Resume Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --resume flag (or -r) lets you continue a specific past session by its ID or title. This is how you pick up an old conversation exactly where you left off.

## Concrete Example

You run hermes --resume 20260804_homework. The old session opens and Hermes remembers the full context.

## Analogy

Like opening a bookmarked book to the exact page you stopped at.
