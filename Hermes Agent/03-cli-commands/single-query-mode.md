# Single Query Mode

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The -q flag lets you ask Hermes one question and get an answer without entering interactive chat. This is perfect for quick lookups from a script or shortcut.

## Concrete Example

You run hermes chat -q with the question about the capital of France, and Hermes prints Paris, then exits.

## Analogy

Like a fortune-telling machine. You insert a coin, ask one question, get an answer, done.
