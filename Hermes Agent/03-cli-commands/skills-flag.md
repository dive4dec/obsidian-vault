# Skills Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --skills flag (or -s) preloads one or more skills at startup. This is useful when you know you will need a specific skill and want it ready immediately.

## Concrete Example

You run hermes -s git-helper,lab-report. Both skills load at startup. When you ask about git, Hermes uses the skill instantly.

## Analogy

Like packing specific textbooks in your bag before class. They are ready when you need them.
