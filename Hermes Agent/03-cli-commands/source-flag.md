# Source Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --source flag tags the session with a label, like cli, telegram, or cron. This helps you filter sessions later by where they came from.

## Concrete Example

You run hermes chat --source school-project. Later, hermes sessions list can filter sessions tagged school-project.

## Analogy

Like colour-coding your notebooks by subject. Easy to find the one you need.
