# Version Flag

> **Domain:** [[_cli-commands-moc|CLI & Commands]]

## Motivation

The --version flag (or -V) prints the installed Hermes version and exits. Useful for checking what you are running or reporting a bug.

## Concrete Example

You run hermes --version. It prints Hermes Agent 2.1.0. You now know which version to report in a bug ticket.

## Analogy

Like checking the edition number on a textbook. Quick, one line, done.
