# Config Defaults

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Default values used when a config option is not set. Hermes has sensible defaults for everything.

## Concrete Example

No config? Hermes uses: model=openrouter auto, max_turns=30, compression=on, memory=off. Everything works out of the box. Config is optional.

## Analogy

Default settings on a new phone - it works without any setup. You can customize later. Hermes defaults let it work immediately.
