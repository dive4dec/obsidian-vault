# Config Export

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Saving your config to a shareable file. Useful for backups or sharing with others.

## Concrete Example

hermes config export my-config.yaml. Your config.yaml is copied to my-config.yaml. Share it with colleagues or back it up.

## Analogy

Exporting your contacts to a file - you save them for backup or sharing. Config export saves your settings for backup or sharing.
