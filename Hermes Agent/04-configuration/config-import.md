# Config Import

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Loading a config from another source. Useful when setting up a new machine or sharing configs.

## Concrete Example

hermes config import my-config.yaml. Your config is replaced with my-config.yaml. All settings transferred in one command.

## Analogy

Importing contacts to a new phone - you load a file and all contacts appear. Config import loads settings from a file.
