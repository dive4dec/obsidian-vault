# Config Path

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Show the location of config.yaml. Command: hermes config path.

## Concrete Example

hermes config path. Output: /home/alice/.hermes/config.yaml. Useful when you need to find the file manually or back it up.

## Analogy

Asking for an address - you need to know where something is. hermes config path tells you where config.yaml lives.
