# Config Reset

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Resetting config to factory defaults. Command: hermes config reset. All custom settings are lost.

## Concrete Example

hermes config reset. Are you sure? y. Config is reset to defaults. All custom model, memory, and security settings are gone. Fresh start.

## Analogy

Factory reset on a phone - everything goes back to how it was when you bought it. Config reset puts Hermes back to defaults.
