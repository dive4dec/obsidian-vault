# Config Sections

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

The major sections of config.yaml: model, agent, terminal, compression, display, stt, tts, memory, security, delegation, checkpoints.

## Concrete Example

config.yaml sections: model: (which LLM), agent: (behavior), terminal: (shell), compression: (context), display: (UI), stt: (voice input), tts: (voice output), memory: (persistence), security: (protection), delegation: (subagents), checkpoints: (snapshots).

## Analogy

Different departments in a school - math, science, English, PE. Each manages its own area. Config sections each manage their own feature area.
