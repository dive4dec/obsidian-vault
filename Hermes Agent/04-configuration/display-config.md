# Display Config

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

The display section: skin, tool_progress, show_reasoning, show_cost, show_models.

## Concrete Example

display: skin: default, tool_progress: true, show_reasoning: medium, show_cost: true. The display section controls what you see in the TUI.

## Analogy

A phone display settings - brightness, dark mode, font size. Display config controls what you see in the Hermes interface.
