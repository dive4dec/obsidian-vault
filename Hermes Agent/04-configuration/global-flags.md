# Global Flags

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Command-line flags that work with all hermes commands: --resume, --continue, --worktree, --skills, --profile, --yolo.

## Concrete Example

hermes --profile work chat. Or: hermes --yolo chat. Or: hermes --skills debugging,github chat. Global flags modify how any command runs.

## Analogy

Universal settings on a camera - flash, timer, resolution work with any photo mode. Global flags work with any hermes command.
