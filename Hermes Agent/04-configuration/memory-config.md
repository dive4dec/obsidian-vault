# Memory Config

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

The memory section: enabled, provider, char_limit. Controls persistent memory.

## Concrete Example

memory: enabled: true, provider: built-in, char_limit: 2000. Hermes remembers your preferences across sessions. The memory config controls how.

## Analogy

A notebook settings - size, type, sections. Memory config sets how Hermes memory works.
