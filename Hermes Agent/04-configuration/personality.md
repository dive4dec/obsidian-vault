# Personality

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A custom personality for Hermes. Defined in SOUL.md. Controls tone, style, and behavior.

## Concrete Example

SOUL.md: You are a patient, encouraging tutor. Explain simply, use analogies, praise effort. Hermes adopts this personality in all conversations.

## Analogy

An actor playing a character - they adopt the character personality in every scene. SOUL.md lets Hermes play a specific character.
