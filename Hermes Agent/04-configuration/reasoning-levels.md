# Reasoning Levels

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

How much the model reasons before responding. Levels: none, minimal, low, medium, high, xhigh. Higher = more thinking.

## Concrete Example

agent.reasoning: high. The model thinks deeply: considers options, plans steps, evaluates trade-offs. Lower levels think less. Higher levels are smarter but slower.

## Analogy

A student deciding how to solve a problem - quick guess (none) vs careful analysis (high). Reasoning levels control how much the model thinks before answering.
