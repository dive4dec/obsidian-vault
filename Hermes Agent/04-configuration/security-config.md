# Security Config

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

The security section: tirith_enabled, redact_secrets, website_blocklist. Controls all security features.

## Concrete Example

security: tirith_enabled: true, redact_secrets: true, website_blocklist: [evil.com]. Three security layers. The security config controls all protection.

## Analogy

A security system settings - alarm, cameras, door codes. Security config sets all Hermes security features.
