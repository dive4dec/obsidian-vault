# Show Cost

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A display setting that shows token usage and cost after each response.

## Concrete Example

display.show_cost: true. After each response: Tokens: 1,234 in, 567 out. Cost: $0.012. You see how much each message costs.

## Analogy

A receipt after shopping - you see how much you spent. Show cost displays the token and dollar cost of each response.
