# Show Reasoning

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A display setting that shows the model reasoning process. Levels: none, minimal, low, medium, high, xhigh.

## Concrete Example

display.show_reasoning: medium. You see: Reasoning: The user wants... I should use the terminal tool... The thought process is visible.

## Analogy

Showing your work in math class - the teacher sees each step. Show reasoning displays the model thought process.
