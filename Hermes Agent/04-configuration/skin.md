# Skin

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

Visual theme for the TUI. Controls colors, borders, and layout. Configured in display section.

## Concrete Example

display.skin: default. Or: minimal, dark, retro. Each skin changes how the TUI looks. Colors, borders, status bar style - all controlled by skin.

## Analogy

A phone case - you pick a color and style. The phone works the same, but looks different. Skins change how Hermes looks, not how it works.
