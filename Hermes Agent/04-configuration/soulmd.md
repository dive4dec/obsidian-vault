# SOUL.md

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A file defining Hermes personality. Located at ~/.hermes/SOUL.md. Contains instructions for tone, style, and behavior.

## Concrete Example

SOUL.md: You are Hermes, a helpful and friendly assistant. Be concise. Use Hong Kong examples. Speak formally. Hermes reads this and adopts the personality.

## Analogy

A role description for an actor - it tells them how to play the character. SOUL.md tells Hermes how to play its role.
