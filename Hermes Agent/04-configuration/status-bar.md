# Status Bar

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A TUI element showing session info: model name, token count, cost, turn number.

## Concrete Example

Status bar: Model: claude-sonnet-4 | Tokens: 12K/200K | Cost: $0.05 | Turn: 5. Always visible at the bottom of the TUI.

## Analogy

A car dashboard - always shows speed, fuel, temperature. The status bar always shows model, tokens, cost.
