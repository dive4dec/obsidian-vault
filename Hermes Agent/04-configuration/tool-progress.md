# Tool Progress

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A display setting that shows tool execution progress in real-time. Configured in display section.

## Concrete Example

display.tool_progress: true. When Hermes runs a tool, you see: Running terminal... Done. Running read_file... Done. Real-time feedback.

## Analogy

A progress bar on a download - you see how it is going. Tool progress shows each tool as it runs.
