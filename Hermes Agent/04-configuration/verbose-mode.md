# Verbose Mode

> **Domain:** [[_configuration-moc|Configuration]]

## Motivation

A display setting that shows full tool input and output. Command: /verbose. Or config: display.verbose: true.

## Concrete Example

/verbose on. Terminal tool: shows full command AND full output. /verbose off. Terminal tool: shows summary only. Verbose mode shows everything.

## Analogy

A teacher showing all steps vs just the answer. Verbose mode shows all steps. Normal mode shows just the answer.
