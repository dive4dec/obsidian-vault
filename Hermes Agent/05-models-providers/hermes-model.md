# Hermes Model

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

The CLI command for managing models. Subcommands: set, list, add, remove, default.

## Concrete Example

hermes model set anthropic/claude-sonnet-4. hermes model list: shows all available. hermes model default: shows current. All model management in one command.

## Analogy

A channel selector on a TV - you pick which channel to watch. hermes model lets you pick which LLM to use.
