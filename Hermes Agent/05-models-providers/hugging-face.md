# Hugging Face

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

An open AI platform. Hosts thousands of open-source models. Can be used as a provider.

## Concrete Example

huggingface/Qwen/Qwen2.5-72B: open-source model. hermes model set huggingface/... Access thousands of community models.

A public library - anyone can contribute and borrow. Hugging Face is the public library for AI models.
