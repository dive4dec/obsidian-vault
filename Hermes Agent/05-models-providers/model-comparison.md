# Model Comparison

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Testing different models on the same task to compare quality, speed, and cost.

## Concrete Example

Ask: Write a Python sort function. Claude: 2s, $0.01, clean code. GPT-4o: 1s, $0.02, clean code. DeepSeek: 3s, $0.001, clean code. Compare and pick best.

## Analogy

Test driving different cars - you try each on the same road and compare. Model comparison tests LLMs on the same task.
