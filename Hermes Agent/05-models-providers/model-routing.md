# Model Routing

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Hermes can route different tasks to different models. E.g., simple tasks to a cheap model, complex tasks to a smart model.

## Concrete Example

Simple question -> DeepSeek (cheap). Complex coding -> Claude (smart). Image analysis -> GPT-4o (vision). Each task goes to the best model.

## Analogy

A hospital routing patients: minor issues to a general doctor, serious cases to a specialist. Model routing sends tasks to the right model.
