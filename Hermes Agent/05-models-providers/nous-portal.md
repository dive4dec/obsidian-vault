# Nous Portal

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Nous Research hosted service. Provides OAuth authentication, hosted models, and the Tool Gateway. Easiest way to start.

## Concrete Example

hermes setup --portal. OAuth login. You get: a model (for chatting) + 4 tools (web search, image gen, TTS, browser). All with one account. No API keys.

## Analogy

A school all-access pass - one ID gives you library, gym, lab, cafeteria. Nous Portal is the all-access pass for Hermes.
