# OpenRouter

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

A popular LLM provider aggregator. One API key gives access to hundreds of models from many companies.

## Concrete Example

OpenRouter: one key, 300+ models. Claude, GPT-4, Gemini, DeepSeek, Llama - all accessible. hermes model set openrouter/anthropic/claude-sonnet-4. One provider, many models.

## Analogy

A supermarket with many brands - you shop at one store but buy different brands. OpenRouter is the supermarket for LLMs.
