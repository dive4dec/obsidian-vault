# Provider Agnostic

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Hermes works with any LLM provider. You are not locked into one company. Switch providers anytime.

## Concrete Example

Today: use Anthropic Claude. Tomorrow: switch to OpenAI GPT-4o. Next week: try DeepSeek. Same Hermes, different providers. One command: hermes model set.

## Analogy

A universal phone - it works with any SIM card. You are not locked into one carrier. Hermes works with any LLM provider.
