# Provider Selection

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Choosing which LLM provider to use. Based on: cost, quality, speed, context length, features.

## Concrete Example

Choose: Claude for coding (best quality), GPT-4o for vision, DeepSeek for compression (cheap), Gemini for long context. Different providers for different needs.

## Analogy

Choosing transportation: MTR for speed, bus for cost, taxi for convenience. Different providers for different needs.
