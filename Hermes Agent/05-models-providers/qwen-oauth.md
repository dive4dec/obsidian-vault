# Qwen OAuth

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Alibaba Qwen models accessible via OAuth instead of API key. Easier authentication.

## Concrete Example

hermes auth add qwen --oauth. Browser opens, you log in. Token is saved. No API key needed. Qwen is now available.

## Analogy

Using a student ID to access campus services - no need for a separate pass. Qwen OAuth uses login instead of API keys.
