# Token Cost

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

The cost of using an LLM. Measured in tokens. Different providers have different prices.

## Concrete Example

Claude: $3/1M input, $15/1M output. GPT-4o: $2.50/1M input, $10/1M output. DeepSeek: $0.14/1M input, $0.28/1M output. Prices vary widely.

## Analogy

Parking fees - different carparks have different rates. Token costs vary by provider. Choose based on budget.
