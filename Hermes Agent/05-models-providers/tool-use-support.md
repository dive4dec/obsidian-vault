# Tool Use Support

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Whether a model supports function/tool calling. Most modern models do, but quality varies.

## Concrete Example

Claude: excellent tool use. GPT-4o: good. Some smaller models: poor or no tool use. Tool use is essential for agents.

## Analogy

A worker who can use tools vs one who can only talk. Tool use support determines if a model can be an agent.
