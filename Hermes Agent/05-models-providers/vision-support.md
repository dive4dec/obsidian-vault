# Vision Support

> **Domain:** [[_models-providers-moc|Models & Providers]]

## Motivation

Whether a model can analyze images. GPT-4o, Claude, and Gemini support vision.

## Concrete Example

GPT-4o: send a photo, it describes what it sees. Claude: same. Some models: text only, no vision. Vision support enables image analysis.

## Analogy

A friend who can see vs one who is blind. Vision support lets the model see and analyze images.
