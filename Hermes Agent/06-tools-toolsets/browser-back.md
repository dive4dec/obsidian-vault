# Browser Back

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that navigates back to the previous page in browser history.

## Concrete Example

browser_back(). Goes back to the previous page. Like pressing the Back button in your browser.

## Analogy

The back button on a browser - you go to the previous page. Browser back lets Hermes navigate backward.
