# Browser Click

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that clicks an element on a web page by its ref ID.

## Concrete Example

browser_click(ref=@e5). Clicks the element with ref @e5 (e.g., a Submit button). The page updates. New snapshot available.

## Analogy

Pressing a button on an elevator - you press floor 5, the elevator goes there. Browser click presses buttons on web pages.
