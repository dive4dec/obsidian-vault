# Browser Console

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that gets browser console output and JavaScript errors. Also evaluates JS expressions.

## Concrete Example

browser_console(expression=document.title). Returns: Example Domain. JavaScript executed in the page. Console errors visible.

## Analogy

Opening Developer Tools in a browser - you see console messages and errors. Browser console lets Hermes see page internals.
