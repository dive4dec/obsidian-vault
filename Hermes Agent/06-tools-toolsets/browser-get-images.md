# Browser Get Images

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that lists all images on the current page with URLs and alt text.

## Concrete Example

browser_get_images(). Returns: [{url: img1.jpg, alt: Logo}, {url: img2.jpg, alt: Photo}]. All images listed.

## Analogy

A photo gallery - you see all photos with labels. Browser get images lists all images on a page.
