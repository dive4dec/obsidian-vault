# Browser Press

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that presses a keyboard key. Useful for submitting forms (Enter), navigating (Tab).

## Concrete Example

browser_press(key=Enter). Submits the form. Or: browser_press(key=Tab). Moves to the next field. Keyboard interaction.

## Analogy

Pressing keys on a keyboard - Enter to submit, Tab to move. Browser press lets Hermes use the keyboard on web pages.
