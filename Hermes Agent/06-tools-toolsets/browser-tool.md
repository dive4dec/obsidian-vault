# Browser Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for web browser automation. Navigate, click, type, screenshot. Uses Browserbase, Camofox, or local Chromium.

## Concrete Example

browser_navigate(url=https://example.com). browser_click(ref=@e5). browser_type(ref=@e3, text=Hello). Full browser automation.

## Analogy

A remote-controlled hand - it navigates, clicks, and types on web pages. The browser tool lets Hermes browse the web.
