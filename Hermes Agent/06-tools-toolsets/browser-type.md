# Browser Type

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that types text into an input field on a web page.

## Concrete Example

browser_type(ref=@e3, text=Hello World). Types Hello World into the text field with ref @e3. Like filling in a form.

## Analogy

Writing on a form with a pen - you fill in the blanks. Browser type fills in web forms.
