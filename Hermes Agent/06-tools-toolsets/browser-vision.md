# Browser Vision

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool that takes a screenshot for visual analysis. Useful for CAPTCHAs, complex layouts, visual verification.

## Concrete Example

browser_vision(question=What does this page look like?). Screenshot taken. Analysis: The page has a blue header with a login form. Visual understanding.

## Analogy

Taking a photo of a screen - you can see what is displayed. Browser vision lets Hermes see what the web page looks like.
