# Code Execution

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for running Python code programmatically. Used for multi-step logic, data processing, loops.

## Concrete Example

execute_code(code=print(2+2)). Returns: 4. Used for: filtering data, conditional logic, loops, calculations. More flexible than single tool calls.

## Analogy

A calculator that can do complex math - not just 2+2 but full equations with variables. Code execution lets Hermes run Python programs.
