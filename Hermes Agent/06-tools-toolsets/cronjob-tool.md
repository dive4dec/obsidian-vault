# Cronjob Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for creating and managing scheduled tasks. The model can set up recurring jobs.

## Concrete Example

cronjob(action=create, schedule=every 2h, prompt=Check server status). A cron job is created. Every 2 hours, Hermes checks the server.

## Analogy

An alarm clock that repeats - you set it and it goes off regularly. The cronjob tool lets the model set recurring tasks.
