# Discord Admin Toolset

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Tools for Discord server administration: manage roles, channels, bans.

## Concrete Example

discord_admin: ban user, create role, delete channel. Administrative actions on Discord. Available when Hermes is a Discord admin.

## Analogy

A moderator badge at an event - you can manage crowd, remove troublemakers. Discord admin tools let Hermes moderate a Discord server.
