# File Tools

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Tools for file operations: read_file, write_file, patch, search_files. Part of the terminal toolset.

## Concrete Example

read_file: cat with line numbers. write_file: create/overwrite. patch: find-and-replace. search_files: grep/find. All file operations.

## Analogy

A filing cabinet with tools - you read, write, modify, and search files. File tools give Hermes a filing cabinet.
