# Hermes Core Tools

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

The set of tools always loaded. Defined in toolsets.py as _HERMES_CORE_TOOLS. Cannot be disabled.

## Concrete Example

_CORE_TOOLS: [terminal, read_file, write_file, patch, search_files, browser_*, web_search, todo, memory, session_search, skills, delegate_task, cronjob, clarify, tts, vision, image_generate]. Always available.

## Analogy

The foundation of a house - always there, cannot be removed. Core tools are always loaded and cannot be disabled.
