# Hermes Tools

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

The CLI command for managing tools. Subcommands: list, search, enable, disable, check.

## Concrete Example

hermes tools list: shows all tools and status. hermes tools enable web_search: turns on a tool. hermes tools disable tts: turns off a tool. All tool management in one command.

## Analogy

A control panel for appliances - you see all appliances and can turn them on/off. hermes tools manages all Hermes tools.
