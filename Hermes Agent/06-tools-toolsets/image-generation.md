# Image Generation

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for creating images from text descriptions. Text-to-image using FAL, OpenAI, or other backends.

## Concrete Example

image_generate(prompt=a cat in a space suit, aspect_ratio=square). Returns: image URL. Text became an image.

## Analogy

A magic paintbrush - you describe what you want, it paints it. Image generation creates images from text descriptions.
