# Kanban Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for managing a Kanban board with columns and cards. Visual task management.

## Concrete Example

kanban(add card=Fix auth bug to column=Todo). kanban(move card=Fix auth bug to column=Doing). Visual project management.

## Analogy

A whiteboard with sticky notes - you move tasks from To Do to Doing to Done. The Kanban tool is a digital whiteboard for tasks.
