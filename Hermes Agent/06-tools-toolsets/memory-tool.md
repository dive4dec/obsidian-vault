# Memory Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for reading and writing persistent memory. The model can save facts and recall them later.

## Concrete Example

memory(action=add, target=user, content=User prefers Python). Fact saved. Next session: fact is recalled. Persistent across sessions.

## Analogy

A sticky note on your desk - you write something and it stays. The memory tool lets the model write and read sticky notes.
