# Messaging Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Tools for sending messages across platforms. The model can send messages to Telegram, Discord, etc.

## Concrete Example

send_message(platform=telegram, chat_id=123, text=Hello). Message sent to Telegram chat. Cross-platform messaging from within the agent.

## Analogy

A messaging app on your phone - you send messages to contacts. The messaging tool lets Hermes send messages to platforms.
