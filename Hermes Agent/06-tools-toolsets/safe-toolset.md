# Safe Toolset

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A restricted toolset with only safe tools. No terminal, no file deletion. Used in educational or restricted environments.

## Concrete Example

safe toolset: [read_file, web_search, todo, memory]. No terminal (no shell commands). No write_file (no file changes). Safe for students.

## Analogy

Training wheels on a bicycle - you can ride but cannot fall. The safe toolset lets the model work but not break anything.
