# Session Search Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for searching past conversation history. FTS5-backed full-text search.

## Concrete Example

session_search(query=docker debugging, limit=3). Returns: 3 past sessions about Docker debugging. The model can recall past conversations.

## Analogy

A search engine for your chat history - you type a keyword and find past conversations. Session search lets the model recall past chats.
