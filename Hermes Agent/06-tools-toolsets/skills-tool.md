# Skills Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for loading and using skills. The model can browse, load, and follow skill instructions.

## Concrete Example

Model: I need to debug. /skill debugging. Skill loaded. Model follows the debugging steps. The skills tool gives access to the skill library.

## Analogy

A library card - you browse, check out, and read books. The skills tool lets the model browse and use skills.
