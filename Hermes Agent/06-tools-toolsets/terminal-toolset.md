# Terminal Toolset

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Tools for shell and file operations: terminal, read_file, write_file, patch, search_files.

## Concrete Example

terminal: run shell commands. read_file: read files with line numbers. write_file: create/edit files. patch: find-and-replace. search_files: grep/find. Full filesystem access.

## Analogy

A terminal window on your computer - you run commands, edit files, search. The terminal toolset gives Hermes a terminal.
