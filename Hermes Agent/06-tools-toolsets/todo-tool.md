# Todo Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for managing a task list within the session. The model can track multi-step tasks.

## Concrete Example

todo(todos=[{id:1, content:Read file, status:done}, {id:2, content:Fix bug, status:in_progress}]). Task list tracked. Progress visible.

## Analogy

A checklist on your desk - you list tasks and check them off. The todo tool lets the model track its task list.
