# Tool Disable

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Turn off a specific tool. Command: hermes tools disable TOOL_NAME. Or /tools disable in session.

## Concrete Example

hermes tools disable terminal. The model can no longer run shell commands. Safer for restricted environments. /tools disable tts. No voice output.

## Analogy

Turning off a light switch - the light is off, cannot be used. Tool disable turns off a specific tool so the model cannot use it.
