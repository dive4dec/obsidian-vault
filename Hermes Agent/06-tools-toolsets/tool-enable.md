# Tool Enable

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Turn on a specific tool. Command: hermes tools enable TOOL_NAME. Or /tools enable in session.

## Concrete Example

hermes tools enable web_search. web_search is now available. The model can use it. /tools enable image_gen. Enabled for this session.

## Analogy

Turning on a light switch - the light is now available. Tool enable turns on a specific tool for the model to use.
