# Tool Progress Display

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A visual indicator showing which tool is running and its progress. Configured in display section.

## Concrete Example

Tool running: [terminal] ls -la... Done. [read_file] notes.txt... Done. [web_search] AI news... Running... Real-time feedback.

## Analogy

A progress bar on a download - you see what is happening. Tool progress display shows each tool as it runs.
