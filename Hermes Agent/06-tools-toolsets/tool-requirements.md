# Tool Requirements

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Some tools require specific config or setup. Hermes checks requirements before enabling a tool.

## Concrete Example

web_search requires: API key or Tool Gateway. spotify requires: Spotify Premium account. vision requires: vision model configured. Requirements checked at startup.

## Analogy

Prerequisites for a class - you need a textbook before attending. Tool requirements must be met before a tool can be used.
