# Tool Search

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Search for tools by keyword. Command: hermes tools search KEYWORD.

## Concrete Example

hermes tools search file. Results: read_file, write_file, patch, search_files. Find the right tool fast.

## Analogy

Searching an app store - you type a keyword and see matching apps. Tool search finds matching tools by keyword.
