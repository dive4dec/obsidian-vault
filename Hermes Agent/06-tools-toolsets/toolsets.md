# Toolsets

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Named groups of tools. Examples: web, terminal, file, vision, image_gen, tts, skills, memory, delegation, cronjob. Each toolset is a category.

## Concrete Example

toolset terminal: [terminal, read_file, write_file, patch, search_files]. toolset web: [web_search, web_extract, browser_navigate]. Groups for easy management.

## Analogy

A toolbox with compartments - screwdrivers in one, wrenches in another, hammers in a third. Toolsets group tools by category.
