# TTS Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for converting text to speech audio. Multiple providers supported.

## Concrete Example

text_to_speech(text=Hello, how are you?). Returns: audio file. On Telegram, sent as a voice message. Text became audio.

## Analogy

An audiobook narrator - they read text aloud. The TTS tool reads Hermes text responses aloud.
