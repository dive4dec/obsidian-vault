# Vision Tool

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

A tool for analyzing images. The model can see and understand images. Uses the vision auxiliary model.

## Concrete Example

vision_analyze(image_url=photo.jpg, question=What is in this image?). Returns: A cat sitting on a desk. Image understood.

## Analogy

A friend who describes what they see - you show them a photo, they tell you what is in it. The vision tool lets Hermes see images.
