# Web Toolset

> **Domain:** [[_tools-toolsets-moc|Tools & Toolsets]]

## Motivation

Tools for web interaction: web_search, web_extract, browser_navigate, browser_click, browser_type, browser_snapshot, browser_vision.

## Concrete Example

web_search: find information. web_extract: read web pages. browser_navigate: open URLs. browser_click: click elements. Full web interaction.

## Analogy

A web browser on your computer - you search, read, click, type. The web toolset gives Hermes a web browser.
