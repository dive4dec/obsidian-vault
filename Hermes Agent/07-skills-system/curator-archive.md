# Curator Archive

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

The curator moves a stale skill to an archive folder instead of deleting it. Archived skills can be restored later.

## Concrete Example

The curator archives unused-skill-v1 to ~/.hermes/skills/.archive/. It is out of the active library but not gone. You can restore it if needed.

## Analogy

Moving old clothes to a storage box in the attic - you are not wearing them but they are not thrown away. You can retrieve them if needed. Archiving skills works the same way.
