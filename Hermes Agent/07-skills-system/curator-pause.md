# Curator Pause

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Temporarily stopping the curator from making changes. Useful when you are actively working on skills and do not want them moved.

## Concrete Example

hermes curator pause stops automatic maintenance. Now your skills stay exactly as they are until you resume. Useful when editing multiple SKILL.md files.

## Analogy

Pausing an alarm system while you are home - you do not want it triggering while you are moving around. Curator pause prevents changes while you are actively editing.
