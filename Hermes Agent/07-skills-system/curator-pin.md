# Curator Pin

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Marking a skill as protected so the curator will never archive or modify it. Pinned skills stay forever.

## Concrete Example

hermes curator pin github-pr-workflow marks it as pinned. The curator sees the pin and skips it during cleanup. Even if unused for a year, it stays.

## Analogy

Putting a do not remove sticker on a box in storage - the cleaners see it and leave that box alone. Pinning protects a skill from being cleaned up.
