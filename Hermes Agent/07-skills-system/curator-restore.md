# Curator Restore

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Bringing an archived skill back into the active library. Useful if you need a skill you previously archived.

## Concrete Example

hermes curator restore unused-skill-v1 moves it from .archive back to the active skills directory. It is available again for the agent to load and use.

## Analogy

Taking winter clothes out of storage when cold weather returns - you packed them away, now you bring them back. Restore does this for archived skills.
