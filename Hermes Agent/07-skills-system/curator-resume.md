# Curator Resume

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Restarting the curator after a pause so it resumes automatic maintenance of the skill library.

## Concrete Example

hermes curator resume un-pauses the curator. It will run on its next scheduled time. Any changes you made to skills during the pause are now visible to it.

## Analogy

Turning the alarm back on after leaving the house - you paused it while inside, now you resume it as you leave. Curator resume restarts maintenance.
