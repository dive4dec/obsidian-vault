# Curator Rollback

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Undoing curator changes by restoring from a backup. If the curator archived something you needed, rollback brings it back.

## Concrete Example

hermes curator rollback skills-backup-2026-08-04 restores all skills to how they were on that date. The wrongly-archived skill comes back.

## Analogy

Pressing undo after a bad edit - you revert to the previous version. Curator rollback undoes the curator changes by restoring a backup.
