# Curator Status

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Checking what the curator is doing or has done: is it running, paused, what changes has it made recently?

## Concrete Example

hermes curator status shows: State: running / Last run: 2 hours ago / Actions: archived 2 stale skills, updated 3 descriptions. You see the curator recent activity.

## Analogy

Checking a cleaning schedule - the cleaner logged: vacuumed living room, cleaned kitchen, skipped garage. Curator status shows what maintenance was done.
