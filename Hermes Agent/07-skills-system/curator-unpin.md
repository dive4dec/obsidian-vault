# Curator Unpin

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Removing the pin protection from a skill so the curator can manage it normally again (archive if stale, update descriptions).

## Concrete Example

hermes curator unpin old-experiment removes the pin. Now if it goes stale, the curator may archive it. You unpin when a skill is no longer critical.

## Analogy

Removing the do not remove sticker - the cleaners can now clear that box if it is old. Unpinning lets the curator manage the skill normally again.
