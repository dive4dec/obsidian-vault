# Curator

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A background process that manages the skill library automatically: archiving stale skills, updating descriptions, and keeping things tidy.

## Concrete Example

The curator notices you have not used old-python-2-tool in 3 months. It archives it. It also updates a skill description that was too vague. The curator keeps the library healthy.

## Analogy

A museum curator who organises exhibits - they rotate old pieces into storage, clean dusty displays, and arrange new items. The skill curator organises the skill library.
