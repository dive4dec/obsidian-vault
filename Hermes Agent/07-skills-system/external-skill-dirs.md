# External Skill Dirs

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Skills do not have to live only in the default folder. You can add external directories so skills can be shared across projects.

## Concrete Example

You set skills_dirs to include /mnt/shared/team-skills/. Now both your agent and your teammate agent can use the same shared skills without copying.

## Analogy

A shared network drive at school - instead of each student having their own copy of files, everyone accesses the shared drive. External skill dirs are shared skill locations.
