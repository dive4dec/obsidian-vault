# Reload Skills

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A command to refresh the skill list after adding or editing skills, so the agent sees the changes without restarting.

## Concrete Example

You just edited a SKILL.md file. Typing /reload-skills makes the agent re-scan the skills directory and pick up your changes immediately.

## Analogy

Refreshing a web page after the content changes - you hit F5 to see the latest version. /reload-skills refreshes the agent view of skills.
