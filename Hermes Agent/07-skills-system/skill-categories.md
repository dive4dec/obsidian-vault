# Skill Categories

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Skills can be grouped into categories like devops, data-science, or mlops. Categories help organise the skill library and find what you need fast.

## Concrete Example

Under the devops category you find dockerfile-optimization, k8s-troubleshooting, helm-chart-deployment. Under creative you find ascii-art, pixel-art, p5js. Categories keep things tidy.

## Analogy

A library with section signs - Fiction here, Science there, History in the back. You go straight to the right section instead of searching every shelf. Categories do this for skills.
