# Skill Command

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A slash command that manually loads a specific skill into the current session, even if the agent did not auto-discover it.

## Concrete Example

Typing /skill debugging loads the debugging skill right now. The agent reads SKILL.md and follows its steps for the rest of the conversation.

## Analogy

Asking a friend to pull out their recipe book - they might not have planned to cook that dish, but you request it, so they get the recipe out. /skill is a manual request.
