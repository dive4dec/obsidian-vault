# Skill Conflict Resolution

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

When two skills cover the same task, the agent needs rules to pick the right one. Conflict resolution prevents confusion.

## Concrete Example

Two skills both handle git commits. The agent picks the one with a more specific description match, or the one with higher usage. Conflict resolution chooses the best match.

## Analogy

Two friends giving you different directions to the same place - you pick the one who knows the area better. Conflict resolution picks the better skill.
