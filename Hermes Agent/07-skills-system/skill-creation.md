# Skill Creation

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

When a task succeeds after several steps, you save the approach as a skill so the agent can repeat it without rediscovering the method each time.

## Concrete Example

You fixed a tricky Docker bug after 5 attempts. You save the working steps as a skill called docker-troubleshooting. Next time, the agent loads it and fixes similar bugs fast.

## Analogy

A student who figured out a great study method and writes it down - next exam, they just follow their notes instead of starting from scratch.
