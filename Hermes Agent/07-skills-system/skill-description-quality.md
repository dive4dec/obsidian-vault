# Skill Description Quality

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A good skill description is specific enough for auto-discovery to match it correctly. Vague descriptions lead to wrong skill choices.

## Concrete Example

Bad: Helps with stuff. Good: Deploy Helm charts to Kubernetes, integrate CRDs, manage releases. The good description has keywords the agent can match to deployment tasks.

## Analogy

A clear shop sign - Sushi Restaurant is better than Food Place. A clear description helps people (and the agent) find the right skill.
