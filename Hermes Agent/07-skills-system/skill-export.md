# Skill Export

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Saving a skill as a shareable file or archive so you can move it to another machine or share with a colleague.

## Concrete Example

hermes skills export debugging creates debugging-skill.tar.gz. You send it to a colleague who runs hermes skills import on their machine. The skill transfers cleanly.

## Analogy

Exporting a presentation as a file - instead of sharing online, you save it as a file someone can open on their computer. Skill export packages a skill for transfer.
