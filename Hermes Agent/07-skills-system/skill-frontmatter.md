# Skill Frontmatter

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

YAML metadata at the top of SKILL.md that gives the agent key info: the skill name, a short description, and optional tags for organising.

## Concrete Example

Frontmatter looks like: name: github-pr-workflow / description: Branch, commit, open PR, check CI / tags: [git, github]. The agent reads this first to decide if the skill is relevant.

## Analogy

The label on a file folder tab - before opening the folder, you read the tab to know what is inside. Frontmatter is the tab label for a skill.
