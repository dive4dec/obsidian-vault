# Skill Import

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Bringing a skill from a file or archive into the skill library, without using the hub. Useful for offline or private skills.

## Concrete Example

hermes skills import ~/downloads/my-private-skill.tar.gz unpacks the archive into the skills directory. The skill is now available, no internet needed.

## Analogy

Importing contacts from a file - instead of adding them one by one online, you load a file. Skill import loads a skill from a file without the hub.
