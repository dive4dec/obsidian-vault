# Skill Lifecycle

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A skill goes through stages: created, active, stale, archived, pruned. Understanding the lifecycle helps you manage skills well.

## Concrete Example

A skill is created (you write it), becomes active (agent uses it), goes stale (not used in months), gets archived (curator moves it), then pruned (deleted after long unused).

## Analogy

A product in a store: new arrival, on display, moved to clearance, sent to warehouse, eventually discontinued. Skills have a similar lifecycle.
