# Skill MOC

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A Map of Content that lists all skills in a domain, helping you navigate the skill library visually.

## Concrete Example

The Skills System MOC lists all 60 concepts in this domain as links. You click any concept to read its note. The MOC is the index page for the domain.

## Analogy

A table of contents in a textbook - it lists all chapters and page numbers. You use it to find what you need. A skill MOC is the table of contents for skills.
