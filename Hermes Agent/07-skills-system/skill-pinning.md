# Skill Pinning

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Manually marking a skill as important so it is never archived. Different from curator pin - this is a user action to protect a favourite skill.

## Concrete Example

You pin debugging and tdd because you use them constantly. Even if usage drops temporarily, they stay in the active library. Pinning gives you control.

## Analogy

Bookmarking a webpage - you mark it as important so it never gets deleted from your history. Pinning marks a skill as permanent.
