# Skill Provenance

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Tracking whether a skill was created by the agent itself, installed from the hub, or written by a human. Provenance tells you where a skill came from.

## Concrete Example

A skill shows provenance: created_by: agent (auto-saved after a successful task) vs created_by: hub (installed from community). You trust agent-created skills differently from hub ones.

## Analogy

A food label showing country of origin - Made in Japan vs Made locally. Provenance tells you the origin of a skill, which affects how much you trust it.
