# Skill References

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Files linked from SKILL.md that provide extra detail: API docs, configuration examples, or reference tables. They keep SKILL.md focused.

## Concrete Example

SKILL.md says: For full API details, see references/api.md. The agent loads references/api.md when it needs the complete API documentation. SKILL.md stays concise.

## Analogy

A textbook with a references section at the back - the main chapter gives the overview, but detailed tables and formulas are in the appendix. Skill references are the appendix.
