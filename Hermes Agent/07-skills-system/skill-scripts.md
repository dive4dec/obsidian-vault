# Skill Scripts

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Executable scripts (Python, shell) within a skill that the agent can run to perform specific actions. Scripts do the heavy lifting.

## Concrete Example

A debugging skill has scripts/trace.sh that adds trace logging to a Python file. The agent runs this script instead of manually editing the file. Scripts automate repetitive work.

## Analogy

Power tools in a workshop - instead of cutting wood by hand (manual steps), you use a saw (script) to do it faster and more consistently. Skill scripts are power tools for the agent.
