# Skill Sharing

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Sharing skills between teammates or projects by placing them in a shared directory or publishing to the hub.

## Concrete Example

Your team puts a shared skill in /mnt/shared/team-skills/code-review. Everyone on the team configures this as an external skill dir. All agents can now use the same review process.

## Analogy

Sharing notes with classmates - you put them in a shared Google Drive folder, and everyone can access them. Skill sharing makes a skill available to others.
