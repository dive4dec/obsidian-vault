# Skill Templates

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Pre-built template files within a skill that the agent can copy and fill in. Templates save time and ensure consistent output.

## Concrete Example

A github-pr skill has templates/pull-request-template.md. The agent copies it, fills in the PR description, and creates a well-structured pull request every time.

## Analogy

A form letter template - you do not write from scratch. You fill in the blanks. Skill templates give the agent a starting structure to fill in.
