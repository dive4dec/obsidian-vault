# Skill Usage Tracking

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Recording how often each skill is used and when. This data helps identify stale skills and popular ones.

## Concrete Example

The agent records each time it loads a skill. github-pr-workflow: used 15 times this week. old-python-2-tool: used 0 times in 3 months. Usage tracking feeds the curator.

## Analogy

A shop tracking which products sell well and which sit on shelves. Popular items stay stocked; unpopular ones get clearance. Usage tracking does this for skills.
