# Skill Versioning

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Tracking skill versions so you know which version you have and can update when improvements are released.

## Concrete Example

A skill shows version: 2.1.0. The hub has 2.2.0 with a bug fix. You update to get the fix. Versioning tracks what changed between versions.

## Analogy

Software version numbers on apps - v1.0, v1.1, v2.0. Each number tells you what version you have and what is newer. Skill versioning does the same.
