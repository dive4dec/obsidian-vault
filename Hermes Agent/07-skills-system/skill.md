# Skill

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

An AI agent needs reusable procedures for recurring tasks. Skills are packaged instructions that teach the agent how to do a specific job well, like a manual the agent can open and follow.

## Concrete Example

A skill called git-workflow tells the agent how to branch, commit, and open a PR. When the agent sees a coding task, it loads the skill and follows the steps.

## Analogy

A recipe card in a kitchen - the chef doesn't memorise every dish. They pull the recipe card (skill) when they need to cook that dish, follow the steps, and put it back.
