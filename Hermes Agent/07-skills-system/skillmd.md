# SKILL.md

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Every skill needs a main file that describes what it does, when to use it, and the steps to follow. SKILL.md is that file - the heart of every skill.

## Concrete Example

A SKILL.md starts with YAML frontmatter (name, description) then has numbered steps: 1. Run npm test 2. Check coverage 3. Fix failing tests. The agent reads this to know exactly what to do.

## Analogy

A recipe page with a title at the top (frontmatter), ingredients list, and step-by-step instructions (body). SKILL.md is the recipe page for an agent skill.
