# Skills Browse

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Exploring the skills hub to discover new skills without knowing a specific name. Browse by category or popularity.

## Concrete Example

hermes skills browse shows categories: devops (12 skills), creative (8 skills), mlops (15 skills). You pick devops and browse the list to find something useful.

## Analogy

Browsing shelves in a bookstore - you walk through sections, pick up books that look interesting, and discover something new. Skills browse does this for the hub.
