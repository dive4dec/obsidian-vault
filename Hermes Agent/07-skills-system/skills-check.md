# Skills Check

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Verifying that all installed skills are valid - SKILL.md exists, frontmatter is correct, no broken links. Catches problems early.

## Concrete Example

hermes skills check scans all skills and reports: OK: github-pr-workflow / WARNING: old-skill missing description / ERROR: broken-skill no SKILL.md found. You fix the issues.

## Analogy

A health check at the doctor - they run tests on everything and tell you what is fine and what needs attention. Skills check does a health check on your skill library.
