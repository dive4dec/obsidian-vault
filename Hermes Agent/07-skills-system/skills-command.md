# Skills Command

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A slash command that lists all available skills in the current session, showing which are loaded and which are available to load.

## Concrete Example

Typing /skills shows: Loaded: debugging, tdd / Available: github-pr-workflow, dockerfile-optimization. You see what is active and what you can activate.

## Analogy

Opening your backpack and seeing what is inside - some books are already on your desk (loaded), others are in the bag (available). /skills shows your skill inventory.
