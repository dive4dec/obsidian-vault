# Skills Config

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Configuring skill settings: which directories to scan, whether auto-discovery is on, and other preferences.

## Concrete Example

hermes skills config shows: skills_dirs: [~/.hermes/skills, ./skills] / auto_discover: true / max_skills: 100. You can change these to fit your setup.

## Analogy

Settings on your phone - you configure which apps can send notifications, how they are grouped, and where they appear. Skills config sets up how skills behave.
