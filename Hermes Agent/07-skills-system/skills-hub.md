# Skills Hub

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

A central online repository where the community shares skills. Think of it as an app store for agent skills.

## Concrete Example

The hub has hundreds of skills: github tools, docker helpers, creative generators. You search, install, and use. Popular skills get many installs and reviews.

## Analogy

The Apple App Store or Google Play Store - a central place where developers publish apps and users download them. The skills hub is the app store for agent skills.
