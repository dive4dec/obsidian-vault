# Skills Inspect

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Looking at the details of a skill before using it - what it does, what files it contains, and how it works.

## Concrete Example

hermes skills inspect debugging shows: Name: debugging / Description: 4-phase root cause debugging / Files: SKILL.md, scripts/trace.sh / Author: agent. You see the full picture.

## Analogy

Reading the back of a box before buying - ingredients, instructions, warnings. Skills inspect shows you what is inside a skill before you commit to using it.
