# Skills Install

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Adding a new skill to your agent from the skills hub or a local path. After install, the agent can use it immediately.

## Concrete Example

hermes skills install github-pr-workflow downloads the skill from the hub, places it in the skills directory, and confirms: Installed github-pr-workflow successfully.

## Analogy

Downloading an app from the App Store - you tap install, it downloads and appears on your phone ready to use. Skills install does this for agent skills.
