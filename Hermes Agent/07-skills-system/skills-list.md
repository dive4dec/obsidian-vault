# Skills List

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

The command to see all installed skills at a glance. Shows skill names and short descriptions so you know what is available.

## Concrete Example

Running hermes skills list outputs: github-pr-workflow - Branch, commit, open PR / debugging - Systematic 4-phase debugging / tdd - Test-driven development. A quick inventory.

## Analogy

Checking your phone's app drawer - you see all installed apps with their icons and names. Skills list shows all installed skills with names and descriptions.
