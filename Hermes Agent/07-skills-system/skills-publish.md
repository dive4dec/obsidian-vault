# Skills Publish

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Sharing a skill you created with the community by uploading it to the skills hub so others can install and use it.

## Concrete Example

You created a great skill for Moodle plugin testing. hermes skills publish moodle-plugin-testing uploads it to the hub. Others can now hermes skills install it.

## Analogy

Publishing a recipe on a cooking website - you share your dish so anyone in the world can try it. Skills publish shares your skill with the whole community.
