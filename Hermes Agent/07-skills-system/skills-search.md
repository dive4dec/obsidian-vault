# Skills Search

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

When you have many skills, searching by keyword finds the right one faster than scrolling through a long list.

## Concrete Example

hermes skills search deploy finds: k8s-troubleshooting, vllm-deployment, helm-chart-deployment. Searching docker finds dockerfile-optimization and k8s-troubleshooting.

## Analogy

Using a search bar in an app store - instead of scrolling through thousands of apps, you type deploy and see only deployment-related results.
