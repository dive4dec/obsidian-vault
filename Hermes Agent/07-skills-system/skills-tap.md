# Skills Tap

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Adding a source repository to your skills hub so you can install skills from that source. Tapping is like adding a new store.

## Concrete Example

hermes skills tap nousresearch/skills adds the Nous Research skill repository as a source. Now you can install skills from that repo alongside the default hub.

## Analogy

Adding a new bookstore to your reading app - previously you only had one store. Now you tap to add another, so you can browse and buy from both.
