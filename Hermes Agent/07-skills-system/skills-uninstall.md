# Skills Uninstall

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Removing a skill you no longer need. Keeps the skill library clean and saves space.

## Concrete Example

hermes skills uninstall old-python-2-tool removes the skill files and confirms removal. The agent will no longer load or suggest this skill.

## Analogy

Deleting an app from your phone - press and hold, tap delete, it is gone. Skills uninstall removes a skill you do not need anymore.
