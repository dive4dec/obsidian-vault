# Skills Update

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Fetching the latest version of skills from the hub. Skills get improved over time, and update keeps you current.

## Concrete Example

hermes skills update checks all installed skills for newer versions. If github-pr-workflow has a v2, it downloads and replaces the old version. You get bug fixes and improvements.

## Analogy

Updating apps on your phone - developers release new versions with fixes and features. You tap update to get the latest. Skills update does this for agent skills.
