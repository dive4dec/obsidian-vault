# Stale Skills

> **Domain:** [[_skills-system-moc|Skills System]]

## Motivation

Skills that have not been used in a long time. They clutter the library and may contain outdated instructions. The curator identifies and archives them.

## Concrete Example

A skill called old-docker-compose was last used 4 months ago. The curator flags it as stale. If still unused, it gets archived to keep the library clean.

## Analogy

Food in the fridge that is past its expiry date - it takes up space and might not be good anymore. Stale skills take up space and may be outdated.
