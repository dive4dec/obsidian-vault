# AGENTS.md

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A file that tells the agent about the project: what it is, conventions to follow, and things to watch out for. Like a briefing document.

## Concrete Example

AGENTS.md says: This is a Flask web app. Use Python 3.11. Tests go in tests/. Never commit to main branch. The agent follows these rules when working on the project.

## Analogy

A briefing packet for a new employee - here is the project, here are the rules, here is what to watch out for. AGENTS.md briefs the agent on the project.
