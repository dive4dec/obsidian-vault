# Built-in Memory

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

The default memory provider. Stores memories locally in files. Simple, no setup needed, but limited features.

## Concrete Example

Built-in memory saves facts to MEMORY.md and USER.md on your machine. No external service needed. It works out of the box but does not have smart search or sharing.

## Analogy

A notebook you keep in your bag - always there, no internet needed, but you have to flip through pages manually. Built-in memory is the simple local notebook.
