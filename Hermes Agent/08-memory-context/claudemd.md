# CLAUDE.md

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A context file originally for Claude Code but widely adopted. Tells the agent coding standards, style preferences, and project-specific instructions.

## Concrete Example

CLAUDE.md contains: Use 4-space indentation. Add type hints to all functions. Prefer composition over inheritance. The agent follows these when writing code.

## Analogy

A style guide for a school newspaper - headline rules, font size, citation format. Writers follow it for consistency. CLAUDE.md is a style guide for the agent.
