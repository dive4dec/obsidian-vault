# Compress Command

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A slash command that manually triggers context compression. Useful when you know the conversation is long and want to compress before the automatic threshold.

## Concrete Example

Typing /compress immediately summarizes older messages. The agent shows: Compressed 30 messages into a summary. Context now at 40 percent. You have room to continue.

## Analogy

Pressing save on a document to reduce its working state - you compress the history into a saved version. /compress compresses conversation history manually.
