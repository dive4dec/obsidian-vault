# Context Files

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Files the agent reads at the start of each session to get context: AGENTS.md, CLAUDE.md, .cursorrules. They set rules and provide project context.

## Concrete Example

The agent starts a session, reads AGENTS.md (project conventions), CLAUDE.md (coding standards). Now it knows the project rules before you even ask a question.

## Analogy

Reading the house rules when you check into a hotel - wifi password, breakfast time, checkout. Before you start your stay, you read the rules. Context files are the house rules.
