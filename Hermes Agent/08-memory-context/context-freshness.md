# Context Freshness

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Recent context is more relevant than old context. The agent weights recent messages and memory higher when deciding what matters now.

## Concrete Example

You switched from Python to JavaScript last week. The agent weights this recent switch higher than your Python preferences from 3 months ago. Freshness keeps the agent current.

## Analogy

News - today headlines matter more than last week. The agent treats recent context as more relevant, like how you prioritise recent news.
