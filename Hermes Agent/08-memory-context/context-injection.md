# Context Injection

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Automatically inserting relevant context (memories, files, past session info) into the conversation before the agent responds.

## Concrete Example

You ask: Help me continue my project. The agent injects: your project details from MEMORY.md, your skills from USER.md, and the last session summary. Now it has full context to help.

## Analogy

A waiter who knows your usual order - before you speak, they already know you want the set lunch with iced tea. Context injection pre-loads what the agent needs.
