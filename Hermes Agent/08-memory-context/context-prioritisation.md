# Context Prioritisation

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

When context is limited, the agent prioritises what to keep: recent messages, important memories, and active instructions come first.

## Concrete Example

With limited context, the agent keeps: the last 10 messages (recent), your user profile (important), and the current task instruction (active). Old tangents get compressed first.

## Analogy

Packing a backpack for a hike - you pack the essentials first (water, map, first aid), then nice-to-haves. Context prioritisation packs the most important context first.
