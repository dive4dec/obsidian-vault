# Context References

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Ways the agent can pull in external context: file references, URL references, and session links. This extends what the agent knows beyond the conversation.

## Concrete Example

You type: Look at @agents.md and @session:work/42. The agent reads AGENTS.md for project rules and session 42 for past context. References pull in extra information.

## Analogy

Footnotes in a book - they reference other pages or sources. You flip to them for more context. Context references let the agent pull in external context.
