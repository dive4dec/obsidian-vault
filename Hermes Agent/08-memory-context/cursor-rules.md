# Cursor Rules

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A file (.cursorrules) that defines how the agent should behave in a project. Originally for Cursor IDE but can be read by other agents.

## Concrete Example

.cursorrules says: Always write tests before implementation. Use descriptive variable names. Comment complex logic. The agent treats these as rules to follow.

## Analogy

Rules posted in a computer lab - no food, log off when done, save files to the shared drive. Cursor rules are the lab rules for the agent.
