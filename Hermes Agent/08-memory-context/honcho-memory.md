# Honcho Memory

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A memory provider that lets multiple agents share the same memory. Good for teams where several agents help the same user.

## Concrete Example

With Honcho, agent A learns you like Python, and agent B (using the same Honcho) also knows this. Shared memory means consistent service across multiple agents.

## Analogy

A shared family calendar - when mom adds an event, dad and kids all see it. Honcho memory lets multiple agents share what they know about you.
