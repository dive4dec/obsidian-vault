# Mem0 Memory

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A smart memory provider that uses AI to organise, summarise, and retrieve memories intelligently. Finds relevant memories even with fuzzy queries.

## Concrete Example

Mem0 stores 100 facts about you. You ask about your coding project. Mem0 finds the 3 relevant memories (your Python level, your project topic, your deadline) and surfaces them.

## Analogy

A smart photo album that tags faces and places - when you search beach, it finds all beach photos even without that word in the filename. Mem0 finds relevant memories smartly.
