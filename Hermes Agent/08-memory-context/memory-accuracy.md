# Memory Accuracy

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Ensuring stored memories are correct. Inaccurate memories lead to wrong personalisation. The agent verifies before saving.

## Concrete Example

Agent hears: I got a B on my math test. It saves: User received a B on the math test (verified from user statement). It does not guess or assume details it was not told.

## Analogy

A journalist fact-checking before publishing - they verify the claim before printing it. Memory accuracy means the agent saves only verified facts.
