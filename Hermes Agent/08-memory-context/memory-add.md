# Memory Add

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Adding a new fact to memory. The agent does this when it learns something new and worth remembering.

## Concrete Example

Agent learns: User has a dog named Rex. It calls memory add: User has a dog named Rex. Now every future session knows about Rex.

## Analogy

Writing a new entry in your diary - today I learned something new, so I add it. Memory add writes a new fact into the agent memory.
