# Memory Char Limit

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A maximum character count for each memory entry. Prevents overly long memories that bloat files and slow loading.

## Concrete Example

A memory entry is limited to 500 characters. The agent wants to save a long story but must compress it: User is building a Flask chatbot for a school project. Concise and under the limit.

## Analogy

Twitter character limit - you cannot write an essay in a tweet. You must be concise. Memory char limit forces the agent to be brief and clear.
