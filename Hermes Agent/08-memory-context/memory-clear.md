# Memory Clear

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Deleting all stored memories. A fresh start. Useful when the agent has accumulated too many outdated or incorrect memories.

## Concrete Example

hermes memory clear wipes all memories. The agent starts the next session knowing nothing about you. Use carefully - this cannot be undone.

## Analogy

Factory reset on a phone - everything is wiped, back to the start. Memory clear resets the agent memory to empty.
