# Memory Confidence

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Some memories are certain (user explicitly stated a fact), others are inferred. Confidence tracks how sure the agent is about each memory.

## Concrete Example

User said: I am 15 years old. Confidence: high (explicit). Agent inferred: User likes coding (from multiple coding questions). Confidence: medium (inferred). The agent trusts high-confidence memories more.

## Analogy

A witness who saw it with their own eyes (high confidence) vs one who heard it second-hand (low confidence). Memory confidence tracks the reliability of each memory.
