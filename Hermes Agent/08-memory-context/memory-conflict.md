# Memory Conflict

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

When two memories contradict each other. The agent needs rules to resolve which one is current and correct.

## Concrete Example

Memory A: User likes dark mode. Memory B: User switched to light mode. The agent uses the most recent (B) and may remove the outdated (A). Conflict resolution keeps memory consistent.

## Analogy

Two friends telling you different times for a meeting - you check which message is more recent and trust that one. Memory conflict picks the most recent memory.
