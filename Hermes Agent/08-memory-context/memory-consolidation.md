# Memory Consolidation

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Combining several related memories into one cleaner, more complete memory. Reduces clutter and redundancy.

## Concrete Example

Three memories: User knows Python, User knows HTML, User knows CSS. Consolidation merges them: User knows Python, HTML, and CSS (web development basics). One memory instead of three.

## Analogy

Merging duplicate contacts on your phone - instead of three entries for the same person, you merge them into one complete contact. Memory consolidation merges related memories.
