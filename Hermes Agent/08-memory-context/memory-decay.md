# Memory Decay

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Old memories that have not been referenced in a long time may become less relevant. Decay reduces their priority in retrieval.

## Concrete Example

A memory from 6 months ago about a project you finished has low priority. A memory from yesterday about your current project has high priority. Decay ranks memories by recency.

## Analogy

Forgetting details of a movie you watched years ago but remembering one you saw last week. Memory decay naturally prioritises recent memories.
