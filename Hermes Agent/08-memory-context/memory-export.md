# Memory Export

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Saving all memories to a file so you can back them up, move them to another machine, or share with another agent.

## Concrete Example

hermes memory export creates memories-backup.json with all 42 memories. You can import this on another machine to transfer your agent memory.

## Analogy

Exporting your contacts to a file - you save them so you can import them on a new phone. Memory export saves memories for transfer or backup.
