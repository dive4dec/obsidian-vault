# Memory Import

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Loading memories from a previously exported file. Useful when setting up a new agent or restoring from backup.

## Concrete Example

hermes memory import memories-backup.json loads 42 memories into the agent. Your new agent now knows everything the old one did.

## Analogy

Importing contacts to a new phone - you load the file and all your contacts appear. Memory import loads saved memories into the agent.
