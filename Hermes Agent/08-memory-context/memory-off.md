# Memory Off

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Turning memory completely off. The agent will not save or recall any facts. Useful for sensitive or one-time sessions.

## Concrete Example

hermes memory off disables all memory. The agent forgets everything after this session. Use this when working on something private where you want zero retention.

## Analogy

Incognito mode in a browser - no history saved, no cookies stored. Memory off is incognito mode for the agent.
