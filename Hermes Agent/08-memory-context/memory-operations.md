# Memory Operations

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

The three core actions on memory: add (new fact), replace (update fact), remove (delete fact). Together they keep memory accurate and useful.

## Concrete Example

In one session the agent: adds your new project, replaces your old grade, removes an outdated preference. Three operations, one clean memory.

## Analogy

Editing a document - you can add text, replace words, or delete paragraphs. Memory operations are add, replace, delete for agent memory.
