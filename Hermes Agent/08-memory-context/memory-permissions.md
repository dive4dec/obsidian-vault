# Memory Permissions

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Controls who can read or write memories. Important for shared agents where multiple users interact with the same agent.

## Concrete Example

User A memories are private. User B cannot see them. An admin can manage all memories. Permissions keep each user data separate and secure.

## Analogy

User accounts on a shared computer - each person logs in and sees only their own files. Memory permissions keep each user memories private.
