# Memory Privacy

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Concerns about what the agent remembers and who can access it. Memory can contain personal info, so privacy controls matter.

## Concrete Example

Your memory contains your real name, school, and grades. You can turn off memory for sensitive sessions, or clear all memory when sharing the agent with others.

## Analogy

A personal journal with a lock - you control who reads it. Memory privacy controls let you decide what the agent remembers and when to forget.
