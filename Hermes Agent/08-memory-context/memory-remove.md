# Memory Remove

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Deleting a memory that is no longer correct or relevant. Keeps memory clean and accurate.

## Concrete Example

Memory says: User is learning Scratch. But you have moved on to Python. The agent calls memory remove to delete the Scratch fact. Memory stays current.

## Analogy

Crossing out an old todo item that is no longer relevant - you remove it so your list stays clean. Memory remove deletes outdated memories.
