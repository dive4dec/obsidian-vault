# Memory Replace

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Updating an existing memory with new information. Prevents outdated facts from confusing the agent.

## Concrete Example

Old memory: User is in F3. New fact: User is now in F4. The agent calls memory replace to update F3 to F4. No stale information remains.

## Analogy

Updating a contact in your phone - your friend changed their number, so you replace the old one. Memory replace updates outdated facts.
