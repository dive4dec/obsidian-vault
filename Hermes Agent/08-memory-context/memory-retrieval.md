# Memory Retrieval

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

How the agent finds the right memories at the right time. Good retrieval surfaces relevant facts without flooding the context with everything.

## Concrete Example

You ask about your web project. The agent retrieves: project details, your Python level, and the framework you chose. It does NOT retrieve your math exam date (irrelevant).

## Analogy

A librarian who finds you the right book - you ask for a mystery novel, they do not bring you cookbooks. Memory retrieval brings relevant memories only.
