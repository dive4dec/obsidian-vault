# Memory Setup

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Configuring memory: choosing a provider, enabling it, and setting preferences. Run once to get memory working.

## Concrete Example

hermes memory setup asks: Which provider? (builtin/mem0/honcho). Enable user profile? (y/n). After answering, memory is configured and ready to use.

## Analogy

Setting up a new phone - you choose a language, sign in, set preferences. After setup, the phone is personalised. Memory setup personalises the agent memory system.
