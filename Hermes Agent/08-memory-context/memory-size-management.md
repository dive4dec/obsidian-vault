# Memory Size Management

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Too many memories slow down loading and fill context. Managing memory size keeps it lean and fast.

## Concrete Example

After 200 memories, the agent consolidates and removes outdated ones, bringing the count to 120. Loading is faster, and the most relevant memories fit in context easily.

## Analogy

Cleaning out your closet periodically - too many clothes make it hard to find what you want. You donate old ones to keep it manageable. Memory size management keeps memory lean.
