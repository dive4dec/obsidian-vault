# Memory Status

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Checking whether memory is on, which provider is active, and how many memories are stored. A quick health check for memory.

## Concrete Example

hermes memory status shows: Memory: enabled / Provider: builtin / Memories stored: 42 / Last updated: 2026-08-03. You see the full memory status at a glance.

## Analogy

Checking your phone storage - how much space is used, what is stored, last backup date. Memory status shows the agent memory state.
