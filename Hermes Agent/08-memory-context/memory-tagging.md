# Memory Tagging

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Labelling memories with tags (project, personal, skill) so they can be filtered and retrieved by category.

## Concrete Example

A memory is tagged: [project:chatbot, skill:flask]. When you work on the chatbot project, the agent retrieves memories tagged project:chatbot. Tagging makes retrieval precise.

## Analogy

Hashtags on social media - you search #travel to find travel posts. Memory tagging lets the agent filter memories by category.
