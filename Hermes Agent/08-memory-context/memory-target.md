# Memory Target

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Deciding whether a memory is about the user (goes to USER.md) or general context (goes to MEMORY.md). Correct targeting keeps memory organised.

## Concrete Example

User name and grade go to USER.md (user target). Project decisions go to MEMORY.md (memory target). The agent picks the right target for each fact.

## Analogy

Sorting mail into different trays - personal letters in one, work documents in another. Memory target sorts facts into the right file.
