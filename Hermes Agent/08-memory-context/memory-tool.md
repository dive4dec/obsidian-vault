# Memory Tool

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

The built-in tool the agent uses to add, replace, or remove memories. The agent calls this tool automatically when it learns something worth remembering.

## Concrete Example

The agent learns you are preparing for a math exam. It calls the memory tool: add memory: User is preparing for a math exam. Next session, it asks how the exam went.

## Analogy

A secretary with a notebook - during a meeting, they jot down important points. The memory tool is the agent secretary, jotting down what matters.
