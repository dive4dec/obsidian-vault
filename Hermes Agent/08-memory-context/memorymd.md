# MEMORY.md

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A file where the agent stores general memories: things it learned, decisions made, and context worth keeping. The agent reads it at the start of each session.

## Concrete Example

MEMORY.md contains: User prefers concise answers. Working on a chatbot project using Flask. Decided to use PostgreSQL. The agent reads this and starts the session already informed.

## Analogy

A personal diary - you write down what happened and what matters. Next time you need to remember, you flip back and read. MEMORY.md is the agent diary.
