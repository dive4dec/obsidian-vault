# Persistent Memory

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

Without memory, every conversation starts from scratch. Persistent memory lets the agent remember facts about you across sessions, so it does not ask the same questions twice.

## Concrete Example

You tell the agent: I prefer Python and I am learning web development. Next session, you ask for a coding example. The agent uses Python and picks a web project, remembering your preferences.

## Analogy

A friend who remembers your birthday and favourite food - you do not remind them every time. Persistent memory lets the agent remember you between conversations.
