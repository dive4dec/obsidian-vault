# Session Links

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A way to reference a past session by its ID, like @session:work/42. The agent can read that session for context from a previous conversation.

## Concrete Example

You type: Remember what we decided in @session:default/15. The agent loads session 15, reads the decisions, and continues from where that session left off.

## Analogy

A hyperlink to a previous email thread - you click it to see what was discussed before. Session links connect the current conversation to past ones.
