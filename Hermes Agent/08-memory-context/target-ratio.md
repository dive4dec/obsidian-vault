# Target Ratio

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

After compression, the agent aims for a target ratio of used context. For example, compress to 50 percent so there is room for more conversation.

## Concrete Example

Context was at 90 percent. After compression, it targets 50 percent. The summary takes 50 percent, leaving 50 percent for new messages before needing another compression.

## Analogy

A suitcase you pack to half full - after compressing clothes (rolling them), you aim for the suitcase to be half full so you have room for souvenirs. Target ratio is the target fullness.
