# User Profile Enabled

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A setting that controls whether the agent builds and maintains a profile of you. The profile stores preferences, skills, and background.

## Concrete Example

user_profile_enabled: true means the agent tracks: you are a student, you know Python basics, you prefer concise answers. This profile shapes every response.

## Analogy

A loyalty card at a shop - they track what you buy and tailor offers to you. User profile enabled lets the agent tailor responses based on what it knows about you.
