# USER.md

> **Domain:** [[_memory-context-moc|Memory & Context]]

## Motivation

A file that stores information specifically about you: your name, role, skills, preferences, and goals. The agent uses this to personalise responses.

## Concrete Example

USER.md contains: Name: Alex / Role: F4 student / Skills: Python basics, HTML / Preferences: Visual explanations, code examples. The agent tailors every answer to this profile.

## Analogy

A student ID card with extra notes - name, grade, subjects. The teacher reads it to know how to help you. USER.md tells the agent who you are.
