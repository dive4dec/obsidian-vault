# Clear Session

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Clear the screen and context. Command: /clear. Similar to /reset but may keep some metadata.

## Concrete Example

/clear. Screen is cleared. Context is cleared. You start fresh visually. Underlying session data may still exist.

## Analogy

Clearing a chalkboard - the board is empty. /clear clears the conversation from view.
