# Cross-Session Search

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Search across all sessions for a keyword or phrase. Powered by FTS5. Command: hermes sessions search.

## Concrete Example

hermes sessions search docker. Results: Session 1 (Docker Fix): 3 matches. Session 5 (DevOps): 1 match. Find conversations by keyword.

## Analogy

A search engine for your chat history - you find any conversation by keyword. Cross-session search finds past discussions.
