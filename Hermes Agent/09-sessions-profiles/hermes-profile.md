# Hermes Profile

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

The CLI command for managing profiles. Subcommands: list, create, use, delete, show, alias, rename, export, import.

## Concrete Example

hermes profile create work. hermes profile use work. Now using work profile. hermes profile list: shows all profiles. All profile management in one command.

## Analogy

A multi-user game - you create and switch between player accounts. hermes profile manages Hermes accounts.
