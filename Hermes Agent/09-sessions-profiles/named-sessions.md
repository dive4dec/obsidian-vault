# Named Sessions

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Sessions can be named for easy reference. Command: /title NAME. Or: hermes --resume NAME.

## Concrete Example

/title Docker Fix. Later: hermes --resume Docker Fix. No need to remember IDs. Names are easier.

## Analogy

Naming a save file in a game - My Game Level 5. You find it by name. Named sessions are found by name.
