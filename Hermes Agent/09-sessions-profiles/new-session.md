# New Session

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Start a fresh session. Command: /new. Or: hermes chat (starts new by default). The old session is saved.

## Concrete Example

/new. Fresh start. No context from previous conversations. Old session is saved and can be resumed later.

## Analogy

Turning to a new page in your notebook - you start fresh. /new starts a new conversation page.
