# Profile Alias

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A short name for a profile. Command: hermes profile alias NAME ALIAS.

## Concrete Example

hermes profile alias work w. Now: hermes --profile w chat. Shorter. Faster. Alias w -> work.

## Analogy

A nickname for a friend - you call them by a short name. Profile alias gives a profile a short name.
