# Profile Config

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Each profile has its own config.yaml. Located at ~/.hermes/profiles/NAME/config.yaml.

## Concrete Example

Profile work: model=claude, memory=on, skills=[github,debugging]. Profile school: model=deepseek, memory=off, safe_toolset_only. Different configs.

## Analogy

Different settings for different phones - work phone vs personal phone. Profile config gives each profile different settings.
