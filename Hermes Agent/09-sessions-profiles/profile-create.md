# Profile Create

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Create a new profile. Command: hermes profile create NAME.

## Concrete Example

hermes profile create school. Profile school is created with default settings. hermes profile use school. Now using school profile.

## Analogy

Creating a new user account - fresh and empty. hermes profile create makes a new profile.
