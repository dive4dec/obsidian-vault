# Profile Delete

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Delete a profile and all its data. Command: hermes profile delete NAME.

## Concrete Example

hermes profile delete test. Profile test, its config, skills, sessions, and memory are all deleted. Permanent. Cannot be undone.

## Analogy

Throwing away a notebook - all notes are gone. Profile delete removes all profile data permanently.
