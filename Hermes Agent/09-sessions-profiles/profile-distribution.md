# Profile Distribution

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Export a complete profile (config, skills, memory) as a shareable package. Command: hermes profile export.

## Concrete Example

hermes profile export work --output work-profile.tar. Contains: config.yaml, skills/, memory/. Share with colleagues. They import: hermes profile import work-profile.tar.

## Analogy

Packing a gift box - you put everything in a box and share it. Profile distribution packs a profile for sharing.
