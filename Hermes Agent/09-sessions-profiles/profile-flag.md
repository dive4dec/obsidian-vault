# Profile Flag

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A global flag to select which profile to use. Usage: hermes --profile NAME.

## Concrete Example

hermes --profile work chat. Uses the work profile: work config, work memory, work sessions. Completely separate from default.

## Analogy

A school ID vs a library card - different cards for different contexts. --profile picks which context Hermes uses.
