# Profile Import

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Import a profile package. Command: hermes profile import FILE.

## Concrete Example

hermes profile import work-profile.tar. Profile work is created with all config, skills, and memory from the package. Ready to use.

## Analogy

Unpacking a gift box - you open it and everything is inside. Profile import unpacks a profile package.
