# Profile List

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

List all profiles. Command: hermes profile list.

## Concrete Example

hermes profile list. Output: default (active), work, school, creative. Shows all profiles and which is active.

## Analogy

A list of user accounts on a computer. hermes profile list shows all Hermes profiles.
