# Profile Memory

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Each profile has its own memory. Memories do not cross profiles.

## Concrete Example

Profile work: User prefers concise responses. Profile school: Student is F3 level. Switching profiles switches memories.

## Analogy

Different contacts on work phone vs personal phone. Profile memory is separate per profile.
