# Profile Rename

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Rename a profile. Command: hermes profile rename OLD NEW.

## Concrete Example

hermes profile rename work office. Profile work is now called office. All data stays the same. Just the name changes.

## Analogy

Renaming a folder on your computer - the contents stay, only the name changes. Profile rename changes the profile name.
