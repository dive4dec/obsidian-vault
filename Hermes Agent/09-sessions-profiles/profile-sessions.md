# Profile Sessions

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Each profile has its own session store. Sessions do not cross profiles.

## Concrete Example

Profile work sessions: about coding projects. Profile school sessions: about homework. Switching profiles switches session history.

## Analogy

Separate notebooks for different subjects - you do not mix math and English notes. Profile sessions are separate per profile.
