# Profile Show

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Show details of a profile. Command: hermes profile show NAME.

## Concrete Example

hermes profile show work. Output: Config: model=claude. Skills: 5 installed. Sessions: 23. Memory: 42 entries. Everything visible at a glance.

## Analogy

A profile page on social media - it shows all your info. Profile show displays all profile details.
