# Profile Skills

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Each profile has its own skills. Located at ~/.hermes/profiles/NAME/skills/.

## Concrete Example

Profile work: github-pr-workflow, debugging, tdd. Profile school: none (restricted). Profile creative: ascii-art, pixel-art. Different skills per profile.

## Analogy

Different textbooks for different classes - math textbook for math, English for English. Profile skills are different per profile.
