# Profile Use

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Switch to a profile. Command: hermes profile use NAME.

## Concrete Example

hermes profile use work. Now all hermes commands use the work profile. Config, skills, memory, sessions - all from work.

## Analogy

Switching user accounts - you log in as a different user. hermes profile use switches Hermes to a different profile.
