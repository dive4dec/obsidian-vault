# Profiles

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Separate Hermes configurations. Each profile has its own config, skills, sessions, memory, and cron jobs.

## Concrete Example

Profile default: personal use. Profile work: work config, work skills, work memory. Profile school: school config, restricted tools. Completely separate.

## Analogy

Different user accounts on a computer - each has its own files and settings. Profiles give Hermes separate identities.
