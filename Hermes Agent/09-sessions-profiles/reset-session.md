# Reset Session

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Clear the current session context without starting a new one. Command: /reset. Keeps the session ID but clears messages.

## Concrete Example

/reset. Session ID stays the same. But all messages are cleared. Fresh context, same session. Useful for starting over on the same topic.

## Analogy

An eraser on a whiteboard - you wipe it clean but the board is still there. /reset clears the conversation but keeps the session.
