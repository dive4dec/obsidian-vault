# Resume Session

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Continue a previous session. Command: hermes --resume ID. Or: --continue (resumes most recent).

## Concrete Example

hermes --resume a1b2c3d4. Previous session loads. All messages restored. You continue where you left off. --continue resumes the last session.

## Analogy

Opening a saved game - you continue from where you saved. --resume continues a saved conversation.
