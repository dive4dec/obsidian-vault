# Retry

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Regenerate the last response. Command: /retry. The model generates a new response to the last message.

## Concrete Example

Hermes gave a confusing answer. /retry. Hermes generates a new answer. Different approach, hopefully clearer.

## Analogy

Asking a teacher to explain again - you get a different explanation. /retry asks the model to answer again.
