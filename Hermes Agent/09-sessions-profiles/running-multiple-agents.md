# Running Multiple Agents

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Run multiple Hermes profiles simultaneously. Each is independent. Useful for parallel work.

## Concrete Example

Terminal 1: hermes --profile work chat. Terminal 2: hermes --profile school chat. Two agents running simultaneously. Independent.

## Analogy

Two cooks in two kitchens - they cook independently. Running multiple agents lets you work on multiple tasks simultaneously.
