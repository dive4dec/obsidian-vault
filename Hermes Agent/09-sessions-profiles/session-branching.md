# Session Branching

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Create a copy of the current session to explore a different path. Command: /branch or /fork.

## Concrete Example

/branch. Session A: original. Session B: branch. In B, try a risky approach. If it fails, A is safe. Two independent paths.

## Analogy

A choose-your-own-adventure book - you bookmark a page, explore a path, go back if it fails. Session branching bookmarks conversations.
