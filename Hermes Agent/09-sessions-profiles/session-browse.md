# Session Browse

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Browse sessions interactively. Command: hermes sessions browse. Shows a list with previews.

## Concrete Example

hermes sessions browse. List: 1. Docker Fix (Aug 3, 15 msgs) 2. Python Project (Aug 2, 30 msgs). Arrow keys to navigate. Enter to resume.

## Analogy

Browsing a photo gallery - you scroll through photos. Session browse lets you scroll through conversations.
