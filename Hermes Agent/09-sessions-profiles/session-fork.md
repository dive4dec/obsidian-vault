# Session Fork

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A forked (branched) session. An exact copy at the fork point. Changes in the fork do not affect the original.

## Concrete Example

Session A: Build web app. /fork -> Session B (copy). In B: try Flask. In A: continue with Django. Two independent paths.

## Analogy

A fork in a hiking trail - the path splits. Both explore independently. Session fork splits the conversation.
