# Session ID

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A unique identifier for each session. Used to resume, export, or delete sessions.

## Concrete Example

Session ID: a1b2c3d4. hermes --resume a1b2c3d4. Or: hermes sessions export --id a1b2c3d4. The ID uniquely identifies one conversation.

## Analogy

A student ID number - it uniquely identifies one student. The session ID uniquely identifies one conversation.
