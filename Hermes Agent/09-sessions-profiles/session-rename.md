# Session Rename

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Rename a session. Command: hermes sessions rename --id ID --title TITLE.

## Concrete Example

hermes sessions rename --id a1b2c3d4 --title My Project. Session a1b2c3d4 is now called My Project. Easier to find later.

## Analogy

Renaming a file - you give it a better name. Session rename gives a conversation a better name.
