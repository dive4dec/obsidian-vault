# Session Source Tag

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A tag indicating where the session started: CLI, telegram, discord, matrix, etc.

## Concrete Example

Session source: telegram. You started this conversation on Telegram. Source: cli. You started it in the terminal. Tags track origins.

## Analogy

A stamp on a letter showing where it was sent from. The session source tag shows where the conversation started.
