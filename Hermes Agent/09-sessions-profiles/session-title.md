# Session Title

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

A human-readable name for a session. Auto-generated or manually set. Helps you find sessions later.

## Concrete Example

Session 1: Python Web Scraper (auto-generated). Session 2: Docker Debugging (auto). /title My Project Debugging (manual). Titles make sessions findable.

## Analogy

Labeling a notebook cover - Math, English, Science. You find the right notebook fast. Session titles label conversations.
