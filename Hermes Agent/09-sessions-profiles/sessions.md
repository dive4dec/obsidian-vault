# Sessions

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Each conversation with Hermes is a session. Sessions are stored in SQLite. You can resume, branch, and export them.

## Concrete Example

You chat with Hermes about a Python project (Session A). Later, you start a new session about a different topic (Session B). Session A is saved. You can resume it anytime.

## Analogy

Notebooks for different subjects - math notes in one, English in another. Each session is a notebook for one conversation topic.
