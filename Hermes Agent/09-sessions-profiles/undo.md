# Undo

> **Domain:** [[_sessions-profiles-moc|Sessions & Profiles]]

## Motivation

Remove the last exchange from the conversation. Command: /undo. The model forgets the last interaction.

## Concrete Example

You asked Hermes to rename a file. It did. You realize: wrong name! /undo. The rename command and result are removed from the conversation.

## Analogy

An eraser on a pencil - you erase the last thing you wrote. /undo erases the last exchange from the conversation.
