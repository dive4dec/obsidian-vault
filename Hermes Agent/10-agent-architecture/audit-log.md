# Audit Log

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The audit log records every tool call, model response, and user input for debugging and review.

## Concrete Example

You can look at the audit log to see exactly which tools were called and what they returned at each step.

## Analogy

Like a CCTV recording in a shop: you can replay it to see what happened and when.
