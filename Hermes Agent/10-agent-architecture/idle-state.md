# Idle State

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

When the agent is not working on anything, it is in idle state, waiting for your next message.

## Concrete Example

The indicator shows a steady dot. No tools are running. The agent is ready for input.

## Analogy

Like a taxi waiting at a stand: engine off, ready to go when a passenger arrives.
