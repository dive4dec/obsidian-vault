# Indicator States

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The indicator can show several states: thinking, tool running, waiting for input, error, and idle.

## Concrete Example

A pulsing dot means thinking. A gear icon means a tool is running. A red dot means an error occurred.

## Analogy

Like traffic lights: green means go, red means stop, yellow means slow down.
