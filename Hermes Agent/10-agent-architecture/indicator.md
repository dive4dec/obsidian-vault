# /indicator

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The indicator is a small icon or dot that shows what the agent is doing: thinking, running a tool, or idle.

## Concrete Example

A spinning circle means the model is thinking. A checkmark means it is done.

## Analogy

Like the status dot on a messaging app: green for online, red for busy.
