# Iteration

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Each pass through the agent loop is one iteration. The model thinks, tools run, and results come back in each iteration.

## Concrete Example

Turn 1 the model searches. Turn 2 it reads a file. Turn 3 it gives the answer. That is three iterations.

## Analogy

Like laps around a running track: each lap is one iteration until you finish the race.
