# Memory Store

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The memory store saves facts and preferences between conversations so the agent remembers you next time.

## Concrete Example

Hermes remembers your name is Alex and you prefer Python. Next session it greets you by name and defaults to Python.

## Analogy

Like a diary the agent writes in and reads from to remember past conversations.
