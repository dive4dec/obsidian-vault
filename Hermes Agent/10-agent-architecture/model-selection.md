# Model Selection

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Hermes can switch between different AI models. Each model has different strengths, speeds, and costs.

## Concrete Example

You pick a fast small model for simple chat and a powerful large model for complex coding tasks.

## Analogy

Like choosing a pen: a fine tip for neat writing, a thick marker for posters.
