# /personality

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

This command lets you switch the agent personality on the fly without restarting.

## Concrete Example

Type /personality friendly tutor and the agent immediately changes its speaking style.

## Analogy

Like changing costumes backstage between scenes in a school play.
