# Plugin System

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Plugins extend Hermes with new tools, skills, or platform connectors without changing the core code.

## Concrete Example

You install a plugin that adds Spotify control. Now the agent can play music without any code changes.

## Analogy

Like adding apps to your phone: each app gives new features without replacing the phone.
