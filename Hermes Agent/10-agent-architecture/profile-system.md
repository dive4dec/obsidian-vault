# Profile System

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Profiles let you keep separate setups: different models, skills, and memories for different purposes.

## Concrete Example

You have a study profile for homework and a game profile for fun. Switching profiles changes everything at once.

## Analogy

Like having different binders for different subjects: each one has its own notes and tools.
