# Reasoning Hide

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

When reasoning is hidden, only the final answer appears. The thinking happens behind the scenes.

## Concrete Example

You just see The file has 42 lines without seeing the intermediate planning steps.

## Analogy

Like ordering at a restaurant: you get the dish without seeing the kitchen work.
