# Reasoning medium

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Level medium gives moderate thinking. A balanced choice for most everyday tasks.

## Concrete Example

For a coding question the medium level plans the approach, writes the code, and double-checks the logic.

## Analogy

Like doing a rough draft before the final copy of an essay.
