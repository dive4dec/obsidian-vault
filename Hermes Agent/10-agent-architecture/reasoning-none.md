# Reasoning none

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Level none means no extra thinking steps. The model answers directly, which is fast but less thorough.

## Concrete Example

For a simple greeting like hi the model just says Hello back without any deep reasoning.

## Analogy

Like answering roll call: you just say present and move on.
