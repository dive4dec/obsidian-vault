# Reasoning Show

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

When reasoning is shown, you can see the model thinking process step by step before the final answer.

## Concrete Example

You see lines like Let me check the file first then I will count the lines before the answer appears.

## Analogy

Like watching a chef cook: you see every step from chopping to plating.
