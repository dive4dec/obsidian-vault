# Reasoning xhigh

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Level xhigh is the deepest reasoning. Reserved for the hardest problems needing maximum effort.

## Concrete Example

For a complex algorithm design the model spends extra turns exploring options and checking edge cases.

## Analogy

Like a student spending an hour on one competition math problem to find the best solution.
