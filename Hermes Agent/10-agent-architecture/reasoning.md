# /reasoning

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

This command changes the reasoning level during a conversation.

## Concrete Example

Type /reasoning high before a hard math question and the model thinks deeper for the next answer.

## Analogy

Like a video game difficulty selector: you raise it when the boss fight starts.
