# /skin

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

This command switches the visual skin or theme of the interface.

## Concrete Example

Type /skin midnight and the colors change to a dark blue palette.

## Analogy

Like swapping your phone case for a new color.
