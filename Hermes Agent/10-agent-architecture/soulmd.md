# SOUL.md

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

SOUL.md is a file that stores the deep identity and values of the agent. It goes beyond a simple system prompt.

## Concrete Example

SOUL.md might say I am Hermes, a curious and patient assistant who always shows working steps and admits mistakes.

## Analogy

Like a personal mission statement that defines your core values and guides every decision you make.
