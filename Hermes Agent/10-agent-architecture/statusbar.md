# /statusbar

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The status bar shows live info at the bottom of the screen: model name, token count, and connection status.

## Concrete Example

You glance at the status bar and see Model: GLM-5.2 and Tokens: 1200 so you know your session status.

## Analogy

Like the HUD in a racing game showing speed and lap number.
