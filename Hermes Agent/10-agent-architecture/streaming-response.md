# Streaming Response

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

Instead of waiting for the full answer, streaming sends text to you piece by piece as the model generates it.

## Concrete Example

You see words appearing one by one on screen while the model is still writing the rest.

## Analogy

Like watching a live text broadcast of a sports match instead of waiting for the final summary.
