# System Prompt

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

The system prompt tells the model who it is and how it should behave. It sets the rules for the whole conversation.

## Concrete Example

Hermes builds a system prompt saying you are a helpful agent with these tools and this personality. The model follows those rules every turn.

## Analogy

Like a school badge and uniform rules: they define who you are and how you act before you even speak.
