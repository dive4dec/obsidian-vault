# /verbose

> **Domain:** [[_agent-architecture-moc|Agent Architecture]]

## Motivation

This command toggles how much detail the agent shows: tool inputs, outputs, and reasoning steps.

## Concrete Example

Turn verbose on to see every tool call and result. Turn it off for a clean, quiet chat.

## Analogy

Like turning subtitles on or off while watching a movie.
