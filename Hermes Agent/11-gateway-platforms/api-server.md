# API Server

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Hermes can run an API server that accepts requests over HTTP, letting other programs talk to the agent.

## Concrete Example

You send a POST request to the API with your question. Hermes processes it and returns a JSON response.

## Analogy

Like a restaurant takeout window: you place an order and pick up the result.
