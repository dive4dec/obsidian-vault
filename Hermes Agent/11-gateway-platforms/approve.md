# /approve

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command approves a pending pairing request from a new user or device.

## Concrete Example

A new user tries to connect. You type /approve and they can now chat with the agent.

## Analogy

Like a bouncer at a club door letting someone in after checking the guest list.
