# Bot Token

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

A bot token is a secret key that lets Hermes connect to a platform as a bot. Keep it private.

## Concrete Example

You get a token from Telegram BotFather and put it in the config. Hermes uses it to log in as your bot.

## Analogy

Like a house key: only the person with the key can open the door.
