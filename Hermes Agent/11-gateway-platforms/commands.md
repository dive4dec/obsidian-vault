# /commands

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command lists all available gateway commands you can use in chat.

## Concrete Example

You type /commands and see a list: /platforms, /gateway, /restart, /sethome, /approve, /deny.

## Analogy

Like a restaurant menu showing all the options you can order.
