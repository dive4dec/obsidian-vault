# /deny

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command rejects a pending pairing request, blocking that user or device.

## Concrete Example

An unknown user tries to connect. You type /deny and they are blocked from messaging the agent.

## Analogy

Like a security guard turning away someone without an ID badge.
