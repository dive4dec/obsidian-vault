# DM Authorization

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Only authorized users can direct message the agent. This prevents strangers from using your agent.

## Concrete Example

Someone messages your bot. If they are not on the approved list, the agent ignores them.

## Analogy

Like a private group chat: only invited members can see and send messages.
