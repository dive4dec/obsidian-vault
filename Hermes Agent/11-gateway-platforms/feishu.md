# Feishu

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Feishu is a collaboration platform by ByteDance. Hermes can connect to answer questions in Feishu chats.

## Concrete Example

You link Feishu and send a message to the bot. Hermes replies with the information you need.

## Analogy
