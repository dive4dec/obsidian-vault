# Gateway Health Check

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

A health check pings the gateway to make sure it is responsive and handling messages correctly.

## Concrete Example

A monitoring tool sends a ping every minute. If the gateway does not respond, it alerts you.

## Analogy

Like a doctor checking your pulse to make sure you are healthy.
