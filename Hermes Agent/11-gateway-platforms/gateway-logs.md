# Gateway Logs

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Gateway logs record all incoming and outgoing messages, errors, and connection events for debugging.

## Concrete Example

You check the logs and see that a Telegram message failed to send due to a network timeout.

## Analogy

Like a ship logbook recording every event during the voyage for later review.
