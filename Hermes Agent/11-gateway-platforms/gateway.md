# /gateway

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command shows gateway info: running status, uptime, and connected platforms.

## Concrete Example

You type /gateway and see: Gateway running for 3 hours, 2 platforms active.

## Analogy

Like a dashboard in a car showing engine status and fuel level.
