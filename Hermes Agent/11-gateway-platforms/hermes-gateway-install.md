# hermes gateway install

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command installs the gateway as a system service so it starts automatically when the computer boots.

## Concrete Example

You run hermes gateway install and the gateway is set up to start every time the server restarts.

## Analogy

Like setting your alarm clock to ring every morning automatically.
