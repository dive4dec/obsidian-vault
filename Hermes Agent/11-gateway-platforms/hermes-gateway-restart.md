# hermes gateway restart

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Restarts the gateway service, applying new settings without a full stop and manual start.

## Concrete Example

You change the config and run hermes gateway restart. The gateway reloads with the new settings.

## Analogy

Like rebooting your phone: it shuts down and starts back up with everything fresh.
