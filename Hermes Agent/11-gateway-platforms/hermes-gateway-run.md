# hermes gateway run

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command starts the gateway process so Hermes can listen for messages from connected platforms.

## Concrete Example

You run hermes gateway run and Hermes begins watching your Telegram and Discord for incoming messages.

## Analogy

Like turning on the school PA system so announcements can go out to every classroom.
