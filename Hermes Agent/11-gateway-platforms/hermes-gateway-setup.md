# hermes gateway setup

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command guides you through connecting a platform for the first time, asking for tokens and settings.

## Concrete Example

You run hermes gateway setup and it asks: Which platform? Enter your bot token. Now it is configured.

## Analogy

Like setting up a new phone: it walks you through language, WiFi, and account step by step.
