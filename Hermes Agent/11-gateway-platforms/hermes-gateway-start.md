# hermes gateway start

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Starts the installed gateway service if it is stopped.

## Concrete Example

You run hermes gateway start and the gateway begins running in the background as a service.

## Analogy

Like pressing the power button to turn on a machine that was set up earlier.
