# hermes gateway status

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Shows whether the gateway is running, which platforms are connected, and any errors.

## Concrete Example

You run hermes gateway status and see: Gateway running, Telegram connected, Discord disconnected.

## Analogy

Like checking a departure board at the airport to see which flights are on time.
