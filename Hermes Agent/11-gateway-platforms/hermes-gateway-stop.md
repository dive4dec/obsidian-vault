# hermes gateway stop

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Stops the running gateway service. Hermes will no longer receive messages from platforms.

## Concrete Example

You run hermes gateway stop before updating. The gateway shuts down and stops listening.

## Analogy

Like closing the school gate: no one can come in or go out until you reopen.
