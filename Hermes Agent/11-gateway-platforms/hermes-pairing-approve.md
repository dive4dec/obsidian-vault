# hermes pairing approve

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command approves a pending pairing request from the terminal.

## Concrete Example

You run hermes pairing approve Sam and Sam can now message the agent from Discord.

## Analogy

Like a teacher approving a late entry slip for a student.
