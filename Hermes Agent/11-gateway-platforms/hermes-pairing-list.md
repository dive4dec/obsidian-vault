# hermes pairing list

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command shows all paired users and devices connected to your agent.

## Concrete Example

You run hermes pairing list and see: Alex (Telegram, approved), Sam (Discord, pending).

## Analogy

Like checking the guest list for a party to see who is invited.
