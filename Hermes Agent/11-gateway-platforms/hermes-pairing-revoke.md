# hermes pairing revoke

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command removes a paired user or device, cutting off their access to the agent.

## Concrete Example

You run hermes pairing revoke Sam and Sam can no longer send messages to the agent.

## Analogy

Like canceling someones library card: they can no longer borrow books.
