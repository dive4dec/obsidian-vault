# linger

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Linger allows a user service to keep running even when the user is logged out. This keeps the gateway alive.

## Concrete Example

You enable linger so the gateway service stays running after you log out of the server.

## Analogy

Like leaving the lights on when you leave a room so things keep working.
