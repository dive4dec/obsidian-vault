# Matrix

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Matrix is an open protocol for decentralized chat. Hermes can join Matrix rooms and respond to messages.

## Concrete Example

You connect Hermes to a Matrix server. In a room you ask a question and the agent replies to the whole room.

## Analogy

Like a town hall meeting where the agent is a speaker who answers questions from the floor.
