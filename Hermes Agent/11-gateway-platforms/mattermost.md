# Mattermost

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Mattermost is an open-source alternative to Slack. Hermes can connect to it for team collaboration.

## Concrete Example

You add Hermes to your Mattermost channel. Team members can ask the agent questions together.

## Analogy

Like a team whiteboard where everyone can see the questions and answers.
