# Multi-Platform Routing

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Hermes can route messages from different platforms to the same agent, keeping one unified conversation.

## Concrete Example

You send a message from Telegram then continue on Discord. The agent knows it is the same conversation.

## Analogy

Like calling a friend from your phone then continuing on your computer: same conversation, different device.
