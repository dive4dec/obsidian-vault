# Open WebUI

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Open WebUI is a web interface for chatting with AI models. Hermes can connect to it as a backend.

## Concrete Example

You open the web UI in your browser, type a message, and Hermes powers the response behind the scenes.

## Analogy

Like a restaurant kitchen: you order at the front counter, but the cooking happens in the back.
