# Pairing

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Pairing links a new device or user to the agent. The owner approves or denies each pairing request.

## Concrete Example

A new phone tries to connect. You get a pairing request and approve it. Now that phone can chat with the agent.

## Analogy

Like pairing Bluetooth headphones: both sides must agree before they connect.
