# /platforms

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command lists all connected platforms and their status.

## Concrete Example

You type /platforms and see: Telegram (connected), Discord (connected), Slack (disconnected).

## Analogy

Like a contact list showing which friends are currently online.
