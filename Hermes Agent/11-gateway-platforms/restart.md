# /restart

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command restarts the gateway from within a chat, reloading all settings.

## Concrete Example

You type /restart in Telegram. The gateway restarts and comes back online in a few seconds.

## Analogy

Like restarting a frozen computer: it reboots and works again.
