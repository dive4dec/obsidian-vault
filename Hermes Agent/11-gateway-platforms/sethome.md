# /sethome

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command sets the current channel or chat as the home channel for the agent.

## Concrete Example

You type /sethome in your Telegram chat. Now this chat is the primary place for agent notifications.

## Analogy

Like setting your home address so mail always goes to the right place.
