# Signal

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Signal is a privacy-focused messaging app. Hermes can connect to it for secure conversations.

## Concrete Example

You set up Signal and message the agent. All communication is encrypted and private.

## Analogy

Like passing notes in a locked box: only you and the agent can read them.
