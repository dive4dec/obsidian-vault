# SMS

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Hermes can send and receive SMS text messages through a phone service, letting you interact via basic texting.

## Concrete Example

You text a short question to the agent number. Hermes replies with a concise text answer.

## Analogy

Like using a hotline number: you text your question and get a text back.
