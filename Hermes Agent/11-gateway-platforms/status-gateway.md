# /status (Gateway)

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

In a gateway context, /status shows the current gateway and platform connection status.

## Concrete Example

You type /status in Telegram and see: Gateway online, Telegram connected, 3 messages queued.

## Analogy

Like a flight status screen showing if your plane is on time or delayed.
