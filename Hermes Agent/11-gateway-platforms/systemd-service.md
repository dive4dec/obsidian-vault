# systemd Service

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

On Linux, the gateway can run as a systemd service that starts automatically and restarts on failure.

## Concrete Example

You install the service. Even if the server reboots, the gateway starts back up on its own.

## Analogy

Like a self-starting generator that turns on whenever the main power is off.
