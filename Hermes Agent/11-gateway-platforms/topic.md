# /topic

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command sets or shows the conversation topic in a group chat context.

## Concrete Example

You type /topic homework help and the agent focuses its answers on homework assistance.

## Analogy

Like a meeting agenda: it tells everyone what the discussion is about.
