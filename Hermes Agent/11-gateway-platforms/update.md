# /update

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

This command updates the gateway settings or platform configurations on the fly.

## Concrete Example

You type /update to reload the latest config without restarting the whole gateway.

## Analogy

Like updating an app: it refreshes without you having to reinstall.
