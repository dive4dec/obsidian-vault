# Webhook Endpoint

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

A webhook endpoint is a URL where external services can send events to Hermes.

## Concrete Example

GitHub sends a POST to your webhook endpoint when a PR opens. Hermes receives and processes it.

## Analogy

Like a suggestion box: people drop notes in and you check them regularly.
