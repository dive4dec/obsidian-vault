# Webhooks

> **Domain:** [[_gateway-platforms-moc|Gateway & Platforms]]

## Motivation

Webhooks let external services send event notifications to Hermes so it can react automatically.

## Concrete Example

GitHub sends a webhook when a PR is opened. Hermes receives it and starts reviewing the code.

## Analogy

Like a doorbell: when someone rings it, you know to answer the door.
