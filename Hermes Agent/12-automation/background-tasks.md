# Background Tasks

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Background tasks run without blocking the main conversation, letting the agent do work while still chatting with you.

## Concrete Example

You ask the agent to run a long build. It starts it in the background and you can keep chatting while it compiles.

## Analogy

Like cooking rice in a rice cooker while you do your homework: both happen at the same time.
