# Cron Job Model Override

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

You can set a specific model for a cron job, different from your default, to save cost or use a specialized model.

## Concrete Example

The daily summary job uses a small fast model while the weekly analysis job uses a powerful model.

## Analogy

Like choosing different tools for different jobs: a scissors for paper, a saw for wood.
