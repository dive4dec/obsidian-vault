# Cron Job Priority

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Cron jobs can have priority levels so important jobs run first when multiple are due at the same time.

## Concrete Example

At 9am two jobs are due. The high-priority report runs first, then the low-priority cleanup job.

## Analogy

Like a VIP line at an airport: priority passengers board first.
