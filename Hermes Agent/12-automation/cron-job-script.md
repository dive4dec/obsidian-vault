# Cron Job Script

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Instead of an AI task, a cron job can run a shell script directly for simple automated tasks.

## Concrete Example

A cron job runs backup.sh every night at midnight to copy files to an external drive.

## Analogy

Like a vending machine: you set it up once and it dispenses the same item every time you press the button.
