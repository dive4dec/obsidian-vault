# Cron Job Skills

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

You can attach a skill to a cron job so it runs with specific instructions every time.

## Concrete Example

A daily report cron job uses the github-pr-workflow skill so it always follows the correct PR review steps.

## Analogy

Like a recipe attached to a timer: when the timer goes off, the recipe is ready to follow.
