# Cron Job workdir

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

You can set a working directory for a cron job so it runs in the right project folder.

## Concrete Example

A cron job set to workdir /projects/homework runs git commands inside the homework folder.

## Analogy

Like a stage manager setting up the right stage before the actors perform.
