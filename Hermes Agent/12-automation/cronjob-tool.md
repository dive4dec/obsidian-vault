# cronjob Tool

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

The cronjob tool is a built-in tool that lets the agent create, list, and manage cron jobs during a conversation.

## Concrete Example

You ask the agent to remind me to study every day at 8pm. The agent uses the cronjob tool to create it.

## Analogy

Like a personal assistant who can set up their own reminders without you filling out forms.
