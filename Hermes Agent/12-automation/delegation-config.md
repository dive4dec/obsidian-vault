# Delegation Config

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Delegation config controls how sub-agents are spawned: what tools they get, what model they use, and their limits.

## Concrete Example

You set delegation config to allow sub-agents with read-only tools and a fast model for quick lookups.

## Analogy

Like a job description for a temp worker: it defines what they can do and what tools they can use.
