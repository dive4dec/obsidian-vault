# Event-Driven Architecture

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

In event-driven architecture, actions happen in response to events instead of on a fixed schedule.

## Concrete Example

A PR opens (event) which triggers a code review (action). No cron schedule needed, the event drives it.

## Analogy

Like a restaurant kitchen: orders come in as events and the chef cooks each one as it arrives.
