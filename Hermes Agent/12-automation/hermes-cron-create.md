# hermes cron create

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command creates a new cron job with a schedule and a task description.

## Concrete Example

You run hermes cron create with schedule every day at 7am and task summarize the news. The job is now active.

## Analogy

Like adding a new recurring event to your calendar.
