# hermes cron edit

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command lets you change an existing cron job: its schedule, task, or settings.

## Concrete Example

You run hermes cron edit weather-check and change the time from 7am to 6:30am.

## Analogy

Like editing a calendar event to move it to a different time.
