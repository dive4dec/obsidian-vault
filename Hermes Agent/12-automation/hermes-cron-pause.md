# hermes cron pause

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command temporarily stops a cron job without deleting it. You can resume it later.

## Concrete Example

You run hermes cron pause weather-check before a holiday. It stops running until you resume.

## Analogy

Like snoozing an alarm: it stops for now but you can turn it back on.
