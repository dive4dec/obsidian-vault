# hermes cron run

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command runs a cron job immediately, regardless of its schedule, to test or trigger it on demand.

## Concrete Example

You run hermes cron run weather-check and it executes right now instead of waiting for 7am.

## Analogy

Like pressing the test button on a fire alarm to check it works.
