# hermes cron status

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command shows the status of a specific cron job: last run, next run, and any errors.

## Concrete Example

You run hermes cron status weather-check and see: Last run 7am today, next run 7am tomorrow, no errors.

## Analogy

Like tracking a package: you see where it is and when it arrives next.
