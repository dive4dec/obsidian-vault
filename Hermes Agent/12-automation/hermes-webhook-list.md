# hermes webhook list

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command shows all registered webhooks and their routes.

## Concrete Example

You run hermes webhook list and see: github-push (active), payment-alert (paused).

## Analogy

Like a subscriptions page showing all the newsletters you are signed up for.
