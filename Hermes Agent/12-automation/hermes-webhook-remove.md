# hermes webhook remove

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command deletes a webhook subscription so Hermes no longer listens for those events.

## Concrete Example

You run hermes webhook remove old-webhook and Hermes stops responding to those events.

## Analogy

Like unsubscribing from a mailing list: you stop receiving those emails.
