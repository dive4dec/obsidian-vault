# hermes webhook subscribe

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command registers a webhook endpoint so Hermes can receive events from an external service.

## Concrete Example

You run hermes webhook subscribe github-push and get a URL to put in GitHub settings.

## Analogy

Like registering your phone number with a delivery service so they text you when your package arrives.
