# hermes webhook test

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

This command sends a test event to a webhook to verify it is working correctly.

## Concrete Example

You run hermes webhook test github-push and see Hermes receive and process the test event.

## Analogy

Like a fire drill: you test the alarm to make sure it works before a real emergency.
