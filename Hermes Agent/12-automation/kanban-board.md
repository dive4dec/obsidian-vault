# Kanban Board

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

A Kanban board is a visual task tracker with columns like To Do, Doing, and Done. Hermes can manage one for projects.

## Concrete Example

The agent creates a Kanban board for your project with 5 tasks in To Do and 2 in Doing.

## Analogy

Like a whiteboard with sticky notes that you move from left to right as tasks progress.
