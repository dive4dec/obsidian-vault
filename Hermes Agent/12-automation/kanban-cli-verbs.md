# Kanban CLI Verbs

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Hermes Kanban has CLI commands to create, move, and manage tasks on the board.

## Concrete Example

You run kanban add write tests, kanban move task-3 doing, kanban done task-2 to manage the board.

## Analogy

Like a remote control for your task board: each button does one action.
