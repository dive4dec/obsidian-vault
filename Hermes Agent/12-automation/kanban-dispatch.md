# Kanban Dispatch

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Dispatch assigns a Kanban task to a worker agent that picks it up and works on it independently.

## Concrete Example

You dispatch task-3 to a worker. The worker agent picks it up and starts coding the solution.

## Analogy

Like a taxi dispatcher sending the nearest available driver to pick up a passenger.
