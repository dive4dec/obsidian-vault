# Kanban Worker Toolset

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

A Kanban worker gets a specific set of tools to do its assigned task, limited to what it needs.

## Concrete Example

A worker assigned to fix a bug gets terminal, read_file, and patch tools but not email or web tools.

## Analogy

Like giving a plumber only plumbing tools: they have what they need without carrying the whole toolbox.
