# no_agent mode

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

In no_agent mode the cron job runs a script or command without calling the AI model at all, saving time and cost.

## Concrete Example

A no_agent job runs git pull every hour to fetch the latest code. No AI thinking needed.

## Analogy

Like an automatic door: it opens when someone approaches, no decision-making required.
