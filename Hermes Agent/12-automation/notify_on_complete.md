# notify_on_complete

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

When a background task finishes, this setting sends a notification to the agent so it can report the result.

## Concrete Example

A 10-minute build finishes and the agent gets notified, then tells you the build succeeded.

## Analogy

Like a timer that beeps when your food is ready so you know to take it out.
