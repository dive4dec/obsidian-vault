# Parallel Execution

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Multiple sub-agents can run at the same time, completing tasks faster than doing them one by one.

## Concrete Example

Three sub-agents review 3 different files simultaneously. The whole review finishes in 1 minute instead of 3.

## Analogy

Like 3 cashiers serving 3 customers at once instead of 1 cashier serving everyone in a single line.
