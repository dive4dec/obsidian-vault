# skip_memory

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

When skip_memory is on, the cron job does not save its conversation to memory, keeping history clean.

## Concrete Example

A quick status check job uses skip_memory so it does not clutter your memory with repeated checks.

## Analogy

Like using scratch paper for rough work that you throw away instead of saving in your notebook.
