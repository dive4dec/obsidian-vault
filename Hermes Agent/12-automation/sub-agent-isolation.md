# Sub-Agent Isolation

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Sub-agents run in isolated spaces with their own context, so they do not interfere with the main conversation.

## Concrete Example

A sub-agent runs a code review in its own space. Its tool calls and results do not clutter your main chat.

## Analogy

Like individual study carrels in a library: each student works in their own space without disturbing others.
