# Task Handoff

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

When a sub-agent finishes, it hands its result back to the parent agent in a structured format.

## Concrete Example

The sub-agent completes the code review and sends back a summary with 3 findings and suggested fixes.

## Analogy

Like a student handing in homework: the teacher receives it and can review or grade it.
