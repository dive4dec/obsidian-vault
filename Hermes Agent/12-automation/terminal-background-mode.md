# Terminal Background Mode

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

You can run terminal commands in the background so they do not block the conversation while they run.

## Concrete Example

The agent starts a build in background mode and immediately continues helping you with other questions.

## Analogy

Like starting the washing machine and going to watch TV while it runs.
