# Webhook Payload

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

The payload is the data sent with a webhook event, containing details about what happened.

## Concrete Example

The GitHub push payload includes the repo name, branch, and list of changed files.

## Analogy

Like the contents of a delivery package: the box label says what it is, the inside has the details.
