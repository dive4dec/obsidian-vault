# Webhook Routes

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

A webhook route maps an incoming event to a specific action or skill in Hermes.

## Concrete Example

The github-push route maps to the code-review skill. When a push event arrives, the review starts automatically.

## Analogy

Like a school bell system: different bell patterns trigger different responses like recess or fire drill.
