# Webhooks

> **Domain:** [[_automation-scheduling-moc|Automation & Scheduling]]

## Motivation

Webhooks let external services trigger Hermes automatically by sending HTTP requests when events happen.

## Concrete Example

GitHub sends a webhook when code is pushed. Hermes receives it and runs a code review automatically.

## Analogy

Like a doorbell connected to a smart home: when someone rings it, the lights turn on automatically.
