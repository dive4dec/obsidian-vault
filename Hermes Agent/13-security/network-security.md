# Network Security

> **Domain:** [[_security-moc|Security]]

## Motivation

Protecting Hermes network communications: HTTPS for API calls, egress proxy for monitoring, website blocklist for filtering.

## Concrete Example

HTTPS: all API calls encrypted. Egress proxy: traffic monitored. Website blocklist: dangerous sites blocked. Three layers of network security.

## Analogy

A armored transport truck - the cargo is locked (HTTPS), the route is monitored (proxy), and dangerous neighborhoods are avoided (blocklist). Network security protects data in transit.
