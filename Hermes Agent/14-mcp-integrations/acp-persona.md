# ACP Persona

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A custom personality or role configured for ACP server mode. Defines how Hermes behaves when connected to an IDE.

## Concrete Example

ACP persona: Code Reviewer. When connected via ACP, Hermes focuses on code review: reads diffs, checks style, suggests improvements. Different persona for different tasks.

## Analogy

An actor playing a role - the same actor can be a hero in one movie and a villain in another. ACP personas let Hermes play different roles depending on the IDE context.
