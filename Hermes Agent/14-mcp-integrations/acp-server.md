# ACP Server

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Agent Communication Protocol. Hermes can run as an ACP server for IDE integration. Connects AI agents to development environments.

## Concrete Example

hermes acp. Hermes starts an ACP server. Your IDE (e.g., VS Code) connects. Now you can chat with Hermes from inside the editor. Hermes can read files, run code, and suggest changes.

## Analogy

An intercom between rooms - you press a button and talk to someone in another room. ACP connects your IDE to Hermes. You talk to Hermes from inside your editor.
