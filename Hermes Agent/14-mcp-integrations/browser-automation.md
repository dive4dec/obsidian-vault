# Browser Automation

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Hermes browser toolset. Automates web browsing: navigate, click, type, screenshot. Uses Browserbase, Camofox, or local Chromium.

## Concrete Example

Hermes: Check the price of iPhone 16 on apple.com. Browser: navigates to apple.com, finds the price, returns: HK$ 8,499. Automated web browsing.

## Analogy

A personal shopper who visits stores for you - they go to the shop, find the product, check the price, and report back. Browser automation is the personal shopper for the web.
