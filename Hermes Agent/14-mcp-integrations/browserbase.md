# Browserbase

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A cloud browser service for Hermes. Runs browser automation in the cloud without local resources.

## Concrete Example

Browserbase: Hermes opens a cloud browser, navigates a website, and extracts data. No local browser needed. Works on any device, even phones.

## Analogy

A cloud computer - instead of running software on your laptop, it runs in the cloud. Browserbase runs browsers in the cloud for Hermes.
