# Built-in Plugins

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Plugins that ship with Hermes. Include Honcho memory, Spotify, and others. Available without installation.

## Concrete Example

Built-in: honcho, spotify, homeassistant, discord. These come pre-installed but may need activation. hermes plugins list shows them. Activate with hermes plugins install <name>.

## Analogy

Pre-installed apps on a new phone - they are there when you buy it. You just need to open them. Built-in plugins come with Hermes, ready to activate.
