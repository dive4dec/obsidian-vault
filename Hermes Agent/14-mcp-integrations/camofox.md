# Camofox

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A stealth browser backend for Hermes. Anti-detection features for web scraping and automation.

## Concrete Example

Camofox: Hermes browses a website that blocks bots. Camofox evades detection. The site thinks it is a real user. Data is extracted successfully.

## Analogy

A camouflage uniform - the soldier blends in and is not detected. Camofox camouflages Hermes browser automation to avoid bot detection.
