# Edge TTS

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Microsoft Edge Text-to-Speech. Free, high-quality voices. Default TTS provider.

## Concrete Example

Edge TTS: Hermes text -> natural-sounding voice. Multiple languages and accents. Free. No API key. Works on any platform.

## Analogy

A free language lab - you type text, it speaks in natural voices, many languages. Edge TTS is the free language lab for Hermes voice output.
