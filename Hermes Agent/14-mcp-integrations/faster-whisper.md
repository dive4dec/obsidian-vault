# Faster-Whisper

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A local, free STT provider. Runs on your machine. No API key needed. Default for voice messages.

## Concrete Example

pip install faster-whisper. Voice message -> faster-whisper transcribes it locally. No internet needed. Free. Models: tiny, base, small, medium, large-v3.

## Analogy

A personal translator who lives in your house - no need to call an agency. They are always there, free. Faster-whisper is the in-house translator for voice messages.
