# Honcho Memory

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A memory provider plugin that gives Hermes deeper memory capabilities. Persistent, context-aware memory across sessions.

## Concrete Example

honcho plugin: instead of simple MEMORY.md, Honcho provides structured memory: user preferences, conversation summaries, and semantic search. Richer memory than built-in.

## Analogy

A personal diary with an index - instead of just writing entries, you can search by topic, date, and importance. Honcho memory is an indexed diary for Hermes.
