# IDE Integration

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Connecting Hermes to development environments (VS Code, JetBrains) via ACP or MCP. The agent works inside the editor.

## Concrete Example

VS Code + Hermes ACP: you highlight code, ask Hermes to refactor. Hermes reads the file, analyzes the code, and suggests changes - all inside VS Code. No terminal needed.

## Analogy

A teaching assistant who sits next to you in class - they look at your work and help immediately. IDE integration puts Hermes next to your code, ready to help.
