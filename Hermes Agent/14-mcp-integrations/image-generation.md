# Image Generation

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

AI image creation via Hermes. Text-to-image using FAL, OpenAI, xAI, or other backends.

## Concrete Example

Hermes: Generate an image of a cat wearing a space suit. FAL backend: creates the image. Returns a URL. You see: a cute cat in a space suit. Text became an image.

## Analogy

A magic paintbrush - you describe what you want, and it paints it. Image generation is the magic paintbrush for Hermes.
