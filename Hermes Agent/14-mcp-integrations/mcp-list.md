# MCP List

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Listing all configured MCP servers. Command: hermes mcp list. Shows name, transport, and status.

## Concrete Example

hermes mcp list. Output: filesystem (stdio, connected), github (stdio, connected), weather (http, disconnected). You see all servers and their connection status.

## Analogy

Checking your contacts list - you see all your contacts and whether they are online. hermes mcp list shows all MCP servers and whether they are connected.
