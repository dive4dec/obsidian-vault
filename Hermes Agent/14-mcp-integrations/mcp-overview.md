# MCP Overview

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Model Context Protocol (MCP) is an open standard for connecting AI models to external tools and data sources. Hermes has a built-in MCP client.

## Concrete Example

hermes mcp list. You see: filesystem, github, slack. These MCP servers provide tools that Hermes can use. Hermes discovers their tools automatically and calls them like built-in tools.

## Analogy

An app store - you browse apps (MCP servers), install the ones you want, and they appear on your phone (Hermes). Each app provides new capabilities. MCP is the app store for AI tools.
