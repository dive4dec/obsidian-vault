# MCP Serve

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Running Hermes itself as an MCP server. Other AI applications can use Hermes tools via MCP.

## Concrete Example

hermes mcp serve. Hermes starts an MCP server. Another AI app (e.g., Claude Desktop) connects to Hermes. Now Claude can use Hermes tools (terminal, file, web). Hermes becomes a tool provider.

## Analogy

A restaurant that also caterings - not only do they serve food in-house, they also provide food to other events. hermes mcp serve lets other AI apps use Hermes as a tool provider.
