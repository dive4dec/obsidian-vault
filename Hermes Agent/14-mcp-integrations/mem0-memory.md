# Mem0 Memory

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Another memory provider option. Offers flexible, configurable memory backends for different use cases.

## Concrete Example

Mem0: configure memory rules. Remember user name always. Remember coding preferences for 30 days. Forget casual chat after 7 days. Fine-grained memory control.

## Analogy

A smart notebook with rules - important notes are kept forever, homework notes are kept until the exam, doodles are erased weekly. Mem0 gives Hermes configurable memory rules.
