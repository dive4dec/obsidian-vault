# Memory Provider

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A pluggable backend for Hermes memory system. Options: built-in (default), Honcho, Mem0. Each offers different features.

## Concrete Example

hermes memory setup. Choose: built-in (simple, free), Honcho (rich, hosted), Mem0 (flexible, configurable). Each provider changes how Hermes remembers things.

## Analogy

Choosing a notebook brand - simple notebook (built-in), smart notebook (Honcho), customizable binder (Mem0). Each memory provider is a different type of notebook.
