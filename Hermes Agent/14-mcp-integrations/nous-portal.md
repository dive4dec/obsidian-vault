# Nous Portal

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Nous Research hosted service. Provides OAuth authentication, hosted models, and the Tool Gateway. The easiest way to get started.

## Concrete Example

hermes setup --portal. OAuth login. You get: a model (for chatting) + 4 tools (web search, image gen, TTS, browser). All with one account. No API keys to manage.

## Analogy

A school all-access pass - one ID card gives you access to the library, gym, computer lab, and cafeteria. Nous Portal is the all-access pass for Hermes.
