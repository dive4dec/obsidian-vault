# Plugin Management

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Managing plugins: hermes plugins list/install/remove. View, add, and delete plugins.

## Concrete Example

hermes plugins list: [honcho (active), spotify (inactive)]. hermes plugins install memory-pro. hermes plugins remove honcho. Full lifecycle management.

## Analogy

Managing apps on your phone - you view, install, and uninstall apps. Plugin management does the same for Hermes plugins.
