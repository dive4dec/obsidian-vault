# Plugin System

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Hermes plugins extend functionality. Installed via hermes plugins install. Add new tools, commands, or integrations.

## Concrete Example

hermes plugins install honcho. Plugin installed. Now Honcho memory is available. Plugins can add tools, modify behavior, or integrate with external services.

## Analogy

Browser extensions - you install an ad blocker extension. Now your browser blocks ads. Hermes plugins work the same way: install new capabilities.
