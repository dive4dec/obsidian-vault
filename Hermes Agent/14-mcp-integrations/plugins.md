# Plugins

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Plugins are packages that extend Hermes. Each plugin can add tools, commands, skills, or integrations.

## Concrete Example

honcho plugin: adds Honcho memory provider. spotify plugin: adds Spotify playback tools. Each plugin adds specific features. Hermes loads them at startup.

## Analogy

Lego expansion sets - you buy a new set and add new pieces to your collection. Each set (plugin) adds new building options. Plugins add new pieces to Hermes.
