# Tool Gateway

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A feature that provides hosted tools (web search, image generation, TTS, browser) via the Nous Portal. One OAuth covers all four.

## Concrete Example

hermes setup --portal. One OAuth gives access to: web search, image generation, TTS, and browser automation. No separate API keys needed. The Tool Gateway hosts these tools.

## Analogy

A all-in-one entertainment package - one subscription gives you movies, music, sports, and games. The Tool Gateway gives you four tools with one login.
