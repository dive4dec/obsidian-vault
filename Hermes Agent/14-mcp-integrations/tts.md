# TTS

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Text-to-Speech. Converts Hermes text responses to voice. Providers: Edge TTS (free, default), ElevenLabs, OpenAI, MiniMax, Mistral, NeuTTS.

## Concrete Example

TTS: Hermes generates text response. Edge TTS converts it to voice. You hear: The weather is 28 degrees and sunny. On Telegram, this is a voice message.

## Analogy

An audiobook narrator - they read text aloud. TTS reads Hermes responses aloud. Different narrators (providers) have different voices.
