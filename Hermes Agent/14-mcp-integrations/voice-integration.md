# Voice Integration

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Hermes voice features: STT (speech-to-text) and TTS (text-to-speech). Multiple providers supported.

## Concrete Example

Voice: you send a voice message on Telegram. Hermes transcribes it (STT), processes it, and replies with a voice message (TTS). Full voice-to-voice conversation.

## Analogy

A walkie-talkie that also translates - you speak, it converts to text, processes, and speaks back. Voice integration lets you talk to Hermes instead of typing.
