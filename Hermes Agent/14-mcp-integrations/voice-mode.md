# Voice Mode

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

A mode where Hermes communicates by voice instead of text. /voice on enables voice-to-voice.

## Concrete Example

/voice on. You speak -> Hermes transcribes -> processes -> speaks response. Full voice conversation. /voice off returns to text mode.

## Analogy

A phone call vs texting - phone calls are voice mode, texting is text mode. /voice on switches Hermes from texting to calling.
