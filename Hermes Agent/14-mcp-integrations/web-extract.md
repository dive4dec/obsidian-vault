# Web Extract

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Extracting content from web pages. Hermes fetches a URL and extracts the main text content.

## Concrete Example

Hermes: Read https://example.com/article. Web extract: fetches the page, removes ads and navigation, returns: Main article text... Clean content for the model.

## Analogy

A highlighter for web pages - you highlight only the important text and ignore the ads and menus. Web extract highlights the main content of a web page.
