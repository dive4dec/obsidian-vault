# Web Search

> **Domain:** [[_mcp-integrations-moc|MCP & Integrations]]

## Motivation

Searching the web via Hermes. Uses hosted search or direct search engines. Returns results for the model.

## Concrete Example

Hermes: What is the latest news about AI? Web search: queries search engine, returns: [1] AI Breakthrough..., [2] New Model Released... Hermes summarizes the results.

## Analogy

A librarian who searches the library for you - you ask a question, they find relevant books and articles. Web search is the librarian for the internet.
