# Branch Session

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Create a copy of the current session to explore a different path. Command: /branch or /fork.

## Concrete Example

/branch. Now you have two sessions: the original and the branch. On the branch, you try a risky approach. If it works, keep it. If not, the original is safe.

## Analogy

A choose-your-own-adventure book - you bookmark a page, then explore a path. If it is a dead end, you go back to the bookmark. /branch bookmarks your session.
