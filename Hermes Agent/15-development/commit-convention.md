# Commit Convention

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Hermes uses conventional commits: type: subject. Types: fix, feat, refactor, docs, chore.

## Concrete Example

git commit -m feat: add Spotify playlist search. Or: fix: crash when tool returns None. Or: docs: update installation guide. Clear, consistent commit messages.

## Analogy

Labeling boxes for moving - each box is labeled: Kitchen: Plates, Bedroom: Books, Garage: Tools. Commit conventions label code changes: feat, fix, docs.
