# Community

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Hermes has an active community: GitHub, Discord, docs. Users contribute skills, report bugs, and help each other.

## Concrete Example

Discord: #help channel. Ask a question, get an answer. GitHub: report issues, submit PRs. Docs: read guides, contribute improvements. The community makes Hermes better.

## Analogy

A school club - members help each other, share ideas, and organize events. The Hermes community is a club where users and developers help each other.
