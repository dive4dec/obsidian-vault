# Debug Command

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Upload a debug report for support. Command: /debug. Collects system info and logs, generates shareable links.

## Concrete Example

/debug. Hermes collects: OS, Python version, config, recent logs, error traces. Uploads securely. Returns a link you can share with support. Fast diagnosis.

## Analogy

A medical report for a doctor visit - it has your history, symptoms, and test results. You give it to the doctor for fast diagnosis. /debug is the medical report for Hermes support.
