# Discord

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

The Hermes Discord server. Real-time chat, help, announcements, and community discussion.

## Concrete Example

Discord: `#general` (chat), `#help` (support), `#dev` (development), `#skills` (sharing). Real-time community. Faster than GitHub issues for quick questions.

## Analogy

A school group chat - everyone is there. You ask questions, share news, and hang out. Discord is the Hermes group chat.
