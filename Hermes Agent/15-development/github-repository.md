# GitHub Repository

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

The Hermes Agent repository on GitHub. Contains source code, issues, pull requests, and documentation.

## Concrete Example

github.com/NousResearch/hermes-agent. Star, fork, clone, contribute. Report bugs via issues. Submit fixes via pull requests. The central hub for Hermes development.

## Analogy

A workshop where everyone is welcome - you can visit, watch, help build, or suggest improvements. The GitHub repository is the Hermes workshop.
