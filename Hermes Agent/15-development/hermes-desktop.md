# Hermes Desktop

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

A desktop application for Windows and macOS. GUI version of Hermes. Download from the website.

## Concrete Example

Download Hermes Desktop installer. Run it. You get a desktop app with a chat interface, settings panel, and visual tool management. No terminal needed.

## Analogy

A remote control for your TV - instead of pressing buttons on the TV, you use a remote. Hermes Desktop is a remote control for Hermes, with buttons and menus instead of commands.
