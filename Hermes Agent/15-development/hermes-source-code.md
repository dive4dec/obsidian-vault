# Hermes Source Code

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

The Hermes Agent codebase is open source on GitHub. Written in Python. Anyone can read, modify, and contribute.

## Concrete Example

git clone https://github.com/NousResearch/hermes-agent. The code is in ~/.hermes/hermes-agent/. Main files: run_agent.py (core loop), model_tools.py (tool dispatch), cli.py (interface).

## Analogy

An open kitchen in a restaurant - you can see how every dish is made. You can suggest improvements or cook yourself. Hermes source code is an open kitchen.
