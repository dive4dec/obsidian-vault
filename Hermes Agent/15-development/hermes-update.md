# Hermes Update

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Update Hermes to the latest version. Command: hermes update. Or /update in gateway.

## Concrete Example

hermes update. Downloads latest version. Updates Python packages. Migrates config if needed. Restarts if necessary. You are now on the latest version.

## Analogy

Updating an app on your phone - it downloads the new version, installs it, and you have new features. hermes update does the same for Hermes.
