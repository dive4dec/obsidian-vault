# Logging

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

Hermes records events in log files. Gateway logs, error logs, session transcripts. Essential for debugging.

## Concrete Example

Logs: gateway.log (messaging events), errors.log (crashes), sessions/ (transcripts). Each log records different information. Together they provide a complete picture.

## Analogy

A diary - you write what happened each day. If you forget something, you read the diary. Logging is Hermes diary, recording what happened for later review.
