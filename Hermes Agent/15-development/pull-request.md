# Pull Request

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

A request to merge changes into the Hermes codebase. Reviewed by maintainers before merging.

## Concrete Example

Fork hermes-agent. Create branch: fix-terminal-bug. Write code. Push. Open PR. Maintainer reviews: Looks good. Merge. Your fix is now in Hermes.

## Analogy

Submitting an article to a magazine - you write it, submit it, the editor reviews it, suggests changes, and if accepted, it is published. A PR is submitting your code for publication.
