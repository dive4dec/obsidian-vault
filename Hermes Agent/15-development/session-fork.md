# Session Fork

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

A forked (branched) session. An exact copy at the fork point. Changes in the fork do not affect the original.

## Concrete Example

Session A: Build a web app. /fork -> Session B (identical copy). In B: try using Flask. In A: continue with Django. Two independent paths from the same point.

## Analogy

A fork in a hiking trail - the path splits. You take the left fork, your friend takes the right. Both explore independently. Session fork splits the conversation.
