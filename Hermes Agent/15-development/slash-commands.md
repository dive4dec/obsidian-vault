# Slash Commands

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

In-session commands starting with /. Provide quick access to features: /new, /model, /tools, /skills, /help.

## Concrete Example

Type /help in a Hermes session. Output: Available commands: /new, /reset, /model, /tools... Each command does one thing. Quick access without leaving the conversation.

## Analogy

Keyboard shortcuts in a video game - press a key to do an action. Slash commands are keyboard shortcuts for Hermes. /new starts fresh, /model changes model.
