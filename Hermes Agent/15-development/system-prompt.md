# System Prompt

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

The initial instruction sent to the LLM. Defines Hermes behavior, available tools, and context. Built by the prompt builder.

## Concrete Example

System prompt: You are Hermes Agent, an intelligent AI assistant... Available tools: terminal, read_file, web_search... User preferences: concise responses... The LLM uses this to guide its behavior.

## Analogy

A job description for a new employee - it explains their role, tools, and expectations. The system prompt is Hermes job description for the LLM.
