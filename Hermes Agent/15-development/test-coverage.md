# Test Coverage

> **Domain:** [[_development-contributing-moc|Development & Contributing]]

## Motivation

How much of the code is tested. Hermes aims for high coverage to catch bugs before release.

## Concrete Example

Coverage: tools/ 95%, agent/ 88%, gateway/ 82%. Uncovered code is a risk. Coverage reports show which lines are tested and which are not.

## Analogy

A security scan at an airport - they check every passenger. Unchecked passengers are a risk. Test coverage checks every code line. Unchecked lines are a risk.
