# flat-layout

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

The simplest layout where the package directory sits at the project root alongside `pyproject.toml` and `tests/`.

## 📋 Concrete Example

Folders: `mypkg/`, `tests/`, `pyproject.toml` — `mypkg` imports directly from the working directory.

## 🔗 Analogy

Flat layout is an open workshop — everything is on the table, easy to reach but easy to mix up.
