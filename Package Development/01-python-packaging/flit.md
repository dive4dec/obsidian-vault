# flit

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

A lightweight build backend for simple pure-Python packages. It reads metadata from your `__init__.py` or `pyproject.toml` and uploads to PyPI.

## 📋 Concrete Example

With `build-backend = "flit_core.buildapi"`, a docstring in `mypkg/__init__.py` provides the package description.

## 🔗 Analogy

Flit is a pocket knife — minimal blades, perfect when you only need to cut string and tape.
