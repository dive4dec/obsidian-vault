# hatch

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

A modern build backend and project manager called Hatchling. It offers environment management, versioning, and publishing in one tool.

## 📋 Concrete Example

Use `build-backend = "hatchling.build"` in `pyproject.toml`; the `hatch` CLI runs `hatch build` and `hatch publish`.

## 🔗 Analogy

Hatch is an all-in-one workshop — build, test, and ship your project without switching tools.
