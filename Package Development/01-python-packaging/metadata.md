# metadata

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

Information about your package: name, version, author, license, description. It lives in `[project]` in `pyproject.toml`.

## 📋 Concrete Example

Fields like `name = "mypkg"`, `version = "1.0.0"`, `authors = [{name="Ada"}]` go in the `[project]` table.

## 🔗 Analogy

Metadata is a name tag on your package — it tells the world who made it and what version it is.
