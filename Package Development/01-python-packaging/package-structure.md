# package-structure

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

How you organise files and folders in a package. Good structure makes imports clear, testing easy, and distribution clean.

## 📋 Concrete Example

A typical layout has `mypkg/__init__.py`, `mypkg/core.py`, `tests/`, and `pyproject.toml` at the root.

## 🔗 Analogy

Package structure is like a filing cabinet — each drawer and folder has a purpose so you find things fast.
