# pip-install

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

The standard command to install Python packages from PyPI or local source. It resolves dependencies and places files in `site-packages`.

## 📋 Concrete Example

Running `pip install mypkg` downloads the wheel and copies it into your environment's `site-packages`.

## 🔗 Analogy

`pip install` is a delivery service — you order a package and it lands on your doorstep ready to use.
