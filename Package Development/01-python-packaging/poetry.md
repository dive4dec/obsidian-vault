# poetry

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

A popular dependency manager and build backend. It uses a `pyproject.toml`-based workflow with a lockfile for reproducible installs.

## 📋 Concrete Example

Run `poetry new mypkg`, then `poetry add requests` and `poetry build` to create distributions.

## 🔗 Analogy

Poetry is a personal assistant for your project — it tracks dependencies and schedules builds for you.
