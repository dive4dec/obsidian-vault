# semantic-versioning

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

A convention using MAJOR.MINOR.PATCH numbers. Breaking changes bump MAJOR, new features bump MINOR, fixes bump PATCH.

## 📋 Concrete Example

Going from `1.2.0` to `2.0.0` signals a breaking change, while `1.2.1` is just a bug fix.

## 🔗 Analogy

Semantic versioning is a traffic light — red means stop (major), yellow means caution (minor), green means go (patch).
