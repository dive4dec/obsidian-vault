# version-bumping

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

The practice of incrementing version numbers on each release. Tools like `bump2version` or `hatch version` automate the process.

## 📋 Concrete Example

Run `hatch version minor` to go from `1.2.3` to `1.3.0`, updating `pyproject.toml` automatically.

## 🔗 Analogy

Version bumping is an odometer rolling over — each release ticks the counter so you track progress.
