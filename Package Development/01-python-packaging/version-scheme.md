# version-scheme

> **Domain:** [[_python-packaging-moc|Python Packaging]]

## 🎯 Motivation

Rules for assigning version numbers consistently. Python packaging favours PEP 440, which defines valid version strings.

## 📋 Concrete Example

A valid PEP 440 version looks like `1.0.0`, `2.3.0a1`, or `0.9!1.0` — pip rejects malformed versions.

## 🔗 Analogy

A version scheme is a grading scale — everyone follows the same marks so results are comparable.
