# anaconda

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A commercial Python distribution and the company behind conda. It provides the `defaults` channel and Anaconda Distribution.

## 📋 Concrete Example

Installing Anaconda gives you `conda`, Python, and 250+ packages in one download.

## 🔗 Analogy

Anaconda is a pre-furnished house — move in and everything is already set up.
