# bioconda

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A conda channel specialising in bioinformatics packages. It works alongside `conda-forge` and `r` channels.

## 📋 Concrete Example

Run `conda install -c bioconda samtools` to install a genomics tool from bioconda.

## 🔗 Analogy

bioconda is a specialty pharmacy — it stocks medical and biological tools you won't find in a general store.
