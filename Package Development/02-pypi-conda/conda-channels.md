# conda-channels

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

Remote repositories that conda searches for packages. Channel priority determines which version wins conflicts.

## 📋 Concrete Example

List channels in `.condarc` or use `-c channelname`; `conda-forge` usually has the latest versions.

## 🔗 Analogy

Channels are TV subscriptions — each broadcasts different shows, and priority picks the channel you watch first.
