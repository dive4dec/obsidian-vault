# conda-environment

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

An isolated workspace with its own Python version and packages. Created with `conda create` and saved to `environment.yml`.

## 📋 Concrete Example

Run `conda create -n myenv python=3.12` then `conda activate myenv` to enter the isolated space.

## 🔗 Analogy

A conda environment is a separate bedroom — each has its own furniture and you switch by walking in.
