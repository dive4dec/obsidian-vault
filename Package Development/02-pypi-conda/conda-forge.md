# conda-forge

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A community-driven conda channel with the widest package selection. It is the go-to source for most conda users.

## 📋 Concrete Example

Add `conda-forge` with `conda config --add channels conda-forge`, then `conda install mypkg`.

## 🔗 Analogy

conda-forge is a farmers market — community stalls offering fresh, diverse produce for everyone.
