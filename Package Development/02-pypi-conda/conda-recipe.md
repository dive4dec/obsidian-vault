# conda-recipe

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A `meta.yaml` file that describes how to build a conda package. It lists source, build, and requirements sections.

## 📋 Concrete Example

A recipe has `package: name/version`, `source: url/sha256`, and `requirements: host/run` sections.

## 🔗 Analogy

A conda recipe is a blueprint — it tells the builder exactly how to assemble the package.
