# conda-vs-pip

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

pip installs Python-only packages from PyPI; conda installs any language's packages and can manage Python itself.

## 📋 Concrete Example

Use `pip install` for pure Python tools, `conda install` when you need C libraries like `numpy` with MKL.

## 🔗 Analogy

pip is a Python-only shop; conda is a multilingual mall that also sells the Python runtime itself.
