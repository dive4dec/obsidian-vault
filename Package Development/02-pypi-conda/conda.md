# conda

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A cross-language package manager and environment manager. It installs Python and non-Python packages from conda channels.

## 📋 Concrete Example

Running `conda install numpy` pulls the package from the `defaults` channel into the active environment.

## 🔗 Analogy

Conda is a supermarket — it stocks groceries from many brands (channels), not just Python shelves.
