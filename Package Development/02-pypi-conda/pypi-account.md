# pypi-account

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A registered account on pypi.org with a username and API token. You need one before you can upload any package.

## 📋 Concrete Example

Sign up at `pypi.org/account/register/`, then generate a token under Account settings → API tokens.

## 🔗 Analogy

A PyPI account is a library card — you need it to check books in and out of the collection.
