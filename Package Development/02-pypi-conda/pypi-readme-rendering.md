# pypi-readme-rendering

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

PyPI displays your `README` as rendered Markdown or reStructuredText on the project page. It must be declared in metadata.

## 📋 Concrete Example

Set `readme = "README.md"` in `[project]`; PyPI renders it with headings, links, and code blocks.

## 🔗 Analogy

Readme rendering is a shop window display — your README is dressed up so passers-by stop and look.
