# pypi-stats

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

Public download statistics available at `pypistats.org` and via the PyPI JSON API. They show how often packages are downloaded.

## 📋 Concrete Example

Visit `pypistats.org/packages/mypkg` or query `https://pypistats.org/api/packages/mypkg/recent` for JSON data.

## 🔗 Analogy

PyPI stats are a bestseller list — they show which packages are flying off the shelves.
