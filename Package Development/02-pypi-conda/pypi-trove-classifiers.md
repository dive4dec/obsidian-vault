# pypi-trove-classifiers

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

Standardised labels on PyPI that categorise packages by topic, language, and license. They help users find your project.

## 📋 Concrete Example

Add `classifiers = ["Programming Language :: Python :: 3", "License :: OSI Approved :: MIT License"]` to metadata.

## 🔗 Analogy

Trove classifiers are library shelf labels — they tell browsers exactly where your book belongs.
