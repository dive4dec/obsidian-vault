# pypi

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

The Python Package Index — the default public repository where anyone can upload and download Python packages with `pip`.

## 📋 Concrete Example

Running `pip install requests` fetches the package from `pypi.org`, the official PyPI host.

## 🔗 Analogy

PyPI is an app store for Python code — developers publish, users download, everyone benefits.
