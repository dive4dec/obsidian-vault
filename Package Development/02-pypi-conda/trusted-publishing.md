# trusted-publishing

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

A passwordless PyPI upload method using OIDC tokens from GitHub Actions. No API token needed, improving security.

## 📋 Concrete Example

Configure a Trusted Publisher on PyPI, then use `pypa/gh-action-pypi-publish` in your workflow.

## 🔗 Analogy

Trusted publishing is a VIP pass — your GitHub identity gets you in without showing a ticket each time.
