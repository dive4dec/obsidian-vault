# wheel-vs-conda-package

> **Domain:** [[_pypi-conda-moc|PyPI & Conda]]

## 🎯 Motivation

Wheels are Python-specific binary packages; conda packages can bundle compiled C/Fortran libraries and non-Python tools.

## 📋 Concrete Example

A `numpy` wheel bundles compiled extensions, but a conda package can also pin the exact BLAS library.

## 🔗 Analogy

A wheel is a photo of a dish; a conda package is the full meal kit with spices and a recipe.
