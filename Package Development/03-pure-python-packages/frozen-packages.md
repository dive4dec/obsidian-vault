# frozen-packages

> **Domain:** [[_pure-python-packages-moc|Pure Python Packages]]

## 🎯 Motivation

Packages compiled into a standalone executable using tools like PyInstaller or cx_Freeze. They bundle Python + code into one file.

## 📋 Concrete Example

Running `pyinstaller --onefile myscript.py` creates a single executable with the interpreter embedded.

## 🔗 Analogy

A frozen package is canned soup — everything cooked and sealed, ready to heat and eat with no kitchen.
