# no-compile-deps

> **Domain:** [[_pure-python-packages-moc|Pure Python Packages]]

## 🎯 Motivation

A property of pure-Python packages: they require no compiler toolchain at install time. This makes installs fast and reliable.

## 📋 Concrete Example

Installing `flask` needs no `gcc` or `make` — all code is `.py` files copied into `site-packages`.

## 🔗 Analogy

No compile deps is pre-cut fabric — you skip the scissors and go straight to sewing.
