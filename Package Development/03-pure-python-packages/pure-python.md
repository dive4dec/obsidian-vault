# pure-python

> **Domain:** [[_pure-python-packages-moc|Pure Python Packages]]

## 🎯 Motivation

Packages written entirely in Python with no compiled C extensions. They install anywhere Python runs, making them portable and simple.

## 📋 Concrete Example

A package like `requests` is pure Python — `pip install requests` works on any OS without a compiler.

## 🔗 Analogy

Pure Python is a handwritten letter — no special equipment needed to read it, just a pen and paper.
