# single-module-package

> **Domain:** [[_pure-python-packages-moc|Pure Python Packages]]

## 🎯 Motivation

The simplest package form: one `.py` file that is importable. Useful for tiny utilities and scripts.

## 📋 Concrete Example

A file `greet.py` with `def hello(): ...` can be installed and imported as `import greet`.

## 🔗 Analogy

A single-module package is a business card — one small item that carries all the essential info.
