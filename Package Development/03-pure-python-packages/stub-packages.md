# stub-packages

> **Domain:** [[_pure-python-packages-moc|Pure Python Packages]]

## 🎯 Motivation

Packages containing only `.pyi` type stub files, providing type information for libraries without shipping the implementation.

## 📋 Concrete Example

Install `types-requests` to get type hints for `requests` in your IDE without changing runtime behavior.

## 🔗 Analogy

Stub packages are nutrition labels — they describe what's inside without you having to open the package.
