# cell-magic

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

A magic command prefixed with `%%` that transforms an entire cell. Common ones include `%%time`, `%%bash`, and `%%writefile`.

## 📋 Concrete Example

Writing `%%bash` at the top of a cell lets you run shell commands across the whole cell body.

## 🔗 Analogy

Cell magic is a factory setting for the whole room — it changes how everything inside the cell behaves.
