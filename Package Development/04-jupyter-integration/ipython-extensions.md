# ipython-extensions

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

Python modules that add features to IPython when loaded with `%load_ext`. They can register magics, hooks, and shell tweaks.

## 📋 Concrete Example

Run `%load_ext mypkg.ipython_ext` to activate an extension that adds custom magics to your session.

## 🔗 Analogy

IPython extensions are browser add-ons — install one and your notebook gains new capabilities.
