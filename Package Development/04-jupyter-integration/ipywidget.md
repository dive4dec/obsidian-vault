# ipywidget

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

The Python package `ipywidgets` that provides widget classes like `IntSlider`, `Button`, and `Text`. It is the kernel-side of interactive controls.

## 📋 Concrete Example

Import `ipywidgets as widgets`; then `widgets.IntSlider(value=5, min=0, max=10)` creates a slider widget.

## 🔗 Analogy

ipywidget is the remote control in your hand — you build the buttons in Python, the frontend renders them.
