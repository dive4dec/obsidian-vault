# jupyter-magic

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

Special commands in IPython/Jupyter that start with `%` or `%%`. They provide shortcuts for common tasks like timing and profiling.

## 📋 Concrete Example

Typing `%timeit sum(range(1000))` measures execution speed; `%%time` times an entire cell.

## 🔗 Analogy

Magic commands are cheat codes in a game — type a short prefix and get a powerful result instantly.
