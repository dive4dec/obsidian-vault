# jupyter-widget

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

Interactive HTML controls in notebooks, like sliders and buttons, built on the `ipywidgets` library. They communicate with the kernel via `comms`.

## 📋 Concrete Example

Creating `widgets.IntSlider()` displays a slider you can drag; Python code reacts to value changes.

## 🔗 Analogy

A Jupyter widget is a dashboard knob — turn it and the connected machinery responds in real time.
