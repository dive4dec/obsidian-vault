# jupyterlab-extension

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

A frontend plugin for JupyterLab written in TypeScript. Extensions add UI panels, commands, and themes to the lab interface.

## 📋 Concrete Example

Install with `pip install jupyterlab-myext` or `jupyter labextension install @author/myext` to add features.

## 🔗 Analogy

A JupyterLab extension is an app on your phone home screen — it adds a new icon with its own features.
