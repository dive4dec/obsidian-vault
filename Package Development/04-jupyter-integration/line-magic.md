# line-magic

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

A magic command prefixed with a single `%` that operates on one line of input. They are quick utilities for inline tasks.

## 📋 Concrete Example

Use `%pwd` to print the working directory, or `%env VAR=hello` to set an environment variable.

## 🔗 Analogy

Line magic is a speed dial button — one press does one specific thing on the current line.
