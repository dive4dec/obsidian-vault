# magic-commands

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

The collective term for all `%`-line and `%%`-cell magics. They are implemented by the `IPython.core.magic` module.

## 📋 Concrete Example

Run `%lsmagic` to list every available magic command in your notebook environment.

## 🔗 Analogy

Magic commands are a remote control — each button triggers a different special function on your notebook.
