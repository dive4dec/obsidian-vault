# nbextension

> **Domain:** [[_jupyter-integration-moc|Jupyter Integration]]

## 🎯 Motivation

A classic notebook extension (for the old `notebook` interface, not JupyterLab). Loaded via `jupyter nbextension install/enable`.

## 📋 Concrete Example

Run `jupyter nbextension enable --py mypkg` to activate a classic notebook extension bundled in your package.

## 🔗 Analogy

An nbextension is a vintage car accessory — it fits the classic notebook model, not the new lab.
