# command-palette

> **Domain:** [[_jupyterlab-gui-moc|JupyterLab GUI]]

## 🎯 Motivation

A searchable popup in JupyterLab (`Ctrl+Shift+C`) that lists all registered commands. Users find and run any command by typing.

## 📋 Concrete Example

Press `Ctrl+Shift+C`, type 'new terminal', and hit Enter to launch a terminal via the palette.

## 🔗 Analogy

The command palette is a search engine for actions — type what you want and it finds the matching button.
