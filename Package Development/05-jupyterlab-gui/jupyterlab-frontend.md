# jupyterlab-frontend

> **Domain:** [[_jupyterlab-gui-moc|JupyterLab GUI]]

## 🎯 Motivation

JupyterLab's browser-based interface built with TypeScript and the Lumino widget toolkit. It is the main GUI users interact with.

## 📋 Concrete Example

When you open `localhost:8888/lab`, the frontend loads tabs, panels, and menus rendered in the browser.

## 🔗 Analogy

The JupyterLab frontend is a cockpit dashboard — all controls, displays, and switches in one browser window.
