# lab-extension

> **Domain:** [[_jupyterlab-gui-moc|JupyterLab GUI]]

## 🎯 Motivation

A plugin package that adds features to JupyterLab's frontend. Built with TypeScript and bundled as a federated extension.

## 📋 Concrete Example

Run `jupyter labextension install @myorg/myext` or `pip install jupyterlab-myext` to add the extension.

## 🔗 Analogy

A lab extension is a Lego block — snap it onto JupyterLab to add a new piece of functionality.
