# left-sidebar

> **Domain:** [[_jupyterlab-gui-moc|JupyterLab GUI]]

## 🎯 Motivation

The collapsible panel on the left of JupyterLab holding the file browser, running tabs, and command palette. Managed by `ILeftSidebar`.

## 📋 Concrete Example

Click the folder icon in the left sidebar to open the file browser; extensions add new sidebar tabs here.

## 🔗 Analogy

The left sidebar is a tool belt — your most-used tools hang on the left, one click away.
