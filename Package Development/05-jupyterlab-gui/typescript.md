# typescript

> **Domain:** [[_jupyterlab-gui-moc|JupyterLab GUI]]

## 🎯 Motivation

A typed superset of JavaScript that compiles to plain JS. JupyterLab extensions are written in TypeScript for safety and tooling.

## 📋 Concrete Example

An extension's `index.ts` defines a `plugin` object with `id`, `autoStart`, and `activate()` function.

## 🔗 Analogy

TypeScript is JavaScript with a seatbelt — same engine, but the type system keeps you safer on the road.
