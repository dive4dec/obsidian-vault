# bitbucket

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`bitbucket` is Atlassian's `git` hosting platform that integrates tightly with Jira and Trello. It is commonly used by enterprise teams already invested in the Atlassian ecosystem for project management.

## 📋 Concrete Example

A developer links a `bitbucket` pull request to a Jira ticket, so when the PR is merged the ticket automatically moves to "Done" status.

## 🔗 Analogy

`bitbucket` is like a filing cabinet that comes pre-linked to your company's task planner, so every code change is automatically tagged with the task it solves.
