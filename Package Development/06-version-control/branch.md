# branch

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

A `branch` lets you create a separate line of development without affecting the main code. This makes it safe to experiment with new features or fixes, and is the foundation of collaborative workflows.

## 📋 Concrete Example

You create a branch with `git checkout -b feature/dark-mode`, make changes there, and the `main` branch stays untouched until you are ready to merge your feature.

## 🔗 Analogy

A `branch` is like a detour on a hiking trail. You can explore a new path without changing the main trail, and later connect your path back if it turns out well.
