# changelog

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

A `changelog` is a file that records notable changes for each release in human-readable language. It helps users understand what is new, fixed, or broken when they decide whether to upgrade.

## 📋 Concrete Example

A `CHANGELOG.md` file lists under `## v2.1.0 - 2026-08-01` the entries "Added: dark mode" and "Fixed: login crash on empty password", grouped by change type.

## 🔗 Analogy

A `changelog` is like a "What's New" sticker on a video game update. Players read it to decide if the patch is worth downloading.
