# clone

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`clone` downloads a full copy of a remote repository to your computer, including all history and branches. It is the first step to working on an existing project locally.

## 📋 Concrete Example

You run `git clone https://github.com/user/project.git` and get a local folder with the entire project, ready to edit and commit to.

## 🔗 Analogy

Cloning is like downloading a complete blueprint of a house. You get every measurement and revision history, not just the final floor plan.
