# commit

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

A `commit` is a saved snapshot of your code at a specific point in time. Writing clear commit messages helps your future self and teammates understand why each change was made, which is a habit every developer should build early.

## 📋 Concrete Example

After fixing a bug you run `git commit -m "fix: handle empty username in login form"` to record the change with a descriptive message that explains the fix.

## 🔗 Analogy

A `commit` is like pressing "save" in a video game at a checkpoint. You can always reload that exact moment if something goes wrong later.
