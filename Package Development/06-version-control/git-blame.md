# git blame

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`git blame` shows who last edited each line of a file and when. It helps you understand the history of specific code and find the right person to ask when a line is confusing or broken.

## 📋 Concrete Example

You run `git blame app.py` and see that line 42 was last changed by Alice on March 3 with the message "optimize query", so you ask her about that change.

## 🔗 Analogy

`git blame` is like a group project where every sentence is initialed by whoever wrote it. When something reads strangely, you know exactly who to ask.
