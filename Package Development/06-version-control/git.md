# git

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`git` is a distributed version control system that tracks every change to your code. For young developers, it acts like a time machine that lets you undo mistakes and collaborate with others on the same project without overwriting each other's work.

## 📋 Concrete Example

You start a project with `git init`, save changes with `git commit -m "add login page"`, and see history with `git log`. Every commit is a snapshot you can return to anytime.

## 🔗 Analogy

Think of `git` as a notebook where every page is numbered and dated. You can tear out any page, photocopy an old one, or let a friend add their own pages without ruining yours.
