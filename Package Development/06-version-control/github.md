# github

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`github` is a cloud platform that hosts `git` repositories and adds collaboration tools like pull requests, issues, and CI/CD. It is where most open-source projects live, making it essential for students who want to share code and contribute to real projects.

## 📋 Concrete Example

You push a local repo with `git push origin main` to `github.com`, then open a pull request so teammates can review your changes before they are merged into the main codebase.

## 🔗 Analogy

If `git` is your personal notebook, `github` is a library where everyone can read, copy, and suggest edits to your notebook from anywhere in the world.
