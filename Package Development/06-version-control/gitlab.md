# gitlab

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

`gitlab` is a DevOps platform that combines `git` hosting with built-in CI/CD pipelines, issue tracking, and container registries. It is popular with companies that want an all-in-one tool or need to host code on their own servers for privacy.

## 📋 Concrete Example

A team uses `gitlab.com` to host their repo and writes a `.gitlab-ci.yml` file that automatically runs tests every time someone pushes code, with results shown right next to the merge request.

## 🔗 Analogy

`gitlab` is like a workshop that not only stores your tools (code) but also has a testing bench and shipping area built in, so you never need to leave the building.
