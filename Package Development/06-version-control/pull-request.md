# pull request

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

A `pull request` (PR) is a proposal to merge your branch into the main codebase, with a place for review and discussion. PRs are how teams maintain code quality by requiring others to read and approve changes before they land.

## 📋 Concrete Example

You open a PR on `github` titled "Add dark mode toggle", and a teammate comments on a specific line, requesting a small fix before approving the merge.

## 🔗 Analogy

A pull request is like submitting an essay for peer review. Your teacher (reviewer) leaves notes, you revise, and only when they approve does the essay get published.
