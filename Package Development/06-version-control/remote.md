# remote

> **Domain:** [[_version-control-moc|Version Control]]

## 🎯 Motivation

A `remote` is a named connection to a repository hosted elsewhere, like on `github`. Managing remotes lets you push and pull code between your computer and the cloud or other developers.

## 📋 Concrete Example

You add a remote with `git remote add origin https://github.com/user/repo.git` and then push changes with `git push origin main` to sync your local commits to the cloud.

## 🔗 Analogy

A `remote` is like a saved phone number for a collaborator. Once saved, you can "call" (push) your changes to them or receive (pull) theirs anytime.
