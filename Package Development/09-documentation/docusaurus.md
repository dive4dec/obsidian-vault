# docusaurus

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`docusaurus` is a React-based documentation site generator by Meta. It produces modern, interactive docs with versioning, blog support, and search, making it popular for JavaScript and cross-language projects.

## 📋 Concrete Example

You run `npx create-docusaurus@latest` to scaffold a site, write pages in MDX (Markdown plus JSX), and `npm run build` produces a static site deployable to any host.

## 🔗 Analogy

`docusaurus` is like a premium website builder for docs. It gives you templates, themes, and plugins out of the box, so you focus on content while it handles the design.
