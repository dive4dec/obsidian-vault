# gh pages docs

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`GitHub Pages` hosts static documentation sites directly from your repository, free of charge. It is a simple alternative to `readthedocs` when you want docs living alongside your code with minimal setup.

## 📋 Concrete Example

You push built HTML to a `gh-pages` branch, and `github.io` serves it at `username.github.io/repo/`. A GitHub Action can automate the build and deploy on every push.

## 🔗 Analogy

`GitHub Pages` is like a free bulletin board in your repo's lobby. You pin pages (HTML) there, and anyone walking by can read them without entering the code.
