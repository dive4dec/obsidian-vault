# google style

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`Google style` is a docstring format known for its clean, readable layout using `Args:`, `Returns:`, and `Raises:` sections. It is the most popular choice for new projects because it looks good even as plain text.

## 📋 Concrete Example

```python
def add(a, b):
    """Add two numbers.

    Args:
        a (int): First number.
        b (int): Second number.

    Returns:
        int: The sum.
    """
```

## 🔗 Analogy

`Google style` is like a clean checklist format. Each section (Args, Returns) is a labeled box, making it easy to scan at a glance without special formatting.
