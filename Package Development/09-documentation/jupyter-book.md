# jupyter book

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`jupyter-book` builds beautiful, book-style websites from Markdown and notebooks. It is ideal for educational material and tutorials where you need to mix prose, code, and executable output in a structured chapter format.

## 📋 Concrete Example

You create a `_toc.yml` listing chapters, write each chapter in `.md` or `.ipynb`, then run `jupyter-book build .` to produce a navigable HTML book with cross-references.

## 🔗 Analogy

`jupyter-book` is like a publishing house for interactive textbooks. You supply the chapters, and it binds them into a polished, searchable web book with a table of contents.
