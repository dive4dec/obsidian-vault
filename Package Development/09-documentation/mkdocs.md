# mkdocs

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`mkdocs` is a fast, simple documentation generator that uses Markdown exclusively and produces static HTML. It is lighter than `sphinx` and ideal for projects where Markdown-only is preferred and advanced `rst` features are not needed.

## 📋 Concrete Example

You create a `mkdocs.yml` with site name and nav, write pages in `docs/` as `.md` files, then run `mkdocs build` to generate a clean HTML site.

## 🔗 Analogy

If `sphinx` is a full publishing suite, `mkdocs` is a sleek blog platform. It does less, but it gets you a beautiful site faster with Markdown alone.
