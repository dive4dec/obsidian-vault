# myst directives

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`MyST directives` are Markdown-flavored block commands like `` ```{note} `` or `` ```{toctree} `` that add `rst`-level functionality. They let you create admonitions, tables of contents, and code blocks within Markdown files.

## 📋 Concrete Example

Writing `` ```{warning} `` followed by text creates a red warning box in the rendered docs, a feature normally only available in `rst`.

## 🔗 Analogy

`MyST directives` are like special stamps you can press onto a Markdown page. Each stamp adds a formatted box or special element that plain Markdown cannot produce on its own.
