# myst parser

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`myst-parser` is the `sphinx` extension that enables Markdown input. It translates Markdown files into `sphinx`'s internal document model, unlocking directives, cross-references, and extensions that plain Markdown cannot do.

## 📋 Concrete Example

You add `extensions = ["myst_parser"]` to `conf.py`, and now `sphinx` accepts `.md` files alongside `.rst`, letting your team write docs in Markdown.

## 🔗 Analogy

`myst-parser` is like a translator who converts your casual notes (Markdown) into the formal language `sphinx` understands, so your notes get the full royal treatment.
