# numpy style

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`numpy style` uses underlined section headers like `Parameters` and `Returns`, making it visually distinct in plain text. It is the standard for scientific Python libraries like NumPy and SciPy.

## 📋 Concrete Example

```python
def add(a, b):
    """
    Add two numbers.

    Parameters
    ----------
    a : int
        First number.
    b : int
        Second number.

    Returns
    -------
    int
        The sum.
    """
```

## 🔗 Analogy

`numpy style` is like a lab report format with bold section headers and precise parameter descriptions, suited for scientific code where every detail matters.
