# readthedocs

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`readthedocs` is a free hosting platform that automatically builds and publishes your `sphinx` or `mkdocs` documentation from a GitHub repo on every push. It handles versioning and search, making it the easiest way to host docs.

## 📋 Concrete Example

You connect your GitHub repo to `readthedocs.org`, and every push to `main` triggers a build that publishes updated docs to `yourproject.readthedocs.io` automatically.

## 🔗 Analogy

`readthedocs` is like a publisher that automatically prints a new edition of your book every time you revise the manuscript. Readers always see the latest version online.
