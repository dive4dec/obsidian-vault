# rst

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`rst` (reStructuredText) is the markup language `sphinx` uses by default. It supports directives, cross-references, and tables, making it powerful for technical docs, though its syntax is stricter than Markdown.

## 📋 Concrete Example

You write `.. code-block:: python` followed by an indented code snippet, and `sphinx` renders it as syntax-highlighted Python code in the final HTML.

## 🔗 Analogy

`rst` is like a professional typesetting language. It has more formatting knobs than Markdown, which is great for complex documents but takes practice to master.
