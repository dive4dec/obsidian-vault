# sphinx theme

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

A `sphinx theme` controls the visual look and layout of generated documentation. Popular themes like `furo` and `sphinx-rtd-theme` make docs look modern and professional without writing custom CSS.

## 📋 Concrete Example

You install `furo` with `pip install furo` and set `html_theme = "furo"` in `conf.py`, instantly giving your docs a clean dark-mode-capable modern look.

## 🔗 Analogy

A `sphinx theme` is like choosing a cover design and font for a book. The content stays the same, but the right theme makes it far more pleasant to read.
