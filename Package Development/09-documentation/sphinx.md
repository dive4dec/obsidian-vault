# sphinx

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`sphinx` is the most widely used Python documentation generator, producing HTML, PDF, and ePub output from source files. It powers docs for major projects like Python itself, making it the standard for serious Python libraries.

## 📋 Concrete Example

You run `sphinx-quickstart` to create a docs folder, write content in `.rst` files, then `make html` to generate a searchable, themed documentation website.

## 🔗 Analogy

`sphinx` is like a printing press for a book. You write the manuscript (source files), and it produces a polished, bound, searchable book (HTML site).
