# tutorial docs

> **Domain:** [[_documentation-moc|Documentation]]

## 🎯 Motivation

`tutorial docs` are step-by-step guides that teach users how to use your package from zero. They are often the first thing new users read, making them critical for adoption and first impressions.

## 📋 Concrete Example

A tutorial titled "Getting Started in 5 Minutes" shows installation, a basic example, and one advanced tip, all in a single page with copy-pasteable code blocks.

## 🔗 Analogy

`tutorial docs` are like the quick-start guide inside a new gadget box. They get you from unboxing to working in minutes, before you need the full manual.
