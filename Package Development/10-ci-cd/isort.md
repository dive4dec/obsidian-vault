# isort

> **Domain:** [[_ci-cd-moc|CI CD Automation]]

## 🎯 Motivation

`isort` automatically sorts and groups `import` statements in Python files. Consistent import ordering improves readability and eliminates a common source of nitpick comments in code reviews.

## 📋 Concrete Example

Running `isort .` reorders your imports into standard library, third-party, and local groups, each alphabetized, with a blank line between groups.

## 🔗 Analogy

`isort` is like organizing a bookshelf by genre then alphabetically. Books (imports) are easy to find because they always follow the same arrangement rule.
