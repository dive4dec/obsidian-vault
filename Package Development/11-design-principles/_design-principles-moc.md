# Design Principles MOC

> **Domain:** [[_design-principles-moc|Design Principles]]

## 🎯 Motivation

Design principles are timeless guidelines that help you write maintainable, flexible, and bug-resistant code. Learning them early builds a foundation for judging good architecture from clever hacks.

## 📋 Concrete Example

Before adding a feature, ask: does this respect `SRP`? Will I need to modify existing code (violating `OCP`)? These quick checks prevent design rot before it starts.

## 🔗 Analogy

Principles are like traffic rules: they seem restrictive until you realize they keep everyone safe and moving. Without them, intersections would be chaos; with them, flow is smooth.
