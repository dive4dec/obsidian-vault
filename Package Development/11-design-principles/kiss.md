# KISS

> **Domain:** [[_design-principles-moc|Design Principles]]

## 🎯 Motivation

"Keep It Simple, Stupid" reminds us that simplicity is a feature. Complex solutions are harder to understand, test, and debug, so prefer the simplest code that works.

## 📋 Concrete Example

Instead of a clever one-liner with nested comprehensions, write a simple `for` loop with clear variable names. The loop is easy to read and modify when requirements change.

## 🔗 Analogy

A plain mug holds coffee just as well as a self-stirring, temperature-controlled gadget mug. The simple mug never runs out of battery or breaks its electronics.
