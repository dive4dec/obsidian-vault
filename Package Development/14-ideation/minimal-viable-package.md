# Minimal Viable Package

> **Domain:** [[_ideation-moc|Package Ideation]]

## 🎯 Motivation

Ship the smallest version that solves the core problem. Early release gathers real feedback, validates demand, and prevents months of work on features nobody wants.

## 📋 Concrete Example

Version `0.1.0` of `timetable-parser` reads one file format and outputs `.ics`. No config, no CLI flags, no GUI. Real users confirm the format is useful before you add extras.

## 🔗 Analogy

A food truck serves one signature dish perfectly before opening a full restaurant. If nobody likes the dish, the truck saved you from building an empty dining room.
