# Scope Creep

> **Domain:** [[_ideation-moc|Package Ideation]]

## 🎯 Motivation

Scope creep is the gradual addition of features beyond the original goal. It bloats the package, delays releases, and confuses users about what the package is actually for.

## 📋 Concrete Example

`timeflex` starts as a timetable-to-calendar converter. Then someone asks for email reminders, then grade tracking, then attendance. Each "small addition" dilutes focus until the package does nothing well.

## 🔗 Analogy

A group project that starts as "make a poster" can creep into "make a poster, a video, a song, and a dance." The deadline hits with nothing finished because the scope never stopped growing.
