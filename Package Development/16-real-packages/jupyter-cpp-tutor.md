# jupyter-cpp-tutor

> **Domain:** [[_real-packages-moc|Real Packages]]

## 🎯 Motivation

`jupyter-cpp-tutor` provides step-by-step C++ code visualization inside JupyterLab. Students see variable values, memory layout, and execution flow at each line — like a debugger but designed for learning, not just debugging.

## 📋 Concrete Example

Install with `pip install jupyter-cpp-tutor`. In a code cell, write C++ code and run `%%tutor` (or use the visual button). The extension renders an interactive step-through view showing variables changing at each line.

## 🔗 Analogy

Like a slow-motion replay in sports — instead of watching the whole play at full speed (running the program), you step through frame by frame to understand exactly what happened at each moment.
