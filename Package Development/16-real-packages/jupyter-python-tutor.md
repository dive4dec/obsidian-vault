# jupyter-python-tutor

> **Domain:** [[_real-packages-moc|Real Packages]]

## 🎯 Motivation

`jupyter-python-tutor` brings Python Tutor-style step-by-step visualization to JupyterLab. Students see how variables change, how lists grow, and how function calls stack — all inline in the notebook.

## 📋 Concrete Example

Install with `pip install jupyter-python-tutor`. Use `%%tutor` in a Python cell, or click the tutor button in the toolbar. The extension renders an interactive visualization showing each execution step with variable state.

## 🔗 Analogy

Like an X-ray machine for your code — you see the bones (structure), the blood flow (data moving through variables), and the heartbeat (execution loop) all at once, without cutting anything open.
