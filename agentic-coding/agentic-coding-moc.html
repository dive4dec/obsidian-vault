🤖 Agentic Coding — Master Map of Content

A comprehensive knowledge base of 1,200+ interconnected concepts for F1–F5 Hong Kong secondary school students. Each note includes a motivation, concrete example, and analogy to make complex AI concepts accessible.

📚 How to Use This Vault

  1. Start anywhere — every note links to related concepts. Follow the [[links]] to explore.
  2. Look for the MOC at the top of each domain folder for a structured overview.
  3. Use Obsidian’s Graph View to see how concepts connect visually.
  4. Each note has: Motivation (why it matters), Example (how it works), Analogy (what it’s like).

🎯 Learning Path Suggestions

For F1–F2 Students (Beginners)

  1. Variable → Function → Loop → If Statement
  2. Algorithm → Sorting → Search
  3. Artificial Intelligence → Machine Learning → Neural Network

For F3–F4 Students (Intermediate)

  1. API → REST API → JSON → Web API
  2. Large Language Model → Token → Context Window → Prompt
  3. AI Agent → Agent Loop → Tool Use → Function Calling

For F5 Students (Advanced)

  1. Agentic Coding → Code Agent → Autonomous Software Development
  2. Multi-Agent System → Hierarchical Agent → Agent Coordination
  3. Alignment → RLHF → Safety → Red Teaming

🔗 Key Cross-Domain Connections

  • Programming → AI: Function → Function Calling → Tool Use
  • Data → Models: Dataset → Training Data → Pre-training → Fine-tuning
  • LLMs → Agents: Large Language Model → Agent Loop → ReAct Pattern → Agentic Coding
  • Web → APIs → Tools: HTTP → API → Function Calling → Tool Use
  • Safety → Evaluation: Alignment → Red Teaming → Benchmark → Model Evaluation
